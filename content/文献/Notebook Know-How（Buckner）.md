# Notebook Know-How（Buckner, 2005）

Buckner, A. (2005). *Notebook Know-How: Strategies for the Writer's Notebook*. Stenhouse Publishers.（Foreword by Ralph Fletcher）

---

## 要約

### この本が答えようとする問い

1. どうやってノートを起動するか（年度初め）
2. 学習者がノートを使いこなせるようにするミニレッスンは何か
3. 書き詰まり（writing rut）にはまった学習者をどう助けるか
4. ノートで学んだことを正式な作品づくりにどうつなげるか
5. ノートをどう整理すると、柔軟かつアクセスしやすいか
6. ライターズ・ノートはどのように読書力を高めるか
7. ノートをどう評価するか

### ライターズ・ノートとは何か／何でないか

Bucknerはライターズ・ノートを「作家が持つ貯蔵庫」として定義する。

| ライターズ・ノートとは | ライターズ・ノートではない |
|---|---|
| アイデアを集める場所 | 完成した文章を書く場所 |
| 技法を試す実験室 | 評価される作品の場所 |
| 観察・記憶・言葉を貯める倉庫 | 日記（出来事の記録） |
| 正式な作品の「種」を育てる場 | 文法練習帳 |
| 低リスク・高頻度の書き実践 | 宿題・課題シート |

### エントリーの種類

Bucknerはノートを「エントリーのタイプ別に整理する」ことを提案している。

| エントリーのタイプ | 内容 |
|---|---|
| リスト書き（Brainstorming Lists） | 好きなこと・嫌いなこと・不思議なことのリスト |
| 観察メモ（Observations） | 今日見たもの・聞いたもの・感じたことのスケッチ |
| 記憶（Memories） | 強く残っている場面・経験を断片的に書く |
| 言葉遊び（Language Play） | 面白い言葉・聞こえた会話・気になるフレーズを集める |
| 人物スケッチ（Character Sketches） | 知っている人・架空の人物の特徴を書く |
| もしも〜（What If / Wonderings） | 「もしこうなったら」「どうして〜なんだろう」 |
| ジャンル試し書き（Genre Experiments） | 詩・物語の書き出し・対話など、ジャンルを試す短い文 |
| 読書への反応（Reading Response） | 読んでいる本から引用し、自分の考えを添える |

### 起動（Launching）

年度初めの「ノート文化をつくる」段階。Bucknerは次の原則を示す：
- メンター作家（ラルフ・フレッチャー等）のノートを見せて「作家はこういうものを持っている」と伝える
- 最初のエントリーは「自分のことを書く」——教師も同じエントリーを書いてモデリングする
- 「正しく書かなくていい」を繰り返し言語化する
- 最初の2週間は毎日ノートを開く時間を確保する

### 書き詰まりへの対処

学習者が「何を書けばいいかわからない」状態になったとき：
- **種探しのミニレッスン**（観察・記憶・言葉など特定のタイプのエントリーを全員で試す）
- **ノートを振り返る**（過去のエントリーに「もっと書きたいこと」を探す）
- **教師との短い対話**（「最近、気になっていることは？」を聞く）
- **種を読み合う**（ペアでノートの気になるエントリーを読み合う）

### ノートから正式な作品へ

Bucknerが示すフロー：
```
ノート（集める）
    ↓
種を選ぶ（Select a seed idea）
    ↓
種を育てる（Develop the seed in the notebook）
    ↓
正式なドラフトへ（Move to a separate draft/folder）
```

**重要な区別**：ノートはドラフトではない。種を選んでもノートに書き続ける——ドラフトは別の場所（フォルダ・別のノート）で行う。

### 評価

Bucknerの評価原則：
- 「正しい文章」ではなく「作家としての関与と成長」を見る
- 頻度（どれくらい書いているか）・多様性（どれくらい違うタイプを試しているか）・深さ（アイデアがどれくらい発展しているか）の3軸
- 評価はノートの「雰囲気」から——「このノートは生きているか？」

## 重要な引用

> 「ノートは作家が持つ私的な貯蔵庫だ。作家はそこに見たもの、聞いたもの、感じたものを——書くに値するかどうかわからなくても——書き溜める。」—Buckner

> 「ノートを使い始めるとき、教師が一番大切なメッセージは『あなたはもう今日から作家です』だ。」—Buckner

## 教育実践への示唆

1. **ノートと正式な作品の場所を分ける**：ノートは「何でも書いていい場所」として守る。作品フォルダは別の場所。この区別が低リスクな実験の場を保証する。

2. **教師が同じエントリーを書く**：教師が「私のノートにはこんなことが書いてある」とモデリングすることが、ノート文化をつくる最も強力な手立て。

3. **エントリーの多様化をミニレッスンで扱う**：「今日は観察メモのエントリーをやってみよう」と特定のタイプをクラス全員で試す時間を年間に何度か作る。

4. **「書けない」を「書き詰まり」として正常化する**：プロの作家でも書き詰まりはある。それは失敗でなく「次の種を探すとき」として扱う。

5. **ノートを振り返る時間をとる**：月1回、過去のエントリーを読み返し「もっと書きたいこと」「気になるアイデア」に印をつける時間を授業に組み込む。
