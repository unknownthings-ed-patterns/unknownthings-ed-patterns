# 問題解決的教材研究

**このパタンが完成を助ける大きなパタン**：[[パタン/熟慮的教材教具]]

> 教材研究とは、教師自身の問題解決的な学びである——教師が「驚き・行き詰まり・解決」の体験をしたとき、子どもも同じ道を歩める授業が生まれる。

---

## [Pattern Connection]

**研究からの補足（2026-10-17）：教科内容を教えるための知識に変える（Shulman1986）**

原典は教科内容の知識とPCKを区別する（pp. 9–10）。Wiki側の適用案として、教師自身が問題を解いた後、なぜその方法が妥当か、子どもがどの考えを持ち込みそうか、どの図や例で説明できるかまで記録する。この教材研究の手順の効果を直接測定した論文ではない。 出典：[[文献/教科内容を教えるための知識に変える（Shulman1986）]]。

## 背景（Context）

教師が教材を「調べてまとめる」だけの教材研究と、教師が「問いをもって本気で追いかける」教材研究では、授業の質が根本から異なる。後者においては、教師自身が「なぜだろう」「どうして？」という感情とともに知識を獲得している。その感情の痕跡が授業に宿り、子どもに届く。

有田和正は「アンテナを張って引っ掛けておく」という言葉でこの姿勢を表現した。教師が日常から意識的にアンテナを張り、引っかかった疑問を教材の種として育てることが教材研究の出発点だ。

## 問題（Problem）

「授業に間に合わせるための教材研究」では、教師は解答を知っている状態で授業に臨む。すると教師は自然と「答えに向けて子どもを誘導する」構造（追い込み漁）をとりやすくなる。教材への本物の驚きも疑問も体験しないまま教えるとき、授業は「情報の伝達」にとどまり、子どもは学び手というより聴衆になる。

## 力のかたち（Forces）

- 教師が「わからない」「気になる」と感じた事象は、子どもも同じ反応をしやすい——共感の根拠になる
- 教材研究に時間をかけすぎると学習指導要領との接続を見失い、授業が成立しにくくなる
- アンテナを張ることは習慣であり、「今日から始める」スイッチが必要
- 教材への共感（人の営みへの感動）がなければ、知識の構造だけを教えることになる

## 解決（Solution）

**近いパタンとの見分け**：教師が「疑問→調べる→解決」の道を歩き、それを授業の骨格にするのが本パタン。教材を体験して問いたいことを見つけるのは [[パタン/素材研究から発問内容を見出す]]。教材の系列の全体の表は [[パタン/熟慮的教材教具#近いパタンとの見分け|熟慮的教材教具]] にある。

**教師自身が「疑問をもつ → 調べる → 疑問を解決する」という問題解決のプロセスを実際に体験してから、教材化して授業を設計する。その体験が授業の骨格になる。**

### 問題解決的教材研究のステップ（本文は7ステップ）

小倉が実際に行った「釜石の奇跡は奇跡ではない」の教材化事例：

| ステップ | 具体的な行動 |
|---------|------------|
| **①学習内容をつかむ** | 学習指導要領「解説社会編」の該当箇所を読み、単元の学習内容を大まかにつかむ |
| **②教科書を読む** | 教科書を読み、単元の概要をつかむ |
| **③ニュースを探す** | 自分が興味をもてそうなニュースを探す（震災の年で「釜石の奇跡」を発見） |
| **④疑問をもつ** | TVニュースで中学生の「奇跡ではない」という言葉に驚き、解決すべき「問い」をもつ |
| **⑤調べる** | 「釜石の奇跡は、奇跡ではない」の真意を調べる |
| **⑥解決する** | 決め手は地元TV局の特集番組と、釜石市役所の方の話 |
| **⑦教材化する** | 自分の問題解決を子どもが追体験できるように指導計画・資料を作成 |

**核心**：授業は「教師の問題解決的な学び」を子どもが追体験する場である。

---

### アンテナを張る——教材の種を日常から収集する

有田和正の言葉：「詳しく見なくても、ざーっと見て、つまりアンテナを張って引っ掛けておく」

アンテナが引っかかった教材候補の例（小倉の実践より）：

- 「**小金井阿波踊り**」——なぜ東京・小金井で阿波踊りが？
- 「**銀座のミツバチ**」——都市のビルの屋上でなぜ養蜂？
- 「**マグロの蓄養**」——「完全養殖」のはずなのに「養殖」と表示されている矛盾
- 「**開かずの踏切**」——日常の通勤体験から
- 「**三陸の魚がない**」——震災後の魚屋で発見

**実践的方法**：引っかかった記事はスクラップ、思いついたことはメモか録音。「少しずつストックしていく」ことが教材の貯蔵庫になる。

---

### シンプルな問いと解を設定する

教材にのめり込みすぎると「盛りすぎ授業」になる。授業に使う教材の**核心は [問い] と [解] の1セット**に絞り込む。

**例（イザ！カエルキャラバンの教材化）**：
- [問い] 国分寺市は、なぜ、イザ！カエルキャラバンを行っているのか？
- [解] 若い住民（親と子）の防災意識を高めるため

教材の要素が多くても、この [問い] と [解] だけに絞ると授業がパンクしない。

**資料の絞り込み目安**：（第4章の国分寺市の防災単元の授業展開より）追究に必要な資料を絞り込む——中心資料1つに対して補助資料2つか3つがめやす。

---

### 単元の内容分析の4視点（第4章・国分寺市の防災単元の実践事例より）

教材を分析するとき、次の4つの視点を意識すると社会科的な深みが生まれる：

1. **事実を見る**：何が起きているか、どういう状況か
2. **人の営みを見る**：誰がどんな思いで働いているか
3. **社会的な意味・価値を考える**：なぜそれが重要なのか、社会的にどんな役割を果たしているか
4. **自分のかかわりを考える**：自分の生活・未来とどうつながるか

---

### 人の働きへの共感を大切にする

> 「人々の働き（営み）を通して社会を見るのが社会科。教師が共感しながら開発した教材は、子どもたちへ力強く訴えていくことになる。」——小倉勝登

「釜石の奇跡」の授業で子どもが振り返りに「自分の仕事に誇りをもてる人になりたい」と書いたのは、教師自身が防災に取り組んだ人たちへの共感を体験していたからだ。

> **研究の裏づけ（2026-10-31）**：高橋昭彦と McDougal（2016）は、日本の授業研究の欠かせない要素の一つに教材研究を挙げ、学習指導要領と教科書で下の学年から上の学年への学びの道筋を調べ、典型的な誤解・使える道具・課題を調べる作業として定義する。科学研究の先行研究の検討にあたり、「車輪の再発明」を避ける（p. 520）。海外の授業研究では、この教材研究の段階がよく省かれるという（p. 514）。本パタンの「教師自身の問題解決的な学び」とは重心が異なるが、授業の前に教師が自分で深く学ぶ点は共通する。米国の学校での試行の事例報告で、効果を検証した研究ではない。出典：[[文献/授業研究の効き目を支える仕組みを取り出す（TakahashiとMcDougal2016）]]。

> **研究の裏づけ（2026-10-31）**：Lewis と Perry（2014）の無作為化比較では、米国の教師のグループが、分数の教材研究の手引き（自分で解く課題・日本の教科書と教師用指導書・授業ビデオ・研究論文）を使って授業研究をし、分数の知識の四つの面のうち三つで有意に伸びた。教師はまず自分で課題を解いて子どもの考えを予想し、ある教師は「同僚が自分の誤解と格闘するのを見て、子どもの誤解を予想できるようになった」と書いた（p. 11）。四辺形の面積の教師用指導書では、子どもの考えについての記述が日本28%、米国1%だった（p. 3）。測ったのは教師の知識で、手引きだけでも同じ変化が起きたかは区別できない（p. 13）。出典：[[文献/教材の手引きを添えた授業研究で教師の分数の知識が伸びる（LewisとPerry2014）]]。

> **研究の裏づけ（2026-10-31）**：上の Lewis と Perry の研究を、開発者でない第三者が四つの条件に分けて追試した Schoen ほか（2023）では、米国80校の教師チームのうち、分数の手引き（日本の教科書と授業ビデオ、研究のまとめ）を受けた二群で授業の質が上がった（授業研究つき 0.82、一人で学ぶ 0.73）。授業研究の過程だけの群では有意な向上はなかった（0.20）。ただし、子どもの分数のテストはどの群も比較群を上回らず、前の研究の子どもへの効果は再現されなかった（pp. 238–239）。授業を良くしたのは、教材を深く学ぶ機会のほうだった。出典：[[文献/授業研究と分数の手引きの効果を追試で分けて確かめる（Schoenほか2023）]]。

## 結果（Consequences）

- 教師が本物の疑問と感動を経験した教材は、授業中の説明の「熱」が変わる
- 子どもが同じ問題解決のプロセスをたどれる授業構造が生まれる
- 「なぜ？」という疑問の連鎖が授業の骨格になるため、教師が答えに誘導しにくくなる
- ただし、問題解決的教材研究は時間と手間を要する——「今日の授業のために」では間に合わない
- 教材への没入と学習指導要領との接続を両立させる意識がなければ、魅力的だが目標未達の授業になる

## Actionable Insight

- **今週、気になった出来事をメモ1行残す**——教材候補のストック帳を作るのではなく、「今日気になった」を1行書く習慣から始める。アンテナは習慣によって育つ
- **次の単元の教材を1つ選び [問い] と [解] だけを書いてみる**——「この教材で子どもに問わせたい問いは何か」「その答え（解）は何か」だけを1行ずつ。これがシンプルな教材研究の最小単位
- **教材の中の「人」を探す**——社会的な仕組みや統計だけを調べるのではなく、「そこで働いている人は誰で、何を考えているか」を調べる。教師がその人に共感するとき、子どもも共感できる授業になる
