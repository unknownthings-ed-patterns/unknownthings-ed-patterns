# インクルーシブ授業の設計

Hammeken（2003）*The Teacher's Guide to Inclusive Education* の750方略をもとに、通常学級でインクルーシブな授業設計を行うための実践ガイド。

---

## この実践の前提

**「配慮は特別扱いではなく、よい設計だ」**

障害・発達特性のある子への配慮の多くは、クラス全体に行っても有効——むしろ全員の学びを深める。まず「全員のための設計」から始め、それでも届かない子に「個別の調整」を加える順序で考える。

---

## ステップ1：授業前の設計（10分でできる点検）

授業準備の最後に以下を確認する：

### 表現の多様化チェック
```
□ 指示は「聴く」だけでなく「見る」でも伝わるか？
    → 板書・カード・プリントで補完する
□ 新しい情報は「言葉」だけでなく「図・絵・実物」でも示せるか？
    → グラフィック・オーガナイザー・モデル・操作物を準備する
□ キーワード・難しい語彙を事前に説明する場はあるか？
    → ミニレッスンの最初に語彙リストを配る
```

### 行動・表現の多様化チェック
```
□ 「書いて提出」だけを求めていないか？
    → 口頭・描く・選択式なども可にする選択肢を1つ用意する
□ 「書く量」が知識の証明になっているか、書く量の多さが障壁になっていないか？
    → 箇条書き・図・キーワードでの代替を認める
```

### 取り組みの多様化チェック
```
□ 全員に同じ難易度を要求していないか？
    → ベーシック・スタンダード・チャレンジの3段階を用意する（または選択させる）
□ 「今すぐやる」以外の選択肢はあるか？
    → 「今やる？5分後にやる？」という小さな選択を与える
```

## ステップ2：教科別の配慮・修正カタログ

### 国語——読むこと

| 困り感の種類 | 配慮（内容は変えない） | 修正（必要なら内容を変える） |
|---|---|---|
| 読む速度が遅い | 時間延長・ページ数を指定 | 短縮版テキストを用意 |
| 文字を認識しにくい | カラーオーバーレイ・フォント拡大 | — |
| 長い文章に疲れる | 段落ごとに区切って読む | テキストを要約版に置換 |
| 語彙が分からない | 事前語彙指導・語彙リスト添付 | — |
| 音読が苦手 | ペア読書・黙読に切替可 | — |
| 読んで内容が残らない | 読みながらメモする枠を提供 | — |

**ペア読書の設計**：
1. 読む分量をページ単位で決める
2. Aが読む→Bが聴く→交替（または交互に一文ずつ）
3. 終わったら「一番残ったこと」を一言交換する

---

### 国語——書くこと

| 困り感の種類 | 配慮 | 修正 |
|---|---|---|
| 何を書けばいいか分からない | グラフィック・オーガナイザー・センテンス・スターター | — |
| 書く量が多い | 重点部分を指定・量を調整 | 短縮版の課題に置換 |
| 字を書くことが難しい | キーボード・音声入力を認める | — |
| スペリング・漢字が難しい | 辞書・ワードバンク・変換ソフト可 | — |
| 作文の構成が立てられない | 構成カード・段落の枠を提供 | — |

**グラフィック・オーガナイザーの最小版**：
```
書くことのテーマ：＿＿＿＿＿

理由①：          理由②：          理由③：

まとめの一文：
```
これをA4で印刷するだけで、書くことが難しい子の足場になる。クラス全員に配っても害がない。

---

### 算数

| 困り感の種類 | 配慮 | 修正 |
|---|---|---|
| 計算手続きが覚えられない | 手順カード・式の枠を提供 | — |
| 文章題の読解が難しい | グラフィック・オーガナイザー（何がわかっている？何を求める？） | 問題数を減らす |
| 数の感覚が育っていない | 具体物（タイル・ブロック）の使用を認める | — |
| 筆算でミスが多い | グラフ用紙・区切り線のある計算用紙 | — |
| 複雑な計算でつまずく | 電卓の使用を認める | — |

**文章題のグラフィック・オーガナイザー**：
```
問題文から分かること：

求めるもの：

使う式：

答え：                   単位：
```

---

### 評価の調整

**評価の調整は「手抜き」ではない**。知識があることを証明するための「形式」を変えることと、「内容」を減らすことを区別する。

| 調整の種類 | 内容 | 誰に有効か |
|---|---|---|
| 時間延長 | 通常の1.5〜2倍の時間 | 処理速度が遅い・書く速度が遅い |
| 分割実施 | 1回でなく2〜3回に分けて | 集中持続が難しい |
| 別室・個別 | 静かな環境で実施 | 感覚過敏・不安 |
| 口頭回答 | 書かずに話して答える | 書くことが難しい |
| 選択式↔記述 | 問いの形式を変換 | 書くことが難しい |
| 読み上げ | テストの文章を読んで聞かせる | 読むことが難しい |
| ヒントカード | 公式・手順の一覧を渡す | 記憶に困難がある |

## ステップ2.5：授業中の参加を保証する指導技術

**① 発問後は最低10秒待つ（ウェイトタイム）**
- 質問した後、すぐに挙手を求めない——情報処理に時間がかかる子には10秒が必要
- 「手を挙げてください」ではなく「準備ができたら合図してください」という教師のシグナルを使う
- 全員が思考を終えてから発表に移ることで、処理の遅い学習者が参加できる

**② Pass or Play! 参加の仕組み**
- 全員の名前を書いた棒（割りばし・カード）を箱に入れる
- 発表者を「くじ引き」で決める——誰が当たるかわからないと注意が上がる
- 一回だけ「パス」できる権利を全員に持たせる——一回のパスはプレッシャーを下げる

**③ ホールグループレスポンス（全員回答）**
- 個人のミニボード：各自で答えを書き、同時に見せる
- インデックスカード：TRUE/FALSE、賛成/反対など事前に配っておく
- サムズアップ/サムズダウン：最もシンプルな全員参加の確認

## ステップ3：行動支援の予防的設計

問題行動が起きてから対応するのでなく、起きないような設計を先に行う。

### 予防的行動支援の5つの手立て

**① 期待される行動を視覚化する**
- 「この時間にすること」を板書・カードで示す
- 「してほしい行動」を肯定的な言葉で（「静かにしなさい」ではなく「手を止めて先生を見よう」）
- 「〇〇するな」でなく「〇〇しよう」という肯定文で伝える

**② 選択肢を与える**
- 「今やる？5分後にやる？」
- 「一人でやる？ペアでやる？」
- 小さな選択が「自分が決めた」という感覚を生む

**③ 合図システムを設計する（[[パタン/合図システム]]）**
- 子どもと事前に「指1本＝助けが必要」「指2本＝動きたい」を決める
- 教師からの合図（目を触る＝見て、耳に手＝聴いて、口の横＝話さない）
- 目立たない合図で双方向の状態確認ができる

**④ クールダウンの場所と手順を設計する（[[パタン/段階的クールダウン]]）**
- 教室内の「考えるコーナー」（Step 1）を全員が使えるものとして設ける
- 4段階の手順を図にして掲示する
- 「いつでも行ける」という安心感が、危機になる前に行動させる

**⑤ ルーティンを作る**
- 一日の流れ・授業の始まり方・終わり方を予測可能にする
- 変更があるときは早めに視覚的に予告する（「今日は〇時間目が特別活動になります」）

### 行動目標がある子どもへの個別支援（[[パタン/行動契約]]）

特定の行動目標のある子どもには、「行動契約」を子ども自身と一緒に作る：
1. 目標を具体的な行動として定義する
2. 達成したときの報酬を子どもが選ぶ
3. 条件を交渉して合意する
4. 紙に書いて両者が署名する

## ステップ4：協働体制の設計

### 通常学級担任 × 特別支援教員の協働

**週1回・15分の共同設計ミーティング**：
- 「この子の今週の状態」の情報共有（5分）
- 「来週の授業でどんな配慮が必要か」の共同設計（7分）
- 「試した配慮の効果確認」（3分）

ポイント：「子どもの問題を話し合う場」から「授業の共同設計の場」に変える。

### 支援員（パラプロフェッショナル）の役割再定義

| 従来の役割 | 推奨する役割 |
|---|---|
| 特定の子にずっとそばにいる | 授業全体のサポートとして動く |
| 子どもの代わりにする | 子どもが自分でできるように支援する |
| 問題が起きてから動く | 事前に担任と授業の流れを確認する |

## よくある誤解と正しい理解

| 誤解 | 正しい理解 |
|---|---|
| 「配慮は特別扱い」 | 「よい設計は全員に効く」 |
| 「配慮すると甘やかしになる」 | 「アクセスの方法を変えることは甘やかしではない」 |
| 「特別支援教員に任せればいい」 | 「通常学級担任が設計者、特別支援教員は共同設計者」 |
| 「全員に同じことをするのが平等」 | 「全員が学べるようにすることが公平」 |
| 「グラフィック・オーガナイザーは特定の子だけのもの」 | 「全員に渡しても害がない——むしろ全員の思考を整理する」 |
