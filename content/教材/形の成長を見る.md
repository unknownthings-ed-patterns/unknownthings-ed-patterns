# 形の成長を見る

> この形はどのように成長していますか？

## この教材について

Ruth Parker が開発し、Boaler（2016, Ch.5）が "Growing Shapes" として紹介する視覚的パタン課題をもとに、本Wikiが階段形に置きかえて作った課題。成長する図形を見て、「どのように見えるか」を問うだけで、算数と代数をつなぐ深い思考が生まれる。

> **本の課題との違い**：Boaler の本の Parker の課題（Exhibit 5.1）は、多連結キューブの形が一辺 n+1 の正方形として育ち、1番目4個・2番目9個・3番目16個、n 番目は (n+1)² 個になる。下の階段形（1, 3, 6 …、n(n+1)/2）は本の図とは別の形で、本では階段（staircase）は別の課題（Exhibit 5.10）として出てくる。[[パタン/視覚的数学]] と [[パタン/豊かな課題]] の両方を体現する教材。

---

## 課題

以下の図形（階段形）をイメージしてください。

```
■          1段目：1個のブロック

■
■■         2段目：3個のブロック

■
■■
■■■        3段目：6個のブロック
```

### 問い1：「どのように見えますか？」

この形の成長を、自分の言葉で説明してください。図や矢印を使ってもよいです。

- どこに注目しましたか？
- 別の見え方はありますか？

### 問い2：「次はどうなりますか？」

- 4段目は何個のブロックでできていますか？
- 5段目は？

### 問い3：「ずっと先を考えましょう」

- 10段目は何個のブロックでできていますか？
- n 段目は？（式で表してみましょう）

---

## 見え方の例

### 本の課題（Parker の形）で出た見え方（Boaler, 2016, Ch.5）

Boaler が一緒に取り組んだ教師や生徒は、Parker の形の成長を次のように見て、名前をつけた（Figures 5.3〜5.11）。

- **雨粒法**：キューブが雨粒のように空から各列の上に降ってくる
- **ボウリングのレーン法**：ボウリングのピンのように、いちばん下に新しい列が加わる
- **火山法**：真ん中の列が高く伸び、残りが火山の溶岩のように続く
- **紅海が割れる法**：列が分かれて、真ん中の列が現れる
- **相似な三角形法**：層を三角形として見る
- **スライス法**：層を斜めに見る
- **正方形法**：並べ替えると毎回正方形になる——だから n 番目は (n+1)² 個

### この階段形での見え方の例（本Wikiの例）

同じ「6個のブロックで作られた3段目」を、子どもたちは様々に見る：

**見え方 A：列の足し算として**
> 1 + 2 + 3 = 6（各段の列の数を足す）
> → n 段目は 1 + 2 + … + n = n(n+1)/2

**見え方 B：正方形の半分として**
> 3段目は「3×3の正方形を対角線で分けた半分に、対角線上のブロックの半分を足した形」に見える
> → (n² + n)/2

**見え方 C：長方形に変形**
> 2つ重ねて長方形にすると n×(n+1) になる
> → n段目は n(n+1)/2

どれも正しい。「見え方」が違うだけで、同じ答えに到達する。

## 授業での使い方

### 基本の流れ（30〜45分）

1. **図を提示するだけ**（「どのように見えますか？」と問う。答えを急がない）
2. **個人でじっくり見る**（2〜3分。ノートに自分の「見え方」をメモ）
3. **ペアで共有**（「あなたの見え方を教えて」——違いを見つける）
4. **全体共有**（黒板に複数の見え方を図示。「みんな見え方が違う！」）
5. **問い2・3へ進む**（自分の見え方で n 段目を求める）

### 特別支援学級での調整

- 実際にブロック・碁石・タイルを使って形を作る
- 「4段目を作ってみてください」から始める（動かして考える）
- 「次は何個になると思う？」——予測→確認のサイクルを繰り返す
- 問い3（n 段目）はスキップしてよい。「どのように成長するか」を言葉で言えれば十分

### 短時間バージョン（5〜10分、温まり活動として）

1. 図を見せて「1段目、2段目、3段目は何個ですか？数えてみて」
2. 「4段目は？数えなくてもわかりますか？」
3. 何人かの「考え方」を聞いて板書する

## この課題で育つ力

- 視覚的・空間的思考
- パタンを見つけて言葉・式で表す力（代数的思考の入口）
- 「一つの答えに到達する複数の道」を体験する
- 「数学は暗記でなく考えること」という数学観
