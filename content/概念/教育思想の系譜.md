**混同しやすい組**：
- [[パタン/フロネーシス（実践的知恵）]]・[[パタン/メソン（中庸）]]・[[パタン/タクト（教育的機転）]]：フロネーシスは判断する知恵そのもの、メソンはその知恵が目指す「ちょうどよさ」、タクトはその場の判断を、あとの言語化と省察で育てる教師の機転。
- [[パタン/暫定的道徳（行動しながら考える）]] と [[パタン/漸進主義（時と地の読み）]]：前者は答えが出る前に暫定の判断で動くこと、後者は理想に向かう最小の確実な一歩を選ぶこと。
- [[パタン/啓蒙（自分の理性を使う勇気）]]・[[パタン/自分の頭で考える（Selbstdenken）]]・[[パタン/念写しない（自分の問いを守る）]]：啓蒙は考えを公に表明して試す。自分の頭で考えるは、読む前に自分の考えを持つ時間。念写しないは、自分の問いを手放さずにかかえ続ける。
- [[パタン/道徳的自律]] と [[パタン/善意志（義務に基づいた行動）]]：道徳的自律は規則を問い直して自分で引き受けること、善意志は見られていなくても結果が出なくても行うこと。
- [[パタン/経験の質を問う]]・[[パタン/副次的学習]]・[[パタン/経験と語りの質（ErfahrungとErlebnis）]]：経験の質を問うは判断の最終基準、副次的学習は経験が形づくる態度、経験と語りの質は体験を語れる経験に変えること。
- [[パタン/認識と評価の区別]] と [[パタン/学習指導の三方面]]：前者は認識を先に、評価をあとにする順序。後者は、認識・評価・価値創造の三つの作用をそろえる学習の全体。
- [[パタン/方法的懐疑（疑いながら問う）]] と [[パタン/明証性と判明性（自分で確かめる知の習慣）]]：前者は疑って一度括弧に入れる。後者は、自分の言葉と根拠で確かめられたかを基準にする。
- [[パタン/産婆役としての教師]]・[[パタン/非可視の教師]]・[[パタン/仲介者（メディエーター）]]：産婆役は問いと最小限の介入で子どもが知識を産むのを助ける。非可視の教師は、子ども同士の助け合いを中心にして教師が前に出ない。仲介者は、教師以外の人やものに思考の仲立ちをしてもらう。
- [[パタン/パレーシア（真実を語る勇気）]] と [[パタン/コラケイア（おべっか）]]：対になる。パレーシアは不快でも真実を語る、コラケイアは快いだけで善をもたらさない語り（授業）への警告。
- [[パタン/コナトゥス（自己保存と自己拡張の力）]] と [[パタン/内発的動機づけ]]：コナトゥスは、力の増大を感じることを意欲の根に置く哲学的な基盤。内発的動機づけは、その心理学の理論の地図。
- [[パタン/前へ進む力（不完全さを推進力に）]] と [[パタン/遅咲きの一歩（perfectibilité - いつからでも）]]：前者は不完全さを推進力にする、後者は年齢や過去で始めることを制限しない。どちらも可完成性（perfectibilité）を前提にする。
- [[パタン/専門以前の人間形成]] と [[パタン/幸福（教育目的としての幸福）]]・[[パタン/教育＝成長]]：教育の目的を、人間形成（ミル）、幸福（牧口）、成長そのもの（デューイ）のどこに置くか。三つは排他ではなく、どれを判断の基準にするかの違い。

## このページの使い方

- 文献を読む順番に迷ったら、まず系譜ごとの「中心の問い」を選ぶ。
- パタンを作るときは、ひとつの文献だけでなく、同じ問いを共有する複数文献を横断して読む。
- 文献ページを更新したら、このページの接続先も必要に応じて見直す。
