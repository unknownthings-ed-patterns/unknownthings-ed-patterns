# 文献成熟度ダッシュボード

文献ページは `literature_status` で成熟度を管理する。パタン側の `status` は使わない。

| ステータス | 意味 | 次にすること |
|---|---|---|
| `ingested` | 文献の基本情報・要約を取り込んだ | 関連パタン・実践・概念へのリンクを足す |
| `linked` | 関連ページへリンクした | 文献の概念をパタン候補・実践手順・概念に翻訳する |
| `translated` | 文献の概念をWiki用の言葉に翻訳した | 接続先ページ側にも文献への参照を足す |
| `integrated` | 文献側・接続先・indexがつながった | 必要に応じて圧縮・再統合する |

## status未設定の文献

既存ページはまだ `literature_status` がないものが多い。新規ページから少しずつ付ける。

```dataview
TABLE type, ingested, reingested, reintegrated, updated
FROM "wiki/文献"
WHERE type = "literature" AND !literature_status
SORT ingested DESC
```

## 次に整えるハブ文献

逆参照が多い文献を優先して、`3行要約`、`このWikiでの使い道`、`関連パタンTOP5` を足す。自動集計は [[メンテナンス/文献自動レポート]] を見る。

```dataview
TABLE literature_status, ingested, reintegrated, updated
FROM "wiki/文献"
WHERE type = "literature" AND (!literature_status OR literature_status != "integrated")
SORT ingested DESC
LIMIT 20
```

## 運用メモ

- `reingested` は読み直し・再取り込みの日付として使う。
- `reintegrated` はリンク追加・逆参照・index反映など、Wiki内に再統合した日付として使う。
- `updated` は最終更新日なので、意味のある作業内容は本文や更新履歴にも残す。
