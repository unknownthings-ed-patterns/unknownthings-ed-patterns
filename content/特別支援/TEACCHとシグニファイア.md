# TEACCHとシグニファイア

## 核心的な接続

TEACCHの「環境構造化」は、ドナルド・ノーマンの「シグニファイア（Signifier）」の概念と深く対応している。

> **シグニファイア**: 人が「何ができるか・何をすればよいか」に気づくための、知覚可能な手がかり。

TEACCHの環境設計は、この「行動を導くシグニファイア」を外部環境に埋め込む実践だと理解できる。

---

## TEACCHの環境構造化 = 外部シグニファイア

| TEACCHの手法         | シグニファイアとしての機能             |
| ----------------- | ------------------------- |
| 作業エリアの区切り（机・棚の配置） | 「ここで作業する」という意味の空間的シグニファイア |
| 作業手順カード・色分け       | 「次に何をするか」を視覚的に知らせるシグニファイア |
| 完了ボックス            | 「終わりがどこか」を明確にする時間的シグニファイア |

**原理**: 内的な推測能力（「次は何をすべきか」の自己判断）に依存せず、外部環境が行動の手がかりを提供する。

---

## ノーマンの「シグニファイア」とアフォーダンス

- ノーマンの「アフォーダンス」は本来ギブソン由来の生態学的概念（誤用があった）
- ノーマンが後に整理した「**シグニファイア**」は「何ができるか・どうすれば良いかに気づくための手がかり」
- TEACCHの構造化は、この「シグニファイア」を**意図的にデザインする実践**として理解できる

→ 既存パタン [[パタン/シグニファイアアフォーダンス]] も参照。

---

## ユニバーサルデザインへの拡張

TEACCHの構造化は自閉症支援に限らず有効：

| 対象      | 応用例                 |
| ------- | ------------------- |
| 幼児      | 視覚的ルーティン・絵カードによる見通し |
| 外国語学習者  | 手順の図示・多言語表示         |
| 高齢者     | わかりやすい動線・色分け        |
| ADHD傾向児 | 課題の区切り・チェックボックス     |
| 一般の教室   | ホワイトボードへの流れの可視化     |

> **ユニバーサルデザインの原理と直結**: 「人が理解・行動しやすい環境をデザインする」原理は普遍的。

---

## 特別支援級での実践ポイント

- 「次の活動は何か」を可視化するだけで、行動問題が減少することがある
- 完了の「形」（完了ボックスへ入れる、ファイルに閉じる等）を作ることで達成感が生まれる
- 「ここで算数をする」という場所の意味付けも環境シグニファイアとして機能する
