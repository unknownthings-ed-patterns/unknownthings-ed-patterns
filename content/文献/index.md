## Obsidian用Dataview

Quartz公開では通常の表を読む。Obsidianでは次のDataviewで、文献の整備状況を動的に確認する。

### 最近取り込んだ文献

```dataview
TABLE literature_status, ingested, reintegrated, updated
FROM "wiki/文献"
WHERE type = "literature"
SORT ingested DESC
LIMIT 20
```

### 未統合・未設定の文献

```dataview
TABLE ingested, updated, tags
FROM "wiki/文献"
WHERE type = "literature" AND (!literature_status OR literature_status = "ingested")
SORT ingested DESC
```

### integrated済み文献

```dataview
TABLE ingested, reintegrated, updated
FROM "wiki/文献"
WHERE literature_status = "integrated"
SORT reintegrated DESC
```
