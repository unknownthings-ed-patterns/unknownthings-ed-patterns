# 文献ページテンプレート

文献ページは「書誌情報の保管」だけでなく、文献からパタン・実践・概念を取り出す作業台として書く。

---
type: literature
title: "文献名"
author: "著者名"
year: 0000
tags: [文献]
literature_status: ingested
ingested: YYYY-MM-DD
updated: YYYY-MM-DD
---

## フロントマターの意味

| フィールド | 意味 | 使いどころ |
|---|---|---|
| `type: literature` | 書籍・論文・資料などの文献ページ | 通常の文献ページ |
| `type: reference` | 動画記録・内部資料・参照メモなど | 書籍以外の参照ページ |
| `literature_status: ingested` | 文献の基本情報・要約を取り込んだ状態 | まだWiki内接続が少ない初期状態 |
| `literature_status: linked` | 関連パタン・実践・概念へのリンクが入った状態 | 文献がWiki内で辿れる状態 |
| `literature_status: translated` | 文献の概念がパタン候補・実践手順・概念ページに翻訳された状態 | 「この文献から何が作れるか」が見えている状態 |
| `literature_status: integrated` | 文献側と接続先ページ側が双方向に結ばれ、indexにも反映された状態 | 文献がネットワークに組み込まれた状態 |
| `ingested` | 最初に文献内容を取り込んだ日 | 初回投入の記録 |
| `reingested` | 同じ文献を読み直し、本文メモを追加・再取り込みした日 | 要約や引用メモを増やしたとき |
| `reintegrated` | 取り込んだ内容をWiki内のパタン・実践・概念へ再接続した日 | リンク追加、逆参照、index反映をしたとき |
| `updated` | ページ本文や導線を最後に更新した日 | 小さな修正・追記も含む最終更新 |

`status` はパタン完成度で使っているため、文献では `literature_status` を使う。

## 書くときの観点

| 観点 | 確認すること |
|---|---|
| 入口 | 冒頭だけで「何に使う文献か」がわかるか |
| 翻訳 | 文献の概念が、どのパタン・実践・概念に変換されるか |
| 未処理 | まだパタン化していない論点が「展開したい問い」に残っているか |
| 双方向 | 文献からリンクしたページ側にも、必要なら文献への参照があるか |
