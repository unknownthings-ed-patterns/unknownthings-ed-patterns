# 分数パズル（Fraction Puzzles）― youcubed 完全版

**出典**: youcubed.org / Jo Boaler（CC BY-NC 4.0）  
**対象学年**: 2年生・5年生（アンカー課題として）

---

## 教師向け解説（翻訳）

このタスクでは、生徒に**面積パズル**が与えられる。パズルを小さなピースに分割し、色のついたマス目が探している**単位分数**を表すようにする。生徒は**面積と分数の関係**を理解し、複合図形の面積を求める練習をしながら、**等価分数**への理解を深める。またパズルを解くために**系統的に考える力**を身につける。

### 必要な材料（原版）

- 分数パズル・導入ビジュアル Part 1・Part 2
- 分数パズル問題用紙（ペアに1枚ずつ、1枚ずつ配布）
- プラスチックスリーブ（ペアに1枚、繰り返し試せるように）
- ホワイトボードマーカー（1人1本）
- ホワイトボード消し（ペアに1つ）

---

## 授業の流れ（翻訳）

### フェーズ1｜導入ビジュアル：気づき・疑問

色のついた面積のビジュアルを見せる。

> 「**気づいたことは何ですか？気になることは何ですか？**」

- 生徒はじっくり見てからパートナーと話し合う
- 全員の意見を集めてリストにする（すべての回答を価値あるものとして扱う）
- Number Talk・Dot Talk と同じ進め方で

**出てきそうな気づき**:
- 色のついた部分がどんな形に見えるか
- 気づいたパターン
- 色のついた部分の面積
- 色のついていない部分の面積
- 色のついた部分が表す分数

---

### フェーズ2｜等価分数を引き出す

> 「**それぞれの正方形のどれくらいが色塗りされていますか？どうしてそう言える？**」

- まずパートナーと話し合う時間をとる
- 異なる答えを共有させ、どうやってその分数を得たかを聞く
- **等価分数**（例: 1/2 = 2/4 = 3/6）を黒板に並べて強調する
- 「他の書き方はある？」「等価分数について知っていることを教えて」

---

### フェーズ3｜分割後の分数

正方形を1本の線で2つの長方形に分けた図を見せる。

> 「**それぞれの小さな長方形のどれくらいが色塗りされていますか？**」

- 考える時間 → パートナーと共有 → 前に出て説明させる

---

### フェーズ4｜コアパズル（探究）

ペアで取り組む。問題用紙をプラスチックスリーブに入れ、ホワイトボードマーカーで繰り返し試せるようにする。

**核心の問い（最初のパズル）**:

> 「**大きな正方形を1本の直線で2つの小さな長方形に分けよう。**  
> 一方の長方形は **¼（4分の1）が色塗り**、  
> もう一方は **⅓（3分の1）が色塗り** になるように。**私は何者？**」

- 5〜10分間、解き始めるが終わらない程度の時間を与える
- 途中で「どんな方法を使っている？」を数人に聞く（答えでなく思考を共有）
- 「速さが目標ではない。深く考えることが大事」と伝える
- 解けたら教師を呼んで「どうしてその答えが正しいと言える？」を説明させる
- 説明できたら次のパズルへ（問題は易しい順に並んでいる）

---

### フェーズ5｜発展（Extension）

> 「**ペアで新しい分数パズルを作ろう。答えも一緒に作ること。**  
> 別のペアと交換して解き合おう。**」

---

### フェーズ6｜振り返り（Reflect）

> - 「どんなストラテジーがパズルを解くのに役立った？」
> - 「分数について新しく学んだことは何？」

生徒の作品を教室に掲示しておくと、後で自分の思考に戻れる。

## 2年生向けアンカータスク

2年生は1/2, 1/3, 1/4 を学習中。面積と分数をつなぐ導入として使う。

### 準備物

5mm方眼紙（A4）、色えんぴつ2色、消せるシートまたはラミネート紙

### Low Floor（入り口）

> 「下の正方形の色のついた部分は、全体のどれくらい？」

```
■■□□
■■□□
□□□□
□□□□
（4×4 = 16マス中4マスが色塗り）
```

- 全部のマスを数える → 色のついたマスを数える → 分数で表す
- 「4/16」でも「1/4」でも、まず自分の言葉で表現させる

### メインパズル（2年生版）

> 「**大きな正方形を1本の線で2つの長方形に分けよう。**  
> 一方は **½（半分）が色塗り**、もう一方は **¼（4分の1）が色塗り** になるように。」

- 紙に印刷した正方形（4×4 or 6×6）を使って試す
- プラスチックスリーブ＋ホワイトボードマーカーで何度でも試せるように

| Low Floor | → | High Ceiling |
|-----------|---|--------------|
| 図に線を引いてみる（どこでも） | | 線を引く位置が決まる理由を説明する |
| マスを数えて確かめる | | 「½と同じ分数を他に書ける？」（2/4, 3/6…） |
| 1通り見つける | | 他の引き方でも成立するか試す |

### 発展（2年生）

> 「自分でパズルを作ろう。正方形に色を塗って、友達に「何分の何？」と問題を出す。」

### 問い返し

- 「これは本当に半分？どうしてそう言える？」
- 「線を引く場所は他にある？」
- 「½と書いても2/4と書いても同じ？なぜ？」

## 5年生向けアンカータスク

5年生は等価分数・約分・分数の大小を学習中。本来のパズルをそのまま使う。

### 準備物

5mm方眼紙、色えんぴつ2色、プラスチックスリーブ＋ホワイトボードマーカー

### 導入（5年生）

いくつかの正方形・長方形の図を見せる。

> 「**気づいたことは？気になることは？**」  
> → 「**それぞれの図の色のついた部分は全体のどれくらい？どうしてそう言える？**」

等価分数が自然に出てきたら：「他にはどう書ける？」

### メインパズル（原版そのまま）

> 「**大きな正方形を1本の直線で2つの小さな長方形に分けよう。**  
> 一方の長方形は **¼（4分の1）が色塗り**、  
> もう一方は **⅓（3分の1）が色塗り** になるように。私は何者？**」

| Low Floor | → | High Ceiling |
|-----------|---|--------------|
| とりあえず線を引いてみる | | 「なぜこの位置でないといけないか」を論理的に説明する |
| マスを数えて確かめる | | 等価分数を使って確認する（例: 3/12 = 1/4） |
| 1通り見つける | | 他の解があるかを系統的に調べる |
| 図だけで考える | | 代数的に「線の位置をxとしたとき…」と一般化する |

**ヒント（詰まった時）**: 「¼が色塗りということは、色のついていない部分は？」「分母を揃えると何か見えてくる？」

### 系統的アプローチの指導ポイント

生徒が「なんとなく試している」段階から「系統的に探す」段階へ進むよう促す：
- 「今どんなやり方で試している？」（教師は答えでなく方法を聞く）
- 「全部の可能性を漏れなく調べるには？」
- 「解けた！と言える理由を説明できる？」

### 発展（5年生）

> 「**自分でパズルを作ろう。**  
> 1本の直線で正方形（または長方形）を2つに分け、それぞれ違う分数が色塗りになるように設計する。  
> 答えと解き方も作ること。別のペアと交換して解き合おう。」

**さらに深める問い**:
- 「分母が違う2つの分数（例: 1/3と1/4）で成立するパズルは作れる？」
- 「2本の線ならどうなる？」
- 「長方形でなく複合図形（L字型）でも作れる？」

### 問い返し

- 「どうしてその解が正しいと言える？」
- 「1/4と3/12、どちらが正しい？どちらも正しい？」
- 「この解き方、別の問題にも使える？」

## 授業での使い方（アンカー課題として）

三層構造の授業（[[特別支援/特別支援級の算数指導]]）での位置づけ：

```
① ウォームアップ（5分）
    └── 「この図の色塗り部分は何分の何？」（フェーズ1・2の簡易版）

② 自分で学ぶ時間
    └── メインパズルに取り組む（プラスチックスリーブを使用）
    └── 早く終わったら発展パズルを自作 → アンカー課題として機能

③ 先生と一緒の時間
    └── 「どうしてその解が正しいと言える？」を教師に説明する
```

2年生と5年生が同じ教室でも、**同じ素材で異なる深さ**に取り組める点がLFHCの強み。
