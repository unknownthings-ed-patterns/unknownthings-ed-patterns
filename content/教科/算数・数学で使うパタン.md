# 算数・数学で使うパタン

算数・数学の授業で使いやすいパタンを、実践の場面ごとに並べた入口。

## 困りごとから探す

| 困りごと・場面 | 使えるパタン | 一言 |
|---|---|---|
| 一部の子しか発言しない | [[パタン/ナンバートーク]] | 解法の多様性を共有し、全員が話す場をつくる |
| 子どもが概念を暗記で済ませている | [[パタン/操作物による概念形成]] | 具体物を操作して概念を体験的に理解させる |
| 文章題で詰まる子が多い | [[パタン/図に表せないか]] | 図化・数直線化で問題構造を可視化させる |
| 算数嫌いの子が参加できない | [[パタン/算数の公平性]] | 全員が参加できるタスクと発話の設計 |
| 解き方は正しいが意味がわかっていない | [[パタン/精緻化]] | 「なぜそうなるの？」と自己説明を促す |
| 早い子が待っているだけになる | [[パタン/豊かな課題]] | 多様な解法・拡張が生まれる設計にする |
| 既習内容がすぐ抜けてしまう | [[パタン/間隔学習]] | 時間を空けて復習を繰り返し定着させる |
| 解法を選ぶ力が育たない | [[パタン/他の表現や方法を問う]] | 「他にはどんな方法がある？」と問う |
| 数学語彙を文脈なく暗記している | [[パタン/数学語彙の文脈的指導]] | 用語を図・例・非例と結びつける |
| クラス全体で考えることが根付かない | [[パタン/数学のクラス規範]] | 算数特有の「わからない」を出せる規範をつくる |

## 学習科学 × 算数

認知科学・学習科学の知見をそのまま算数授業に使うパタン群。

| パタン | 算数授業での使い方 |
|--------|------------------|
| [[パタン/間隔学習]] | 前時の計算問題を毎朝冒頭5分で少量復習し、記憶の定着を高める |
| [[パタン/テストを繰り返す]] | ミニホワイトボードで既習の解法を毎時間1問テスト形式で引き出す |
| [[パタン/インターリービング]] | 同種の計算問題を連続させず、混在配列で演習することで転用力が育つ |
| [[パタン/精緻化]] | 「どうしてこのやり方になるの？」と問い、自己説明で理解を深める |
| [[パタン/望ましい困難]] | あえて少し難しい問題を最初に提示し、試行錯誤で記憶定着を高める |
| [[パタン/メタ認知的モニタリング]] | 「この問題、わかった？」を自分で評価させ、学習の自己調整を育てる |

## 近いパタンとの見分け

算数・数学のパタンのうち、ほかの系列の表に入っていないものを、課題と問題の設計、授業の形、概念の芯と言葉、現象と記号の往来、考えを見えるようにすること、教室の文化と公平、で並べる。

| 迷いどころ | パタン | 見分けの問い |
| --- | --- | --- |
| 課題と問題の設計 | [[パタン/Thin-Slicing設計（薄切り問題の作り方）]] | 数学的な構造を保ったまま、一度に一つだけ変えた問題の列になっているか（Liljedahl） |
| 課題と問題の設計 | [[パタン/同一文脈・複数概念の展開]] | 一つの場面を使い続け、問いだけを変えて、なぜ別の計算が要るのかを場面から引き出しているか |
| 課題と問題の設計 | [[パタン/逆算・双方向思考]] | 同じ数・同じ場面のまま、問いの向きを逆にした問題を続けて出しているか |
| 課題と問題の設計 | [[パタン/同等点と差異点の均衡設計（学習の駆動エンジン）]] | 一つの事例の中に、既知と同じところ（安心）と、新しく違うところ（発見）を両方入れているか（戸田城外） |
| 課題と問題の設計 | [[パタン/解説を先に渡さない（自得の設計）]] | ヒントは比べる先を指さすだけにし、解き方を先に教えていないか（戸田城外） |
| 課題と問題の設計 | [[パタン/数学的モデリング]] | 現実の場面から問いを立て、数学のモデルに表すところまでを子どもが行っているか（Boaler） |
| 授業の形 | [[パタン/ナンバートーク]] | 一つの計算を全員が暗算で解き、いくつもの解き方をクラスで共有しているか |
| 授業の形 | [[パタン/数学ワークショップ]] | ウォームアップ・ミニレッスン・問題解決・対話・ジャーナルの流れで、数学者として考える時間をとっているか |
| 授業の形 | [[パタン/視覚的数学]] | 「どのように見える？」「別の見方は？」と問い、見え方をクラスで共有しているか |
| 概念の芯と言葉 | [[パタン/概念の芯をつかむ（地力の学び方）]] | 「そもそもこれは何をとらえようとしているか」から入り、身近な場面で芯を感じてから定義や公式へ進んでいるか |
| 概念の芯と言葉 | [[パタン/定義から始める（言葉を厳密にする）]] | あいまいな理解のまま進まず、言葉を定義してから考えているか |
| 概念の芯と言葉 | [[パタン/数式は言葉（式を読む・式で語る）]] | 式を、考える道具として読み、伝える道具として語っているか |
| 概念の芯と言葉 | [[パタン/数学語彙の文脈的指導]] | 数学の言葉を、意味のある場面の中で、使える語彙として育てているか |
| 概念の芯と言葉 | [[パタン/分類の設計（「同じ」を決める力）]] | 「何が同じか」の基準を決め、その基準で本当に分けられるかを確かめてから分類しているか |
| 概念の芯と言葉 | [[パタン/帰納的推論と演繹的推論]] | 「たくさん試したからきっとそう」と「必ずそうなる理由がある」を、区別して使っているか |
| 現象・身体と記号を往来する | [[パタン/二つの世界の橋（現象と数式を往来する）]] | 現象の世界と数式の世界のあいだに橋を架け、行き来しているか（結城浩） |
| 現象・身体と記号を往来する | [[パタン/記号接地（Symbol Grounding）]] | 記号やことばの意味が、身体の経験に根を下ろしているか |
| 現象・身体と記号を往来する | [[パタン/抽象と具象のはしご]] | 抽象と具体のあいだを、一度ではなく何度も昇り降りしているか（ハヤカワ） |
| 考えを見えるようにする | [[パタン/思考の可視化]] | 考えていることを外に出す活動を定期的に入れ、思考を共有できるようにしているか（Ritchhart） |
| 教室の文化と公平 | [[パタン/数学のクラス規範]] | 最初の授業で、算数の時間をどんな場所にするかを、規範として明示しているか（Boaler） |
| 教室の文化と公平 | [[パタン/算数の公平性]] | 「算数は才能のある子のもの」というラベルを、教室から取り除いているか |
| 教室の文化と公平 | [[パタン/脱トラッキング（De-tracking）]] | 能力別のグループ分けをやめ、同じ課題に全員で取り組んでいるか |
| 教室の文化と公平 | [[パタン/複雑指導（Complex Instruction）]] | 能力を多次元に広げ、どの子もグループに知的に貢献できるように設計しているか |

**混同しやすい組**：
- [[パタン/Thin-Slicing設計（薄切り問題の作り方）]]・[[パタン/同一文脈・複数概念の展開]]・[[パタン/逆算・双方向思考]]：どれも問題の並べ方。Thin-Slicing は一度に一つだけ変える。同一文脈は場面を変えずに問いを変える。逆算は同じ数と場面のまま問いの向きを逆にする。
- [[パタン/同等点と差異点の均衡設計（学習の駆動エンジン）]] と [[パタン/Thin-Slicing設計（薄切り問題の作り方）]]：前者は一つの事例の中に既知と新しさを同居させる。後者は、問題の列の中で変える要素を一つずつにする。
- [[パタン/二つの世界の橋（現象と数式を往来する）]] と [[パタン/数学的モデリング]]：前者は現象と数式を行き来する見方、後者は問いを立ててモデルをつくる一連の活動。
- [[パタン/記号接地（Symbol Grounding）]] と [[パタン/抽象と具象のはしご]]：記号接地は、記号の意味が身体経験に根を下ろしているかを問う。はしごは、抽象と具体を何度も昇り降りする。
- [[パタン/概念の芯をつかむ（地力の学び方）]] と [[パタン/定義から始める（言葉を厳密にする）]]：芯をつかむは、身近な場面から入って定義へ向かう。定義から始めるは、言葉を先に厳密にしてから考える。どちらから入るかは、子どもがその概念の場面をすでに持っているかで決める。
- [[パタン/算数の公平性]]・[[パタン/脱トラッキング（De-tracking）]]・[[パタン/複雑指導（Complex Instruction）]]：公平性は「誰が数学をする人か」というラベルを外す考え方。脱トラッキングは能力別の編成をやめる。複雑指導は、能力を多次元に広げてグループで貢献する仕組み。
- [[パタン/ナンバートーク]] と [[パタン/数学ワークショップ]]：ナンバートークは短い暗算と解き方の共有。数学ワークショップは、一時間全体の流れ。
