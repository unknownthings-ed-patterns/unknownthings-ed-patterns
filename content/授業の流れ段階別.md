# 授業の流れ段階別

授業の「導入・展開・まとめ」と「単元設計」の各段階から、使えるパタンを逆引きする入口。

→ 困りごとから探す場合は [[困りごとから探す]]  
→ 育てたい力から探す場合は [[目標から探す]]  
→ 教科から探す場合は [[教科/算数・数学で使うパタン]] / [[教科/国語]]

---

## 単元設計（授業を作る前）

単元全体の目的・順序・評価を設計するパタン。

| パタン | 一言 |
|--------|------|
| [[パタン/概念型の目標]] | 単元の到達点を汎用的な概念として設定する |
| [[パタン/胚細胞モデル]] | 単元を貫く中心概念（胚細胞）を見つけ展開する |
| [[パタン/熟慮的配列]] | 学習経験をどの順序で並べるかを設計する |
| [[パタン/駆動質問]] | 探究を動かす単元中心の問いを設計する |
| [[パタン/熟慮的教材教具]] | 教材・教具を価値・目的・使いやすさから吟味する |
| [[パタン/出入り口を明確にする（目標設定）]] | 単元の始まりと終わりを学習者に見えるようにする |
| [[パタン/パフォーマンス課題]] | 単元の終わりに知識・技能を総合する課題を設計する |
| [[パタン/逆向き設計]] | 評価（ゴール）から逆算して単元を設計する |

## 導入（最初の5〜15分）

「今日の学習に引き込む」段階のパタン。

| パタン | 一言 |
|--------|------|
| [[パタン/A1.興味の獲得（知覚的喚起）]] | 驚き・新奇性で「なんだろう？」を引き出す |
| [[パタン/認知的コンフリクト]] | 矛盾・予期しない結果で思考を揺らす |
| [[パタン/切実性（必要感）]] | 「これを知らないと困る」という必要感を作る |
| [[パタン/先行オーガナイザー]] | 全体の枠組みを先に示してから内容に入る |
| [[パタン/既知から未知へ]] | 学習者がすでに知っていることを起点にする |
| [[パタン/問題設定]] | 解きたい問いや課題から学習を起動する |
| [[パタン/アンカーイベントから問いへ]] | 体験・映像・話題から問いを立てる |
| [[パタン/ナンバートーク]] | 算数の冒頭5分で数感覚を育てる日課活動 |
| [[パタン/アンティシペーション・ガイド]] | 本文を読む前に予測・立場を表明させる |

## 展開（学習活動の中心）

「理解を深める・練習する・協働する」段階のパタン。

### 説明・モデリング

| パタン | 一言 |
|--------|------|
| [[パタン/シンクアラウド]] | 教師が声に出して考え、思考プロセスを見せる |
| [[パタン/マルチモダール]] | 音声・文字・図・実物・動作を組み合わせる |
| [[パタン/見てから聞く]] | 視覚情報を先に提示してから説明する |
| [[パタン/実物を見せる]] | 「こういうものだ」という基準を実例で示す |
| [[パタン/段階的手放し]] | I Do→We Do→You Do で主体を移していく |
| [[パタン/簡明の原則（端的に具体的に出す）]] | 指示を短く・具体的に・肯定形にする |

### 問いかけ・対話

| パタン | 一言 |
|--------|------|
| [[パタン/熟慮的問い]] | 目的・相手・方法・文脈から問いを設計する |
| [[パタン/深める問い]] | 思考を一段深く進める問いを置く |
| [[パタン/問い返しのデザイン]] | 発言を受けて次の思考へつなげる |
| [[パタン/沈黙の間の設計]] | 考えが深まる間を意図的に設ける |
| [[パタン/具体的・限定的に問う]] | 答えやすい具体的な文脈で問いかける |

### 練習・活動

| パタン | 一言 |
|--------|------|
| [[パタン/能動的関与]] | 全員が思考・発言・動作で関与する設計 |
| [[パタン/自己選択自己決定]] | 課題・方法・ペースを学習者が選ぶ |
| [[パタン/個別化]] | 一人ひとりに合った課題・支援を提供する |
| [[パタン/ジグソーパズル]] | 専門を分担して相互依存する協働学習 |
| [[パタン/フィッシュボウル（金魚鉢）]] | 内側が討論し外側が観察する対話形式 |
| [[パタン/精緻化]] | 新知識を既有知識と結びつけて理解を深める |

### フィードバック・確認

| パタン | 一言 |
|--------|------|
| [[パタン/フィードバック]] | ゴール・現在地・次の一手を伝える |
| [[パタン/形成的評価]] | 学習中に理解を確認して授業を調整する |
| [[パタン/ピアフィードバック]] | 学習者同士でフィードバックし合う |
| [[パタン/意味のある具体的なフィードバック]] | 何が良くて何を改善するかを具体的に返す |

| パタン | 一言 |
|--------|------|
| [[パタン/省察的評価]] | 振り返りを通じて学びを深め次につなぐ |
| [[パタン/自己内フィードバック]] | 学習者が自分で評価・改善するループ |
| [[パタン/自己記録]] | 自分の行動・学習を記録する習慣をつくる |
| [[パタン/Consolidation（収束の時間）]] | 活動の最後に考えを整理・統合する時間 |
| [[パタン/共有の時間]] | 学びを全体で共有し価値を可視化する |
| [[パタン/作家の椅子（Author's Chair）]] | 書いたものを仲間に読み反応を受け取る |
| [[パタン/テストを繰り返す]] | 引き出しによって記憶が強化される |
| [[パタン/概念モデル]] | 学んだことを構造化して見えるようにする |
