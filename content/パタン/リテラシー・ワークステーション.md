# リテラシー・ワークステーション

> 教師が小グループ指導をしている間、残りの子どもたちが「目的のある本物の練習」に取り組む場所——ワークステーションは忙しくさせるためでなく、すでに教えたことを深く練習するために設計する。

---

## Pattern Connection

**出典**: Diller, D.（2005）*Practice with Purpose: Literacy Work Stations for Grades 3-6*. Stenhouse Publishers.

- **Stress the Highlighted Word**：1文を複数回書き毎回別の語を強調して音読 → 解釈を横に書く

## 背景（Context）

リーディング・ワークショップや読み書き指導において、教師が小グループ（4〜6人）と読書指導をする時間を確保したい。しかし教師が小グループに集中している間、残りの20人前後の子どもたちが意味のある活動をしていなければ、その時間は失われる。

Debbie Diller（2005）は小学校3〜6年生の教師とともに「リテラシー・ワークステーション」を体系化した。その出発点は一つの問い：**「なぜ？何の目的で？」（Why? What's the purpose?）**。

ワークステーションが「忙しくさせるだけ」になることを Diller は「フラフとお飾り（fluff and frills）」と呼んで批判する。本当のワークステーションは「授業で教えたことを、子どもが自立して練習できる場所」だ。

## 問題（Problem）

小グループ指導中に残りの子どもたちが：

- 「先生、終わりました！次は何をしますか？」と中断してくる
- やることがなくて雑談・ぼーっとするなど離脱してしまう
- 「何かをさせるため」だけの活動（塗り絵・ワークシートの写し）に流れる
- 全員が同じ活動をしているため、習熟度・興味の差が活かされない

これらは「ワークステーションが目的を持っていない」サインだ。

## 力のかたち（Forces）

- 教師は小グループ指導に集中したい——中断なしに20〜30分続ける必要がある
- 子どもは「何をすればいいか分からない」とき、教師に頼るか離脱する
- 「すでに教えたこと」だけが独立した練習の対象になれる——新しいことは小グループで教える
- 子どもが活動を選べることで、内発的動機が持続する
- パートナーがいることで互いにアカウンタビリティが生まれ、教師なしでも機能する
- 材料が頻繁に変わると「次は何をするか」を常に考えるコストがかかる

## 解決（Solution）

**「教えた内容の本物の練習」を2人組で行う場所として、ワークステーションを設計する。I Can リストが子どもの自立を保証し、パートナーアカウンタビリティが教師不在でも機能させる。**

---

### 設計の3原則

**① 教えたことだけを入れる**

ステーションに入れる活動は、必ずミニレッスンや全体授業で先に教えたものに限る。教えていない活動は独立してできない——独立できない活動はステーションに置かない。

**② 目的を持たせる（フラフにしない）**

各活動について「なぜこれをするか」を自問する。答えられない活動はステーションに入れない。

> 「リテラシーセンターは、あなたが教えているスキルから始まることで、目的のある練習を提供できる。鍵はコンテントに集中し、フラフとお飾りを排除すること。」——Diller

**③ 2人組（パートナー）で行う**

1ステーションに生徒2人。これにより：
- 互いにアカウンタビリティを持つ（「これ合ってる？」「次どうする？」）
- 問題解決を2人でできる（教師に頼らなくて済む）
- 少人数のスペースで活動しやすい

クラスが多い場合は同じステーションを複数設置する（例：30人なら読書ステーションを3つ）。

---

### ステーションの種類

| ステーション | 主な活動例 |
|---|---|
| **独立読書** | 自分で選んだ本を読む、推薦カードを書く、読書ノートを書く |
| **応答的ライティング** | 読んだ本への反応を書く（考え・驚き・疑問・推薦） |
| **ライティング** | 草稿を書き続ける、推敲する、作品を仕上げる |
| **ワードスタディ** | 単語仕分け・漢字の構造分析・語彙ゲーム・語族（ファミリー）探し |
| **詩** | 詩を読む・書く・暗唱・2人読み（Readers Theater） |
| **コンテント・エリア** | 理科・社会のテーマと連携したノンフィクション読み書き |
| **ドラマ** | セリフ読み・即興演技・音読劇・声だけ朗読録音 |
| **その他** | 新聞読み・ゲーム・コンピュータ・聴き取り（リスニング） |

最初は**独立読書ステーション**から始めるのが最も安全。すでに「自分で本を読む」習慣があれば、ステーション化しやすい。

---

### "I Can" リスト（できることリスト）

各ステーションに「I Can リスト」を置く——3〜4つの活動の選択肢が書かれた掲示物。

**I Can リストの作り方**：

1. ミニレッスンで活動を教える
2. 「このステーションでできること」を子どもと一緒にリストアップする
3. 掲示物として視覚化し、ステーションに置く
4. 数週間同じリストを使い続け、慣れたら活動を追加する

**ポイント**：
- 子どもと一緒に作ることで所有感が生まれ、「自分たちのルール」になる
- シンプルな言語・絵・アイコンを使う
- 3〜4つに絞ることで選択の混乱を防ぐ

例（独立読書ステーション）：
```
📚 このステーションでできること
□ 自分で選んだ本を読む
□ 読んだ本の推薦カードを書く
□ 読書ノートに気づいたことを書く
□ パートナーに「次に読むといいよ」と書き置く
```

---

### モデリング：ステーション導入の手順

ステーションを動かす前に、教師は徹底的にモデリングする：

1. **全体でモデリング**：「こういう場所があります。こんなことをします」と全員に見せる
2. **考えて声に出す（シンクアラウド）**：「私なら I Can リストを見て、今日は推薦カードを書こうと思います。なぜかというと……」
3. **ペアで試す（教師が見ている前で）**：2人組に実際にやらせ、機能するか確認する
4. **フィードバックとリフレクション**：「うまくいったことは？難しかったことは？」
5. **独立稼働**：準備が整ってから実際のワークステーション時間に組み込む

**一度に1つだけ追加する**：最初の1週目は1つのステーションだけ。2週目に2つ目を追加。3〜4週間で5〜7つのステーションが稼働する体制を育てる。

---

### ローテーションとスケジュール管理

教師が小グループ指導をしている間（20〜40分）、子どもたちはステーションにいる：

- **固定型**：その日のパートナーとステーションが決まっている（教師が決める）
- **選択型**：I Can リストのように選択肢があり、子どもが選ぶ
- **ローテーション型**：週に一度ステーションを交代する

どの形であれ、**ステーションに「自分は今日何をするか」が分かる仕組み**が必要。掲示物・ポケットチャート・個人計画カードなどを使う。

---

### 材料の安定性：2〜4週間変えない

従来のセンターと最大の違いが「材料の安定性」だ。

- 同じステーション・同じ活動を2〜4週間続ける
- 「次は何をするか」の認知コストが消え、深い練習に入れる
- 教師が毎週新しい材料を準備するコストが激減する
- 慣れた頃に1つだけ活動を追加して「I Can リスト」を更新する

---

## 結果（Consequences）

- 教師が小グループ指導に集中できる時間が確保される——中断がほぼなくなる
- 子どもたちが「目的のある練習」を自律的に行う習慣が育つ
- I Can リストにより、教師なしで活動を選び続けられる独立性が育つ
- ミニレッスンで教えた内容がステーションで何度も繰り返し練習される——定着が深まる
- ただし、最初の3〜4週間はモデリングと導入に時間を要する——急ぐと機能しない
- 「フラフ」なステーションを許容すると独立性は育つが学習は起きない——目的の明確さが機能の前提

## Actionable Insight

- 来週の小グループ指導の日を1日決めて、そのとき他の子どもたちが何をしているかを観察する——「フラフ」になっていたら、I Can リストを作る最初の理由になる

- 新しいステーション活動を加える前に「これはミニレッスンで教えたか？」を自問する——「まだ教えていない」なら、先にミニレッスンをする
