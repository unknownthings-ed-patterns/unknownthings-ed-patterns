# Classroom Strategies for Interactive Learning（Buehl, 2017）

Buehl, D. (2017). *Classroom Strategies for Interactive Learning* (4th ed.). Stenhouse Publishers.
（初版1995年、第2版2001年、第3版2009年、第4版2017年）

著者はウィスコンシン州マディソンの高校教師・リテラシーコーチ。30年以上にわたりコンテント・エリア（教科横断的）リテラシー研究に取り組み、「インタラクティブ・ラーニング」を軸に40以上の教室使用可能な読解ストラテジーを体系化した。

---

## 要約

### 核心の哲学

Buehl の中心主張：**読解は受動的な受け取りではなく、能動的な意味の構築**である。

> 「読解は、ある形式の情報を戦略的に検討して理解を達成するプロセスだ。読者は意味を受動的に受け取るのでなく、能動的に作り出す。」

教師の役割は「ステージ上の賢者（sage on the stage）」から「傍らのガイド（guide on the side）」へ。

**"Interactive Learning"** の意味：テキストと読者が相互作用する学習——学習者が自分の問いを立て、予測し、確認し、修正し、統合する過程を、構造的な方略によって促進する。

---

### BDA フレームワーク（前・中・後）

本書の全戦略は **Before-During-After（読む前・読む間・読んだ後）** の3段階フレームワークで整理される：

| フェーズ | 目的 | 代表的な方略 |
|---|---|---|
| **Before（読む前）** | 背景知識の活性化・目的設定・語彙の事前準備 | アンティシペーション・ガイド、KWL、チャプター・ツアー、語彙プレビュー |
| **During（読む間）** | 理解のモニタリング・つながりの構築・問いの生成 | テキスト・コーディング、シンクアラウド、インタラクティブ・リーディング・ガイド、ダブルエントリー |
| **After（読んだ後）** | 要約・統合・反省・転移 | クイックライト、マグネット・サマリー、RAFT、ディスカッション・ウェブ |

**フロントローディング（Frontloading）**という概念が重要：複雑なテキストの「知識要求」に事前に応えることで、読む前から理解の足場を作る。

---

### 6つのテキスト・フレーム（文章構造）

Buehl はほとんどのアカデミックなテキストが6つの構造を使うと整理する：

| テキスト・フレーム | 説明 | 典型的な文章ジャンル |
|---|---|---|
| **原因と結果** | 出来事・現象の原因とその影響 | 理科・社会の説明文、歴史 |
| **概念と定義** | 概念の特徴・属性・例を説明 | 辞典・説明文・学術文章 |
| **問題と解決** | 問題の記述と解決策の提示 | 社会問題・医療・工学 |
| **比較と対比** | 2つ以上のものの類似と相違 | 比較説明文・レビュー |
| **目標・行動・結果** | 目標→行動→結果の流れ | 伝記・歴史・プロセス記述 |
| **主張と根拠** | 主張と、それを支える証拠・論拠 | 議論・論説・意見文 |

テキスト・フレームを読む前に明示することで、「この文章は何の構造で書かれているか」という読みの枠組みが生まれ、理解が深まる。

---

### 主な戦略（40以上の中から重要なものを抜粋）

**Before（読む前）の戦略：**

| 戦略 | 概要 |
|---|---|
| **アンティシペーション・ガイド** | トピックに関する5〜8の記述文に賛否を事前表明し、読後に見直す——認知的葛藤が理解を深める |
| **KWL Plus** | K（知っていること）W（知りたいこと）L（学んだこと）チャートで読みを目的化する |
| **チャプター・ツアー** | 見出し・図版・キャプションを事前に「巡回」して概略を把握する |
| **マインド・マッピング（事前）** | トピックについて知っていることをウェブ状に出す |
| **語彙プレビュー** | 重要語彙に事前に出会わせ、意味の仮説を立てさせる |

**During（読む間）の戦略：**

| 戦略 | 概要 |
|---|---|
| **テキスト・コーディング** | 記号（✓知ってた・？わからない・！驚き）を使って読みながら考えを追跡する |
| **シンクアラウド** | 教師が読みながら思考を声に出してモデリングする |
| **ダブルエントリー・ダイアリー** | ページを半分に割り、左：テキスト引用、右：自分の反応・疑問・つながりを記録する |
| **インタラクティブ・リーディング・ガイド** | 読みを構造化するガイド付き質問シートを使いながら読む |
| **クエスチョニング・ザ・オーサー** | 著者の意図・選択に疑問を向けながら読む批判的読み |

**After（読んだ後）の戦略：**

| 戦略 | 概要 |
|---|---|
| **クイックライト（Quick-Write）** | 5〜10分の自由書きで理解を深め、残す |
| **マグネット・サマリー** | キーワード（磁石語）を選び、周辺情報を付けて一文要約を書く |
| **RAFT** | 役割（Role）・読者（Audience）・形式（Format）・トピック（Topic）を設定して書く |
| **ディスカッション・ウェブ** | 賛否両論の証拠を整理して、議論・批判的思考を深める |
| **スケッチ・トゥ・ストレッチ** | テキストの意味を視覚的に表現し、統合的理解を図る |
| **パワー・ノーツ** | 主要概念・補助詳細・例を階層化したノートにまとめる |

### コンテント・エリア・リテラシー

Buehl の重要な主張：**読解力はELAだけで育つのではない**——すべての教科（理科・社会・算数）が固有の「教科のリテラシー」を持っており、それぞれの教科で読み方・書き方・考え方を教えることが必要だ。

> 「ある学問分野でリテラシーがあるということは、テキストを読んで理解できることだけでなく、その分野の専門家のように考え、語り、書けることを意味する。」

- 理科：実験記録・観察報告・科学的説明文を読む
- 社会：因果・変化・複数の視点・一次資料を読む
- 算数：文章題・数学的説明・グラフを読む

小学校では同一教師がすべての教科を教えるため、「教科のリテラシー指導」を横断的に設計できる強みがある。

## 重要な引用

> 「読解は、ある形式の情報を戦略的に検討して理解を達成するプロセスだ。読者は意味を受動的に受け取るのでなく、能動的に作り出す。」

> 「自分で問いを立てる学習者は、新しいアイデアと個人的に相互作用し、遭遇したことを理解しようとするために問いを使っている。」

> 「教師の役割は、ステージ上の賢者から傍らのガイドへ。」

## 教育実践への示唆

1. **BDAで授業を設計する**：単元・本時の読解指導を「読む前・読む間・読んだ後」で分けて設計する——各フェーズで何の方略を使うかを意識するだけで授業が変わる

2. **フロントローディングを惜しまない**：複雑なテキストを読む前に、知識・語彙・目的を整えることに時間を使う——「先に整えるほど、読む間の理解が深まる」

3. **テキスト・フレームを使って説明文指導を設計する**：「この説明文は問題と解決の構造だ」と事前に伝えるだけで、読みの枠組みが変わる

4. **書くことを読解の道具にする**：読んだ後に「書くために読む」のでなく、書くことが理解を深める道具になる（クイックライト・ダブルエントリー・RAFT）

5. **理科・社会の説明文を「教科のリテラシー」として扱う**：理科・社会の読み物を「内容を覚えるもの」としてではなく「その教科の読み方を学ぶもの」として使う
