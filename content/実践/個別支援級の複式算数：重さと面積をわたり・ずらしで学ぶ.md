# 個別支援級の複式算数：重さと面積をわたり・ずらしで学ぶ

> 複数の教育課程が同時に走る個別支援級で、直接指導と自力解決をずらしながら、重さと面積の単位理解を深める実践。

- [[パタン/個別化]] — 学年・理解・集中の違いに合わせて課題を調整する。

- [[パタン/具体から抽象へ]] — 操作・測定から、式や単位の理解へ移る。

## 実践の概要

個別支援級の算数科実践。3年生の「重さをはかって表そう」と、4年生相当の「広さのくらべ方と表し方を考えよう」を、同じ授業時間の中で進める。

この実践の中心は、重さや面積の内容そのものだけではない。複数の教育課程がある教室で、教師がどのように直接指導と間接指導を組み合わせ、子どもが考える時間を確保するかにある。

指導案では、複式指導のために「わたり」と「ずらし」が意識されている。

- **わたり**：複数の教育課程の間を移動して指導する
- **ずらし**：複数の教育課程を同時に直接指導しないよう、学習過程を意図的にずらす

限られた直接指導の時間でも、教え込みやプリント処理だけに寄せず、既習事項の確認、見通しづくり、数学的な見方や考え方を促す問いを入れて、児童が思考し表現する時間を増やそうとしている。

## 実践のねらい

- 複式編成の個別支援級で、直接指導と間接指導を有効に組み合わせる
- 既習事項を想起させ、新しい単位や公式への見通しをもたせる
- 重さや面積を、具体物・任意単位・共通単位・公式へと段階的につなげる
- 児童が「測る」「比べる」「表す」「説明する」時間をもてるようにする
- 複数の教育課程があっても、算数の概念理解に向かう学習をつくる

## 2つの学習の流れ

### 3年：重さをはかって表そう

重さの学習では、まず身の回りのものの重さをどう比べるかを考える。積み木や1円玉などの任意単位を使って重さを比べ、自作天びんで測定する。そこから、共通単位としてのグラム、キログラム、トンへ進む。

単元の流れは、次のように組まれている。

| 時間 | 主な活動                                   | 見方・考え方                 |
| ---- | ------------------------------------------ | ---------------------------- |
| 1    | 文房具などの重さの比べ方を考える           | 直接比較・間接比較           |
| 2    | 積み木や1円玉、自作天びんで重さを測る      | 任意単位で数値化する         |
| 3    | グラムを知り、測定前におよその見当をつける | 共通単位で表す               |
| 4    | はかりの針の動き方、目盛りの読み方を考える | 数直線と結びつける           |
| 5    | キログラム、1kg=1000gを理解する            | 大きな量の単位へ広げる       |
| 6    | 正味・風袋・全体の重さを線分図で整理する   | 関係を図で表す               |
| 7    | トン、1t=1000kgを理解する                  | さらに大きな量の単位へ広げる |
| 8    | キロ、ミリなど接頭語に着目する             | 単位の関係を統合する         |
| 9    | 単元を振り返る                             | 算数の目で整理する           |

本時は第3時。重さの単位「グラム」を知り、測定前におよその見当をつける時間である。

### 4年：広さのくらべ方と表し方を考えよう

面積の学習では、花壇の設計図をつくる活動から、広さの比べ方や表し方を考える。1cm²、長方形・正方形の面積公式、組み合わせた図形、大きな面積の単位へと進む。

単元の流れは、次のように組まれている。

| 時間 | 主な活動                                   | 見方・考え方             |
| ---- | ------------------------------------------ | ------------------------ |
| 1    | 花壇の設計図をつくり、広さの課題を設定する | 広さを比べる必要感       |
| 2    | 面積の意味、1cm²を知る                     | 共通単位で表す           |
| 3    | 長方形・正方形の面積公式を考える           | 1cm²の数として見る       |
| 4    | 公式を使い、周りの長さと面積の違いを調べる | 条件の違いを考える       |
| 5    | L字型の図形を分割・補完して求める          | 図形を構成要素で見る     |
| 6    | 教室の面積を求め、m²を知る                 | 大きな面積の単位へ広げる |
| 7    | a、ha、km²を知る                           | 単位の相互関係           |
| 8    | 町の面積を調べ、単位を表に整理する         | 単位体系を整理する       |
| 9    | 縦の長さと面積の関係を表・グラフで見る     | 変化の関係               |
| 10   | 単元を振り返る                             | 算数の目で整理する       |

本時は第6時。長方形の形をした教室の面積の求め方を考え、面積の単位「平方メートル」を知る時間である。

## 追試するなら

この実践を試すときは、先に「同じ時間に何を直接指導し、何を自力で進められるようにするか」を決める。

1. それぞれの教育課程で、本時の核になる見方を決める
2. 直接指導が必要な場面と、自力解決できる場面を分ける
3. 直接指導の時間が重ならないように、導入・自力解決・共有・まとめをずらす
4. 自力解決中に見返せる手順、既習事項、ワークシートを用意する
5. 教師がわたる前に、次に何をすればよいかを明確にする
6. 戻ってきたときに、考えたことを説明できるようにしておく

「先生がいない時間」を空白にしないことが重要である。その時間に子どもが何を考え、何を記録し、どこまで進めばよいのかが見えている必要がある。

## 手立て

### 既習事項を想起させる

重さでは、長さやかさで「基にする量を決めて、何こ分で表した」ことを思い出させる。グラムやキログラムに入る前に、任意単位で表す経験を置くことで、共通単位の必要性が見えやすくなる。

面積では、長さ・かさ・重さにも大きな量を表す単位があったことを想起させる。1cm²からm²へ進むとき、「大きな広さを表す単位が必要になる」という見通しをもてるようにする。

### 類推で単位を広げる

指導案では、「長さやかさと同様に」「重さと同様に」「数直線の読み方を想起させる」といった支援が繰り返し出てくる。

これは、単位の学習を孤立した知識として扱わず、すでに学んだ量の単位から類推して考えさせる設計である。

例：

- 長さにも単位がある。かさにも単位がある。では重さにも単位があるのではないか。
- 1kgは1000g。では1tは1000kgと考えられないか。
- はかりの目盛りも、数直線の読み方と似ているのではないか。
- 1cm²で面積を表せる。では教室の広さはもっと大きな単位で表せないか。

### 具体物から共通単位へ進む

重さでは、文房具、積み木、1円玉、自作天びんなど、具体物を使って比べる。面積では、花壇の設計図、1cm²、教室の面積など、具体的な場面から広さを考える。

具体物や生活場面から入り、任意単位、共通単位、公式へ進むことで、単位が「覚える記号」ではなく「比べるために必要な道具」として理解されやすくなる。

### わたり・ずらしを前提に教材を置く

複式指導では、教師が常にそばにいることはできない。そのため、自力解決に入る前に、次のような足場が必要になる。

- 何を考えるかがわかる課題
- 既習事項を思い出せる掲示やノート
- 手順が見えるワークシート
- 考えを書き残せる欄
- 戻ってきた教師に説明できる形

教師が別の教育課程へ「わたって」いる間も、子どもが学習を続けられるようにする。

## うまくいかないときの支援

| 困りごと                   | 支援                                                           |
| -------------------------- | -------------------------------------------------------------- |
| 教師がいない間に手が止まる | 次にすることを1つずつ見える形にしておく                        |
| 任意単位の意味がつかめない | 積み木や1円玉で「何こ分」を実際に数える                        |
| グラムが突然の記号になる   | 任意単位では人によって違うことを確認し、共通単位の必要性を出す |
| m²がcm²とつながらない      | 1cm²で表した経験を振り返り、「教室なら何を基にするか」と問う   |
| 公式だけを使ってしまう     | 1cm²や1m²がいくつ分かという意味に戻す                          |
| 複式の一方だけが進む       | 直接指導が必要な山場が重ならないように活動をずらす             |

## この実践の意味

この実践は、個別支援級の複式算数を「仕方なく分けて進める授業」としてではなく、複数の学びが同時に進む授業として設計しようとしている。

教師がすべての時間を直接指導に使えないからこそ、既習事項、問い、ワークシート、具体物、見通しが重要になる。子どもが一人で考える時間は、放置ではなく、設計された余白になる。

重さと面積は別の単元だが、どちらも「何を基にして比べるか」「どの単位で表すか」「単位どうしはどう関係するか」という同じ構造をもっている。この共通構造を意識すると、複式指導の中でも算数の深い見方を育てることができる。

## 参観の視点

- わたり・ずらしによって、直接指導と自力解決の時間が有効に分かれていたか
- 教師がいない時間にも、児童が何を考えればよいか分かる足場があったか
- 既習事項を想起させる問いは、新しい単位や公式への見通しにつながっていたか
- 重さや面積を、具体物・任意単位・共通単位・公式へと段階的に理解できていたか
