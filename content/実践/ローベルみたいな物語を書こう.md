# ローベルみたいな物語を書こう

> アーノルド・ローベルの物語構造を借りて書き換え、友達との交流を通して物語の構想を広げる作文実践。

## 実践の概要

小学校3年生の国語科単元。アーノルド・ローベルの『ズボンつり』をもとに、物語の構造を借りてパロディ作文を書く。

2年生で『お手紙』を学んだ経験を生かし、子どもたちに馴染みのあるローベル作品を学習材料にする。原作の構造をそのまま借りて書き換えることで、遊び感覚で楽しみながら、自然にストーリーの組み立て方や表現技法を身につけられるようにする。

## 単元の目標

- 「初め」「中」「終わり」の組み立てを使い、物語の構成を考えることができる
- 場面の様子や人物の気持ちを詳しく書いたり、会話文を入れたりして、想像したことをもとに物語を書くことができる
- 文字や句読点の位置、文章表現に気をつけながら、推敲することができる

## 追試するなら

この実践を試すときは、「ローベル作品を読ませる授業」ではなく、**ローベル作品の構造を借りて、自分の物語を書く授業**として設計する。

まず原作を読み、どのような順番で出来事が進んでいるかを短く確認する。次に、その構造を残したまま、登場人物、困りごと、出来事、結末を入れ替えて、自分の物語にしていく。

### 準備するもの

- 原作として使うローベル作品（指導案では『ズボンつり』）
- 原作の流れを整理した構成表
- 子ども用の物語構成表
- 物語作りを助ける質問のワークシート
- 交流会で使う「相談したいこと」欄
- 教師のモデル作品、または教師が途中まで作った構成表

### 7時間で行う場合の例

| 時間 | 主な活動                                       | ねらい                               |
| ---- | ---------------------------------------------- | ------------------------------------ |
| 1    | ローベル作品を読み、物語の流れを確認する       | 原作の構造をつかむ                   |
| 2    | 自分の物語の登場人物、困りごと、出来事を考える | 書き換えの材料を集める               |
| 3    | 交流会をして、構成表を手直しする               | 友達の助言で構想を広げる             |
| 4    | 下書きを書く                                   | 構成表を文章にする                   |
| 5    | 会話文、気持ち、様子の描写を加える             | 表現を詳しくする                     |
| 6    | 推敲する                                       | 文章表現、句読点、読みやすさを見直す |
| 7    | 作品を読み合う、紹介する                       | 書き手としての達成を共有する         |

時間数は固定ではない。短く行うなら、1〜3時間目を中心にして「構造を借りて構成表を書く」ところまでを試すだけでもよい。

## 手立て

### 書き換え（パロディ作文）

『ズボンつり』の物語構造を借りて、別の内容へ書き換える。まったく自由に創作するのではなく、原作の構造を足場にすることで、物語の組み立て方や表現の技法を使いやすくする。

### 物語作りを助ける質問

物語を作るために何を考えればよいかを支える質問のワークシートを用意する。子どもが「何を書けばよいか」で止まらないように、構想を広げるための問いを外部化しておく。

質問は、自由に発想させるためだけでなく、原作の構造に戻るための足場として使う。

例：

- 主人公はだれですか
- 主人公は何に困っていますか
- だれが助けようとしますか
- どんなことをして、うまくいきませんか
- 途中でどんな会話を入れますか
- 最後はどうなりますか
- 友達に相談したいところはどこですか

### 事前の準備

書き手は、交流会の前に相談したいところを明確にしておく。物語作りを助ける質問の中に「相談したいこと」を尋ねる問いを入れ、友達からの助言が作品の手直しにつながるようにする。

「全部見てください」ではなく、「ここで困っています」と言えるようにしておく。たとえば、「終わり方が決まらない」「会話文をどこに入れたらよいか迷っている」「主人公の困りごとが弱い気がする」のように、相談の焦点を一つ持たせる。

## 本時の位置づけ

本時は全7時間中の3時間目。目標は、交流会で物語の構想を広げ、参考になった意見を反映させて構成表を手直しすること。

## 本時の流れ

1. 前時までのことを振り返る
2. 本時のめあてを確認する
3. 教師のモデルから、交流会のイメージを持つ
4. 交流会をする
5. 交流会を振り返り、構成表を手直しした人から下書きをする

教師は、前時までのことを振り返らせることで本時のめあてを意識させる。交流会の前には教師がモデルを示し、どのように相談し、どのように助言するのかを具体的に見せる。助言が出にくい場合は、質問やよかったところがないかを声かけする。

### 交流会の進め方

追試しやすくするなら、交流会は短い型にしておく。

1. 書き手が、物語の構成表を見せる
2. 書き手が、相談したいことを一つ言う
3. 聞き手は、まず「よいと思ったところ」を一つ言う
4. 聞き手は、相談されたことについて質問や提案を一つ言う
5. 書き手は、参考になったことを構成表にメモする

教師のモデルでは、よい助言だけでなく、助言しにくいときの言い方も見せる。

例：

- 「ここが面白いと思いました」
- 「主人公がどうして困っているのか、もう少し知りたいです」
- 「最後にもう一つ出来事を入れると、終わり方が分かりやすくなると思います」
- 「会話文を入れるなら、この場面がよさそうです」

### うまくいかないときの支援

| 困りごと                 | 支援                                                                         |
| ------------------------ | ---------------------------------------------------------------------------- |
| 物語を思いつけない       | 原作の登場人物だけを入れ替えるところから始める                               |
| 構成がばらばらになる     | 原作の「初め・中・終わり」と並べて確認する                                   |
| 交流会で助言が出ない     | 「よかったところ」「もっと知りたいところ」「困っていそうなところ」の順に聞く |
| 相談したいことが言えない | 教師が「終わり方、会話、主人公、困りごとのどれを相談したい？」と選択肢を出す |
| 助言を受けても直せない   | 参考になった意見を一つだけ選ばせ、構成表のどこを変えるか印をつける           |

## この実践の意味

この実践は、単なる作文交流ではなく、類推的学習を土台にした物語創作の実践である。原作の構造を借りることで、子どもはゼロから創作する負荷を減らしながら、物語の構成や表現の工夫を試すことができる。

また、交流会の前に「相談したいこと」を明確にするため、ピアフィードバックが感想の交換で終わりにくい。書き手が自分の困りごとや試したいことを持ち、聞き手がそれに応じて助言する構造になっている。

## 参観の視点

- 事前に相談したいことを明確にすることは、作文の構想を交流し合う学習で効果的であったか
- 作文の構成や下書きを友達と交流し合う授業で大切なこと、工夫には他にどんなものがあるか
- パロディ作文は、物語の構造や表現技法を学ぶ足場として機能していたか
