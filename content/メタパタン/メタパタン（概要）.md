# メタパタン（概要）

> パタンを発見し、検証し、使い続けるための上位の設計思想。

## メタパタンとは

「教育のパタン・ランゲージ」における**メタパタン**は、個別のパタン（解決策の記述）を生み出すための**原理・思考様式**である。教育実践からパタンを発見し、それを検証し、共有するための根本的な方法論を示す。

牧口常三郎の教育探求をパタン・ランゲージ・アブダクション・因果推論という現代的レンズで読み解くことから、この層は生まれた。

## メタパタンの二つの種類

| 種類 | 役割 | 該当 |
|---|---|---|
| **タイプA（エンジン）** | パタンを発見し・検証し・設計するための原理。パタン活動そのもののメタ原理 | 発見・検証・設計規準の各メタパタン |
| **タイプB（束ね）** | 複数系譜にまたがるパタン群の共通原理に名前を与えるもの | 非知の文化 など |

新しいメタパタンを立てるときは「①3系譜以上にまたがるか ②既存の束ね（緊張関係マップ・近いパタンの違い・ハブパタン）で代替できないか ③パタンの設計・読み方を実際に変えるか」の3条件を課す（乱立への歯止め）。

## 牧口の研究法との対応（『創価教育学体系Ⅰ』p.89）

牧口は「教育学の研究法」として真理探究の一般過程を定式化した。この層のエンジン構造は、その過程の現代的展開に正確に対応している：

| 牧口の過程（体系Ⅰ p.89） | 対応するメタパタン |
|---|---|
| 観察の三方面（迎観・縦観・統観） | [[メタパタン/経験から出発する]]（観察方法論として記載） |
| （一）（A）偶然の成功の記録——目立つ結果の認識→原因の分析的観察 | [[メタパタン/アブダクション（仮説形成）]]（教師の研究の型） |
| （一）（B）堪能者の成功の観察と特殊の原因の考察 | [[メタパタン/アブダクション（仮説形成）]]（帰納の第二の源泉。文献ingestの理論的根拠） |
| （一）（C）因果律に基づく総合的概念 | パタンの記述そのもの |
| （二）学問の生活化——演繹的考察・法則の実験的証明 | [[メタパタン/反事実（因果推論）]]（共時的検証）＋次の実践での試行 |
| （三）進化論的考察——歴史的考察による妥当性論証 | [[メタパタン/反事実（因果推論）]]に通時的検証として記載。Pattern Connectionの思想史接続が実践形 |
| （四）真理の批判的考察——生活上の価値の判断 | [[メタパタン/価値を目標とする]]（探究サイクルの出口の門） |

## パタン発見のサイクル

```
経験（現場）── 観察の三方面：迎観・縦観・統観
  ↓  ← アブダクションでパタンを見出す（自分の驚き＋堪能者の観察）
仮説（パタン候補）── 非知に留まってから跳ぶ（名づけを急がない）
  ↓  ← 他の場で試す（介入）
検証（再現）
  ↓  ← 反事実で因果を確かめ、思想史との接続で通時的に確かめる
パタン（記述・共有）
  ↓  ← 価値に照らして吟味
経験（現場に戻る）
```

このサイクルは一方通行ではなく、常に経験と理論のキャッチボールである。
