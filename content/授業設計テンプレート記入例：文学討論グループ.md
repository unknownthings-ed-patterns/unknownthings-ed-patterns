# 授業設計テンプレート記入例：文学討論グループ

[[授業設計テンプレート]] を、[[実践/文学討論グループの設計]] に沿って記入した例。

## 授業の概要

| 項目                 | 記入例                                                           |
| -------------------- | ---------------------------------------------------------------- |
| 教科・単元           | 国語・文学作品を読んで話し合う                                   |
| 学年・対象           | 小学校中学年〜高学年                                             |
| 時間                 | 1時間                                                            |
| 今日の中心概念       | 読みは、根拠と他者の見方によって深まる。                         |
| 今日のゴール         | 作品への自分の考えを、本文の根拠と友だちの意見を使って書き直す。 |
| 子どもに残したい経験 | 話し合うことで、自分一人では出なかった読みが生まれるという経験。 |

## 1. 育てたいこと

- 育てたい力・姿：本文を根拠にしながら、他者の読みを受けて自分の考えを更新する力。
- 関係する目標：[[目標から探す]]
- 使う大パタン：
  - [[パタン/深い理解（3水準の読解）]]
  - [[パタン/熟慮的問い]]
  - [[パタン/聴き合う文化]]
  - [[パタン/フィードバック]]

## 2. 導入

| 観点                           | 記入例                                                                  |
| ------------------------------ | ----------------------------------------------------------------------- |
| 最初に子どもがすること         | 今日の問いを読み、自分の立場を短くメモする。                            |
| 必要感・切実性                 | 「同じ作品でも読み方が分かれる」ことを示し、話し合う理由を作る。        |
| 見通し・ルール・ゴールの可視化 | 問い、話し合いの順番、最後に書き直すことを板書する。                    |
| 小さな成功体験                 | まず全員が30秒で自分の考えを話す。                                      |
| 使うパタン                     | [[パタン/オンボーディング]] · [[パタン/可視化]] · [[パタン/熟慮的問い]] |

## 3. 活動

| 観点               | 記入例                                                                             |
| ------------------ | ---------------------------------------------------------------------------------- |
| 中心活動           | 3〜5人で、教師が用意した第3水準の問いについて話し合う。                            |
| 教材・道具         | 作品本文、問いカード、根拠メモ、話し合い後の書き直し欄。                           |
| 活動の順序         | 個人メモ → 全員発言 → 自由討論 → 印象に残った発言の記録 → 自分の考えの書き直し。   |
| 個別差への対応     | 話すのが苦手な子は本文の一文を指してから話す。早い子には反対意見の根拠を探させる。 |
| 子どもが選べること | 取り上げる根拠、反応したい友だちの意見、最後に書き直す観点。                       |
| 使うパタン         | [[パタン/文学討論グループ]] · [[パタン/ブッククラブ]] · [[パタン/段階的手放し]]    |

## 4. 共有・対話

| 観点               | 記入例                                                                      |
| ------------------ | --------------------------------------------------------------------------- |
| 共有するもの       | 立場、本文の根拠、友だちの発言で考えが変わった点。                          |
| 取り上げたい考え   | 同じ根拠から違う読みが生まれている発言。                                    |
| 問い返し           | 「どの言葉からそう考えた？」「友だちの意見で変わったところは？」            |
| 聴き合うための支え | 話し手を見る、本文を指す、同じ・違う・付け足しで反応する。                  |
| 使うパタン         | [[パタン/聴き合う文化]] · [[パタン/問い返しのデザイン]] · [[パタン/可視化]] |

## 5. 振り返り・評価

| 観点                   | 記入例                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| 子どもが記録すること   | 最初の考え、話し合いで印象に残った発言、書き直した考え。                                    |
| 教師が見取ること       | 本文の根拠を使っているか。他者の意見を受けて読みが深まっているか。                          |
| 次の一手につながる情報 | 根拠は出せるが解釈が浅い子、意見は言えるが本文に戻れていない子。                            |
| 残す作品・記録         | 個人メモ、話し合い後の書き直し、教師の観察メモ。                                            |
| 使うパタン             | [[パタン/形成的評価]] · [[パタン/自己内フィードバック]] · [[パタン/ポートフォリオファイル]] |
