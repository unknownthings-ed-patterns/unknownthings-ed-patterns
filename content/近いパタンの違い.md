# 近いパタンの違い

似ているパタンを見分けるためのページ。どれを使うか迷ったときは、まず「何を変えたいのか」を見る。

## 教材・表現まわり

| 迷いやすい組み合わせ | 見分け方 | 選ぶ基準 |
| --- | --- | --- |
| [[パタン/可視化]] / [[パタン/シグニファイアアフォーダンス]] / [[パタン/マルチモダール]] | 可視化は「見えないものを見えるようにする」。シグニファイアアフォーダンスは「教材や環境が何をすればよいかを示す」。マルチモダールは「複数の感覚チャンネルで届ける」。 | 目標・状態・成長を見せたいなら可視化。行動を迷わせたくないならシグニファイアアフォーダンス。言葉だけで届きにくいならマルチモダール。 |
| [[パタン/作業例の提示]] / [[パタン/ルーブリック]] / [[パタン/達成規準の共同構築]] | 作業例は「できあがりや途中過程を見る」。ルーブリックは「よさの段階を基準化する」。共同構築は「基準を学習者と一緒に作る」。 | まずイメージを持たせるなら作業例。評価を透明にするならルーブリック。基準への納得を作るなら共同構築。 |
| [[パタン/作ることで学ぶ]] / [[パタン/表現して学ぶ]] / [[パタン/パフォーマンス課題]] | 作ることで学ぶは「制作プロセスで理解する」。表現して学ぶは「表現を思考の道具にする」。パフォーマンス課題は「現実に近い課題で総合的に使う」。 | 作品づくりを通して理解したいなら作ることで学ぶ。考えを外に出したいなら表現して学ぶ。評価まで含めた課題にするならパフォーマンス課題。 |

## 評価・改善まわり

| 迷いやすい組み合わせ | 見分け方 | 選ぶ基準 |
| --- | --- | --- |
| [[パタン/形成的評価]] / [[パタン/フィードバック]] / [[パタン/自己内フィードバック]] | 形成的評価は「途中で見取り、調整する」。フィードバックは「ゴール・現在地・次の一手を返す」。自己内フィードバックは「学習者が自分で照合する」。 | 教師が授業を変えたいなら形成的評価。学習者へ改善情報を返すならフィードバック。自分で改善できる力を育てるなら自己内フィードバック。 |
| [[パタン/ピアフィードバック]] / [[パタン/フィードバック文化]] / [[パタン/聴き合う文化]] | ピアフィードバックは「学習者同士の具体的な返し合い」。フィードバック文化は「返し合うことが当たり前の文化」。聴き合う文化は「相手の考えを受け取る基盤」。 | 一回の活動を設計するならピアフィードバック。継続的な習慣にするならフィードバック文化。まず聞ける場を作るなら聴き合う文化。 |
| [[パタン/ポートフォリオファイル]] / [[パタン/自己記録]] / [[パタン/ドキュメンテーション]] | ポートフォリオは「作品や成長の蓄積」。自己記録は「自分で行動や学習を記録する」。ドキュメンテーションは「学びの過程を記録して共有する」。 | 成長を振り返りたいならポートフォリオ。習慣や進み具合を見たいなら自己記録。過程を他者と見たいならドキュメンテーション。 |

## 導入・足場まわり

| 迷いやすい組み合わせ | 見分け方 | 選ぶ基準 |
| --- | --- | --- |
| [[パタン/オンボーディング]] / [[パタン/スモールステップ]] / [[パタン/足場がけへの誘発]] | オンボーディングは「活動の土台に乗せる」。スモールステップは「課題を小さく刻む」。足場がけへの誘発は「解決の道具や支援へ向かわせる」。 | 最初に参加できないならオンボーディング。難しすぎるならスモールステップ。支援を使えるようにしたいなら足場がけへの誘発。 |
| [[パタン/先行オーガナイザー]] / [[パタン/見てから聞く]] / [[パタン/作業例の提示]] | 先行オーガナイザーは「理解の枠組みを先に示す」。見てから聞くは「視覚情報を先に置く」。作業例は「実際のやり方や出来を示す」。 | 概念の地図が必要なら先行オーガナイザー。説明が流れてしまうなら見てから聞く。手順が分からないなら作業例。 |
| [[パタン/安心基地]] / [[パタン/心理的安全性（コンフォートゾーン）]] / [[パタン/成長マインドセット]] | 安心基地は「戻れる関係や場」。心理的安全性は「失敗や未完成を出せる空気」。成長マインドセットは「能力は伸びるという信念」。 | 個別の不安を支えるなら安心基地。クラス全体の発言や挑戦を支えるなら心理的安全性。失敗の意味づけを変えたいなら成長マインドセット。 |

## 問い・対話まわり

| 迷いやすい組み合わせ | 見分け方 | 選ぶ基準 |
| --- | --- | --- |
| [[パタン/熟慮的問い]] / [[パタン/深める問い]] / [[パタン/問い返しのデザイン]] | 熟慮的問いは「問い全体を目的・相手・文脈から設計する」。深める問いは「思考を一段深くする」。問い返しのデザインは「発言を受けて次の思考へつなげる」。 | 授業前に問いを設計するなら熟慮的問い。問いの質を深めたいなら深める問い。授業中の応答を考えるなら問い返しのデザイン。 |
| [[パタン/発問を問いにしない]] / [[パタン/駆動質問]] / [[パタン/問いを整理する]] | 発問を問いにしないは「教師の問いが学習者の思考を狭める危険を見る」。駆動質問は「探究を動かす中心の問い」。問いを整理するは「出てきた問いを扱える形に整える」。 | 教師主導が強すぎるなら発問を問いにしない。単元を動かすなら駆動質問。問いが散らばるなら問いを整理する。 |
