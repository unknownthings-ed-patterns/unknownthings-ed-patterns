# つながり反映テンプレート

関連パタン・実践・概念・文献へのリンクを本文に反映するときの書き方。

候補をそのまま足すのではなく、関係が読める短い説明を添える。

## 関連パタン欄に足す

```markdown
## 関連パタン

- パタンページへのリンク — 前提: このパタンが働く前に必要な土台になる。
- パタンページへのリンク — 補完: こちらが○○を支え、相手ページが△△を具体化する。
- パタンページへのリンク — 対比: こちらは○○を扱い、相手ページは△△を扱う。
- パタンページへのリンク — 発展: こちらを広げると、相手ページのより大きな実践につながる。
```

## 実践ページへ足す

```markdown
## 圧縮されているパタン

- パタンページへのリンク — 実践化: この実践の中では、○○の場面で働く。
```

## 概念ページへ足す

```markdown
## 関連するパタン

- パタンページへのリンク — 抽象化: このパタンは、○○という概念を授業場面に落としたもの。
```

## 文献ページへ足す

```markdown
## この文献から生まれたパタン

- パタンページへのリンク — 出典: この文献の○○という議論から補強される。
```

## 近いパタンの違いを書く

```markdown
## 近いパタンとの違い

- パタンページへのリンク — 対比: どちらも○○に関わるが、このパタンは△△を扱い、相手ページは□□を扱う。
```

## 反映前チェック

- リンク先のページ名が現在名になっている。
- 既存の関連パタン欄と重複していない。
- 「似ている」だけでなく、前提・補完・対比・発展・実践化・抽象化・出典のどれかが説明されている。
- 新規パタンを作る前に、既存ページへ吸収できるか確認している。
