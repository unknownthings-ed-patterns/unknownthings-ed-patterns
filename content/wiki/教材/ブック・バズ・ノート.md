# ブック・バズ・ノート

> 読んだ本について、短い問いと答えを準備し、本の魅力を仲間に紹介するための読書紹介ノート。

## 教材の概要

ブック・バズは、本の魅力や読んで考えたことを短く紹介し合う活動である。

このノートは、ブック・バズの前に、紹介する本の基本情報、評価、質問、答え、自己評価を整理するための教材である。単なる読書カードではなく、「どんな問いで本を紹介するか」「その問いにどう答えるか」を準備する点に特徴がある。

## 使う場面

- 読んだ本を友だちに短く紹介する前に使う
- フィクションとノンフィクションで、紹介の問いを選び分ける
- 本の評価やおすすめしたい理由を準備する
- ブック・バズのあとに、紹介の手応えを自己評価する
- クラスの中で、本のおすすめがめぐる読書文化をつくる

## ノートの基本項目

| 項目 | 役割 |
|------|------|
| 本の題名 | 紹介する本を明確にする |
| 評価 | 星の数で自分の読みを表す |
| フィクション／ノンフィクション | 本の種類を意識する |
| 作者 | 作者にも目を向ける |
| ページ | 読んだ範囲や本の量を記録する |
| 質問 | ブック・バズで話す焦点を決める |
| 答え | 自分の読みを準備する |
| 今日のブック・バズ自己評価 | 紹介の手応えを振り返る |

自己評価は、原資料では「すばらしい」「まあまあ」「ふつう」「がんばろう」の4段階で示されている。

## フィクションの質問例

- どんな問題がお話の中に起きましたか。どのようにその問題が解決されると予想しましたか。
- 登場人物や出来事と、自分の生活にはどのようなつながりがありますか。
- どの登場人物が最も興味深かったですか。その登場人物について説明し、なぜ惹かれるのかを書きましょう。
- もしお話の中の登場人物に会うことができたら、友だちになりたいと思いますか。それはなぜですか。
- その数の星で評価したのはなぜですか。
- あなたはその本を他の人におすすめしたいですか。それはなぜですか。

## ノンフィクションの質問例

- なぜその本を選んだのですか。よい選書でしたか。説明しましょう。
- 本の情報と、あなたが知っていることを比べるとどうですか。
- この本から学んだことで、あなたの生活に影響を与えるかもしれないことは何ですか。
- この本から学んだ最も興味深いことは何ですか。
- あなたはこの本をおすすめしたいですか。なぜですか。

## 低学年・読み始めの子に使いやすい質問

- いつ、どこで起きたお話ですか。
- 主人公は誰ですか。
- 一番好きな登場人物は誰ですか。なぜですか。
- どの挿絵や写真が最も好きですか。
- どの場面が一番好きですか。
- その物語の終わり方について、どう感じましたか。
- そのお話について最も記憶に残っていることは何ですか。
- 他の人もこの本を読んだほうがいいと思いますか。なぜですか。
- 同じ作者の違う本を読みたいですか。なぜですか。

## 高学年・読み慣れた子に使える質問

- 主人公について、困ったところや本当に好きなところを一つ選びましょう。なぜそう感じましたか。
- その本の中で起きる最も大きな問題は何ですか。それはどのように解決されると思いますか。
- 脇役を一人選び、なぜその登場人物が作られたのか説明しましょう。その人物がいなかったら物語はどう変わりますか。
- 設定について説明しましょう。その設定は物語にとって重要ですか。別の場所に変えても物語は成り立ちますか。
- 主人公の動機は何だと思いますか。なぜそう考えますか。
- クライマックスはどこですか。そこがクライマックスだと、どのように分かりましたか。
- この本にはテーマがあると思いますか。作者は読み手に何を伝えようとしているのでしょうか。
- 登場人物を三つの形容詞で説明しましょう。自分や家族と比べると、何が似ていて何が違いますか。
- 作者が使っている技法の例を探しましょう。たとえば回想、伏線、ユーモアなどです。
- 同じ作者の別の本を読んだことがあるなら、似ているところや違うところを比べましょう。

## 追試するなら

最初は、質問を1つだけ選ばせる。

たとえば低学年なら、「どの場面が一番好きですか」「他の人におすすめしたいですか」のように答えやすい問いから始める。高学年なら、「この本のテーマは何だと思うか」「主人公の動機は何か」など、解釈を必要とする問いを選ぶ。

ブック・バズの時間は短くてよい。1人1分でも、本の題名、星の数、選んだ質問と答え、おすすめしたい相手を話せれば、読書がクラスの中で動き始める。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| あらすじ紹介だけになる | 「質問」と「答え」を一つ決め、本の魅力や考えたことに焦点を移す |
| 長く話しすぎる | 題名、星、質問、答え、おすすめの順に絞る |
| 質問を選べない | 教師が3つだけ候補を示す |
| おすすめの理由が浅い | 「その星の数にした理由は？」と聞く |
| フィクションとノンフィクションが混ざる | 本の種類を先にチェックし、質問の種類を変える |
| 紹介後に振り返らない | 「今日のわたしのブック・バズ」を4段階で自己評価する |

## この教材の意味

ブック・バズ・ノートは、読んだ本を「読んで終わり」にしないための道具である。

本を紹介するには、自分がその本をどう読んだのかを一度整理する必要がある。どの問いで語るかを選び、星の数で評価し、答えを準備することで、読みが短いメッセージにまとまる。

ブック・バズが日常化すると、子どもたちは本を選ぶときに友だちの紹介を手がかりにするようになる。本が個人の持ち物から、クラスの中をめぐる文化資源へ変わっていく。
