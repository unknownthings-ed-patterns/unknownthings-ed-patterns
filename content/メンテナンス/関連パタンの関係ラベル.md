# 関連パタンの関係ラベル

関連パタンは、ただ近いページを並べるだけでなく、「どのような関係で近いのか」を短く添える。リンクを思考地図として使うためのラベル。

## 基本ラベル

| ラベル | 意味 | 書き方の例 |
|---|---|---|
| 前提 | そのパタンが働く土台になる | `[[パタン/安心基地]] — 前提: 挑戦する前に必要な安全感` |
| 補完 | 一緒に使うと働きが強まる | `[[パタン/フィードバック文化]] — 補完: 個別フィードバックを文化に広げる` |
| 対比 | 似ているが、問題設定や使う場面が違う | `[[パタン/評定（成績評価）]] — 対比: 学習を支える評価か、成績を決める評価か` |
| 発展 | より大きい・複雑な実践へ広げる | `[[パタン/ブッククラブ]] — 発展: 個の読書から共同の読書へ広げる` |
| 実践化 | 抽象的な考えを具体的な授業手順にする | `[[実践/文学討論グループの設計]] — 実践化: パタンを授業構造に落とす` |
| 抽象化 | 実践や個別パタンの背後にある概念へ上げる | `[[概念/教育思想の系譜]] — 抽象化: 実践の思想的背景を捉える` |
| 出典 | 文献から抽出・補強された関係 | `[[文献/Experience and Education（Dewey）]] — 出典: 経験の質を考える根拠` |

## 迷ったとき

| 迷い | 優先するラベル |
|---|---|
| 一緒に使うとよい | 補完 |
| 順番がある | 前提、発展 |
| 違いを示したい | 対比 |
| 文献から来た | 出典 |
| 実践ページへつながる | 実践化 |
| 概念ページへつながる | 抽象化 |

## 判断基準

| ラベル | こういうとき使う |
|---|---|
| 補完 | 片方が場・方法・支えをつくり、もう片方の働きが強まるとき |
| 対比 | 似ているが、設計対象・問題設定・使う場面を分けておくと読みやすいとき |
| 発展 | 一方を入口にして、より広い実践・深い理解・複雑な活動へ進むとき |
| 出典 | 同じ文献や著者から関係を説明でき、本文の根拠を文献に戻せるとき |

## 実例

| 関係 | ラベル | 判断の理由 |
|---|---|---|
| [[パタン/熟慮的問い]] ↔ [[パタン/豊かな課題]] | 対比 | どちらも思考を深める入口だが、片方は問いの設計、片方は課題空間の設計を扱う |
| [[パタン/リーディング・ワークショップ]] ↔ [[パタン/読書アイデンティティ]] | 補完 | ワークショップは読者として育つ場をつくり、読書アイデンティティはそこで育つ自己像を説明する |
| [[パタン/読書パートナーシップ]] ↔ [[パタン/読書アイデンティティ]] | 補完 | パートナーとの継続的な読書対話が、読者としての自己像を相手との関係の中で育てる |
| [[パタン/シンクアラウド]] ↔ [[パタン/背景知識]] | 補完 | 背景知識は読解の素材であり、シンクアラウドはその素材が読みの中でどう使われるかを見える化する |
| [[パタン/タウマゼイン（驚きから始まる探究）]] ↔ [[パタン/エピステーメーとドクサ（知識と正しい考え）]] | 発展 | 驚きから始まった探究が、思い込みと知識を区別する知の吟味へ進む。入口と到達点があり、順序をもって読むと導線が強くなる |
| [[パタン/読書パートナーシップ]] ↔ [[パタン/レターエッセイ（Letter-Essay）]] | 発展 | 口頭で本について語り合う経験が、手紙による往復対話へ広がる |
| [[パタン/タウマゼイン（驚きから始まる探究）]] ↔ [[パタン/アポリアの設計]] | 発展 | 驚きが、知っているつもりを揺さぶる「分からなさ」へ深まる |
| [[パタン/リーディング・ワークショップ]] ↔ [[パタン/レターエッセイ（Letter-Essay）]] | 発展 | ワークショップでの読書体験が、手紙として書かれ、対話として残る |

## 関連パタン欄の型

```markdown
## 関連パタン

- パタンページへのリンク — 前提: なぜ土台になるか
- パタンページへのリンク — 補完: どう一緒に働くか
- パタンページへのリンク — 対比: 何が違うか
- パタンページへのリンク — 発展: どこへ広がるか
- 実践ページへのリンク — 実践化: どの授業手順になるか
- 概念ページへのリンク — 抽象化: どの概念に接続するか
- 文献ページへのリンク — 出典: どの根拠から来たか
```

## 運用ルール

- 既存の関連パタンを一度に全部ラベル化しなくてよい。新しく足すリンクからラベルを添える。
- 自動逆参照で追加されたリンクは、まずはラベルなしでもよい。後で重要なものからラベルを足す。
- `関連パタン` 欄には、似ているページだけでなく、前提・補完・対比・実践化の関係を残す。
- 文献ページでは「この文献から生まれたパタン」に `出典` や `発展` を使う。
