# 読書への情熱を育てる実践集

Layne, S. L.（2009）*Igniting a Passion for Reading* に基づく、**読む意志（WILL）を育てる年間を通じた実践の設計ガイド**。読む技術（SKILL）の指導と並行して、「読みたくなる」ための環境・関係・体験を計画的に積み上げる。

## 全体構造：四半期計画

WILLを育てる実践を「なんとなく」ではなく、年間4つの時期に分散して計画する。

| 四半期 | 時期（目安） | 主な実践 |
|---|---|---|
| **第1四半期** | 4〜6月（年度初め） | 興味調査（Initial Self-Assessment）・読書ラウンジ・Hot Read Sign・Reading Log・Status of Class・ブック・チャット開始 |
| **第2四半期** | 7〜9月 | 本を祝う実践（Golden Rec Shelf・First Read Club・Read Arounds・YA Café・Genre Breaks）・Buzz About Books |

## 実践①：興味調査（Interest Inventory）

### 目的

「この子に合う本を薦める根拠」を年度初めに収集する。読書の好みではなく**生活全体の興味**から入る。

### 調査票の例

```
名前：___________  日付：___________

1. 好きなスポーツ・習い事は何ですか？
2. 放課後に何をして過ごすことが多いですか？
3. 好きなテレビ・アニメ・映画は？
4. 最近ハマっていることは？
5. 将来の夢は何ですか？
6. 一番好きな科目は？ 一番苦手な科目は？
7. 家族の中で一番仲が良いのは誰ですか？
8. ペットはいますか？どんな動物が好きですか？
9. 「知りたい！」と思っていることは？（不思議に思うこと・疑問）
10. 前に読んで面白かった本があれば書いてください
```

### 使い方

- 調査結果を**ブック・チャットの地図**として手元に置く
- 「サッカーが好き」→「熱血スポーツ小説」を準備
- 「昆虫が好き」→「昆虫の図鑑・科学絵本」を準備
- 「将来の夢が料理人」→「食にまつわる物語・料理の科学」を準備

### タイミング

- 年度初め（4月最初の1週間以内）に実施する
- 必要に応じて11月頃に「今の興味」の更新調査を行う（子どもの興味は変わる）

## 実践②：読書ラウンジ（Reading Lounge）の設計

### 目的

「読書は特別な体験だ」を空間で伝える。快適な読書環境が「読む時間は気持ちいい」という連合を作る。

### 基本設計

教室の一角（壁側の2〜3㎡）を読書ラウンジとして整備する：

| 要素 | 具体的な方法 |
|---|---|
| **座る場所** | 低めのソファ・クッション・マット——椅子とは違う座り方 |
| **明るさ** | 窓際を活用する。照明を柔らかくする（可能なら） |
| **音** | 静かな場所。仕切りになる本棚やパーティション |
| **本棚** | 「おすすめの本」「今月の特集」などの小さな展示コーナー |
| **名前** | 子どもと一緒に「このコーナーの名前」を決める——当事者性が愛着を生む |

### 使い方のルール

- 人数制限（3〜4人まで）を設けて「特別感」を維持する
- 順番に使う機会を設ける——「今日は〇班のラウンジの日」
- 持ち込む本は「自分で選んだ本」——課題テキストは持ち込まない

### 日本の教室での工夫

- 専用スペースが取れない場合：1つの机と2つのクッション＋ブックスタンドだけでも「ラウンジ」になる
- 廊下の一角に「読書コーナー」を設けることも可能（学校による）

## 実践③：読み聞かせのパフォーマンス化

Layne は読み聞かせを「技芸（craft）」として位置づける——聴衆を本の世界へ引き込むパフォーマンスとして準備する。

### 準備のチェックリスト

```
□ 本を事前に一度通読する（初見で読まない）
□ 感情の山場・クリフハンガーの場所に付箋を貼る
□ 声のトーンを変える場所を決める（低く・高く・ゆっくり・速く）
□ 顔を上げて子どもを見る場所を決める（2〜3か所）
□ 「止める場所」を決める——最もドラマチックな場面で「続きは明日」
```

### 読み聞かせ中のテクニック

**声の変化：**
- キャラクターごとに声のトーンを変える（同じキャラはいつも同じ声）
- 緊迫した場面：速度を上げ、声量を下げる
- 感動の場面：速度を落とし、間を取る

**表情・視線：**
- 本から顔を上げて子どもを見る（描写の直後が効果的）
- 「次に何が起きるか分かる？」という目で子どもを見る
- 驚いた場面では、自分も「おっ」と声に出す

**クリフハンガーで止める：**
```
「次のページで、ついに主人公は決断を下すのですが……今日はここまで。」
「"扉を開けると、そこには——" 続きはまた明日。」
```

次の日に「続きが気になって仕方ない」状態を作ることが目的。

### 子どもへの選択権

- 月に1〜2回「今日の本、AとB、どっちがいい？」と子どもが選ぶ日を作る
- 「先生のおすすめリスト」から子どもが選んでもいい

## 実践④：教師のモデリングツール

Layne（2009）第5章は「私のモデリング・キャリア」として、教師が「読む人間」として可視化される具体的な道具を紹介する。

**Hot Read Sign と Book Stand**：教師の机に「今読んでいる本のサイン」と Book Stand（本を立てかけるスタンド）を常設。「今日の先生の読んでいる本」がいつも見える——毎日のさりげないモデリング。

**Reading Log**：四半期・タイトル・著者・ジャンル・1〜5評価（星）を記録。教師自身の Reading Log を教室に貼ることで「先生が今学期読んだ本」が全員に見える。

**テキストのプレビュー（Previewing）——9つの領域**：本を読む前に探索するスキルをモデルで示す：①タイトル ②著者・イラストレーター ③献辞 ④前カバー ⑤表紙の絵 ⑥CIPページ ⑦裏カバー ⑧章タイトル ⑨内部の図版

**Someday Book List（低学年向け）**：「いつか読みたい本」のタイトル・著者・本がある場所を記録。次の図書館ショッピング時に参照する。

**Books to Consider（高学年向け）**：4セクション——ショッピング中に見つけた本 / Book Chatで薦められた本 / 友達の推薦 / Read Aroundsで手に取った本。

**Status of the Class（独立読書の冒頭に）**：全員からタイトル・著者・ページ・評価（1〜5）を「稲妻のように速く」収集し、クラス名簿に略記。読書の進捗がクラス全体に可視化される。

## 実践⑤：Book Celebration（本の祭典）

詳細は [[パタン/本を祝う]] を参照。本を「祝う」実践を年間に複数回配置することで、「読書は価値あるものとして扱われている」という文化を制度として作る。

**Golden Recommendation Shelf**：読んで「最高」と思った本だけを置く特別な棚。最初は教師の3冊から始め、"Highly Recommended" ステッカーを貼る。

**First Read Club**：新着本の裏に "This book was First Read by: ___" のラベルを貼り、最初に読んだ人の名前を記録する。

**Read Arounds**：教室中の本を1冊1.5分で回覧。ハードカバーのみ、最大3回ホールド可。「次に読む本探し」として機能する。

**Elementary Café / YA Café**：月1回の朝の会、ホットチョコレート＋ドーナツ。教職員または生徒が本を紹介。任意参加。

**Genre Breaks**：Poetry Break（詩）・Comic Break（漫画）・Magazine Break（雑誌）を突然「今日はジャンル探索デー」として挿入。固定された「読書 = 章のある本」という観念を崩す。

**Picture Book of Month**：月1冊の絵本を教師の机に置き、月末にクラス全員で読む。「絵本は低学年のもの」という誤解を壊す。

**Club Read**：テーマ別（例：アメリカ革命・動物・スポーツ）の本バッグを作り、グループで並行して読む。Buzz About Books の素材になる。

**本の帯コンテスト・読書ポスター・ブック・トレーラー**：
- 本の帯コンテスト：「この本を読みたくさせる一言」を書く——書く技術と読む動機の両方を育てる
- 読書ポスター：キャッチコピー・あらすじ・「この本はどんな人に合う？」を書く
- ブック・トレーラー（高学年向け）：映画予告編のように「本の予告動画」を作る

## 実践⑥：著者研究と著者への手紙

### 目的

「本は人が書いたものだ」という認識を育てる——著者が生きている人間だと感じることで、本が身近になる。

### 進め方（2〜3時間）

**時間1：著者の生涯と作品を調べる**
- 著者の公式サイト・出版社サイト・インタビュー動画
- 「なぜこの本を書いたのか」「子どもの頃どんな本を読んでいたか」を調べる

**時間2：著者への手紙を書く**
- 感謝の手紙（「この本を読んで何が変わったか」を書く）
- 質問の手紙（「この場面はなぜこうしたのか」を聞く）

**返事が来た場合：**
- 教室に掲示する——「著者から手紙が来た」という体験は強烈な動機になる

### 日本語の著者を対象にする場合

- 出版社の問い合わせ窓口経由で手紙を送ることが可能なことがある
- 著者のSNS・ウェブサイトに問い合わせフォームがある場合も

## 実践⑦：年度末の自己評価（Changed Reader Paper）

Layne（2009）第2章が示す「自分の変化を記録する」実践を年度末に行う。

**Initial Self-Assessment（年度初め・緑の紙）**：
「今の自分の読書習慣・好み・読書観」を自己評価。年度初め第1週に実施。

**Final Self-Assessment（年度末・ピンクの紙）**：
同じ質問を年度末に再度行う。2枚を並べることで1年間の変化が可視化される。

**Changed Reader ペーパー（8問・120分）**：
「自分はこの1年でどう変わったか」を書く年度末の振り返りエッセイ。採点なし——「先生との二人だけの手紙」として扱う。質問例：「去年の自分と今の自分の読書の違いは何か」「読書に対する態度は変わったか」。選択で「先生と点数を交換する（trade the grade）」オプションあり。

## 実践⑧：「読む春休み・夏休み」の計画

### 目的

学校を離れた時間にも読書が続くよう、年度末・長期休み前に個別の読書計画を作る。

### 設計

**個別の選書支援（休み前の1週間）：**
- 「春休みに読む3冊」を一人ひとりと選ぶ（カンファリングの時間を使う）
- 「1冊目は薄くて面白いもの・2冊目は中くらい・3冊目は挑戦」という構成を提案

**読書目標カード：**
```
春休みの読書計画

名前：___________

読みたい本（タイトル）：
1. ___________
2. ___________
3. ___________

読んだら先生に教えてください。楽しみにしています。
```

- 保護者にも「この子の読書計画」を共有し、図書館利用を促す

## よくある課題と対処

| 課題 | 対処 |
|---|---|
| 読書ラウンジで話してしまう | 「ラウンジでは静かに読む」ルールを最初に共同作成する。違反した場合は次の機会に参加できないルールを設ける |
| Book Celebrationの参加率が低い | 「全員発表」ではなく「参加自由・見るだけも可」にする。教師も参加する |
| 著者への手紙が「感想文」になる | 「先生への手紙」として書く練習をしてから著者への手紙に移行する |
| 興味調査を読書選書に生かせない | まず調査結果から「1人だけ」に本を薦めてみる——全員に同時にしようとしない |
