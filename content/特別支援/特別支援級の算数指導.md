# 特別支援級の算数指導

Vaultに蓄積された思考・実践の総合。

---

## 授業構造：三層固定モデル

情緒支援学級（1年・2年・5年混在、週5回45分）の文脈から導き出された構造。

> **「構造が固定されているから、子どもが自律して動ける」** ([[パタン/余白をつくる]]と接続)

```
45分
├── ① ウォームアップ（約5分）
│       └── 学年別プリントの「引き出し」から出して各自取り組む
├── ②③ 自分で学ぶ時間 ／ 先生と一緒の時間（約40分、わたり・ずらし）
│       ├── 学年別プリント（自分のペースで）
│       └── 早く終わったら → アンカー課題の引き出しへ
```

**前年度との違い**：
- ウォームアップを「構造として」固定した（以前はなかった）
- 待っている時間の出口を「タブレット等」から「アンカー課題」に変えた

---

## ウォームアップの設計原則

- **型を固定し、中身だけ変える**（毎回作らない）
- 学年別に引き出し（ストック）を作り、そこから取り出すだけ
- 全学年が「自分のレベルで即座に取り組める」形式
- [[パタン/シグニファイア]]：プリントの設計で「何をするか」が一目でわかる

**学年別の型（案）**：

| 学年  | 型               |
| --- | --------------- |
| 1年  | 数の並び・簡単な計算カード1枚 |
| 2年  | 短い文章題1問         |
| 5年  | 前回の問題の振り返り1問    |

---

## アンカー課題（早く終わった子の「次」）

> アンカー課題 = 一人でもチャレンジでき、終わりがない（または十分に難しい）課題

**目的**：待機時間を算数の学習時間に変える。「終わったらタブレット」を脱却。

**リソース一覧**（Vaultより）：

| 種類      | 教材・リソース                                                             |
| ------- | ------------------------------------------------------------------- |
| 操作教材    | ポリドロン、パターンブロック、タングラム                                                |
| 良問集（英語） | Continental Mathematics League (CML)、MATHCOUNTS、Nimble with Numbers |
| グループ対応  | United We Solve（グループ数学）、The Game of Set                             |

**引き出しの分類（案）**：
- 全学年共通
- 1・2年生向け
- 5年生向け

---

## バインダー（個人版算数ポートフォリオ）

> 「子どもが自分の算数の歴史を持てる場所」

**構成**：
1. **ガイドライン・手順書**（最初のページ、立ち返る拠点）
2. **算数用語辞典**（用語・定義・図・例）← 主役
3. **思考の跡**（図、式、説明、先生と一緒に解いたもの）
4. **自作問題・面白かった問題**
5. **振り返り記録**

**バインダー形式の利点**：どこにでも新しい紙を差し込める → 思考の流れをそのまま保存できる

**関連パタン**: [[パタン/メタ意識]]（自分の学びを俯瞰する手がかり）

## 身体と算数：学習前の運動

前年度の実践から: 毎日の運動（ジャンピングジャック・スクワット・ダンス等）を授業前に実施。

- 最初はバラバラだった動きが、継続によってスムーズになる（**Body Shape Brain** の神経科学的根拠）
- 子ども自身も「できるようになる」体験を毎日積み重ねる
- 算数の「できるようになる感覚」への橋渡しになる可能性
