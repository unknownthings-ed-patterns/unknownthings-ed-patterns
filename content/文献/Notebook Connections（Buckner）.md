# Notebook Connections（Buckner, 2009）

Buckner, A. (2009). *Notebook Connections: Strategies for the Reader's Notebook*. Stenhouse Publishers.

*Notebook Know-How*（2005）の姉妹書。ライターズ・ノートを書くことのための道具として位置づけた前書に対し、本書はリーダーズ・ノートを「読むことを思考する道具」として位置づける。

---

## 要約

### 核心：読書記録ではなく「思考の道具」

Bucknerはリーダーズ・ノートを「読む量を管理する記録帳」でも「感想を書く日記」でもなく、**読者として成長するための思考の道具**として再定義する。

| 種類 | 目的 | Bucknerの評価 |
|---|---|---|
| **読書ログ（Reading Log）** | タイトルと読了の記録（量の管理） | 必要だが「読者」を育てない |
| **反応日記（Response Journal）** | 「面白かった」などの感情反応 | 表面的；深い思考を引き出せない |
| **リーダーズ・ノート** | 思考の可視化・読書アイデンティティの発達 | 真の読者を育てる道具 |

「このノートが問うのは『何を読んだか』ではなく『どう考えたか』『どんな読者になりつつあるか』だ」——Buckner

### 3つのフェーズ

| フェーズ | 内容 |
|---|---|
| **起動（Launching）** | ノート文化をつくる。「評価されない低リスクな場所」として位置づける |
| **発展（Developing）** | 思考の深さとスタミナを育てる。多様なエントリータイプを体験させる |
| **精緻化（Fine-tuning）** | 関与を深め、振り返りを増やす。読者としての自覚を育てる |

### 章構成と主要な知見

**第1章：読むこと、書くこと、希望を収穫すること**
- ノートは「やらされる課題」ではなく「作家が希望を収穫する畑」のようなもの
- 学習者が受け身の読者から思考する読者になる橋渡し

**第2章：招待状——読者として自分を知る（History of a Reader）**
- 年度初めの最重要エントリー：**読者の自分史（History of a Reader）**
  - 「最初に覚えている読書の記憶は？」「好きだった本は？」「読むのが得意だったときは？」「苦手だったときは？」
  - 読書アイデンティティを年度初めに掘り起こし、年度末に見直す
- 教師も同じエントリーを書いてモデリングする

**第3章：読解ストラテジーからノートへ**
- TS（自分とのつながり）・TT（テキスト間）・TW（世界とのつながり）の記録
- 疑問（Wonderings）の記録——「なぜ？」「次はどうなる？」を書き残す
- 推論の記録——「書いていないことを自分で考えたこと」を書く
- 重要な部分とそう感じた理由の記録

**第4章：作家のように読む（Reading Like a Writer）**
最も独自性の高い章。読書と作文指導の橋渡し。

- 作家が「何をしたか（What）」と「なぜ効果があるか（Why it works）」を注目する
- ノートに「気づき（Noticings）」として書き留める
  - 「この書き出しは○○という書き方をしている——なぜかというと……」
  - 「この著者は対話を使っていて、テンポが速くなっている」
- 集めたクラフト・ムーブ（Craft Moves）を書くときの引き出しにする

→ リーダーズ・ノートとライターズ・ノートが「作家のように読む」でつながる

**第5章：物語の深層——隠れた層を発見する（Beneath the Story）**
- テーマ・象徴・登場人物の変化を掘り下げる
- 「このテキストが本当に言っていることは何か？」という問いをノートに書く
- 「物語の表層（出来事）」と「深層（意味・テーマ）」を区別する練習

**第6章：評価——今の教えのための道具**
- ノートの評価は「正しい文章か」ではなく：
  - 関与の質（どれだけ思考しているか）
  - 多様性（どんなエントリータイプを使っているか）
  - 成長（年度を通してどう変わったか）
- 教師にとってはノートが**カンファリングの最も重要な資料**になる

### ライターズ・ノートとの比較

| | ライターズ・ノート（2005） | リーダーズ・ノート（2009） |
|---|---|---|
| **目的** | アイデアの種を集める・技法を試す | 思考を可視化・読者として成長する |
| **中心活動** | 書く素材を生み出す | 読む経験を深める |
| **カンファリングでの役割** | ドラフトの前段階として | 読書状態を理解する主要な資料として |
| **共通点** | 低リスク・評価しない・教師のモデリング | |

## 教育実践への示唆

1. **読書ログとリーダーズ・ノートを区別する**：読書ログ（量の管理）は別のシートで。ノートは「どう考えたか」の場所として守る。

2. **読者の自分史を年度初めに書く**：「あなたはどんな読者か」を問うことが、読書指導の出発点になる。教師も書いて共有する。

3. **「作家のように読む」エントリーで読書と作文をつなぐ**：作者の技法に気づいてノートに書くことが、書くための引き出しを増やす最も自然な方法。

4. **カンファリングの前にノートを読む**：ノートに書かれている思考が、その子の読書状態をもっともよく示す。「今何を読んでいる？」に加えて「ノートに何を書いた？」を聞く。

5. **物語の深層の問いをミニレッスンで育てる**：「出来事を書く」から「このテキストが言っていることは何か」を問う習慣をつくる。
