# メタパタン（概要）

> パタンを発見し、検証し、使い続けるための上位の設計思想。

## メタパタンとは

「教育のパタン・ランゲージ」における**メタパタン**は、個別のパタン（解決策の記述）を生み出すための**原理・思考様式**である。教育実践からパタンを発見し、それを検証し、共有するための根本的な方法論を示す。

牧口常三郎の教育探求（「教授の統合中心としての郷土科研究」等）をパタン・ランゲージ・アブダクション・因果推論という現代的レンズで読み解くと、以下の5つのメタパタンが浮かび上がる。

## 5つのメタパタン

| メタパタン | 核心 |
|-----------|------|
| [[メタパタン/経験から出発する]] | 理論より先に、現場の経験・実践からパタンを見出す |
| [[メタパタン/価値を目標とする]] | パタンの目的は価値の実現である |
| [[メタパタン/経済を原理とする]] | 最小の手段で最大の価値を生む「経済の道」 |
| [[メタパタン/アブダクション（仮説形成）]] | 驚くべき事実から最良の説明仮説を見出す思考 |
| [[メタパタン/反事実（因果推論）]] | 「もしなかったら」と問うことでパタンの因果性を確かめる |

## パタン発見のサイクル

```
経験（現場）
  ↓  ← アブダクションでパタンを見出す
仮説（パタン候補）
  ↓  ← 他の場で試す（介入）
検証（再現）
  ↓  ← 反事実で因果を確かめる
パタン（記述・共有）
  ↓  ← 価値に照らして吟味
経験（現場に戻る）
```

このサイクルは一方通行ではなく、常に経験と理論のキャッチボールである。
