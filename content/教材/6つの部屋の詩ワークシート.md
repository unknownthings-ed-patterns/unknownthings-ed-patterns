# 6つの部屋の詩ワークシート

> 見たこと、聞いたこと、したこと、感じたこと、思ったことを部屋のように分け、キーワードの繰り返しで詩を書き始めるための小さな足場。

## 教材の概要

詩を書く前に、材料を集めるためのワークシートである。

原資料にある要素は、とても少ない。

- かんじたこと
- おもったこと
- 見たこと
- 聞いたこと
- したこと
- 書くこと
- キーワードを3回くりかえす

この少なさが、この教材のよさである。詩を書くことを、最初から長い文章を書く活動にしない。自分の中にある感覚や経験を小さく取り出し、言葉の部屋に置いていく。

## 使う場面

- 詩を書く前に、経験・感覚・キーワードを集める
- 「何を書けばよいか分からない」子に、書き始める場所を渡す
- 詩のテーマを決めたあと、言葉の材料を広げる
- 短い3行の詩から創作を始める
- [[実践/詩を紹介する・詩を創作する]] の中で、詩の材料集めとして使う

## 6つの部屋

| 部屋 | 書くこと |
|------|----------|
| 見たこと | 目で見えたもの、色、形、動き |
| 聞いたこと | 音、声、静けさ、繰り返し聞こえたもの |
| したこと | 自分の動き、行動、手ざわり |
| 感じたこと | うれしい、こわい、さびしい、あたたかいなど |
| 思ったこと | 気づき、考え、ふしぎに思ったこと |
| 書くこと | 詩に使いたい言葉、中心にしたいキーワード |

「見たこと」「聞いたこと」「したこと」は、経験に戻る部屋である。「感じたこと」「思ったこと」は、内側の反応に戻る部屋である。最後に「書くこと」で、詩に使いたい言葉を選ぶ。

## キーワードを3回くりかえす

このワークシートには、「キーワードを3回くりかえす」という手がかりがある。

たとえば、中心になる言葉を一つ選び、少しずつ言い方や周りの言葉を変えて3回出す。

```text
雨がふる
雨がつぶつぶ窓にくる
雨がぼくの帰り道を青くする
```

繰り返しがあると、詩にリズムが生まれる。書くことが苦手な子も、まず一つの言葉を繰り返すところから始められる。

## 追試するなら

まず、詩のテーマを一つ決める。

例：

- 雨
- 運動会
- 帰り道
- 給食
- 友だち
- 教室
- 夏の朝

次に、6つの部屋に短い言葉を入れる。文でなくてもよい。単語、音、色、動きでよい。

最後に、その中から一つキーワードを選び、3回くり返して詩にする。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| 何も思いつかない | 「見たこと」から始める。実際に見えるものを一つ書く |
| 感情語だけになる | 「どこでそう感じた？何が見えた？」と経験の部屋へ戻す |
| 説明文になる | キーワードを3回出し、同じ言葉を少しずつ変えてみる |
| きれいな言葉を探しすぎる | まず普通の言葉でよいことにする |
| 長く書けない | 3行だけで完成としてよいことにする |
| どの言葉を選べばよいか分からない | 一番声に出して言いたい言葉を選ばせる |

## この教材の意味

詩を書くことは、いきなり「詩らしい言葉」を探すことではない。

まず、見たこと、聞いたこと、したこと、感じたこと、思ったことを思い出す。そこから一つの言葉を選び、繰り返してみる。すると、経験が少しずつ詩の形を取り始める。

このワークシートは、詩を完成させる型というより、詩が生まれる前の場所をつくる教材である。小さな部屋に言葉を置くことで、子どもは「書くことがある」状態から詩を書き始められる。
