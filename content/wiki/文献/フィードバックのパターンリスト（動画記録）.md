# フィードバックのパターンリスト（動画記録）

> 出典：YouTube動画 https://youtu.be/rmAT3N9wshM  
> 内容：教育のパタンリスト「フィードバック」の解説。ハッティ、サドラーらの研究をもとに整理した73のパタンを紹介する。

---

## フィードバックの定義

**教育の定義**：意図的に、目的的に、設計・構造化された経験である。

**フィードバックの定義**：教育経験から得られる情報のこと。

- 従来のイメージ：教師から子どもへのコメント、子ども同士の評価
- 拡張した意味：介入によって得られる**あらゆる反応・情報**（作品・声・表情・アンケートなど）
- フィードバックには**形成的評価・総括的評価を含む**
- フィードバック制御の語源：エアコンの温度制御（目標と現状のギャップを埋める自動制御）

> 「フィードバックとは学習者に関わりをもつ人、もの（たとえば、教師、仲間、本、保護者、学習者自身の経験など）から与えられる、学習者の到達状況や理解の程度に関する情報である」（ハッティ、2018）

---

## ギャップ原則（サドラー）

効果的なフィードバックの核心：**ゴールと現状のギャップを認識し、埋めること**。

1. 狙っているゴール・目標・成功規準の概念を持つ
2. ゴールと今の実際のパフォーマンスレベルを比べる
3. ギャップを認知する
4. ギャップを埋めるための行動を取る

---

## 達成規準の構築

達成規準（成功規準）はできれば**教育者と被教育者が共同構築**することが望ましい。

### 達成規準の構築方法

| 方法 | 説明 |
|------|------|
| 実例を比べて分析する | 作品・実例を観察・比較することで基準を構築 |
| 技術やスキルの実演を分析する | 何ができれば良いかを可視化 |
| 間違ったやり方をする | 対比から基準を浮かび上がらせる |
| 悪い実例を示す | 「これはいい例か？」と問うことで基準を引き出す |
| 不備のある実例を示す | 改善点を考えることで基準を構築 |
| 振り返りでのねらいの共同構築 | 学習後に振り返りで達成規準を更新する |
| ジグソーパズル | 優れた実例（新聞など）を切り刻んで組み立て直す |
| 間違いがある達成規準を示す | 誤りを含む基準を使って批評的思考を育てる |
| 最初から良い例を見て分析する | ポジティブな出発点で基準を形成する |

### 達成規準の種類

**脱文脈化された達成規準**：特定の問題だけに使えるのではなく、転移できる汎用的な規準。
- 例：「13+15の筆算ができる」→「位を揃えて書く」「1の位から計算する」

**おきまりの学習のねらい**：全員が達成すべき必須の目標（文の終わりに丸をつけるなど）。

**多様に想定される学習のねらい**：書き出しを工夫するなど、表現が多様に現れる目標。

## フィードバックの3方向（ハッティ）

| 方向 | 問い |
|------|------|
| フィードアップ | どこに向かっているのか？（目標・ゴール） |
| フィードバック | 進み具合はどうか？（現状との照合） |
| フィードフォワード | 次に何をするべきか？（改善のステップ） |

---

## フィードバックの4レベル（ハッティ）

| レベル | 内容 |
|--------|------|
| 自己レベル | 「すごいね」など人格・自己への評価 |
| タスクレベル | 課題の正誤・完成度へのフィードバック |
| プロセスレベル | やり方・戦略・思考過程へのフィードバック |
| 自己調整レベル | 学習の調整・モニタリングへのフィードバック |

**重要**：自己レベルのフィードバック（褒め・承認）とパフォーマンスレベルのフィードバックを**混ぜない**。自己レベルのフィードバックは効果が低い（ハッティ）。

---

## フィードバックの方向性

- **教師 → 被教育者**（一般的なイメージ）
- **被教育者 → 教師**（授業改善のための情報）
- **ピア**（仲間同士）
- **外部**（地域・保護者・専門家）
- **全体へ**（個別ではなくクラス全体へ）

## 評価ツール・記録

| ツール | 説明 |
|--------|------|
| 形成的評価 | 学習過程での継続的な評価 |
| 総括的評価 | 学習終了後の評価 |
| ルーブリック | 達成規準を複数の次元で記述した評価表 |
| ポートフォリオファイル | 学習の成長を記録する作品集 |
| ドキュメンテーション | 学習過程の記録・可視化 |
| 評定（成績評価） | A/B/CやSなどの評定 |
| 記述式フィードバック | コメント・初見などの文章によるフィードバック |
| テストを繰り返す | 想起練習としてのテスト |

## 授業中の実践パタン（シャーリー・クラーク）

| パタン | 内容 |
|--------|------|
| 授業中の学習のストップ（批評） | 途中で立ち止まり作品を批評する |
| 授業の中で批評する | 学習物を全体で批評する |
| 学習パートナーとの協働 | パートナーが成功を確認し改善案を示す |
| 一時に一つの学習物を話し合う | 全員で一つの作品を協働で話し合う |
| 無作為の学習物による改善のモデル | 誰かの作品を匿名で使って改善案を示す |
| 最も良い学習物を探す | 成功規準に焦点化し最良作を探し改善案を示す |
| 自分の学習物が批評される | 本人の作品がクラスで批評される経験 |
| フィッシュボウル（金魚鉢） | 内側の小グループが対話し外側が観察する |
| 1対1の面談 | 個別カンファランス |

## フィードバックの形式

| 形式 | 特徴 |
|------|------|
| サンドウィッチフィードバック | 良い点→改善点→良い点の順 |
| 大切な友だち（クリティカルフレンド） | 批評的な友人として改善を促す |
| Iメッセージ | 「私はこう感じた」という一人称フィードバック |
| 近接賞賛 | ターゲット以外の行動を褒めることで誘導する |
| 非随伴的な賞賛 | 行動と無関係な賞賛（効果が低い） |
| 確証フィードバック | 正しいことを確認するフィードバック |
| 非確証フィードバック | 誤りを指摘するフィードバック |
| 誤りフィードバック | 誤りの種類を特定し修正を促す |
| 即時的なフィードバック | タイムリーに与えるフィードバック |
| 意味のある具体的なフィードバック | 漠然とせず、具体的で行動可能なフィードバック |

## 誘発・支援

| 種類 | 説明 |
|------|------|
| 想起させる誘発 | 既習事項と繋げることで解決に向かわせる |
| 足場がけへの誘発 | ヒントカードなど足場へ誘導する |
| 例示による誘発 | 参照できる情報・例を示す |
| ノートの余白 | 学習パートナーとの話し合いでメモできる余白 |

## 振り返り・発見

- フィードバックのパタンリストは「長すぎる」ので整理が必要（本人談）
- シャーリー・クラークはフィードバックを形成的評価の一部とみなすが、作者はその逆（フィードバックが評価を包含する）
- フィードバックが広い概念であるほど汎用性が高く応用が効く
- 「受け取られ方」がフィードバックの効果を決定する（ハッティ）
