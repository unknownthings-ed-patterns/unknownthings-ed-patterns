# 増える算数辞典

> 算数の言葉を、定義・例・図・使う場面・似ている言葉とともに少しずつ蓄積していく、子ども自身の算数辞典。

## 教材の概要

算数の用語を、子どもが自分で書き足していくための辞典型ワークシートである。

算数では、「面積」「単位」「倍」「何通り」「分ける」「そろえる」などの言葉が、概念理解の入口になる。けれども、用語を定義だけで覚えても、問題を解く場面で使える言葉にはなりにくい。

この教材では、算数の言葉を次の4つの欄で整理する。

| 欄 | 子どもへの問い |
|----|----------------|
| 図や絵など | かいてみよう |
| 定義（説明）と例 | どういう意味？例えば？ |
| 使う場面 | 生活の中では？ |
| 似ている言葉 | なかまの言葉 |

辞典は一度で完成するものではない。授業の中で新しい言葉に出会うたびに増えていく。

## 使う場面

- 新しい算数用語を扱う単元の導入
- 問題を解いた後に、使った言葉を整理するとき
- ナンバートークや説明活動の後
- 算数バインダーやポートフォリオに蓄積するとき
- 既習事項を見返して、次の単元で使うとき

## 1ページの構成

### 図や絵など

言葉の意味を、図・絵・数直線・表・式・具体物の絵などで表す。

例：

- 「面積」なら、ます目を塗った図
- 「倍」なら、同じ量をいくつ分か並べた図
- 「何通り」なら、表や樹形図
- 「単位」なら、10をひとまとまりにした図

### 定義（説明）と例

教師の定義を写すだけでなく、自分の言葉で説明する。

例：

- 面積：形の広さを数で表したもの
- 何通り：できる組み合わせの数
- 単位：いくつ分かを考えるときのまとまり

「例えば？」を入れることで、定義が具体的な場面と結びつく。

### 使う場面

その言葉を、算数の問題や生活の中でどこで使うかを書く。

例：

- 面積：机の上の広さ、畑の広さ、紙の大きさを比べるとき
- 何通り：サイコロの目、服の組み合わせ、道順を考えるとき
- 単位：10円玉で金額を見る、100をまとまりにして計算するとき

### 似ている言葉

仲間の言葉や、混同しやすい言葉を書く。

例：

- 面積：広さ、体積、周りの長さ
- 倍：いくつ分、半分、割合
- 何通り：組み合わせ、場合、表

似ている言葉を並べることで、言葉の境目が見えやすくなる。

## 追試するなら

最初は、1単元に1語だけでよい。

たとえば「面積」の単元なら、まず「面積」だけを辞典に入れる。図を描き、自分の言葉で説明し、生活の中の使う場面を一つ書く。慣れてきたら「1平方センチメートル」「たて」「横」「公式」などを増やす。

教師が完成例を1つ見せると、子どもは書き方をつかみやすい。ただし、全員が同じ定義を写すだけにならないように、「自分の言葉」「自分の例」を少し入れる。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| 定義が書けない | 先に図や例を書かせてから、「これは何を表している？」と聞く |
| 教科書の文を写すだけになる | 「自分なら1年生にどう説明する？」と問い直す |
| 図が描けない | 教師が半分だけ描いた図を示し、続きを描かせる |
| 使う場面が出ない | 教室、家、買い物、ゲームなど生活場面を一緒に探す |
| 似ている言葉が出ない | 「まちがえやすい言葉」「同じ仲間っぽい言葉」から始める |
| 継続しない | 算数バインダーの決まった場所に入れ、単元末に見返す |

## この教材の意味

増える算数辞典は、算数の言葉を「覚えるもの」から「使うもの」へ変える教材である。

子どもは、新しい言葉を聞いたときに、意味を写すだけでなく、図にし、例を出し、生活の中で使う場面を探す。さらに、似ている言葉と並べることで、その言葉の輪郭がはっきりする。

この辞典が増えていくと、子どもは自分だけの算数の道具箱を持つことになる。分からないときに戻れる場所があり、前に学んだ言葉を次の単元で使えるようになる。
