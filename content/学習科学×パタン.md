## やりがちな誤用と正しい理解

| 誤用 | 正しい理解 |
|---|---|
| ノートを見直す（再読）は検索練習 | 「ノートを閉じて思い出す」行為が検索練習——再読は錯覚的理解を生む |
| 同じ種類の問題をまとめてやる（ブロック練習）はインターリービング | 異なる種類を意図的に混ぜることで「どれを使うか」の判断力が育つ |
| 間隔を空けるだけで間隔学習になる | 「思い出そうとする努力」が必須——ただ忘れて再学習するだけでは不十分 |
| 図を資料に貼るだけで二重符号化になる | 言語と視覚が相互補完する設計が必要——無関係な装飾は逆効果 |
| 授業中に覚えた気がすれば定着した | 「楽に感じる」学習ほど定着が弱い——望ましい困難の逆説 |

## パタンとの接続マップ

学習科学の6方略はこのWikiの以下の概念領域と深くつながっている：

**動機付け**  
[[パタン/内発的動機付け]] ← 望ましい困難は自律感・有能感と連動  
[[パタン/切実性（必要感）]] ← 「なぜ覚える必要があるか」が検索練習の効果を高める

**メタ認知**  
[[パタン/メタ認知的モニタリング]] ← 6方略を効果的に使うにはメタ認知が前提  
[[パタン/自己調整]] ← 自分の学習法を評価・修正する力

**評価**  
[[パタン/形成的評価]] ← 検索練習は同時に形成的評価として機能  
[[パタン/省察的評価]] ← 単元後に「どの方略が効いたか」を振り返る
