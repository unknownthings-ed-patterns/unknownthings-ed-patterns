# 算数・数学で使うパタン

算数・数学の授業で使いやすいパタンを、実践の場面ごとに並べた入口。

## まず読むなら

| 場面 | パタン | 使いどころ |
|------|--------|------------|
| 冒頭5分で数感覚を育てる | [[パタン/ナンバートーク]] | 1問を複数の解法から考え、考え方を共有する |
| 具体物から概念へ進む | [[パタン/具体から抽象へ]] | 操作・事例・図から、数や式の概念へつなぐ |
| 考え方を見える形にする | [[パタン/可視化]] | 式だけでなく、図・数直線・表・言葉で考えを残す |
| 問題解決の見落としを防ぐ | [[パタン/条件をすべてつかったか]] | 文章題や証明で、使っていない条件を点検する |
| 算数語彙を文脈の中で育てる | [[パタン/数学語彙の文脈的指導]] | 用語を定義だけでなく、図・例・非例と結びつける |

## 学習科学 × 算数

認知科学・学習科学の知見をそのまま算数授業に使うパタン群。

| パタン | 算数授業での使い方 |
|--------|------------------|
| [[パタン/間隔学習]] | 前時の計算問題を毎朝冒頭5分で少量復習し、記憶の定着を高める |
| [[パタン/テストを繰り返す]] | ミニホワイトボードで既習の解法を毎時間1問テスト形式で引き出す |
| [[パタン/インターリービング]] | 同種の計算問題を連続させず、混在配列で演習することで転用力が育つ |
| [[パタン/精緻化]] | 「どうしてこのやり方になるの？」と問い、自己説明で理解を深める |
| [[パタン/望ましい困難]] | あえて少し難しい問題を最初に提示し、試行錯誤で記憶定着を高める |
| [[パタン/メタ認知的モニタリング]] | 「この問題、わかった？」を自分で評価させ、学習の自己調整を育てる |
