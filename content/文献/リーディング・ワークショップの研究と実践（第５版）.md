# リーディング・ワークショップの研究と実践（第５版）

> 岩井輝久が自身の研究・実践を通じて書き続けてきたRW研究報告。アトウェル・カルキンズを日本の学校文脈で読み直し、実践可能な形に翻案した集大成。

---

## 要約

- **RWとは**：読むことをワークショップ形式で学ぶこと。ナンシー・アトウェルが創始。目的は「熟練した・情熱的・習慣的・批評的な読書家になること」（Reading Zone, p.15）
- **日本での導入方針**：そのまま移植は困難。教科書・学習指導要領の目標を押さえ、「発展・応用・活用」としてRWの読む時間（Independent Reading）を位置付ける
- **4つの必須要素**（スィベーソン, Day-to-Day Assessment, p.17）：①読む時間の確保 ②予測できる枠組み ③学習のオーナーシップ ④本への反応
- **授業サイクル**：ミニ・レッスン → 読む時間（Independent Reading）→ 共有の時間
- **読書サイクル**：選書（計画）→ 読書 → 共有（ブッククラブ等）
- **学習環境の中核は図書コーナー**：カゴを使った分類（シリーズ別・著者別・ジャンル別）が選書を助ける
- **カンファランス**：教師と子どもが1対1で読書について対話する。評価と支援を同時に行う
- **評価ツール**：心のつぶやきシート・20冊チャレンジ・1週間の読書目標・ブックレビュー・レターエッセイ・ブックバズ・読書ノート
- **選書のオーナーシップ**：「子どもたちに本を愛するように勧める唯一の絶対確実の方法は、自分自身で本を選ぶように招くことだ」（Atwell, Reading Zone, p.12）
- 第5版で**評価の章**を新設

## 各章の核心

### 一. RWとは

**4要素の詳細：**

| 要素          | 核心                                 |
| ----------- | ---------------------------------- |
| ①読む時間の確保    | 最低30分。苦手な子ほど必要。15分では選書後に本の世界に入れない  |
| ②予測できる枠組み   | ミニレッスン→読む時間→共有の時間という不変のリズムが自己調整を生む |
| ③学習のオーナーシップ | 選書・計画を子ども自身がする。読書家としてのアイデンティティの発達  |
| ④本への反応      | 読んで考えたことを書き・話し交流することで読みが修正・深化する    |

### 二. 学習環境のデザイン

**カゴを使った図書コーナー**（スィベーソン, Still Learning to Read, p.12）：
- 「自分にぴったりの本を選ぶことを子どもたちに教えるのに最もよい方法は、図書コーナーをよく考えて組織することである」
- カゴの分類例：シリーズ別・著者別・ジャンル別・新着本・クラスメイト一押し・読み聞かせ関連本
- カゴのよさ：表紙が外を向く・移動しやすい・意図的な分類がしやすい
- **詩のカード**：詩集の選書を助けるために詩1篇をカードに。「この詩が好きならこの本も好きかも」
- **読書箱**：読みかけの本・未完成作品・ポートフォリオを入れる個人の箱

**推薦書リスト（岩井実践から）**：
- シリーズ：かいけつゾロリ・ローワン・デルトラ・グレッグのダメ日記 他
- ブッククラブ向け：岡田淳『二分間の冒険』『びりっかすの神様』・飛ぶ教室 他

### 三. ミニ・レッスン

5〜15分の短い指導時間。学年全体への指導。ビッグメッセージを届ける場。
- 読み方のスキル（関連付ける・推測する・イメージする・要約する等）
- 選書の方法（自分にぴったりの本・読書のサラダ・下読み）
- ジャンルの理解（スキーマ・ローラー）
- 読書ノートの使い方・付箋の使い方

### 四. 読む時間とカンファランス

**カンファランス**（1対1の読書対話）：
- よく尋ねる質問：「今何を読んでいますか」「どんな本を読んできましたか」「今難しいことは？」
- 目的：記録・評価・選書支援・読み方の支援を1回の会話でまとめて行う
- 「付箋作戦」：子どもが気になった場所に付箋を貼り、それをもとに対話

### 五. 共有の時間

- クラス全体・ペア・小グループで読んだことを共有
- ブッククラブ：同じ本を複数で読み、対話で読みを深める
- ブック・バズ：短時間で本の魅力を伝え合う

### 六. 評価

| ツール       | 目的                      |
| --------- | ----------------------- |
| 心のつぶやきシート | 読書中の心の動きを記録             |
| 20冊チャレンジ  | 年間読書量の目標設定              |
| 1週間の読書目標  | 短期の計画と振り返り              |
| ブックレビュー   | 本の評価文。選書を助けるガイドブックとして機能 |
| レターエッセイ   | 教師・友人への読書報告手紙           |
| 読書ノート     | 読書中の気づき・考えの記録           |

## 実践への示唆

- **まず30分の読む時間を死守する**：苦手な子がフロー状態に入るには30分必要
- **カンファランスで見取る**：全体指導より個別対話に時間を使うほど力がつく
- **図書コーナーをデザインする**：カゴの分類方法が子どもの読書の広がり方を決める
- **ブックレビューを蓄積する**：次年度の子どもの選書を助けるクラスのガイドブックになる
- **選書のオーナーシップを育てる**：「先生が指定した本を読む」から脱却するのがRWの核心
