# 僕らの世界を作りかえる哲学の授業（土屋陽介）

## 要約

- **哲学対話（P4C）** とは、答えがすぐに見つからない哲学的な問いについて、子どもと教員が一緒に「議論が導くところについていく」ように対話し、思考を深めていく教育活動である。
- 哲学対話はリップマン（Matthew Lipman, 1923–2010）が1960年代末に米国コロンビア大学で始めた「子どもの哲学（P4C）」に端を発する。リップマンの動機は「暴力を選ぶ大学生」への危機感——「言葉で考えられない人間は暴力に訴える」という確信から思考力教育へ転換した。
- P4Cはフランス・オーストラリア（1982年〜）・ハワイ（ジャクソン由来）・メキシコ・ブラジル・韓国・台湾・日本など世界各地に広がり、それぞれの地域の問題（貧困・校内暴力・多文化共生）に対応した独自の形に進化している。
- ハワイ大学のトーマス・ジャクソンは「知的に安全な共同体（Intellectually Safe Community）」を掲げる。多様な文化的背景をもつ子どもが混在するハワイで、「自分らしく自分のままでいられること」を最重視した実践が校内暴力の改善につながった。
- 著者は東京の開智日本橋学園で「フィロソファー・イン・レジデンス（学校駐在哲学者）」として哲学対話だけを担当する専門教員。ハワイの高校に駐在している哲学教師にならって自らを名乗る。
- 哲学対話には2つの思考の方向がある。**概念の洗練**（世界が透明化していく——「幸せとは？」という漠然とした概念が対話で明確になる）と**無知の気づき**（世界が不透明化していく——当然と思っていたことが実はよく分かっていなかったと気づく）。
- 哲学対話の授業はリップマンの言う「**探究の共同体（Community of Inquiry）**」を教室に実現する——参加者全員が協力して真理を愛し求める場。
- **哲学対話の5ステップ**：①顔を見合える体勢で座る→②思考の素材をシェアする→③問いを作る→④問いをめぐって対話する→⑤ふりかえる。
- **哲学カフェ** は1992年夏、パリのカフェ・デ・ファールで哲学者マルク・ソーテが偶然始めた（ラジオリスナーが押しかけてきた即興討論が評判になり150人が集まる回も生まれた）。ソーテは1998年に49歳で急逝したが哲学カフェは世界中に広がった。日本では2000年前後に大阪大学臨床哲学研究室（お寺での開催）や関東実験哲学カフェとして始まった。
- 哲学対話の授業の負の側面として、リップマンは「学校が子どもの好奇心と探究心を破壊する」と述べる——「出来合いの答えに満ちた学校空間」に子どもたちは驚きを持ち込む意欲を失っていく。

## 具体的な授業例（開智日本橋）

### 中学1年生：「アンパンマン」と正義の問い

初代アンパンマン（作：やなせたかし）の童話を読む——自分の顔（パン）を配って人助けをし、最終的に見知らぬ子どもを助けるために自分の命を犠牲にする主人公。

対話の経過：最初は「アンパンマンは正しい」で一致していたクラスが、徐々に疑問を深めていく。

> 「アンパンマンの言う"正義"には、独りよがりの部分も多い。『困っている人を助ける』のは正義だけど、『命を粗末にしない』のも同じくらい大事な正義。アンパンマンは前者のために後者を無視した」

さらに対話は「そもそもアンパンマンはばいきんまんと戦う前に全然話し合いをしていない」「暴力で解決しているアンパンマンって正義なのか」というメタ問いへと発展した——正義の概念の洗練と無知の気づきが両方起きた授業例。

### 中学2年生：「YAMASUKI」と言語統一の問い

フランスのレコード作品「Le Monde Fabuleux Des YAMASUKI（素晴らしきYAMASUKIの世界）」を聴く——フランス語と日本語の単語が入り混じった奇妙な音楽。

問い：「言語は統一されるべきか」——多様な言語があることで理解が難しくなるのか、それとも多様な言語が豊かさをもたらすのか。「YAMASUKI」という作品の不思議さがこの問いへの入り口となる。

### 中学3年生：「ゲノム編集はアリ？ナシ？」と生命倫理

2018年、中国の賀建奎教授がゲノム編集した受精卵から双子を誕生させたニュースを素材にする。理科の授業でちょうどゲノム編集を学んでいたタイミングで実施。

対話の経過：「病気予防なら許される」「完璧な人間を作ろうとするのは倫理的に問題」「ゲノム編集のいちばんの問題は生まれてくる子どもの同意なしに遺伝子をいじること」など多様な立場が展開。

> 「私がゲノム編集された子どもだとしたら、たとえ病気の予防が目的でも、ちゃんと私の同意を取ってからゲノム編集してよ、って怒ると思う」

## P4C世界展開の概略

| 地域 | 特徴・動機 |
|---|---|
| 米国（コロンビア大学）| リップマン1968年〜：思考力教育として開発。「暴力を選ぶ大学生」への危機感 |
| フランス（幼稚園）| 「フランス語で考え表現する習慣」をつけるため。3〜5歳から実施 |
| オーストラリア（1982年）| スプリッターがリップマンのもとを訪問して持ち帰り |
| ハワイ（カイルア高校等）| ジャクソン主導：多文化共生・校内暴力改善。「知的に安全な共同体」 |
| メキシコ・ブラジル（ラテンアメリカ）| 貧困・社会的不公正への取り組みとして。「なぜこんなに貧しいのかを問い直す」 |
| 韓国・台湾・シンガポール（アジア）| 2010年代に急速に広がる |
| 日本（2010年代〜）| 開智・お茶の水附属小・p4cみやぎなど。道徳科「考え議論する道徳」との一致 |

## フィロソファー・イン・レジデンスという役割

著者は哲学対話の授業だけを担当する専門教員として開智日本橋に勤務し、自らを「フィロソファー・イン・レジデンス（学校駐在哲学者）」と自称する。通常の教科担当教師と異なり、「教科の知識を伝える」役割を持たず、「哲学する空間を学校に作り出す」ことが職務。

毎週複数のクラスで哲学対話を実施し、教材開発・教材研究・授業計画立案を担当する。同じ手順を繰り返さず「毎回子どもたちが新鮮な気持ちで思考を楽しめるようにする」のが腕の見せどころ。

## アジール（型域・避難所）としての哲学対話教室

哲学対話の教室は、学校のなかにありながら学校的な秩序が相対化される「アジール（型域・避難所）」となる——保健室に似た空間として機能する。

- 「優等生」よりも「常識に馴染めない子」がしばしば哲学対話で輝く
- 勉強が苦手だったり授業参加意欲が低い生徒が、哲学対話になると「人が変わったように」積極的に発言してクラス担任を驚かせることが多い
- 「常識」への率直な違和感を語るだけで、ほかの参加者の凝り固まった固定観念をときほぐせる
- 著者自身も高校生のとき図書室がアジールだった

## Qワードと対話促進

NHK・Eテレ『Q〜こどものための哲学』は哲学対話を促進する問いかけを「Qワード」と名付け「Qワードカード」という教材にまとめた。進行役や参加者が質問しやすくなるツール。

代表的なQワードの例：「たとえば？」（具体例を求める）、「本当に？」（前提を疑う）、「どうして？」（理由を求める）、「もう少し詳しく言える？」（掘り下げる）など。

これは哲学対話の心得④「意見より質問を大事にする」を実践するための具体的道具。

## 教育実践への示唆

- **道徳科・学活での活用**：「考え、議論する道徳」の具体的方法として哲学対話を使える。特定の徳目を一方的に教えるのでなく、答えのない問いを一緒に考える場をつくる。
- **問いを子どもが作る**：思考の素材を共有した後、子ども自ら問いを立てることが哲学対話の核心——「出来合いの問い」ではなく「自分が本当に気になる問い」が思考を駆動する。
- **沈黙・不発言も参加**：手を挙げなくても、頭の中が活発に動いていれば哲学対話に参加している——発言量で評価しない文化をつくる。
- **「負けること」の肯定**：反論されて自分の考えの弱点に気づくことが哲学対話の本来の目的——「論破」でなく「掘り下げ」を目指す。
- **人格攻撃と反論の区別**：相手の意見への疑問・反論と、相手の人格への攻撃は根本的に異なる——この区別を授業文化として丁寧に作る。
- **アジール的空間の設計**：「常識に馴染めない子」が哲学対話で輝ける空間を意図的に作る——保健室・図書室のような「学校的秩序からの一時的解放」として機能させる。
