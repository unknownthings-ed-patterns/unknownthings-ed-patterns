# 次に学ぶ30パタン

[[まず覚える30パタン]] を使いこなした教師のための第二軍。基礎30が「授業の骨格」を作るとすれば、この30は「授業の質」を高め、「学習者の自律」を育て、「文化」を深める。

## 使い方

1. 今の課題に近いカテゴリを選ぶ。
2. 1〜2パタンのページを読み、Actionable Insightから1つ試す。
3. [[パタン組み合わせ例]] でこのカテゴリのレシピを参照する。
4. 授業後に [[授業後リフレクションテンプレート]] で「働いたか」を記録する。

## 使いどころ・使いすぎ注意

| パタン | 使いどころ | 使いすぎ注意 |
| --- | --- | --- |
| [[パタン/熟慮的問い]] | 授業全体を貫く問いを立てたいとき。 | 問いが大きすぎると、子どもがどこから考えるか迷う。 |
| [[パタン/熟慮的インストラクション]] | 授業の型を意識して設計したいとき。 | 型に縛られすぎると、子どもの反応への即興が難しくなる。 |
| [[パタン/豊かな課題]] | 全員が参加でき深く探究できる課題にしたいとき。 | 課題が広すぎると、方向性が定まらない子どもが出る。 |
| [[パタン/問い返しのデザイン]] | 発言が表面的・一方向的なとき。 | 問い返しすぎると、子どもが答えることに疲れる。 |
| [[パタン/段階的手放し]] | 自律を段階的に育てたいとき。 | 手放しが速すぎると、支援が必要な子どもが置き去りになる。 |
| [[パタン/リーディング・ワークショップ]] | 毎日の読書習慣と読者としての力を育てたいとき。 | 構造が固定化しすぎると、目的より手続きが主になる。 |
| [[パタン/シンクアラウド]] | 教師の思考プロセスを見せたいとき。 | 教師が長く話しすぎると子どもが聴衆になる。 |
| [[パタン/ミニレッスン・サイクル]] | 技法を短く焦点化して教えたいとき。 | 10分を超えるとミニレッスンでなくなる。 |
| [[パタン/ブッククラブ]] | 同じ本を読む共同体を育てたいとき。 | 議論の場より報告の場になると深まらない。 |
| [[パタン/作家のクラフト]] | 書く力を読書と結びつけたいとき。 | 技法の観察が終わり自分の書き方につながらないと意味が薄れる。 |
| [[パタン/内発的動機づけ]] | 長期的な動機の土台をつくりたいとき。 | 外的報酬を組み合わせると内発的動機が弱まることがある。 |
| [[パタン/自己選択自己決定]] | 学習者に自律を経験させたいとき。 | 選択肢が多すぎると決断疲れが起きる。 |
| [[パタン/メタ認知的モニタリング]] | 自己評価・自律的学習を育てたいとき。 | モニタリングを強制すると負担になる。 |
| [[パタン/自己調整]] | 計画→実行→振り返りを自分で回す力を育てたいとき。 | 支援なしに求めすぎると、スキルのない子どもが迷子になる。 |
| [[パタン/能動的関与]] | 受け身になっている学習者を引き込みたいとき。 | すべての条件を一度に整えようとすると負荷が高い。 |
| [[パタン/間違いや失敗から学ぶ文化]] | 間違いへの抵抗感が強いクラスで。 | 失敗を過度に称賛すると、成功への動機が弱まる。 |
| [[パタン/フィードバック文化]] | 互いの作品・考えに返し合う文化をつくりたいとき。 | 関係性が弱いうちに始めると表面的な感想になる。 |
| [[パタン/エクセレンスの文化]] | 質の高い作品・行動を広めたいとき。 | 卓越を求めすぎると、挑戦できない子どもが萎縮する。 |
| [[パタン/環境調整]] | 人的・物的・空間的環境を学習に合わせて整えたいとき。 | 整えすぎると探索の余地が減る。 |
| [[パタン/省察]] | 自分の実践を問い直したいとき。 | 省察が反省になると萎縮を生む——改善の見通しとセットで。 |
| [[パタン/望ましい困難]] | 楽な学習に慣れた学習者に効果的な学習法を体験させたいとき。 | 難しさが適切でないと、ただ苦しいだけになる。 |
| [[パタン/間隔学習]] | 単元後の長期定着を設計したいとき。 | 間隔を空けるだけで思い出す努力がないと効果が薄い。 |
| [[パタン/テストを繰り返す]] | 覚えたかどうかを確認したいとき。 | 採点・評価目的の繰り返しは効果を妨げる。 |
| [[パタン/具体から抽象へ]] | 概念の理解が浅いとき。 | 具体にとどまりすぎると抽象化への移行が起きない。 |
| [[パタン/ナンバートーク]] | 数の柔軟な見方を育てたいとき。 | 解法の多様性より正解の速さを求めると文化が壊れる。 |
| [[パタン/意味のある具体的なフィードバック]] | 成長につながるフィードバックをしたいとき。 | 多すぎると、どれに取り組むかが分からなくなる。 |
| [[パタン/達成規準の共同構築]] | 評価の基準を学習者と共有したいとき。 | 細かくなりすぎると規準に縛られ自由な表現が減る。 |
| [[パタン/省察的評価]] | 学習の質を振り返りで高めたいとき。 | 振り返りが形式的になると意味がない。 |
| [[パタン/ポジティブフィードバック]] | 望ましい行動を増やしたいとき。 | 過剰なほめが自律的判断力の形成を妨げることがある。 |
| [[パタン/自己記録]] | 自律的な自己管理習慣を育てたいとき。 | 記録が目的になると学習そのものが手段になる。 |
