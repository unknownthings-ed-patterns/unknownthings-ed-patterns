## 要約

### 「三つのバランス」（本Wikiでは三円モデルと呼ぶ）

授業の成否は「その前に決している」（はじめに）。「子ども理解」「教材の開発・吟味」「学習内容の理解」の三つのバランスのなかで楽しい授業を考える、と著者は言う：

| 円 | 内容 |
|---|---|
| ①子ども理解（学級経営） | 認め合える学級風土があってこそ子どもは力を発揮できる |
| ②教材の開発・吟味 | 子どもの興味・関心に基づく問題解決的な教材研究 |
| ③学習内容の理解 | 学習指導要領の趣旨・内容に基づいた単元構成 |

どれかに偏ると授業が破綻する（銀座のミツバチ事例：魅力的な教材でも学習指導要領との接続が不十分なため協議会で指摘された）。

### 第1章の8つの仕掛け（子どもとかかわる）

**仕掛け①：6つの約束（学級開き）**

| 約束 | 語りかけの核心 |
|---|---|
| 35+1でつくる | 「誰か一人でも欠けてもダメ」「あなたが大切、あなたの居場所はここ」 |
| チャレンジしよう | 「失敗の後に次を考えよう」（ドウエック研究を根拠に） |
| 提案しよう | 「学級・学校生活を自分たちでつくる」 |
| 助け合い・認め合い・高め合い | 「同じことが同じようにできる力ではなく、多様な力の結集」 |
| あたたかい言葉かけ | 「特に身体的なことは冗談でも言ってはいけない」＋「そのたった一言が人の心を傷つける／そのたった一言が人の心をあたためる」という言葉の紹介 |
| 遠慮せず | 「私が間違えたら言ってください」「私も間違えます、人間ですから／間違えたら謝ります」 |

「遠慮せず」実例：走り高跳びの授業で学習を保証できなかったとき、次の授業が始まる前にみんなの前で謝り、頭を下げた→子どもたちが許し、フォローしてくれた。

**仕掛け②：朝のスピーチ（日直スピーチ）**

1. 日直が1分間スピーチ（テーマは子どもたちが話し合って決める）
2. 日直が「何か質問はありますか？」とクラスに問う
3. **教師が真っ先に手を挙げて質問する**（「なぜ？」「どうして？」を中心に）
4. 教師が先に質問することで他の子どもも「聞いてみたい」気持ちが高まる

4つの期待効果：
- 「あなたのことを知りたい」という空気をつくる
- 子どもが「なぜなら」と理由を交えて話すようになる
- 聞いている子どもも「なぜ」を聞きたくなる
- 話し合い・聞き合いの関係性が育つ

**仕掛け③：二つの日記**

| | 三行日記「よかったよ・たのしかったよカード」 | 5分間日記「いっぽいっぽ」 |
|---|---|---|
| タイミング | 毎日下校前→翌朝返却 | 家→毎朝提出 |
| 形式 | 3行＋「おうちのひとから」欄 | 漢字練習（1文字）＋日記欄 |
| 内容 | ポジティブな出来事 | 完全自由 |
| 週末 | 持ち帰り保護者サイン→月曜返却 | 継続 |

**SOS機能**：アンパンマンの顔を描く＝「明日、相談があります」の秘密のサイン  
**学級通信増幅**：許可を得て日記を紹介→1年でクラス全員の日記が載るように工夫→互いのよさを認め合う文化が広がる

**仕掛け④：1×1を1×35に広げる**

- 発言者の**対角線上・最も遠い位置**に立つ＋「私に聞こえるように言ってね」
- 理由：①子どもは教師めがけて発言するので、教師が発言者の対角線上にいれば、その発言が学級全体に届く②話し手も聞き手も全員を視野に収められる（廊下側でうなずく子の様子にも気づける）
- （仕掛け⑧「子どもとの会話を楽しみ、会話で育てる」より）日常的な問い返しの型：「ほかには、どう？」「たとえば、どういうこと？」「どこから、そう思ったの？」「つまり、どういうこと？」

**仕掛け⑤：わたしのうれしいをみんなのうれしいにする**

体育・跳び箱の実践：跳べないAくんをBくんが自発的に「手伝っていい？」と申し出る→数人が加わり役割分担（解説・実演・励まし）→Aくんが跳べた瞬間、関係のない子も全員集まって大騒ぎ。「友達の成功に自分がかかわった」という感覚が自己肯定感を高める。

**仕掛け⑥：みんなで問題解決する場面をつくる（台風の目事例）**

- 子どもから「作戦会議を開きたい」という提案
- 教師は録画映像を見せて「ポイントがわかるかな？」と問うだけ
- 子どもが自分で気づく（ノーミス・集まる・声かけ）
- 優勝後「作戦会議」が学級文化になる

**仕掛け⑦：子どもの言葉は子どもに解説してもらう**

「よくわからなかったから、もう一度教えてくれる？」→それでもわからなければ「Aくんが言いたかったこと、わかる人いる？」→代弁者確認。応用：本当はわかっていても**わからないフリをする**——「よくわからなかったので、みんなに教えてくれない？」

### 第2章の4つの仕掛け（教材研究）

**問題解決的な教材研究のステップ（釜石の奇跡事例。本文は7ステップ）**：

①「解説社会編」を読んで学習内容をつかむ→②教科書を読んで単元の概要をつかむ→③興味をもてそうなニュースを探す→④中学生の言葉に驚き、解決すべき「問い」をもつ→⑤「釜石の奇跡は、奇跡ではない」の真意を調べる→⑥真意をつかんで解決する（決め手は地元TV局の特集番組と釜石市役所の方の話）→⑦教材化を図る。なお資料3の図は「疑問をもつ→調べる→疑問を解決する→教材化する」の4段

> 「授業とは、（教材研究を通して）教師自身が学んだことを、子どもたちに追体験させる試みなのだと言い換えることができます」

**アンテナを張る**（有田和正の言葉）：「ざーっと見て引っ掛けておく」
- 小金井阿波踊り、銀座のミツバチ、マグロの蓄養、開かずの踏切、三陸の魚がない、など

**シンプルな問いと解**：教材の核心を [問い] と [解] の1セットに絞る  
例：[問い] なぜ国分寺市はイザ！カエルキャラバンを行っているのか → [解] 若い住民の防災意識を高めるため

### 第3章の4つの仕掛け（学習内容・単元設計）

**縦糸と横糸**：
- **縦糸**＝単元全体の問いの連鎖（前時→本時→次時）
- **横糸**＝1時間の資料→活動→評価の連動

**学習問題の一語が問いの質を変える**：  
「だれが〜しているのか」という主語の有無だけで、子どもが注目する対象が変わる

**三つの場面**：
1. **見通しをもつ**：課題が届いているか・予想から見通しをもてるか
2. **かかわり合いながら学ぶ**：目的共有が先決。話し言葉の型（つまり/たとえば/なぜなら/Aさんと関連して/Aさんと違って）
3. **まとめる**：三人称（「地域の人々は…」）→一人称（「私は…と考える。なぜなら…」）への転換で自分ごと化

### 第4章：想定外を楽しむ

**仕掛け8割・本番2割**：授業はベルが鳴った瞬間に8割の仕掛けが済んでいる状態をつくる

**追い込み漁批判**：「教師が考えた結論に子どもを追い込む授業」を自戒的に命名。教師が思った通りに進む授業は実はおもしろくない——子どもを信じきれていないことが根底にある。

**「想定外は想定内」**：単元目標・教材研究・学習計画が揃っていれば、1時間の逸脱は問題ない。

**単元の内容分析の四つの視点（国分寺市の防災単元の実践事例より）**：①事実を見る②人の営みを見る③社会的な意味や価値を考える④自分のかかわりを考える

**資料の絞り込み目安**：追究に必要な資料を絞り込む——中心資料1つに対して補助資料2つか3つがめやす（同事例より）。

## 教育実践への示唆

1. **三円モデルの自己診断**：「子ども理解・教材研究・学習内容理解」のどれが最も薄いかを問うだけで、次に伸ばすべきことが明確になる

2. **学期はじめの6つの約束**：言語化→教師が最初に体現することがセット。「遠慮せず」を言葉だけで終わらせず、実際に謝る姿を見せることが「教師の姿勢が子どもの行動規範になる」

3. **対角線の立ち位置＋問い返し4パターン**：今日から試せる最小の授業技術。立ち位置だけで授業の「空気」が変わる

4. **学習問題に「だれが」を入れる**：一語の追加が単元のねらいを問いに織り込む

5. **三人称→一人称のまとめ**：「Aさんにとって〇〇とは何か」ではなく「私にとって〇〇とは何か」へ転換するだけで学びが深まる
