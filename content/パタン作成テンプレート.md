# パタン作成テンプレート

最初から完成したパタン記述にしなくてよい。まずは、経験から仮のパタンを取り出すための短いテンプレートとして使う。

## 最小テンプレート

```markdown
# 仮のパタン名

## くり返し起きる場面

どんな授業・活動・支援の場面で起きるか。

## 困っていたこと

その場面では、何がうまくいきにくいか。

## 自分がしている工夫

そこで、どんな手立て・環境・問い・順序・教材を置いているか。

## なぜ効くのか

その工夫は、子どもの経験をどう変えているか。

## もしなかったら

その工夫がなかったら、何が起きにくくなるか。

## 似た場面

別の学年・教科・教材・支援でも同じ働きが見られるか。

## 関連しそうなパタン

- パタンページへのリンク — 補完: どう補い合うか
```

## もう少し育てるテンプレート

| 要素 | 書くこと |
|------|----------|
| 背景（Context） | どんな状況で必要になるか |
| 問題（Problem） | 何が難しいのか |
| 力のかたち（Forces） | 何と何が引っ張り合っているか |
| 解決（Solution） | どんな関係・手立てを置くか |
| 結果（Consequences） | 子どもの経験や学習がどう変わるか |
| 関連パタン | `前提`、`補完`、`対比`、`発展`、`実践化`、`抽象化` などの関係ラベルを添える |
| Actionable Insight | 明日から試せる小さな行動 |

## 名前をつけるコツ

- 行為が見える名前にする
- 教師目線だけでなく、子どもの経験も含める
- 具体的すぎず、抽象的すぎない名前にする
- 似た場面で再利用できる名前にする
- 迷ったら仮名でよい

## 確かめる問い

- これは単なる出来事ではなく、関係や働きとして繰り返し現れるか
- よい結果との関係があるか
- そのパタンを重ねると、状況はどう変わるか
- もしそのパタンがなかったら、同じ結果は起きただろうか
- 関連パタンは、ただ似ているだけでなく、どんな関係かを一語で言えるか
