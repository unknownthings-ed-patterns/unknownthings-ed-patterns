# 逆算・双方向思考

> 同じ数字を、同じ場面で、逆から問う。かけ算の答えが、わり算の出発点になる。

## 背景（Context）

日本の算数教育では、かけ算と割り算、足し算と引き算は「別々の単元」として順番に教えることが多い。九九を覚えてからわり算を学ぶ。この順序に問題があるわけではないが、多くの子どもが「かけ算」と「わり算」を「別々の手順」として学び、**両者が同じ関係の「方向違い」であることに気づきにくい**。

Liljedahl & Giroux（2024）のTask 38「Track Day」は、この分断を正面から解消しようとする設計だ——同じ数字・同じ場面を使い、「合計を求める（かけ算）」から「1組の人数を求める（わり算）」へと問いの方向を変える。

## 問題（Problem）

乗法と除法を「別の操作」として覚えた子は、「どちらを使うか」を問題文の手がかりから判断しようとする（「合わせると」→たし算、「同じ数ずつ分けると」→わり算）。**手がかり語を探す作業**になり、「なぜわり算なのか」を自分で考えることがない。

逆算（未知数を求める）も同様——「逆から考える」という思考ができず、「どの公式を当てはめるか」を外から探してしまう。

## 力のかたち（Forces）

- 操作と逆操作が同じ場面にあると、「この2つは同じ関係の方向違いだ」という気づきが生まれる
- 一方向だけの問いを繰り返すと、「かけ算の場面は見ればわかる」という記号的理解に止まる
- 同じ数字を使って方向を変えることで、「確認の計算」が「逆演算の理解」になる
- 逆算を「計算の確認」としてではなく「問いの立て方の転換」として体験させると、方程式的思考の入口になる

## 解決（Solution）

**同じ数字・同じ文脈のまま、問いの方向を変えた問題を連続して出す。子どもが「今度は逆だ」と気づいたとき、逆演算を発見している。**

---

### 設計の原則

1. **同じ数字で方向を変える**——3×4=12を学んだ直後に「12を3で分けると？」を出す。数字が同じだから「同じ場面だ」とわかる
2. **文脈を変えない**——数字や操作の「手がかり語」を頼りにした判断でなく、「何を求めたいか」から式を立てる思考を促す
3. **方向が変わることに気づかせる**——「今日の問いは前と何が違う？」と問う。この問いが逆演算の発見の入口になる
4. **「確かめ算」として使う**——わり算の答えをかけ算で確かめる（÷確認として×を使う）体験が、両者の関係を深める

---

### 代表例①：Track Day（Task 38）

```
同じ場面：運動会のリレー

Type 1（乗法）：
  「3組に4人ずついる——全部で何人？」
  3 × 4 = 12

Type 2（除法・等分除）：
  「12人を3組に分けると1組何人？」
  12 ÷ 3 = 4

Type 3（除法・包含除・余り）：
  「25人を4人ずつの組にしたら何組できる？余りは何人？」
  25 ÷ 4 = 6 あまり 1
```

Consolidationで問う：
> 「Type 1とType 2、使った数字は同じだ。何が違った？式はどう変わった？なぜ？」

---

### 代表例②：Sum Some More / Subtraction is the Main Attraction（Task 32〜33）

```
同じ場面：兄弟がポケモンカードを比べる

Task 32（加法）：
  「兄が23枚、弟が74枚——合わせると何枚？」
  23 + 74 = 97

Task 33（減法）：
  「兄が23枚、弟が74枚——どちらが多い？差は何枚？」
  74 - 23 = 51
```

2回の授業で同じ登場人物・同じ枚数を使い、「問われること」だけが変わる。

---

### 代表例③：Keep the Balance / I'm Thinking of a Number（Task 48〜49）

```
Task 48（視覚的逆算）：
  天秤でねこの重さ＝おもりの値——バランスからねこの重さを求める

Task 49（記号的逆算）：
  「ある数に3を足したら12になった——最初の数は？」
  式：x + 3 = 12 → 逆算：x = 12 - 3 = 9
```

天秤（具体）→記号の方程式（抽象）と移行しながら、「逆算で未知数を求める」思考が育つ。

---

### 「逆算」の思考ステップ

| ステップ | 具体的な操作 |
|---------|------------|
| 1. 操作の順番を記録する | 「3を足した、次に2倍した」 |
| 2. 逆順で逆の操作をする | 「まず÷2（最後の操作の逆）、次に−3」 |
| 3. 確認する | 「元の数から順番に操作して答えになるか？」 |

この3ステップが「逆算」の手続き的理解であり、これを**繰り返し体験させることで「方程式を解く」という操作の内面化**が進む。

## 結果（Consequences）

- 乗法と除法、加法と減法が「方向の違い」として理解される——九九の逆引きが自然にできる
- 「どの式を使うか」より「何を求めたいか」を問いの起点にする思考が育つ
- 方程式（中学数学）への橋渡しが、小学校算数の中で自然に始まる
- ただし、「逆算して確かめる」ことを全員に求めると、逆算が苦手な子に二重の負荷をかける——Mild段階では「確認なし」でよい
- Task 49（I'm Thinking of a Number）で小数を使う理由：整数だと暗算で解けてしまい逆算の思考が起きない——計算が簡単すぎると思考が省略される、という設計上の問題への意図的な対応

## Actionable Insight

- **かけ算九九を教えた次の授業で「逆問題」を出す**——「3×4=12がわかったら、12÷3は？」を口頭で問う（新しい「わり算の単元」として構えさせない）。「九九の答えから元の数を探す」体験が逆演算の最初の感覚になる
- **「答えを確かめてみよう」より「逆から問ってみよう」**——「52÷4=13を確かめたい人は、13×4を計算してみよう」ではなく、「52÷4の問題を逆にすると何？誰か問いを作ってみて」。確認より「問いの転換」を意識させる
- **天秤の絵を描く習慣をつける**——「□＋5＝12」を解くとき、左右の皿を描いて「両方から5を取るとバランスが崩れない」を体験させる。方程式を「天秤の操作」として視覚化する習慣が逆算の直感を育てる
