2. 自分で学ぶ時間 + 先生と一緒の時間（40分、わたり・ずらし）

## 数学ワークショップ（参考枠組み）

Nancie Atwell の数学ワークショップを支援級の文脈に適応:
- **ミニレッスン**: 短く焦点化（自立時間を確保するための必然）
- **数学ジャーナル**: 思考の記録
- **学習グループテスト**: 解法共有・振り返り
- **ウォームアップ**: 毎回同じ形式、中身だけ変える

Building Thinking Classrooms（BTC）の知見も参照:
- 構造の固定化で子どもの安心・自律を生む
- ランダムグループ・思考の可視化

## アンカー課題ストック

**目的**: 「待ち時間」を算数の学習時間に変える。終わりのない（または十分に難しい）課題。

| 良問集（英語） | Continental Mathematics League (CML)、MATHCOUNTS、Nimble with Numbers |
| グループ | United We Solve、The Game of Set |

## バインダー（個人算数ポートフォリオ）

- 算数用語辞典（用語・定義・図・例）が主軸 → [[パタン/数学語彙の文脈的指導]] のフォーマットで設計
- 思考の跡・問題解決の記録を蓄積
- 子どもが「自分の算数の歴史」を持てる場所

**語彙辞典1ページの構成（Muray, 2004 準拠）**：

| 欄 | 内容 |
|----|------|
| 用語 | 算数語彙（例：面積） |
| 自分の言葉 | 自分で書いた説明 |
| 図・絵 | 視覚的イメージ |
| 例 | 当てはまるもの |
| 非例 | 当てはまらないもの（理由付き） |
