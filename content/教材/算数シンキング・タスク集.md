## 1. おはじきの分け方

**学年目安**: K〜1年（非カリキュラムタスク）  
**数学的ねらい**: 数の合成・分解（10のボンド）、複数解の存在に気づく

### 導入の言葉

> 「今日は10個のおはじきを使います。このおはじきを2つの山に分けてください。どんな分け方ができますか？全部見つけてみよう。」

おはじきを子どもに配る（または床に置く）。「答えは何通りです」とは言わない。数え方や記録の仕方も指示しない。「どうやって記録する？」と聞かれたら「好きなやり方で」と返す。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 3つの分け方を見つけて、それぞれの数を書こう |
| **ミディアム** | 全部の分け方を見つけよう。どうすれば「全部」と言える？ |
| **スパイシー** | 全部で何通りある？1と9、2と8…と並べてみると何が見える？0や10はどうする？ |

### 収束の問い（Consolidation questions）

- 「どんな分け方が出た？黒板に全部書いてみよう」（子どもが発表したものを教師が板書）
- 「0＋10、1＋9、2＋8……と並べると、どんなことが見える？」
- 「全部で何通りあった？なぜその数になるの？」
- 「いつも2つの数を足したら10になっているね。これを『10のペア（10のボンド）』と呼ぼう」

### 教師へのメモ

- 予想される解法：おはじきを分けてから数える、表にする、式で書く、絵で表す
- 0+10 と 10+0 をどう扱うかで盛り上がる（「どちらが先でも同じ？違う？」）
- Consolidationで10の合成一覧（0+10, 1+9, 2+8, ..., 10+0）を視覚的に並べると、後の計算学習への橋渡しになる
- **特別支援対応**：Mildをさらに下げるなら「5個を2つに分ける」から始める

## 2. 正方形と長方形を全部数えよう

**学年目安**: 1〜2年（非カリキュラムタスク）  
**数学的ねらい**: 体系的な数え方、正方形・長方形の認識

### 導入の言葉

黒板に3×3のマス目を描く（または印刷して配る）。

> 「このマス目の中に、正方形はいくつありますか？小さいのも大きいのも全部数えよう。」

「1個？9個？もっとある？」という問いかけでよい。余分なヒントは出さない。

```
┌─┬─┬─┐
│ │ │ │
├─┼─┼─┤
│ │ │ │
├─┼─┼─┤
│ │ │ │
└─┴─┴─┘
```

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 一番小さい正方形（1マス分）を全部数えよう |
| **ミディアム** | 大きさが違う正方形を全部数えよう（1×1, 2×2, 3×3） |
| **スパイシー** | 正方形だけでなく、長方形も全部数えよう（縦長・横長も含む）|

### 収束の問い（Consolidation questions）

- 「1×1の正方形は何個あった？どうやって数えた？」
- 「2×2の正方形が5個あると言う人と4個あると言う人がいるね。どちら？どうやって確かめる？」
- 「長方形も全部数えたら、どうすれば漏れなく数えられる？」（体系的な数え方の共有）
- 「正方形は長方形の仲間です。なぜ？」

### 教師へのメモ

- 答え：1×1が9個、2×2が4個、3×3が1個 → 正方形合計14個
- 長方形（正方形を含まない）：1×2が6個、1×3が3個、2×3が2個、2×1が6個、3×1が3個、3×2が2個 → 非正方形長方形18個、合計32個
- **体系的数え方の種類**：左上から順に数える・大きさ別に数える・位置別に数える
- 「どうやって間違えないようにしたか」の方法を共有することが本タスクの核心

## 3. 面積が24cm²の長方形を全部見つけよう

**学年目安**: 2〜3年（カリキュラムタスク：面積・かけ算）  
**数学的ねらい**: 面積の意味、因数の概念への入口、周の比較

### 導入の言葉

> 「面積が24cm²の長方形を作ります。辺の長さは整数センチメートルとします。どんな長方形が作れますか？全部見つけよう。」

方眼紙があれば配る（なければ式だけでもよい）。「面積＝縦×横」だけ確認し、他のヒントは出さない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2種類の長方形を見つけて、式と図で表そう |
| **ミディアム** | 全部の長方形を見つけよう。漏れなく見つけるにはどうする？ |
| **スパイシー** | 全部の長方形の「周の長さ」を計算しよう。いちばん周が短いのはどれ？なぜそれが短くなるの？ |

### 収束の問い（Consolidation questions）

- 「見つかった長方形をまとめると？」（板書：1×24, 2×12, 3×8, 4×6）
- 「縦の長さと横の長さのペアを見ると、どんな数？」（24の約数のペア）
- 「全部で何種類あった？なぜそれ以上はない？」
- スパイシー到達組へ：「周が一番短いのは4×6。なぜ正方形に近い形ほど周が短いの？」

### 教師へのメモ

- 答え：1×24（周50cm）、2×12（周28cm）、3×8（周22cm）、4×6（周20cm）
- 「縦×横＝24になる整数のペア」＝24の因数ペアである。「因数」という言葉は高学年で出てくるが、概念としてここで経験できる
- Consolidationで「同じ面積でも形が変わると周が変わる」を発見するだけで十分。「最適な形はいつも正方形に近い」まで到達できればスパイシー達成

## 4. 奇数の和のパターン

**学年目安**: 2〜4年（非カリキュラムタスク）  
**数学的ねらい**: 数列・パターン発見・平方数の視覚的理解

### 導入の言葉

黒板に書く：

```
1 = 1
1 + 3 = 4
1 + 3 + 5 = 9
1 + 3 + 5 + 7 = 16
```

> 「続きはどうなると思いますか？どんなパターンが見えますか？」

計算させる前に「どんなパターンが見える？」と一度聞く。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 次の5行を続けよう（1＋3＋5＋7＋9＝？から5行）|
| **ミディアム** | 1＋3＋5＋…＋19はいくつ？式を全部書かずに予想してから確かめよう |
| **スパイシー** | 1＋3＋5＋…＋99はいくつ？なぜいつも平方数になるの？図を使って説明できる？ |

### 収束の問い（Consolidation questions）

- 「答えを並べてみると？（1, 4, 9, 16, 25, ...）これは何という数？」
- 「1×1, 2×2, 3×3, ... と比べると？」
- 図で見せる：奇数個ずつ点を追加すると正方形になる図

```
●          ●●         ●●●
           ●●         ●●●
                      ●●●

1個        4個（+3）   9個（+5）
```

- 「なぜ奇数を足し続けると正方形の数になるのか、この図で説明できる？」

### 教師へのメモ

- スパイシーの答え：1＋3＋…＋99 ＝ 50² ＝ 2500（1から99は50個の奇数）
- 「どこまでが奇数か」の確認：99＝2×50−1なので50番目の奇数
- 図の説明は「L字型の点を追加していくと次の正方形になる」という視覚的証明
- 低学年でもパターンの発見（マイルド・ミディアム）は十分楽しめる。スパイシーは3〜4年生向け

## 5. 1/2と2/3の間の分数

**学年目安**: 3〜4年（カリキュラムタスク：分数の大小）  
**数学的ねらい**: 分数の大小比較・通分・分数の稠密性

### 導入の言葉

> 「1/2と2/3の間にある分数を1つ見つけてください。」

数直線の絵を描いて「1/2と2/3の間」を示してもよい。ヒントは出さない。「本当に間にあるか確かめる方法は？」とだけ問う。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 1/2と2/3の間にある分数を1つ見つけよう。なぜ「間」といえる？ |
| **ミディアム** | 分母が違う5つの分数を見つけよう（例：分母が4の分数、5の分数、6の分数…）|
| **スパイシー** | 1/2と2/3の間には分数は何個ある？もっともっと探したらどうなる？ |

### 収束の問い（Consolidation questions）

- 「見つかった分数を数直線に並べてみよう」
- 「1/2と2/3の間に分数はいくつある？」（無限にある——いつでも「真ん中の分数」が作れる）
- 「どんな2つの分数の間にも、必ず別の分数が入れられる。なぜ？」
- 「この性質、整数でも同じ？」（整数は稠密ではない——比較）

### 教師へのメモ

- 例となる分数：7/12（通分で確認）、3/5、5/8、11/18など
- 「真ん中を取る」方法：(1/2 + 2/3) ÷ 2 ＝ (3/6 + 4/6) ÷ 2 ＝ 7/12
- スパイシーは「有理数の稠密性」に触れる。小学生向けには「いつでも間の分数が作れる」レベルで十分
- 間違いやすい点：「3/5は1/2と2/3の間？」→ 1/2=0.5, 3/5=0.6, 2/3≈0.667 → 間にある

## 6. おにぎりの組み合わせ

**学年目安**: 2〜3年（カリキュラムタスク：場合の数）  
**数学的ねらい**: 組み合わせの数え方・体系的な列挙・順列と組み合わせの区別

### 導入の言葉

> 「鮭・ツナ・卵・梅・昆布の5種類のおにぎりがあります。この中から3個選んで買います。どんな選び方がありますか？全部見つけよう。」

「たとえば、鮭・ツナ・卵という選び方があります。他には？」と1例だけ示す。「順番は考えない（鮭・ツナ・卵と卵・ツナ・鮭は同じ）」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | できるだけたくさんの選び方を見つけよう（漏れや重複は気にしなくてよい）|
| **ミディアム** | 全部の選び方を漏れなく・重複なく見つけよう。どんな順序で探すと間違えない？ |
| **スパイシー** | ①同じ種類を2個選んでいいとしたら、全部で何通り？　②3個の順番が違っても別の選び方とするなら何通り？ |

### 収束の問い（Consolidation questions）

- 「全部で何通りあった？（10通り）どうやって確認した？」
- 「どの順で探すと漏れなく数えられる？」（例：鮭を必ず入れる場合→4通り、鮭なしツナを入れる場合→3通り、...）
- 表に書いてまとめる：鮭○ の組み合わせ 4、ツナ○鮭× の組み合わせ 3、...合計10
- スパイシー①：重複を許す組み合わせ → C(5+3-1, 3)=35通り（中学生向けの発展）
- スパイシー②：3個を並べる順列 → 10×6＝60通り（順列 vs 組み合わせの区別）

### 教師へのメモ

- 答え（組み合わせ）：C(5,3) ＝ 10通り
  - 鮭を入れる4通り：鮭ツナ卵、鮭ツナ梅、鮭ツナ昆布、鮭卵梅、鮭卵昆布、鮭梅昆布（6通り）→ 間違い。鮭を含む組み合わせはC(4,2)＝6通り
  - 正しい木図：鮭入り6通り+鮭なしC(4,3)=4通り → 計10通り
- 体系的数え方の指導ポイント：「一番左に来る具材を固定して数える」方法が漏れ・重複なし
- 2年生でも「鮭から始めてすべての組み合わせを書く→次はツナから」という方法で取り組める

## 7. 階段の形を続けよう

**学年目安**: 1〜3年（非カリキュラムタスク）  
**数学的ねらい**: 視覚的パターンの発見・三角数・「なぜ？」を図で説明する

### 導入の言葉

黒板に階段の形を3ステップ描く。

```
ステップ1   ステップ2    ステップ3
            ●●          ●●●
●           ●           ●●
                        ●
（1枚）     （3枚）      （6枚）
```

> 「この形はどのように成長していますか？ステップ4はどんな形になる？何枚のタイルが必要？」

「ステップ10は何枚？」とだけ付け加える。計算の方法は教えない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | ステップ4・5を紙に描いて、タイルの枚数を数えよう |
| **ミディアム** | ステップ10はいくつ？全部描かずに求める方法を考えよう |
| **スパイシー** | 2つの階段を組み合わせると何ができる？その図を使ってステップnの枚数を式で表せる？ |

### 収束の問い（Consolidation questions）

- 「各ステップの枚数を書き出すと？」（1, 3, 6, 10, 15, 21, ...）
- 「増える枚数はどう変わっている？」（2, 3, 4, 5, ...——1ずつ増える。なぜ？）
- 「2つのステップ4の階段を組み合わせると何の形になる？」（4×5の長方形→20枚）
- 「だからステップ4は？」（20÷2＝10枚）→ 「ステップnは n×(n+1)÷2と表せる」
- 「1, 3, 6, 10 ...という数を『三角数』と呼びます。なぜその名前だと思う？」

### 教師へのメモ

- **答え**：ステップn ＝ n(n+1)/2。ステップ10＝55枚
- **視覚的証明**：2つの階段をひっくり返して合わせると n×(n+1) の長方形になる。これがBoalerの言う「数学は証明を図で見せられる」という実例
- **スパイシーの核心**：「なぜ2で割るのか」——2つ合わせたから。図が説明を引き出す
- **特別支援対応**：マイルドは「次のステップを1段増やして描く」だけでよい。1枚ずつ貼れるタイルや付箋を使うとより具体的に操作できる
- 1年生でも「次はどうなる？」の問いで参加できる。3年生でもスパイシーで十分に深められる

## 8. 百マスで宝探し

**学年目安**: 2〜4年（非カリキュラムタスク）  
**数学的ねらい**: 倍数の視覚的パターン・数の構造・公倍数への入口

### 導入の言葉

1〜100の百マス表を全員に配る（または黒板に大きく描く）。

> 「2の倍数（2, 4, 6, 8 ...）をすべて赤で塗りつぶしましょう。どんな形が見えますか？」

「きれいな形が見えるはず」とだけ伝え、何が見えるかを当てない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2の倍数を赤で塗ろう。どんなパターンが見える？言葉で説明しよう |
| **ミディアム** | 今度は3の倍数を青で塗ろう。赤と青の両方になる数はどれ？それはどんな数？ |
| **スパイシー** | 5の倍数を緑で塗ろう。3色全部ついた数はいくつある？いちばん小さい数は？100以上でも予測できる？ |

### 収束の問い（Consolidation questions）

- 「2の倍数はどんな模様？」（縦の縞——偶数の列だけ）
- 「3の倍数は？」（斜めに走る縞のようなパターン）
- 「赤と青の両方の数をリストすると？」（6, 12, 18, 24 ...）「これはどんな数？」（6の倍数）
- 「なぜ2の倍数でもあり3の倍数でもある数は、6の倍数になるの？」
- スパイシー到達組：「3色全部 ＝ 2でも3でも5でも割れる数 → 30の倍数（30, 60, 90）。なぜ30？」

### 教師へのメモ

- **答え**：赤×青（2と3の公倍数）＝ 6の倍数。赤×青×緑（2と3と5の公倍数）＝ 30の倍数（30, 60, 90）
- 「最小公倍数（LCM）」という言葉は使わなくてよい。「2でも3でも割り切れる一番小さい数は？」という問いから概念が自然に出る
- **Boalerの視覚的数学との接続**：百マス表は数のパターンを「見える」化する強力な道具。「数学はパターンの科学」を体感させる場面
- **準備物**：百マス表（A4印刷）、3色の色えんぴつ
- **特別支援対応**：マイルドだけでも十分に完結する。赤の縞模様が見えた時点で「すごい発見！」と価値づける
- 発展として「4の倍数だったら？」「7の倍数だったら？」と自分で探究できる

## 9. 紙を折って分数を見つけよう

**学年目安**: 2〜4年（カリキュラムタスク：分数の視覚化）  
**数学的ねらい**: 分数の等分の意味・折り紙で作れる分数の規則・視覚的理解

### 導入の言葉

細長い紙（A4を縦に細く切ったもの）を1人1枚配る。

> 「この紙を折って、1/2を見せてください。どんな折り方ができますか？」

「折り方は1通りとは限りません」と伝える。「1/2にできた人は、次に1/4を折ってみよう」とだけ言う。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 折って1/2を作ろう。次に1/4、3/4を作ろう。折った形を図に描いて記録しよう |
| **ミディアム** | 1/8、3/8、5/8は折れる？折れた分数をリストにしよう。分母にどんな数が出てくる？ |
| **スパイシー** | 折りだけで1/3はぴったり作れる？作れない理由を説明しよう。折りで作れる分数はどんな特徴がある？ |

### 収束の問い（Consolidation questions）

- 「折って作れた分数をリストしよう」（1/2, 1/4, 3/4, 1/8, 3/8, 5/8, 7/8 ...）
- 「分母の数に注目すると？」（2, 4, 8, 16 ...——2の累乗）
- 「1回折ると2等分。2回折ると4等分。3回折ると？」→ 「折るたびに等分の数が2倍になる」
- 「1/3を作ろうとするとどうなる？」（3等分にならない——3は2の累乗じゃないから）
- 「折り紙で作れる分数は、分母が2・4・8・16...の分数だけ。なぜ？」

### 教師へのメモ

- **答え**：折り紙（半分折りのみ）で作れる分数は、分母が 2ⁿ（2の累乗）の分数。具体的には 1/2, 1/4, 3/4, 1/8, 3/8, 5/8, 7/8 など
- 「1/3はなぜ無理？」——3は2の累乗ではないため、半分折りを繰り返しても3等分にはならない。これは直感に反していて、子どもが「なぜ？」を感じる良い場面
- **Boalerの視覚的数学との接続**：分数を「数直線の点」ではなく「物理的な等分」として体験する。「見て、触って、わかる」アプローチ
- **準備物**：細長い紙（A4長辺を縦に4等分に切ったもの）人数分＋予備
- **特別支援対応**：マイルドは「折って2つに分けた1つ分が1/2」という操作体験だけでよい。紙を折って色鉛筆で区画を塗ると視覚化できる
- 発展：「1/3を折りで近似するには何回折ればよいか？」（2回目で1/4≈0.25、4/3 of ... → 不可能であることを実感）

## 10. とびいし何通り？

**学年目安**: 1〜3年（非カリキュラムタスク）  
**数学的ねらい**: 場合の数・パターンを使って先を予測する・フィボナッチ数列の発見

### 導入の言葉

黒板に飛び石を横一列に描き、石に番号を書く。

```
スタート → ①→ ② → ③ → ④ → ⑤ → ゴール
```

> 「スタートから石を渡ってゴールを目指します。1マスか2マスずつ進めます。石①まで行く進み方は何通り？石②は？石③は？」

「答えから始めず、まず書き出してみよう」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 石③までの全部の進み方を線で描こう（矢印で図に表す）|
| **ミディアム** | 石①〜⑤までの通り数を表にしよう。数のならびに何か見える？ |
| **スパイシー** | 石⑩は何通り？石nまでの通り数はどう求める？なぜそのルールが成り立つ？ |

### 収束の問い（Consolidation questions）

- 「石①〜⑤の通り数を並べると？」（1, 2, 3, 5, 8）
- 「前の2つを足すと次の数になっているね。なぜ？」
- 「石⑤に着くには、石④から1マス跳ぶか、石③から2マス跳ぶしかない。だから石④の通り数 ＋ 石③の通り数 ＝ 石⑤の通り数になる」
- 「この数列（1, 1, 2, 3, 5, 8, 13, 21 ...）はフィボナッチ数列と呼ばれている。自然界にも現れる」
- 「石⑩は何通り？」（55通り——計算せず、前2つを足し続けるだけでわかる）

### 教師へのメモ

- **答え**：石1: 1通り、石2: 2通り、石3: 3通り、石4: 5通り、石5: 8通り、石10: 55通り
- **収束の核心**：「石nへの道 ＝ 石(n-1)から1マス ＋ 石(n-2)から2マス」という構造が、「前2つを足す」ルールの理由そのもの
- **Boalerの接続**：「数学の美しさ」を体験させる典型。フィボナッチ数列はひまわりや松ぼっくりにも現れると伝えると驚きが生まれる
- **特別支援対応**：マイルドは石③まで、矢印を引いて確かめるだけでよい。「1マス」「2マス」のジャンプを体を使って実際に跳んでみると具体化できる
- **タスク7（階段の形）との接続**：両方とも「同じ構造が別の問題に現れる」体験になる

## 11. 9のひみつを解き明かせ

**学年目安**: 2〜3年（カリキュラムタスク：かけ算の構造）  
**数学的ねらい**: 9の段のパターン発見・「暗記でなく仕組みで分かる」体験・かけ算の意味の深化

### 導入の言葉

黒板に9の段を縦に書く（9×1＝9 から 9×9＝81まで）。

> 「この表をよく見てください。何か気づくことがありますか？気づいたことを2つ以上見つけよう。」

「答えを言わないで、まず自分で探してみよう」とだけ伝える。「正解は1つではない」と付け加える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 9×1〜9×9の答えの「一の位」と「十の位」を別々に書き出そう。それぞれ何が見える？ |
| **ミディアム** | 答えの「十の位 ＋ 一の位」を計算しよう。何が見える？なぜそうなるか考えよう |
| **スパイシー** | 9×n ＝ 10×n − n という式を使って「なぜ十の位と一の位の和がいつも9になるか」を説明しよう。9×11, 9×12 でもそのルールは続く？ |

### 収束の問い（Consolidation questions）

- 「一の位はどう変わる？」（9, 8, 7, 6...——9から1ずつ減る）
- 「十の位はどう変わる？」（0, 1, 2, 3...——0から1ずつ増える。掛ける数より1小さい）
- 「十の位 ＋ 一の位 ＝ ？」（いつも9）「なぜ？」
- 「9×n ＝ 10n − n を使うと：十の位は n−1、一の位は 10−n なので、足すと (n−1) ＋ (10−n) ＝ 9」
- 「指を使う方法を知っている人は？」（10本の指を広げ、掛ける数の番号の指を折る——左の本数が十の位、右の本数が一の位）「なぜこれで計算できる？」

### 教師へのメモ

- **答えの確認**：9×1＝9（0＋9）、9×2＝18（1＋8）、...、9×9＝81（8＋1）——十の位と一の位の和は必ず9
- **Boalerの核心接続**：「計算を暗記するより、仕組みを理解する方が応用できる」——9の段のパターンはその最もわかりやすい例。「数学は手順でなくパターン」
- **スパイシーの証明**：9×n ＝ 10n − n。十の位は (10n − n) ÷ 10 の商の部分 ＝ n−1（nが1〜9のとき）。一の位は 10 − n。合計 ＝ 9
- **特別支援対応**：まず9の段の答えをブロックで作り、「10のまとまりから1個取る」操作で 9×3 ＝ 30−3 ＝ 27 を体験してから表を見ると、パターンが見えやすい
- **発展**：「18の各桁の和は 1＋8＝9。27は 2＋7＝9。これはどこまで続く？9の倍数は必ず各桁の和が9の倍数になる」——3〜4年生向け発展

## 12. グリッドを歩いて数えよう

**学年目安**: 3〜5年（非カリキュラムタスク）  
**数学的ねらい**: 体系的な場合の数・パターンの発見・パスカルの三角形への出会い

### 導入の言葉

黒板に2×2の交差点グリッドを描く。左下をスタート、右上をゴールとする。

```
ゴール
  ・ー・
  ｜　｜
  ・ー・
スタート
```

> 「スタートからゴールまで、右か上にだけ進みます。何通りの行き方がありますか？」

まず「右右」「右上...」と実際に線を引いて見せる。「もっとある？」とだけ問い、答えを言わない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2×2グリッドの全ルートを矢印で描こう。次に、3×2グリッド（横3×縦2）は何通り？ |
| **ミディアム** | 3×3グリッドの全ルートを体系的に数えよう。「右右右上上上」のような記号で表すとわかりやすい |
| **スパイシー** | 各交差点に「そこまでの道の数」を書き込もう。書き込んだ数が三角形を作る。どんなパターン？ |

### 収束の問い（Consolidation questions）

- 「各交差点に道の数を書き込むと、どうやってその数が決まる？」（左から来る数 ＋ 下から来る数）
- 「なぜ足し算になる？」（ある交差点に着くには、左の交差点から右に進むか、下の交差点から上に進むかしかない）
- 全体を見渡して：「この三角形の形を見たことある？」（パスカルの三角形）
- 「1, 1, 2, 1, 1, 3, 3, 1, 1, 4, 6, 4, 1...——二項係数の三角形。数学の世界で何百年も研究されてきた」

```
（4×4グリッドで書き込まれる数）
1
1  1
1  2  1
1  3  3  1
1  4  6  4  1
```

- 「タスク6（おにぎりの組み合わせ）の答えと比べてみよう」（C(5,3)＝10 がこの三角形のどこかに現れる）

### 教師へのメモ

- **答え**：2×2: 2通り、3×2: 3通り、3×3: 6通り、4×4: 20通り（C(2n, n)の公式——高学年発展）
- **収束の核心**：各交差点への「道の数 ＝ 左の点の数 ＋ 下の点の数」という加法規則が、パスカルの三角形の生成ルールそのもの
- **Boalerの接続**：「美しい数学的構造が日常の問題から現れる」体験——パスカルの三角形はグリッドの問題・組み合わせ・二項定理・確率など全方向につながる
- **準備物**：方眼紙（5mm方眼）または黒板に大きく描く
- **特別支援対応**：マイルドは 2×2 グリッドを紙に印刷して渡し、矢印を実際に引かせる。「右・右で来た」「上・右で来た」とルートを言葉で言いながら確かめる
- **タスク6（おにぎりの組み合わせ）との接続**：組み合わせの数え方を別の文脈で再体験させる絶好の拡張タスク
