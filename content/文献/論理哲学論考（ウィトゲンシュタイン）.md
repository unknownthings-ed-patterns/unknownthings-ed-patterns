# 論理哲学論考（ウィトゲンシュタイン）

**書誌情報**

## 要約

本書は命題番号付きの独特の形式で書かれており、世界・言語・論理・倫理の関係を根本から問い直した20世紀哲学の最重要文献の一つ。前期ウィトゲンシュタインの主著であり、フレーゲ・ラッセルの影響のもと書かれた。序文にラッセルの序論が付される。

**主要概念：**

- **世界は事実の総体（命題1）**：「世界は成立していることがらの総体である」——世界は事実（Tatsache）の総体であり、ものの総体ではない（1.1）。事実とは「諸事態の成立」（2）で、事態（Sachverhalt）はものの結合（2.01）。何かがどのように成り立っているかという関係・構造こそが世界の実態、というのは本Wikiの読み。

- **写像理論（Bildtheorie）（命題2–3）**：「像（Bild）は現実に対する模型（Modell）である」（2.12）。命題（Satz）は事実の像であり、命題と世界は論理形式（logische Form）を共有することで表示関係が成立する。「名は命題において対象の代わりをする」（3.22）——名は対象を指示し、対象が名の意味である（3.203）。

- **思考は命題に表現される（命題3）**：命題3は、事実の論理像を思考と呼ぶ（序論のラッセルも同じ内容を要約している）。思考と命題は共有された論理形式を通じて世界と接続する。

- **哲学の問題は言語の誤用（4.003）**：「哲学者たちの発するほとんどの問いと命題は、われわれが自分の言語の論理を理解していないことに基づいている」——形而上学的問いの多くは言語の文法的誤用の産物。

- **語る（Sagen）と示す（Zeigen）の区別（4.12–4.121）**：命題は現実を語ることができるが、命題と現実が共有する論理形式そのものは命題によって語られることができない——それはただ示される（sich zeigen）のみ。論理・倫理・美・哲学的自我——これらは語られえず、示されるだけである。「命題は現実の論理形式を示す。命題はそれを提示する」（4.121）。4.12は「命題は現実をすべて描写しうる。しかし、現実を描写するために命題が現実と共有せねばならないもの——論理形式——を描写することはできない」と述べる。

- **言語の限界 = 世界の限界（5.6）**：「私の言語の限界が私の世界の限界を意味する」——語れないものは世界の外にある。語彙の豊かさが、その人が住める世界の広さと重なる。

- **独我論と哲学的自我（5.62–5.641）**：「独我論の言わんとするところはまったく正しい。ただ、それは語られえず、示されているのである」——自我は世界の内容ではなく世界の限界であり、語れない。「哲学的自我は人間ではなく、人間の身体でも、心理学が扱うような人間の心でもない。それは形而上学的主体、すなわち世界の部分ではなく限界なのである」（5.641）。

- **論理はトートロジー（6.1）**：「論理学の命題はトートロジーである」——論理は世界について何も語らず、ただ論理形式を示すのみ。「論理学は学説ではなく、世界の鏡像（ein Spiegelbild der Welt）である」（6.13）。

- **自然法則批判（6.371）**：「現代の世界観はすべて、その根底において、いわゆる自然法則を自然現象の説明とする誤りを犯している」（6.371）。因果連鎖については「因果連鎖を信じること、これこそ迷信にほかならない」（5.1361）と述べる。

- **倫理と美の超越論性（6.41–6.421）**：「世界の意義は世界の外になければならない」「倫理は超越論的である」「倫理と美はひとつである」——善悪・美醜は事実の世界に属さない。倫理学の命題も存在しえない。

- **善き意志は世界の限界を変える（6.43）**：「善き意志、あるいは悪しき意志が世界を変化させるとき、変えうるのはただ世界の限界であり、事実ではない」——倫理的変化は事実を変えるのではなく、その人が住む世界の構造（限界）を変える。

- **神秘的なもの（Das Mystische）（6.44–6.522）**：「神秘とは、世界がいかにあるかではなく、世界があるというそのことである」（6.44）。「だがもちろん言い表しえぬものは存在する。それは示される。それは神秘である」（6.522）。

- **はしごのメタファー（6.54）**：「私を理解する人は、私の命題を通り抜け——その上に立ち——それを乗り越え、最後にそれがナンセンスであると気づく。そのようにして私の命題は解明を行なう。（いわば、梯子をのぼりきった者は梯子を投げ捨てねばならない。）私の命題を捨て去ること。そのとき世界を正しく見るだろう。」——命題自体は足場（はしご）であり、使い終えたら捨てる。

- **沈黙（命題7）**：「語りえぬものについては、沈黙せねばならない」——本書の最後にして最も有名な命題。語れないことは沈黙するしかない。

## 教育実践への示唆

1. **「語る」と「示す」の区別——教師が「語れない」ものを「示す」責任**：道徳的感性・審美的判断力・知的誠実さ・学ぶことへの愛——これらは命題として語ることができず、ただ示されるのみ。「誠実であることが大切です」と語るより、教師が誠実な姿を示すことの方が本質的。道徳教育・人格形成は「示す」教育である。

2. **語彙の拡張 = 世界の拡張**：「私の言語の限界が私の世界の限界を意味する」（5.6）——子どもの語彙を豊かにすることは、子どもが住む世界を広げること。語彙指導の根本的意義がここにある。言葉を知らなければその現実を捉えられない。

3. **神秘的なものへの開かれ（Das Mystische）**：「世界があるということ」への驚き——タウマゼイン（驚きから始まる探究）の哲学的根拠の一つ。授業で「世界があることの不思議さ」に触れる瞬間を設計することは、Das Mystischeへの入口を開くこと。

4. **はしごを捨てる（足場の設計と手放し）**：学習の足場（scaffold）は最終的に捨てられるためにある。「100÷4の計算の手順」という足場は、割り算が内面化されたら不要になる。産婆役の教師は「はしごを提供し、しかし最終的には学習者が自分ではしごを捨てられるように」設計する。

5. **倫理の超越論性——価値は世界の「外」から来る**：「倫理は超越論的」（6.421）——世界の事実を並べるだけでは道徳は生まれない。価値観・意義・目的は「なぜ世界があるのか」「何のために生きるのか」という世界の外からの問いと関係する。道徳教育が単なる規則の暗記では機能しない理由がここにある。

6. **哲学の問題は言語の誤用（4.003）——言語の使い方を教える**：「なぜ？」という問いの多くは、言葉の意味を明確にすることで解消される（または深まる）。「正義とは何か」「幸福とは何か」を問う前に、その言葉がどのように使われているかを検討することが哲学教育の第一歩。

## 展開したい問い

1. 教師が「示す」べき最も重要なものは何か——授業設計において「語る」と「示す」をどう使い分けるか。
2. 「言語の限界 = 世界の限界」だとすると、言語を習得させる教育は世界を広げる行為である——小学校教育において語彙・言語指導が他のすべての教科の基盤になるという主張をどう根拠づけるか。
3. 倫理が「超越論的」で命題として語れないとすれば、道徳教育はどのような形をとるべきか——「道徳の時間」で何を扱えるのか。
4. 「はしごを捨てる」という体験を意図的に設計することはできるか——単元の最後に「使ってきた足場が不要になった」と学習者が感じるような体験はどう作れるか。
5. Das Mystische（神秘的なもの）——「世界があること」の驚きを授業の中でどう扱うか。宗教性のない「世界への驚嘆」という体験は教室に持ち込めるか。
