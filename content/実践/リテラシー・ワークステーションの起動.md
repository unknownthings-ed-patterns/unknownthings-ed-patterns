# リテラシー・ワークステーションの起動

Diller（2005）_Practice with Purpose_ をもとにした、3〜6年生での**ワークステーションの立ち上げ方**。Diller は、年度の初めに3〜4週間をかけて手順を作るよう勧めている。教師が小グループ指導をしている間、クラスの残りの子どもたちが「目的のある本物のリテラシー練習」に取り組む体制を、段階的に育てる。

---

## この実践で働くパタン

- [[パタン/リテラシー・ワークステーション]] — 目的のある練習を、子どもだけで進められる場にする。
- [[パタン/リーディング・ワークショップ]] — 教師の小グループ指導と独立活動を両立させる。
- [[パタン/ミニレッスン・サイクル]] — 教えた内容だけをワークステーションで練習させる。
- [[パタン/シンクアラウド]] — 活動の考え方や判断を、起動時に教師が見せる。

- [[パタン/自己選択自己決定]] — I Canリストから今日の活動を子どもが選ぶ。
- [[パタン/習慣化]] — 毎回の終わりの短い共有で独立練習の習慣を形成する。

## 起動の前提：先に整えること

ワークステーションを始める前に、次が整っていること：

| 前提条件                                         | なぜ必要か                               |
| ------------------------------------------------ | ---------------------------------------- |
| 独立読書の習慣（20〜30分）                       | 最初のステーション（読書）が機能するため |
| ペア（パートナー）の決め方ルール                 | ステーション中の相手が分かるため         |
| 「先生が小グループ中は話しかけない」ルールの合意 | 教師が中断されないため                   |
| 掲示物を置ける物理的なスペース                   | I Can リストを置くため                   |

---

## Diller の立ち上げの流れ

1. 最初の二週ほどで、独立読書と、読んだ本への反応を書くことを固める。最初に置くステーションは、教室文庫と書くステーションの二つ
2. それから、ステーションの手順を教える。一週間、一日に一つずつステーションを紹介し、教えた活動を示しながら、I Can リストをクラスで作っていく（できそうなら一日に二つ）。立ち上げやすいステーションから始める
3. その週の終わりに、一か所に四人（二人組を二つ）ずつ置いて、十分から十五分動かしてみる
4. 次の一週ほどで、ステーションを少しずつ足す。五か所以上になったら、管理ボード（誰がどこへ行くかの掲示）を使う
5. ステーションの時間の終わりには、毎回、短く全体で振り返る。出てきた困りごとは翌日のミニ・レッスンになる。することが増えるのに合わせて、時間を十分から二十分へ延ばす
6. 教師が小グループを持ち始めるのは、静かな独立読書が定着してから（三週間ほど）

---

## 最初のステーション（1）：教室文庫——独立読書

### なぜ独立読書から始めるか

子どもたちはすでに「自分で本を読む」経験がある。最初のステーションとして最もモデリングしやすく、失敗が少ない。

### モデリングと「独立読書ステーション」の紹介

1. ステーションの場所を指定する（教室の特定のカゴ・棚・コーナーを「独立読書ステーション」と名付ける）
2. 教師がシンクアラウドで実演する：
   > 「ここに来たとき、私だったら……まず I Can リストを見ます。今日は推薦カードを書こうかな、と思います。なぜかというと、昨日読んだ本がとても面白くて、パートナーにも読んでほしいから」
3. うまくいったこと・難しかったことを全体でシェアする

### I Can リストを子どもと一緒に作る

全体で問う：「独立読書ステーションでできることを一緒に考えよう」

子どもの意見を集めて絞る（3〜4つに限定）：

```
📚 独立読書ステーション — できること（I Can）
□ 自分で選んだ本を読む
□ 読んだ本の推薦カードを書く（タイトル・著者・一言コメント）
□ 読書ノートに気づいたことを書く
□ 次に読みたい本リストを作る
```

掲示物として作り、ステーションに貼る。子どもが作ることで「自分たちのルール」になる。

### 週の終わり：実際に動かしてみる（教師が見ている前で）

一か所に四人（二人組を二つ）ずつ置いて、十分から十五分動かしてみる。教師はクラス全体を見ながら観察する（小グループは組まない）。

終わったら：「うまくいったことは？難しかったことは？I Can リストで選べたか？」を振り返る。

## 最初のステーション（2）：書く

### ライティング・ステーション

**I Can リストの例：**

```
✏️ ライティングステーション — できること（I Can）
□ 今書いている草稿を続ける
□ 草稿を読み返して1つ直す
□ パートナーと互いの草稿を読んで感想を伝える
□ 新しいアイデアをライターズ・ノートに書く
```

**モデリングのポイント**：「草稿を続ける」が最も簡単。「草稿がない子はどうするか」を先に決めておく（ライターズ・ノートにアイデアを書くなど）。

## ステーションを足していく

### 選択基準

- 直近のミニレッスンで扱った内容に直結するステーションを選ぶ
- 子どもがすでにある程度慣れている活動であること

### 足し方

次の一週間ほどで、ステーションを少しずつ足す。時間も、することが増えるのに合わせて十分から二十分へ延ばす。五か所以上になったら管理ボード（誰がどこへ行くかの掲示）を使う。教師が小グループを持つのは、手順が定着してからだ。

**原則**：ミニレッスンで教えたものだけ追加する。教えていない活動はステーションに入れない。

### ワードスタディ・ステーション

**I Can リストの例：**

```
🔤 ワードスタディステーション — できること（I Can）
□ 今週の単語カードで仕分けゲームをする
□ パートナーと問題を出し合う（フラッシュカード）
□ 単語の「仲間（語族）」を探してノートに書く
□ 今週の漢字で文を作る
```

### 応答的ライティング・ステーション

読んだ本への反応を書く。リーダーズ・ノートとつながる。読んで反応を書くことは、最初の二週ほどで固めておくものでもある。

**I Can リストの例：**

```
📝 応答的ライティングステーション — できること（I Can）
□ 読んだ本について「つながり（自分・本・世界）」を書く
□ 気になった場面について自分の考えを書く
□ 本に出てきた疑問・不思議を書く
□ 「作家のように読む」気づきをメモする
```

### 詩ステーション

**I Can リストの例：**

```
🎵 詩ステーション — できること（I Can）
□ お気に入りの詩を声に出して読む（2人読みも可）
□ 詩のコレクションに1つ詩を書き加える
□ 詩の言葉から「好きな言葉・驚いた言葉」を選んでノートに書く
□ パートナーと詩を一緒に暗唱する
```

## 起動後の管理：定常稼働のために

### ステーションの時間の終わりの共有

ステーションの時間の終わりには、毎回、短く全体で振り返る。その日に考える問いを一つ掲げておくとよい。たとえば：

- 「今日のステーションでうまくいったことは？」
- 「I Can リストを見て選べたか？」
- 「先生に聞かなくても解決できたことは？」

子どもの声から新しい I Can 活動のアイデアが生まれる。共有で出た困りごとは、翌日のミニレッスンの題材になる。

### I Can リストの更新タイミング

| タイミング   | やること                                   |
| ------------ | ------------------------------------------ |
| 新単元開始時 | ミニレッスンで教えた新活動をリストに加える |

### 材料の補充と整理

- ステーションの材料は、みんなが一通り使うまで変えない。興味が落ちてきたら入れ替える
- 子どもが自分で材料を管理できる仕組みを作る（ラベル・色分け・定位置）
- 「取り出しやすく・片付けやすい」が独立性の前提

## トラブルシューティング

| よくある問題                               | 対応策                                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------------------ |
| 「先生、何をしたらいいですか？」が頻発する | I Can リストを指さして「リストを見てね」と返す。次のモデリングでリストの使い方を再確認する |
| ペアが機能していない（片方が何もしない）   | ペアを組み替える。一人で取り組むほうがよい子もいる                                         |
| 早く終わってしまう子がいる                 | I Can リストに「終わったら→〇〇をする」オプションを追加する                                |
| ステーションが騒がしくなる                 | 「ひそひそ声（6インチボイス）」のルールを確認する。席の配置を見直す                        |
| 教師が小グループを中断せざるを得ない       | まだモデリングが足りないサイン。その日はステーションをやめて全体でリフレクションする       |

---

## 完全稼働時のタイムライン（例）

小グループ指導日のスケジュール例（70分の国語時間）：

```
0〜10分    全体ミニレッスン
10〜15分   ステーションの確認・ペア発表・移動
15〜45分   【同時並行】
              教師：小グループ読書指導（15〜20分×2グループ）
              子ども：ワークステーション（独立練習）
45〜55分   片付け・ステーションの振り返り
55〜70分   全体シェア・ミニレッスンとのつながり確認
```
