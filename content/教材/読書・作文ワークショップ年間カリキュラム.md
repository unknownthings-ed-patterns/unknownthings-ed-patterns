# 読書・作文ワークショップ年間カリキュラム

リーディング・ワークショップとライティング・ワークショップを、1年間の国語実践として並べるためのカリキュラム案。

読書と作文を別々の単元に分けきらず、「読むことで書く」「書くことで読む」「話すことで考える」という往復を年間で育てる。

## 年間の大きな流れ

| 時期 | 読むこと | 書くこと | 中心にする文化 |
|------|----------|----------|----------------|
| 4月 | 読書スタミナ・選書・読者の自分史 | 白紙の冊子・書く前に話す | 読者・書き手として始める |
| 5月 | 付箋・リーダーズ・ノート | ライターズ・ノート | 思考と材料を残す |
| 6月 | つながり・疑問・推論 | 観察メモ・リスト書き | ノートを使って考える |
| 7月 | 1学期の読書振り返り | ノートの読み返し | 自分の成長を見る |
| 9月 | 読書会の入口 | 書き出しのクラフト | 友だちと読み、技法を借りる |
| 10月 | リテラチャー・サークル | 物語を書く | 役割から対話へ移る |
| 11月 | 文学討論 | 推敲・ピアフィードバック | 深い問いで読み書きを直す |
| 12月 | 2学期の読書振り返り | 作品選集・共有会 | 作品と読書履歴をまとめる |
| 1月 | テーマ読書・テキストセット | 詩・短歌・俳句 | 言葉に立ち止まる |
| 2月 | 著者研究・作家のように読む | ジャンルを選んで書く | 読む技法を自分の表現へ移す |
| 3月 | 年度末の読者の自分史 | 年度末の書き手の自己評価 | 1年間の変化を言語化する |

1学期の目標は、うまい読書感想文や完成度の高い作文ではない。読む時間・書く時間があり、子どもが自分の考えや材料を残せる状態を作る。

3学期の目標は、言葉の選択を意識し、自分が1年間でどんな読者・書き手になったかを言語化することである。

## 週の基本リズム

| 曜日 | 例 | ねらい |
|------|----|--------|
| 月 | 読書ワークショップ | 今週の読み方・読書目標を決める |
| 火 | 独立読書＋カンファリング | 一人ひとりの読書を支援する |
| 水 | ライティング・ワークショップ | ノートや作品を書く |
| 木 | 読書会・共有 | 読んだことを話し、問いを育てる |
| 金 | 振り返り・作家の椅子 | 読者・書き手としての成長を見る |

毎日45分を確保できない場合は、週3回でもよい。重要なのは、読む時間・書く時間・共有の時間が周期的に戻ってくることである。

## 評価として見るもの

| 見るもの | 評価の観点 |
|----------|------------|
| 読書記録 | 読書量だけでなく、ジャンル・作者・再読・選書の変化を見る |
| 付箋・リーダーズ・ノート | つながり、疑問、推論、作者の技法への気づきが増えているかを見る |
| ライターズ・ノート | 材料の量、多様性、過去のエントリーを使い直しているかを見る |
| 作品 | 完成度だけでなく、試した技法・直した跡・読者への意識を見る |
| カンファリング記録 | 次に何を試すかが、子ども自身の言葉で言えるかを見る |
