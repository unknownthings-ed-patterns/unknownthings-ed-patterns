# ライターズ・ノートの道具棚

ライターズ・ノートで使うエントリーのタイプ・書き始めるための問い・詰まったときの道具を、目的別に並べた棚。

Buckner, A. (2005). *Notebook Know-How*. Stenhouse. をもとに再構成。

---

## エントリーのタイプ別道具

### リスト書き（Brainstorming Lists）

アイデアの種を素早く大量に集める。文章にしなくてよい。

| 問い | 書き始めの言葉 |
|---|---|
| 好きなものを10個挙げる | 「好きなのは〜」 |
| 嫌いなものを10個挙げる | 「苦手なのは〜」 |
| 不思議に思っていること | 「なぜ〜なんだろう？」 |
| 怖いもの・心配なこと | 「こわいのは〜」 |
| うれしいとき・楽しいとき | 「〜のとき、うれしい」 |
| 絶対に書きたくないこと | 「書きたくないのは〜」（逆説から種が生まれる） |

**使う場面**：年度初めの起動・書き詰まりのリセット・トピック探しミニレッスン

---

### 観察メモ（Observations）

今日の感覚をことばにとめる。スケッチと併用してよい。

| 書き始めの問い |
|---|
| 今日、目に留まったものは？ |
| 今日、聞こえてきた音は？ |
| 今日、感じたこと・触れたものは？ |
| 今日、においを感じた場面は？ |
| 何かが気になった瞬間はあったか？ |

**書き方のコツ**：「大きい犬がいた」より「白と茶色のブチ、首のところの毛がもじゃもじゃしていた犬がいた」——具体的に書く練習。

---

### 記憶（Memories）

強く残っている場面・経験を断片として書く。物語の素材になる。

| 切り口 | 書き始めの言葉 |
|---|---|
| 昔住んでいた場所 | 「あのころ、家の近くには〜があって」 |
| 誰かのことばが刺さった瞬間 | 「〜と言われたとき」 |
| 楽しかった時間 | 「〜をしていたとき、〜だった」 |
| 後悔していること | 「あのとき〜すればよかった」 |
| 自分が変わったと感じた瞬間 | 「〜のとき、何かが変わった気がした」 |

---

### 言葉遊び（Language Play）

気になる言葉・フレーズを集める。語の感覚を育てる。

| やり方 | 内容 |
|---|---|
| 面白いと思った言葉を書き留める | 本・テレビ・会話から |
| 同じ意味の違う言葉を並べる | 「走る」→「かける」「ダッシュする」「飛ぶように走る」 |
| 聞こえた会話の断片 | そのまま書く（セリフとして） |
| 好きな文・嫌いな文 | 理由なしでよい |
| 文字・音が面白い言葉 | 「ぽっかぽか」「ぽつりぽつり」 |

---

### 人物スケッチ（Character Sketches）

知っている人・架空の人物の特徴を書く。物語のキャラクター素材に。

**問いリスト**：
- その人はどんな歩き方をするか？
- その人の口グセは何か？
- その人が一番大切にしているものは何か？
- その人が怒るのはどんなとき？
- その人の笑い方は？

---

### もしも〜・問い（Wonderings）

「わからない」「不思議だ」から書き始める。

| 問いの形 | 例 |
|---|---|
| 「もしも〜だったら」 | 「もしも犬が話せたら」 |
| 「なぜ〜なんだろう」 | 「なぜ夕焼けは赤いんだろう」 |
| 「〜って何だろう」 | 「友だちって何だろう」 |
| 「〜が好きな人はどんな人だろう」 | 雨が好きな人はどんな人だろう |

---

### ジャンル試し書き（Genre Experiments）

正式な作品を書く前に短く試す。うまくなくていい。

| 試すジャンル | 最小単位 |
|---|---|
| 詩 | 3〜5行 |
| 物語の書き出し | 1〜2文 |
| 対話（会話シーン） | 3〜4往復 |
| 説明文の書き出し | 事実を1つ書く |
| 気持ちを「見せる描写」で | 「悲しい」と書かずに悲しさを見せる1文 |

---

### 読書への反応（Reading Response）

読んでいる本と書くことをつなぐ。

| やり方 |
|---|
| 気になった一文を引用して「これが気になった理由は〜」 |
| この本の書き出しをモデルに、自分の書き出しを書いてみる |
| 主人公に手紙を書く |
| 「この本にもし第1章の前があったとしたら？」を書く |

---

## 書き詰まったときの道具

| 状態 | 使う道具 |
|---|---|
| 何も思いつかない | リスト書き（好きなもの10個）から始める |
| 書き始めたが続かない | 観察メモ（今日見たもの）に切り替える |
| 毎回同じことを書いている | ジャンル試し書き（詩・対話）で気分転換 |
| 前のエントリーが気に入らない | 過去のエントリーを読んで★印をつける |
| 書くのが怖い | 「消してよい」エントリーを1ページ書く |

---

## 月1回のノート振り返り（Revisiting）

月1回、ノートを読み返して：

1. 一番好きなエントリーに★印
2. もっと書きたいこと・広げたいことに→印
3. 「これ、作品にできそう」と感じるものに◎印
4. ◎がついたエントリーをノートの最後の「種リスト」ページに移す

---

## 評価のための観察ポイント

| 視点 | 見ること |
|---|---|
| **頻度** | どれくらいのペースでエントリーが増えているか |
| **多様性** | エントリーのタイプが広がっているか |
| **深さ** | 断片が膨らんでいるか・続きを書いているか |
| **声** | 「この子らしさ」が感じられるか |
| **関与** | 「生きているノート」か（使い込まれているか） |
