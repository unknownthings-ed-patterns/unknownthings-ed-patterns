# 2列メモ（シンクシート）

## この実践で働くパタン

- [[パタン/思考の可視化]] — 左に事実、右に考えを置き、読んでいる途中の思考を外に出す。
- [[パタン/メタ認知的モニタリング]] — 自分が何に気づき、どこで迷ったかを見取りやすくする。
- [[パタン/能動的関与]] — 読むだけでなく、反応を書きながらテキストに関わる。
- [[パタン/フィードバック]] — 教師や友だちが、考えの次の一手を返しやすくする。
- [[パタン/可視化]] — 見えにくい読みの過程を、共有できる記録に変える。

- [[パタン/読書アイデンティティ]] — 自分の読み方・反応を記録して読者としての自己を育てる。
- [[パタン/自己説明（精緻化）]] — 「なぜそう感じたか」を書く行為が自己説明の機能を果たす。

## 実践の概要

「読みながら考えたこと」と「その分類（記号）」を2列に並べるシンプルなメモ様式。Harvey & Goudvis（2007）が提唱する "Think Sheet" を日本語教室に適応した形。

テキストコーディング（[[実践/テキストコーディング]]）と組み合わせて使うと特に効果的。付箋でコーディングした後に2列メモでまとめると、読書中の思考が整理され、話し合いや振り返りの基盤になる。

---

## 基本様式

| 気づいたこと・考えたこと                     | 記号                        |
| -------------------------------------------- | --------------------------- |
| （テキストを読んで浮かんだ考え・疑問・反応） | TS / TT / TW / ? / ! / I 等 |

左列：**自分の言葉で** — 「〜だと思った」「〜が気になった」「〜と同じだ」  
右列：**テキストコーディングの記号** — TS, TT, TW, ?, !, I, Huh? など

---

## 使い方

### パターン1：読みながら書く（並行型）

- テキストを手元に置き、読みながら2列メモを書き込む
- 1行に1つの考えを書く——長い文章は不要
- 「気づいたことがあったら止まって書く」を習慣にする

### パターン2：読後にまとめる（後書き型）

- 付箋（テキストコーディング）に書いたメモを2列シートに転記・整理する
- 「付箋→シート」の流れで思考が深まる
- 読後のグループ対話の前に個人の記録として整理する

### パターン3：問いに応えながら書く（誘導型）

- 特定の問いを左列の上に書いておき、その問いに関わる気づきだけを記録する
- 例：「主人公の気持ちはどう変わったか」→変化に関わる気づきだけを集める

## 記入例

| 気づいたこと・考えたこと                   | 記号 |
| ------------------------------------------ | ---- |
| おじいちゃんの家と同じ匂いがした           | TS   |
| なんでこんなことをしたの？動機が分からない | ?    |
| ニュースで見た話と似ている                 | TW   |
| この後、また同じことが起きる気がする       | I    |
| 急に意味が分からなくなった                 | Huh? |

---

## 特別支援学級での調整

- 左列を「感じたこと」「思ったこと」だけに絞る（記号は省略）
- 右列を「はっぴょうしたい / したくない」の2択にする（自己開示の程度を選ばせる）
- 教師が口頭でサポートしながら、代わりに書く（書記補助）
- 1枚に1行だけ書く小型シートにして負担を下げる

---

## うまくいく条件・注意点

**うまくいく条件：**

- 「正解はない」「自分が思ったことを書く」をはっきり伝えてから始める
- 最初は左列だけ（記号なし）でも十分——慣れてから記号を加える
- 先生が自分の2列メモをプロジェクターで見せながら説明する（モデリング）

**起きやすい課題と対処：**

| 課題                                 | 対処                                                     |
| ------------------------------------ | -------------------------------------------------------- |
| 「気づいたこと」が書けない           | 「面白かったところ」「不思議に思ったところ」と言い換える |
| 左列が一言（「面白かった」）で終わる | 「なんで面白かったの？」を一言付け加える練習             |
| 書くことに時間がかかって読書が止まる | 1セッションで2〜3行を目安にする                          |
| 記号を覚えられない                   | 記号の一覧表を机に貼っておく                             |
