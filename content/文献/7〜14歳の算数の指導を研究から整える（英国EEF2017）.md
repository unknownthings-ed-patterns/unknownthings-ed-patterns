# 7〜14歳の算数の指導を研究から整える（英国EEF2017）

> 英国の Education Endowment Foundation が、7〜14歳（キーステージ2・3）の算数の指導について、国際的な研究のまとめから八つの勧めを示した指針。子どものいまの理解を評価して次の指導につなぎ、具体物と図を目的をもって使い、問題解決の方略とメタ認知を教え、数学の知識を互いにつながった網にする。

**原題**：Improving Mathematics in Key Stages 2 and 3: Guidance Report（Education Endowment Foundation、2017年、2022年11月にデザイン更新、38ページ）

**読んだもの**：財団が公開しているPDF（2022年11月のデザイン更新版）。本文・囲み・用語集・作り方の説明まで全文読み、参考文献は必要な箇所を確かめた。キーステージ2は小学校3〜6年（7〜11歳）、キーステージ3は中学校の前半（11〜14歳）にあたる。指針の土台になった Hodgen ほかの根拠のレビューは読んでいない。OpenAlex ではこの指針そのものの被引用はうまく引けなかった（根拠のレビューは10件）。

## 要約（八つの勧め）

| 勧め | 中身 |
| --- | --- |
| 1. 子どもの既有の知識と理解を評価し、その上に積む | 評価は記録のためだけでなく、何を知り何を知らないかを教師が知るために使う。フィードバックは具体的で正確に、直し方を示し、多すぎないように。誤概念は避けずに取り上げる |
| 2. 具体物と図を使う | 具体物と図は道具にすぎず、使い方が大事。概念ごとに使う理由を明確にする。子どもが具体物と数学のつながりを分かるようにし、具体物の限界も知る。足場として、理解に応じて外す |
| 3. 問題解決の方略を教える | 子どもが決まった解き方を持っていない本物の問題を選ぶ。違う解き方を比べる。既有の知識を探す。図を使う。解き方の例を分析する。自分の解き方を点検し、ふり返り、伝える |
| 4. 数学の知識の豊かな網をつくる | 基本の計算をすぐ思い出せるようにする。手順の意味を理解する。方略を意識して選ぶ。比例の素朴な理解から手順へ。分数と小数は数の体系を広げるものとして教える。数学の構造を見る |
| 5. 自立と意欲を育てる | メタ認知（計画・点検・評価）を、教師が考えを声に出して示し、自己説明や説明の場で育てる。早すぎ・多すぎに注意。前向きな態度は大事だが、育て方の根拠は乏しい |
| 6. 課題と教材で挑戦と支えをつくる | どの課題・教材を選ぶかより、教師がどう使うかが大事。誤概念を取り上げる課題、例と例でないもの、話や問題で構造を見せる、手続きと概念を同時に育てる課題。技術は万能ではない |
| 7. 構造化された介入で補う | まず学級全体の授業をよくする。介入は早く、根拠があり、明示的で体系的に。学級の授業とつなぐ。退屈や不安を生まないように |
| 8. 小学校から中学校への移行を支える | 中学1年の終わりに、小学6年の終わりより算数の成績が下がる研究がある。学校間で教育課程と教え方を共有する。習熟度で学級を分ける（セッティング）と、恵まれない子との差が広がりやすい |

## 要約（目立つ点）

- **誤概念は「部分的な真実」から**：「かけ算は大きくし、わり算は小さくする」は1より大きい正の整数では正しく、その外に持ち出すと誤概念になる。誤概念は避けずに取り上げ、どこまで正しくどこから当てはまらないかを子どもと探る。反例は効くが、より豊かな概念を育てるには時間と支えが要る（p. 9）
- **数直線で分数の誤った足し算に気づく**：分子どうし・分母どうしを足す子がいたので、教師が「1/2 + 1/8 = 2/10 は正しい？」と問うた。2/10 が 1/2 より小さいことに気づいた子がいて、数直線に三つの分数を置くと、1/2 が 4/8 と同じで答えが 5/8 だと分かった。その後、子どもが自分で正しい例と誤った例を作った（p. 12、囲みC）
- **具体物を外すのは年齢でなく理解で決める**（p. 10）
- **問題の構造と文脈を入れ替えて並べる**：同じ構造で文脈の違う問題、同じ文脈で構造の違う問題を一緒に出す（p. 14）
- **電卓は、暗算や筆算の力を一般に損なわない**とする研究をまとめ、使い分けを教えるよう勧める（p. 16）
- **嫌いの増加**：算数の学習が好きでないと答えた子は、イングランドの5年生（9〜10歳）で17%、9年生（13〜14歳）で48%だった（p. 19）
- **保護者の宿題への関与**は、成績の向上につながらなかった介入が多いので慎重に（p. 19）
- **習熟度で学級を分けること**は、平均では成績を上げず、下の組の子にわずかに負の影響があり、差を広げやすい（p. 28）

## 適用範囲と限界

- **新しい研究ではなく、既存の研究の読みやすい概観**だと指針自身が書く（p. 3）。メタ分析と系統的レビューを中心に集めたが、勧めごとに根拠の強さを等級で示してはいない。「根拠の要約」の欄で、根拠の強弱を文章で示す
- 根拠の要約の多くは、米国教育科学研究所の実践ガイド（Woodward 2012、Siegler 2010、Gersten 2009 の多層の支援のガイドなど）に拠っている
- 前向きな態度の育て方、移行期の落ち込みへの対策、課題そのものの選び方などは、根拠が乏しいと明記している
- 英国（イングランド）の教育課程と学校制度が前提である
- 電卓についての判断は、[[文献/算数の土台を研究から絞り込む（全米数学諮問委員会2008）]] の「影響は限られているか、ない。自動化を妨げる程度に応じて計算の流暢さが損なわれる」と強調が異なる

## 原典で確かめたこと（wiki との照合）

1. **[[文献/Developing Effective Fractions Instruction（Siegler et al., 2010）]]** と同じく、分数を数直線上の数として教え、分子・分母どうしを足す誤りに、答えの大きさから子どもが気づく（ここでは囲みCの授業例）。本指針は勧め4の根拠の一つとして同ガイドを挙げる
2. **[[文献/算数の問題解決を4〜8年生で育てる（Woodwardほか2012）]]** を勧め3の根拠に挙げ、図・解き方の例・点検とふり返りの根拠がいちばん強いとする要約も同じである
3. **[[文献/算数の土台を研究から絞り込む（全米数学諮問委員会2008）]]** とは、電卓の扱いの強調が分かれる（上記）
4. **[[パタン/誤概念の組み替え（素朴概念を資源にする）]]** の「素朴概念は間違っていたのではなく、ここまでしか効かなかった」という見方は、本指針の「部分的な真実」の説明（p. 9）と同じ向きである

## 教育実践への示唆（Wiki側の適用案）

以下はこの Wiki の適用案である。

1. **分数のたし算で分子・分母どうしを足す誤りが出たら、答えの大きさを数直線で確かめる**：「1/2 にたしたのに、答えが 1/2 より小さくなるのはおかしくない？」
2. **誤答を「どこまでなら正しいか」から扱う**：その考えが通用する範囲を一緒に確かめてから、通用しない例を出す
3. **具体物を外す時期は学年で決めず、子どもの説明を聞いて決める**
4. **計算の工夫を出し合い、似ている点と効率を比べる**（5×18 の三つの求め方の例、p. 22）
