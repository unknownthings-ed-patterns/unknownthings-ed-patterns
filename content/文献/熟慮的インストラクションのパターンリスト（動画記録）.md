# 熟慮的インストラクションのパターンリスト（動画記録）

動画: https://youtu.be/WqTdgVeIcTQ

## 概要

熟慮的インストラクション（指示・説明）のパターンリストを解説した動画。リチャード・ソウル・ワーマン（1993）『理解の秘密―マジカル・インストラクション』NTT出版を柱に、向山洋一の授業原則、土居正博の指示論、山本弘樹「教師のための説明実践の心理学」を組み合わせて整理したもの。

## 主要内容

### ワーマン「理解の秘密」によるインストラクションの5要素

インストラクションは1つのシステムである。

| 要素 | 説明 |
|------|------|
| 送り手 | インストラクションを出す人。受け手・内容・チャンネル・コンテクストを決定する |
| 受け手（相手意識） | アクティブに行動する責任主体。理解したかどうか送り手に伝える責任がある |
| 内容 | メッセージそのもの。表現方法には制約されない |
| チャンネル | メッセージの形式・伝達手段（言葉・絵・図表・映像など） |
| コンテクスト | インストラクションが届く場面・背景。3レベル（場の状況 / 仕事の広がり / 社会的状況） |

### インストラクションの3種類（内容の分類）

| 種類 | 説明 |
|------|------|
| 過去のインストラクション | 知識の移動・伝達。即座の行動は求められない |
| 現在のインストラクション | 今すぐの行動を求める。動かし方・組み立て方・道案内など |
| 未来のインストラクション | 将来のいつかの行動を求める。目標・ビジョン提示など |

**価値のインストラクション**：岩瀬直樹・チン聖子が教育文脈で示した概念。価値についての説明・意味付け。

### インストラクションの内容の6要素（ワーマン）

| 要素 | 説明 |
|------|------|
| 使命（目的） | インストラクションの目的・意図。最初に与えられるべき |
| 最終イメージ（目指す具体の姿） | インストラクションの最終結果・具体的なゴール（ワーマンは「最終目的」） |
| 手順 | インストラクションの心臓部。実際の指示内容 |
| 時間 | 実行に必要な予定時間。不安を減らし間違いを早期発見 |
| 予測 | 実行中に起こりそうなことを示す安心要素 |
| 失敗 | 指示から外れたことを知らせる警告信号。欠落しやすいが重要 |

### 向山洋一の原則（「授業の腕を上げる法則」より）

- **趣意説明の原則**：なぜそうするのかを説明する
- **一時一事の原則（シングルタスク）**：一度に一つだけ指示する
- **簡明の原則**：端的に具体的に出す
- **全員の原則**：全員に届く指示を出す
- **所時物の原則**：場所・時間・物を用意する（大森修の言葉より）
- **細分化の原則**：複雑な指示を分けて出す
- **空白禁止の原則**：何をすべきかわからない空白の時間をなくす
- **確認の原則**：指示通りできているかを確認する
- **個別評定の原則**：個別に評価する
- **激励の原則**：励ます

### 指示の種類・工夫（土居正博の指示論）

- **終末の指示**（行動の終わりまで示す）
- **結論を先に言う**（全体像を先に示す）
- **行動を評価する**
- **理解確認**
- **受け手を育てる**
- **動かす指示**
- **自ら考え動く指示**
- **問いかけを入れる**
- **自己選択自己決定の機会**
- **挑発する**（相手によって効果的な場合）
- **大人扱いした指示**

### 伝達の準備・技術（山本弘樹「教師のための説明実践の心理学」等）

- **指示前の準備**：環境・物・気持ちを整える
- **注意を向ける**：指示前に注意を集める
- **予告**：これから何をするかを前もって伝える
- **ナンバリング**：「3つ説明します。1つ目は…」
- **マルチモダール**：複数の表現モードで伝える（音声＋視覚など）
- **指示後に質問を受ける**：理解不足を補う機会

### 自己説明の5形態（山本弘樹）

| 形態 | 説明 |
|------|------|
| 自由に表現できる自己説明 | 思いついたことを自由に説明させる |
| 焦点づけられた自己説明 | 説明すべき内容を明確にする情報を付加して説明させる |
| 足場組みの自己説明 | 欠落した部分を穴埋めで説明させる |
| リソースを利用した自己説明 | 必要な概念・法則を示し利用させて説明させる |
| メニュー選択の自己説明 | 候補の中から正しいものを選択させる |

### メッセージの種類・認知的方略

- **リヴォイシング**：発言を言い換えて確認する発話
- **直接的に伝えるメッセージ**
- **間接的に説明するメッセージ（メタメッセージ）**
- **フィードバックの要請**
- **自己説明（精緻化）**・**相互説明**

### 伝達手段・表現技法

強調 / ジェスチャー / 抑揚 / 繰り返し / 例示 / 図表 / 図解 / 実物を見せる

### 認知的方略・構造的技法

- **注意焦点化方略**
- **読み返し方略**：つまずきに気づいて修復する自己調整的方略。事後質問を入れることで促進
- **橋渡し推論**（命題間の関係の明示化）：文間の繋がり・結束性を構築する
- **カット技法**：映像の一部を寸断し時間を省略する（学習阻害部分を除く）
- **構造方略（標識化）**：見出し・余白等で構造を強調するメタテキスト
- **先行オーガナイザー**：理解を助ける足場がけ
- **紙芝居（KP法）**：紙芝居プレゼンテーション法
