# 授業のユニバーサルデザイン

> 障害のある子のために行う配慮の多くは、クラスの他の子どもたちにも効果的だ。よい設計は全員を支える。— Peggy Hammeken（2007）

## [Pattern Connection]

- **既存パタンとの関連**：Hammeken（2007）の750方略の全体は、UDLの哲学を「具体的な行動」として実装したものであり、本パタンを「今日の授業で試せる」レベルに変換する実践集。
- **補強・拡張された点（配慮の3段階）**：従来の「配慮（Accommodation）vs 修正（Modification）」の2段階に加え、Hammeken は「適応（Adaptation）」を中間に置く**3段階**を提示する：
  - **配慮（Accommodation）**：学習内容・ゴールは変えない。アクセスの方法を変える（例：テスト時間延長）
  - **適応（Adaptation）**：方法・手段を変えるが、同じゴールを目指す（例：手書きの代わりにキーボード使用）
  - **修正（Modification）**：カリキュラム自体を変える。ゴールが変わる（例：別の課題に置換）
  - **原則**：まず配慮→次に適応→最後に修正の順で試みる
- **新たに接続される実装パタン**：Hammeken の再統合（2026-05-20）で以下の新規パタンが追加された：
  - [[パタン/合図システム]] — 子どもと教師の間の目立たない双方向コミュニケーション設計
  - [[パタン/行動契約]] — 子どもが目標と強化子を自分で選ぶ動機付けの構造
  - [[パタン/段階的クールダウン]] — 感情の高まりに対応する予防的な空間と手順の設計
  - [[パタン/コーティーチング]] — 一般担任×特別支援教員の役割分担の4形態

## 背景（Context）

Universal Design for Learning（UDL）は、CAST（米国特殊教育技術応用センター）のロゼとメイヤー（2002/2011）が提唱した授業設計の枠組みだ。建築のユニバーサルデザイン（すべての人が使えるように設計する）を学習環境に応用した概念で、「特定の子のための特別対応」ではなく「はじめから全員が使える設計」を目指す。

日本では「授業のユニバーサルデザイン（授業UD）」として桂聖らが学校現場向けに展開している（参加→理解→関与→できるの4段階）。

Hammeken（2003）*The Teacher's Guide to Inclusive Education* は、このUDLの哲学を750の具体的方略として実践化したものだ。「通常学級教師が特別支援の専門家になる必要はない——すべての子どもが学べるように授業を設計すればよい」という立場を取る。

## 問題（Problem）

特別支援が必要な子への配慮は「その子のための特別対応」として個別に行われることが多い。しかしこの設計では、①教師の負担が増え、②特別扱いされる子の自尊感情が傷つき、③他の子どもにも実は有効な工夫が届かない。授業の設計段階から多様な学習者を想定していなければ、後から「配慮を追加する」という構造になってしまう。

## 力のかたち（Forces）

- 事後的な個別配慮は担任の負担が大きく、持続しにくい
- 「特別扱いされている」という感覚が子どもの自尊感情を傷つけることがある
- 多様な学習者を想定した設計は、学習困難のない子どもにも学びを深める
- 完全なUDL実装は難しいが、小さな変化から始められる
- 「配慮」と「修正」を区別しないと、支援が過剰または過少になる

## 解決（Solution）

**授業の計画段階から多様な学習者を想定し、3つの原則に沿って設計する。**

---

### UDLの3原則

**① 表現の多様化（Multiple Means of Representation）**

情報を届ける方法を複数用意する。「聴く」だけでなく「見る」「触る」「操作する」を組み合わせる。

| 具体的な手立て |
|---|
| 指示を口頭＋板書の両方で伝える（マルチモダール） |
| テキストに絵・図・グラフィック・オーガナイザーを添える |
| 難しい語彙を事前に説明する・語彙リストを渡す |
| 操作できる具体物・モデルを用意する（算数のマニピュラティブス等） |
| 手順を視覚化して掲示する（TEACCHの手順カード） |

**② 行動・表現の多様化（Multiple Means of Action & Expression）**

「どうやって知識を示すか」の方法を複数用意する。書くことだけを求めない。

| 具体的な手立て |
|---|
| 口頭回答・描く・実演・作る、など書く以外の選択肢を認める |
| グラフィック・オーガナイザー（箇条書き・図で整理できる枠） |
| 書く量を減らして知識を示す（要点だけ・キーワードだけ） |
| テストを「選択式」「記述」「口頭」から選択可にする |
| キーボード・音声入力を書くことの代替として認める |

**③ 取り組みの多様化（Multiple Means of Engagement）**

動機づけと参加の方法を複数用意する。すべての子が同じ方法で「やる気になる」わけではない。

| 具体的な手立て |
|---|
| 難易度の選択肢を作る（やさしい・ふつう・むずかしい） |
| 選択肢を与える（「今やる？5分後にやる？」） |
| 短い目標と確認のサイクルを作る |
| 興味の接点を見つける（子どもが関心を持つ文脈で課題を提示） |
| ペア学習・グループ学習・個別学習を選べるようにする |

---

### 配慮（Accommodation）と修正（Modification）の区別

| 配慮（Accommodation） | 修正（Modification） |
|---|---|
| 学習内容・ゴールは変えない | 学習内容・ゴール自体を変える |
| アクセスの方法を変える | 何を学ぶかを変える |
| 例：テスト時間延長・口頭回答 | 例：設問数を半分に・別課題に置換 |
| まず試みる | 本当に必要なときのみ |

**原則**：まず「配慮（アクセスの方法を変える）」から試み、それでも届かないときに「修正（内容を変える）」を検討する。

---

### 教科別の具体的な配慮例（Hammeken, 2003）

**国語（読むこと）**：
- ペア読書（交互に読み合う）
- 録音テキスト・音声読み上げ
- カラーオーバーレイ（読んでいる行を際立たせる）
- 読む前のキーワード事前指導
- 難易度別の複数テキストを用意

**国語（書くこと）**：
- グラフィック・オーガナイザー（構成の枠）
- ワードバンク（使っていい言葉のリスト）
- センテンス・スターター（書き出しの文の枠）
- 箇条書き・図で代替（作文の量を減らす）

**算数**：
- 電卓・補助具の使用
- グラフ用紙での計算
- 具体物・操作（マニピュラティブス）
- 文章題のグラフィック・オーガナイザー
- 公式シート・ヒントカードの提供

---

### UDL設計のチェックリスト（授業準備時）

```
□ この授業の「情報の届け方」は1種類だけか？→ 視覚＋音声＋操作を組み合わせる
□ 「知識の示し方」は書くことだけか？→ 口頭・描く・選択肢を追加する
□ 全員が同じ難易度か？→ 選択肢（やさしい・むずかしい）を用意する
□ 指示は視覚化されているか？→ 板書・カード・プリントで補完する
□ 「この配慮は他の子にも有効か？」を問う→ クラス全体への設計に昇格できないか
```

## 結果（Consequences）

- 特定の子のための「特別対応」が減り、クラス全体の授業設計として機能するようになる
- 教師の「あの子だけ別対応」の負担が下がる
- 学習に困難を抱える子が目立たずに支援を受けられる
- 多様な学習スタイルへの対応が、クラス全体の学びの質を上げる

## Actionable Insight

- 次の授業で「指示を口頭だけで伝えている箇所」を一つ見つけ、板書かカードで視覚化する——表現の多様化の最小単位
- 「書いて提出」だけを求めているテストや課題で、「口頭で話してもいい」という選択肢を1つ加える——行動・表現の多様化が特定の子の参加を可能にする
- 「この配慮、みんなに広げたらどうなる？」を授業後に自分に問う——個別対応をUDLへ昇格させる思考習慣
