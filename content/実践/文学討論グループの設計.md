# 文学討論グループの設計

Dorn & Soffos（2005）_Teaching for Deep Comprehension_ に基づく、**深い理解（第3水準）を引き出すことを目的とした文学討論グループの設計と進め方**。ブッククラブ・リテラチャー・サークルとの違いは、「楽しく語り合う」だけでなく「第3水準（応用的理解）への到達を意識した問いの設計」にある。

## 文学討論グループとは

**文学討論グループ（Literature Discussion Groups）**：同じテキスト（または同じテキスト・セット）を読んだ3〜5人が集まり、教師がデザインした「深い問い」を中心に話し合う小グループ活動。

| 観点       | 文学討論グループ（Dorn & Soffos） | ブッククラブ（岩井）   | リテラチャー・サークル（Daniels） |
| ---------- | --------------------------------- | ---------------------- | --------------------------------- |
| 主な目的   | **第3水準（応用的理解）への到達** | パタンを重ねる場       | 生徒主導の対話                    |
| 問いの源   | 教師が設計した「深い問い」        | 生徒の問い・教師の問い | 討議リーダーが作る問い            |
| 教師の役割 | 問いを設計し、討論後に観察        | コーチとして外に出る   | コーチとして外に出る              |
| 役割シート | なし                              | なし                   | あり（段階的消去）                |
| テキスト   | テキスト・セット推奨              | 1冊                    | 1冊（複数グループで異なる）       |

## 設計の3原則

**① 問いは第3水準を狙う**

第1水準（誰が・何を）の確認で終わる問いは討論には使わない。第2〜3水準の問いが討論の火種になる：

| 水準      | 問いの例                                                                                           | 討論への効果                 |
| --------- | -------------------------------------------------------------------------------------------------- | ---------------------------- |
| ❌第1水準 | 「主人公の名前は？」「どこへ行きましたか？」                                                       | 答えがあるため討論にならない |
| △第2水準  | 「なぜ主人公はそうしたのですか？」                                                                 | 推論の違いが討論を生む       |
| ✅第3水準 | 「主人公の選択に賛成しますか？あなたならどうしますか？」「この本が問いかけていることは何ですか？」 | 複数の立場・視点が交差する   |

**② 教師は問いを「仕掛けて」外に出る**

討論中に教師が介入すると、生徒が教師に向けて話す——これを防ぐため、教師は：

- 問いを黒板や紙に書いてから「では始めましょう」と退く
- 物理的に離れた場所で観察メモを取る
- 「先生に向けて話すのではなく、グループの仲間に向けて話す」文化を育てる

**③ 話した後に「書く」で個人の理解を深める**

討論は「社会的な理解」——後に個人の理解として定着させるために、討論後に必ず書く時間を置く：

- 「今日の討論で、考えが変わったことを1〜2文で書く」
- 「この本の『問い』に対する今の自分の答えを書く」
- 「グループで一番印象に残った発言を書いて、なぜか書く」

## 討論前の準備：問いの設計

### 「討論を生む問い（Discussion-worthy Questions）」の条件

1. **正解が1つない**——複数の立場・視点・解釈が可能
2. **テキストの証拠が必要**——「テキストのどこからそう言えますか？」が成立する
3. **個人の経験・価値観と接続する**——「自分なら」「自分の生活では」が言える
4. **読んでいないと答えられない**——当日その場で読まずには参加できない

### 問いの3レベル設計（1回の討論に1〜2問）

1. **入口の問い**（討論の起点）——第2水準寄り。全員が何か言える問い
2. **核心の問い**（討論の本体）——第3水準。立場が分かれ、証拠が必要
3. **締めの問い**（討論の着地）——テキストが自分の生き方に与える影響

**例：「ヒロシマのピカ」（丸木俊）を使った討論**

| 役割 | 問い                                                                                  |
| ---- | ------------------------------------------------------------------------------------- |
| 入口 | 「この本を読んで、最初に気になったことは何でしたか？」（第1〜2水準）                  |
| 核心 | 「この本は子どもたちに見せるべきだと思いますか？なぜですか？」（第3水準・価値判断）   |
| 締め | 「この本を読んで、あなたが変わったこと・変えたいことはありますか？」（第3水準・影響） |

## 討論の進め方（40〜50分）

### フェーズ1：準備（5〜10分）

**個人準備（最初の5分）：**

- テキストを手元に置く
- 「今日の問いに対して、自分が言いたいことを1〜2文メモする」
- メモなしで始めると「何を話せばいいか分からない」が起きる

**問いの提示：**

- 教師が問いを黒板・スクリーン・カードに示す
- 「では今日の問いです。まず一人ずつ自分の考えを30秒ずつ話してみましょう」

---

### フェーズ2：討論（25〜35分）

**第1ラウンド（全員発言）：**

- 一人ずつ「入口の問い」への考えを短く言う（1〜2分/人）
- 聴く側は「自分と同じこと・違うこと」を心の中でメモする

**第2ラウンド（核心の問い）：**

- 「核心の問い」に移る
- 自由な討論形式——話したい人が話す・仲間の発言に反応する
- 教師は観察メモを取りながら介入しない

**教師の観察メモ（討論中）：**

```
グループ名：___________  日時：___________

発言している生徒（均等か？）：
_________________________

テキストを参照した場面：
_________________________

印象的な発言（第3水準の発言）：
_________________________

追加したい問い（もし止まったら）：
_________________________
```

**もし討論が止まったら（教師の介入は最小限）：**

- 「テキストのどのページからそう思いましたか？」（証拠への返し）
- 「△△さんの言ったことについて、どう思いますか？」（応答を促す）
- 「別の立場からはどう見えますか？」（視点の拡張）

---

### フェーズ3：着地と書く（10〜15分）

**締めの問い（教師から）：**

- 「今日の討論で、考えが変わったことはありますか？」
- 「この本が問いかけていることに対する、今のあなたの答えは何ですか？」

**個人の書く時間（5〜7分）：**

- クイックライト：「今日の討論で一番印象に残ったこと・変わったこと」を自由に書く
- 評価しない・採点しない——思考の外在化として使う

**全体共有（任意・3分）：**

- 「書いたことで、誰か一つシェアしてもいいですか？」（任意参加）
- 強制しない——書いたことはプライベートでも構わない

## テキスト・セットでの活用

文学討論グループはテキスト・セット（複数テキスト）との相性が特によい：

```
テキスト・セット × 文学討論グループのスケジュール例

1時間目：1冊目を全体で共有読書
2時間目：2冊目を独立読書 → ペアトーク
3時間目：3冊目を読む → 文学討論グループ（核心の問い：3冊を比べて）
4時間目：「セット全体を通した問い」で文学討論グループ（最も深い第3水準）
```

セット全体を通した問いの例：

- 「3冊を読んで、あなたの考えはどう変わりましたか？」
- 「3冊に共通するテーマは何だと思いますか？なぜそう思いますか？」

## よくある問題と対処

| 問題                                | 対処                                                                    |
| ----------------------------------- | ----------------------------------------------------------------------- |
| 特定の生徒だけが話す                | 第1ラウンドで「全員発言」を設ける。「まだ言っていない人はいますか？」   |
| 話が第1水準（あらすじ確認）に留まる | 「でも、それはなぜ大切だと思いますか？」と第2〜3水準へ問い返す          |
| 沈黙が続く                          | 「教科書の〇〇ページを一緒に読み直しましょう」とテキストに戻す          |
| 討論が脱線する                      | 問いカードを指して「この問いに戻りましょう」                            |
| 教師に向けて話す生徒がいる          | 「私にではなく、グループの仲間に話してみて」と穏やかに方向を変える      |
| 書く時間に何も書けない              | 「今日聞いた中で一番印象に残った言葉を1つ書く」という具体的な入口を示す |
