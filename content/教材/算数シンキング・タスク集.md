## 1. おはじきの分け方

**学年目安**: K〜1年（非カリキュラムタスク）  
**数学的ねらい**: 数の合成・分解（10のボンド）、複数解の存在に気づく

### 導入の言葉

> 「今日は10個のおはじきを使います。このおはじきを2つの山に分けてください。どんな分け方ができますか？全部見つけてみよう。」

おはじきを子どもに配る（または床に置く）。「答えは何通りです」とは言わない。数え方や記録の仕方も指示しない。「どうやって記録する？」と聞かれたら「好きなやり方で」と返す。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 3つの分け方を見つけて、それぞれの数を書こう |
| **ミディアム** | 全部の分け方を見つけよう。どうすれば「全部」と言える？ |
| **スパイシー** | 全部で何通りある？1と9、2と8…と並べてみると何が見える？0や10はどうする？ |

### 収束の問い（Consolidation questions）

- 「どんな分け方が出た？黒板に全部書いてみよう」（子どもが発表したものを教師が板書）
- 「0＋10、1＋9、2＋8……と並べると、どんなことが見える？」
- 「全部で何通りあった？なぜその数になるの？」
- 「いつも2つの数を足したら10になっているね。これを『10のペア（10のボンド）』と呼ぼう」

### 教師へのメモ

- 予想される解法：おはじきを分けてから数える、表にする、式で書く、絵で表す
- 0+10 と 10+0 をどう扱うかで盛り上がる（「どちらが先でも同じ？違う？」）
- Consolidationで10の合成一覧（0+10, 1+9, 2+8, ..., 10+0）を視覚的に並べると、後の計算学習への橋渡しになる
- **特別支援対応**：Mildをさらに下げるなら「5個を2つに分ける」から始める

## 2. 正方形と長方形を全部数えよう

**学年目安**: 1〜2年（非カリキュラムタスク）  
**数学的ねらい**: 体系的な数え方、正方形・長方形の認識

### 導入の言葉

黒板に3×3のマス目を描く（または印刷して配る）。

> 「このマス目の中に、正方形はいくつありますか？小さいのも大きいのも全部数えよう。」

「1個？9個？もっとある？」という問いかけでよい。余分なヒントは出さない。

```
┌─┬─┬─┐
│ │ │ │
├─┼─┼─┤
│ │ │ │
├─┼─┼─┤
│ │ │ │
└─┴─┴─┘
```

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 一番小さい正方形（1マス分）を全部数えよう |
| **ミディアム** | 大きさが違う正方形を全部数えよう（1×1, 2×2, 3×3） |
| **スパイシー** | 正方形だけでなく、長方形も全部数えよう（縦長・横長も含む）|

### 収束の問い（Consolidation questions）

- 「1×1の正方形は何個あった？どうやって数えた？」
- 「2×2の正方形が5個あると言う人と4個あると言う人がいるね。どちら？どうやって確かめる？」
- 「長方形も全部数えたら、どうすれば漏れなく数えられる？」（体系的な数え方の共有）
- 「正方形は長方形の仲間です。なぜ？」

### 教師へのメモ

- 答え：1×1が9個、2×2が4個、3×3が1個 → 正方形合計14個
- 長方形（正方形を含まない）：1×2が6個、1×3が3個、2×3が2個、2×1が6個、3×1が3個、3×2が2個 → 非正方形長方形18個、合計32個
- **体系的数え方の種類**：左上から順に数える・大きさ別に数える・位置別に数える
- 「どうやって間違えないようにしたか」の方法を共有することが本タスクの核心

## 3. 面積が24cm²の長方形を全部見つけよう

**学年目安**: 2〜3年（カリキュラムタスク：面積・かけ算）  
**数学的ねらい**: 面積の意味、因数の概念への入口、周の比較

### 導入の言葉

> 「面積が24cm²の長方形を作ります。辺の長さは整数センチメートルとします。どんな長方形が作れますか？全部見つけよう。」

方眼紙があれば配る（なければ式だけでもよい）。「面積＝縦×横」だけ確認し、他のヒントは出さない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2種類の長方形を見つけて、式と図で表そう |
| **ミディアム** | 全部の長方形を見つけよう。漏れなく見つけるにはどうする？ |
| **スパイシー** | 全部の長方形の「周の長さ」を計算しよう。いちばん周が短いのはどれ？なぜそれが短くなるの？ |

### 収束の問い（Consolidation questions）

- 「見つかった長方形をまとめると？」（板書：1×24, 2×12, 3×8, 4×6）
- 「縦の長さと横の長さのペアを見ると、どんな数？」（24の約数のペア）
- 「全部で何種類あった？なぜそれ以上はない？」
- スパイシー到達組へ：「周が一番短いのは4×6。なぜ正方形に近い形ほど周が短いの？」

### 教師へのメモ

- 答え：1×24（周50cm）、2×12（周28cm）、3×8（周22cm）、4×6（周20cm）
- 「縦×横＝24になる整数のペア」＝24の因数ペアである。「因数」という言葉は高学年で出てくるが、概念としてここで経験できる
- Consolidationで「同じ面積でも形が変わると周が変わる」を発見するだけで十分。「最適な形はいつも正方形に近い」まで到達できればスパイシー達成

## 4. 奇数の和のパターン

**学年目安**: 2〜4年（非カリキュラムタスク）  
**数学的ねらい**: 数列・パターン発見・平方数の視覚的理解

### 導入の言葉

黒板に書く：

```
1 = 1
1 + 3 = 4
1 + 3 + 5 = 9
1 + 3 + 5 + 7 = 16
```

> 「続きはどうなると思いますか？どんなパターンが見えますか？」

計算させる前に「どんなパターンが見える？」と一度聞く。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 次の5行を続けよう（1＋3＋5＋7＋9＝？から5行）|
| **ミディアム** | 1＋3＋5＋…＋19はいくつ？式を全部書かずに予想してから確かめよう |
| **スパイシー** | 1＋3＋5＋…＋99はいくつ？なぜいつも平方数になるの？図を使って説明できる？ |

### 収束の問い（Consolidation questions）

- 「答えを並べてみると？（1, 4, 9, 16, 25, ...）これは何という数？」
- 「1×1, 2×2, 3×3, ... と比べると？」
- 図で見せる：奇数個ずつ点を追加すると正方形になる図

```
●          ●●         ●●●
           ●●         ●●●
                      ●●●

1個        4個（+3）   9個（+5）
```

- 「なぜ奇数を足し続けると正方形の数になるのか、この図で説明できる？」

### 教師へのメモ

- スパイシーの答え：1＋3＋…＋99 ＝ 50² ＝ 2500（1から99は50個の奇数）
- 「どこまでが奇数か」の確認：99＝2×50−1なので50番目の奇数
- 図の説明は「L字型の点を追加していくと次の正方形になる」という視覚的証明
- 低学年でもパターンの発見（マイルド・ミディアム）は十分楽しめる。スパイシーは3〜4年生向け

## 5. 1/2と2/3の間の分数

**学年目安**: 3〜4年（カリキュラムタスク：分数の大小）  
**数学的ねらい**: 分数の大小比較・通分・分数の稠密性

### 導入の言葉

> 「1/2と2/3の間にある分数を1つ見つけてください。」

数直線の絵を描いて「1/2と2/3の間」を示してもよい。ヒントは出さない。「本当に間にあるか確かめる方法は？」とだけ問う。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 1/2と2/3の間にある分数を1つ見つけよう。なぜ「間」といえる？ |
| **ミディアム** | 分母が違う5つの分数を見つけよう（例：分母が4の分数、5の分数、6の分数…）|
| **スパイシー** | 1/2と2/3の間には分数は何個ある？もっともっと探したらどうなる？ |

### 収束の問い（Consolidation questions）

- 「見つかった分数を数直線に並べてみよう」
- 「1/2と2/3の間に分数はいくつある？」（無限にある——いつでも「真ん中の分数」が作れる）
- 「どんな2つの分数の間にも、必ず別の分数が入れられる。なぜ？」
- 「この性質、整数でも同じ？」（整数は稠密ではない——比較）

### 教師へのメモ

- 例となる分数：7/12（通分で確認）、3/5、5/8、11/18など
- 「真ん中を取る」方法：(1/2 + 2/3) ÷ 2 ＝ (3/6 + 4/6) ÷ 2 ＝ 7/12
- スパイシーは「有理数の稠密性」に触れる。小学生向けには「いつでも間の分数が作れる」レベルで十分
- 間違いやすい点：「3/5は1/2と2/3の間？」→ 1/2=0.5, 3/5=0.6, 2/3≈0.667 → 間にある

## 6. おにぎりの組み合わせ

**学年目安**: 2〜3年（カリキュラムタスク：場合の数）  
**数学的ねらい**: 組み合わせの数え方・体系的な列挙・順列と組み合わせの区別

### 導入の言葉

> 「鮭・ツナ・卵・梅・昆布の5種類のおにぎりがあります。この中から3個選んで買います。どんな選び方がありますか？全部見つけよう。」

「たとえば、鮭・ツナ・卵という選び方があります。他には？」と1例だけ示す。「順番は考えない（鮭・ツナ・卵と卵・ツナ・鮭は同じ）」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | できるだけたくさんの選び方を見つけよう（漏れや重複は気にしなくてよい）|
| **ミディアム** | 全部の選び方を漏れなく・重複なく見つけよう。どんな順序で探すと間違えない？ |
| **スパイシー** | ①同じ種類を2個選んでいいとしたら、全部で何通り？　②3個の順番が違っても別の選び方とするなら何通り？ |

### 収束の問い（Consolidation questions）

- 「全部で何通りあった？（10通り）どうやって確認した？」
- 「どの順で探すと漏れなく数えられる？」（例：鮭を必ず入れる場合→4通り、鮭なしツナを入れる場合→3通り、...）
- 表に書いてまとめる：鮭○ の組み合わせ 4、ツナ○鮭× の組み合わせ 3、...合計10
- スパイシー①：重複を許す組み合わせ → C(5+3-1, 3)=35通り（中学生向けの発展）
- スパイシー②：3個を並べる順列 → 10×6＝60通り（順列 vs 組み合わせの区別）

### 教師へのメモ

- 答え（組み合わせ）：C(5,3) ＝ 10通り
  - 鮭を入れる4通り：鮭ツナ卵、鮭ツナ梅、鮭ツナ昆布、鮭卵梅、鮭卵昆布、鮭梅昆布（6通り）→ 間違い。鮭を含む組み合わせはC(4,2)＝6通り
  - 正しい木図：鮭入り6通り+鮭なしC(4,3)=4通り → 計10通り
- 体系的数え方の指導ポイント：「一番左に来る具材を固定して数える」方法が漏れ・重複なし
- 2年生でも「鮭から始めてすべての組み合わせを書く→次はツナから」という方法で取り組める

## 7. 階段の形を続けよう

**学年目安**: 1〜3年（非カリキュラムタスク）  
**数学的ねらい**: 視覚的パターンの発見・三角数・「なぜ？」を図で説明する

### 導入の言葉

黒板に階段の形を3ステップ描く。

```
ステップ1   ステップ2    ステップ3
            ●●          ●●●
●           ●           ●●
                        ●
（1枚）     （3枚）      （6枚）
```

> 「この形はどのように成長していますか？ステップ4はどんな形になる？何枚のタイルが必要？」

「ステップ10は何枚？」とだけ付け加える。計算の方法は教えない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | ステップ4・5を紙に描いて、タイルの枚数を数えよう |
| **ミディアム** | ステップ10はいくつ？全部描かずに求める方法を考えよう |
| **スパイシー** | 2つの階段を組み合わせると何ができる？その図を使ってステップnの枚数を式で表せる？ |

### 収束の問い（Consolidation questions）

- 「各ステップの枚数を書き出すと？」（1, 3, 6, 10, 15, 21, ...）
- 「増える枚数はどう変わっている？」（2, 3, 4, 5, ...——1ずつ増える。なぜ？）
- 「2つのステップ4の階段を組み合わせると何の形になる？」（4×5の長方形→20枚）
- 「だからステップ4は？」（20÷2＝10枚）→ 「ステップnは n×(n+1)÷2と表せる」
- 「1, 3, 6, 10 ...という数を『三角数』と呼びます。なぜその名前だと思う？」

### 教師へのメモ

- **答え**：ステップn ＝ n(n+1)/2。ステップ10＝55枚
- **視覚的証明**：2つの階段をひっくり返して合わせると n×(n+1) の長方形になる。これがBoalerの言う「数学は証明を図で見せられる」という実例
- **スパイシーの核心**：「なぜ2で割るのか」——2つ合わせたから。図が説明を引き出す
- **特別支援対応**：マイルドは「次のステップを1段増やして描く」だけでよい。1枚ずつ貼れるタイルや付箋を使うとより具体的に操作できる
- 1年生でも「次はどうなる？」の問いで参加できる。3年生でもスパイシーで十分に深められる

## 8. 百マスで宝探し

**学年目安**: 2〜4年（非カリキュラムタスク）  
**数学的ねらい**: 倍数の視覚的パターン・数の構造・公倍数への入口

### 導入の言葉

1〜100の百マス表を全員に配る（または黒板に大きく描く）。

> 「2の倍数（2, 4, 6, 8 ...）をすべて赤で塗りつぶしましょう。どんな形が見えますか？」

「きれいな形が見えるはず」とだけ伝え、何が見えるかを当てない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2の倍数を赤で塗ろう。どんなパターンが見える？言葉で説明しよう |
| **ミディアム** | 今度は3の倍数を青で塗ろう。赤と青の両方になる数はどれ？それはどんな数？ |
| **スパイシー** | 5の倍数を緑で塗ろう。3色全部ついた数はいくつある？いちばん小さい数は？100以上でも予測できる？ |

### 収束の問い（Consolidation questions）

- 「2の倍数はどんな模様？」（縦の縞——偶数の列だけ）
- 「3の倍数は？」（斜めに走る縞のようなパターン）
- 「赤と青の両方の数をリストすると？」（6, 12, 18, 24 ...）「これはどんな数？」（6の倍数）
- 「なぜ2の倍数でもあり3の倍数でもある数は、6の倍数になるの？」
- スパイシー到達組：「3色全部 ＝ 2でも3でも5でも割れる数 → 30の倍数（30, 60, 90）。なぜ30？」

### 教師へのメモ

- **答え**：赤×青（2と3の公倍数）＝ 6の倍数。赤×青×緑（2と3と5の公倍数）＝ 30の倍数（30, 60, 90）
- 「最小公倍数（LCM）」という言葉は使わなくてよい。「2でも3でも割り切れる一番小さい数は？」という問いから概念が自然に出る
- **Boalerの視覚的数学との接続**：百マス表は数のパターンを「見える」化する強力な道具。「数学はパターンの科学」を体感させる場面
- **準備物**：百マス表（A4印刷）、3色の色えんぴつ
- **特別支援対応**：マイルドだけでも十分に完結する。赤の縞模様が見えた時点で「すごい発見！」と価値づける
- 発展として「4の倍数だったら？」「7の倍数だったら？」と自分で探究できる

## 9. 紙を折って分数を見つけよう

**学年目安**: 2〜4年（カリキュラムタスク：分数の視覚化）  
**数学的ねらい**: 分数の等分の意味・折り紙で作れる分数の規則・視覚的理解

### 導入の言葉

細長い紙（A4を縦に細く切ったもの）を1人1枚配る。

> 「この紙を折って、1/2を見せてください。どんな折り方ができますか？」

「折り方は1通りとは限りません」と伝える。「1/2にできた人は、次に1/4を折ってみよう」とだけ言う。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 折って1/2を作ろう。次に1/4、3/4を作ろう。折った形を図に描いて記録しよう |
| **ミディアム** | 1/8、3/8、5/8は折れる？折れた分数をリストにしよう。分母にどんな数が出てくる？ |
| **スパイシー** | 折りだけで1/3はぴったり作れる？作れない理由を説明しよう。折りで作れる分数はどんな特徴がある？ |

### 収束の問い（Consolidation questions）

- 「折って作れた分数をリストしよう」（1/2, 1/4, 3/4, 1/8, 3/8, 5/8, 7/8 ...）
- 「分母の数に注目すると？」（2, 4, 8, 16 ...——2の累乗）
- 「1回折ると2等分。2回折ると4等分。3回折ると？」→ 「折るたびに等分の数が2倍になる」
- 「1/3を作ろうとするとどうなる？」（3等分にならない——3は2の累乗じゃないから）
- 「折り紙で作れる分数は、分母が2・4・8・16...の分数だけ。なぜ？」

### 教師へのメモ

- **答え**：折り紙（半分折りのみ）で作れる分数は、分母が 2ⁿ（2の累乗）の分数。具体的には 1/2, 1/4, 3/4, 1/8, 3/8, 5/8, 7/8 など
- 「1/3はなぜ無理？」——3は2の累乗ではないため、半分折りを繰り返しても3等分にはならない。これは直感に反していて、子どもが「なぜ？」を感じる良い場面
- **Boalerの視覚的数学との接続**：分数を「数直線の点」ではなく「物理的な等分」として体験する。「見て、触って、わかる」アプローチ
- **準備物**：細長い紙（A4長辺を縦に4等分に切ったもの）人数分＋予備
- **特別支援対応**：マイルドは「折って2つに分けた1つ分が1/2」という操作体験だけでよい。紙を折って色鉛筆で区画を塗ると視覚化できる
- 発展：「1/3を折りで近似するには何回折ればよいか？」（2回目で1/4≈0.25、4/3 of ... → 不可能であることを実感）

## 10. とびいし何通り？

**学年目安**: 1〜3年（非カリキュラムタスク）  
**数学的ねらい**: 場合の数・パターンを使って先を予測する・フィボナッチ数列の発見

### 導入の言葉

黒板に飛び石を横一列に描き、石に番号を書く。

```
スタート → ①→ ② → ③ → ④ → ⑤ → ゴール
```

> 「スタートから石を渡ってゴールを目指します。1マスか2マスずつ進めます。石①まで行く進み方は何通り？石②は？石③は？」

「答えから始めず、まず書き出してみよう」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 石③までの全部の進み方を線で描こう（矢印で図に表す）|
| **ミディアム** | 石①〜⑤までの通り数を表にしよう。数のならびに何か見える？ |
| **スパイシー** | 石⑩は何通り？石nまでの通り数はどう求める？なぜそのルールが成り立つ？ |

### 収束の問い（Consolidation questions）

- 「石①〜⑤の通り数を並べると？」（1, 2, 3, 5, 8）
- 「前の2つを足すと次の数になっているね。なぜ？」
- 「石⑤に着くには、石④から1マス跳ぶか、石③から2マス跳ぶしかない。だから石④の通り数 ＋ 石③の通り数 ＝ 石⑤の通り数になる」
- 「この数列（1, 1, 2, 3, 5, 8, 13, 21 ...）はフィボナッチ数列と呼ばれている。自然界にも現れる」
- 「石⑩は何通り？」（55通り——計算せず、前2つを足し続けるだけでわかる）

### 教師へのメモ

- **答え**：石1: 1通り、石2: 2通り、石3: 3通り、石4: 5通り、石5: 8通り、石10: 55通り
- **収束の核心**：「石nへの道 ＝ 石(n-1)から1マス ＋ 石(n-2)から2マス」という構造が、「前2つを足す」ルールの理由そのもの
- **Boalerの接続**：「数学の美しさ」を体験させる典型。フィボナッチ数列はひまわりや松ぼっくりにも現れると伝えると驚きが生まれる
- **特別支援対応**：マイルドは石③まで、矢印を引いて確かめるだけでよい。「1マス」「2マス」のジャンプを体を使って実際に跳んでみると具体化できる
- **タスク7（階段の形）との接続**：両方とも「同じ構造が別の問題に現れる」体験になる

## 11. 9のひみつを解き明かせ

**学年目安**: 2〜3年（カリキュラムタスク：かけ算の構造）  
**数学的ねらい**: 9の段のパターン発見・「暗記でなく仕組みで分かる」体験・かけ算の意味の深化

### 導入の言葉

黒板に9の段を縦に書く（9×1＝9 から 9×9＝81まで）。

> 「この表をよく見てください。何か気づくことがありますか？気づいたことを2つ以上見つけよう。」

「答えを言わないで、まず自分で探してみよう」とだけ伝える。「正解は1つではない」と付け加える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 9×1〜9×9の答えの「一の位」と「十の位」を別々に書き出そう。それぞれ何が見える？ |
| **ミディアム** | 答えの「十の位 ＋ 一の位」を計算しよう。何が見える？なぜそうなるか考えよう |
| **スパイシー** | 9×n ＝ 10×n − n という式を使って「なぜ十の位と一の位の和がいつも9になるか」を説明しよう。9×11, 9×12 でもそのルールは続く？ |

### 収束の問い（Consolidation questions）

- 「一の位はどう変わる？」（9, 8, 7, 6...——9から1ずつ減る）
- 「十の位はどう変わる？」（0, 1, 2, 3...——0から1ずつ増える。掛ける数より1小さい）
- 「十の位 ＋ 一の位 ＝ ？」（いつも9）「なぜ？」
- 「9×n ＝ 10n − n を使うと：十の位は n−1、一の位は 10−n なので、足すと (n−1) ＋ (10−n) ＝ 9」
- 「指を使う方法を知っている人は？」（10本の指を広げ、掛ける数の番号の指を折る——左の本数が十の位、右の本数が一の位）「なぜこれで計算できる？」

### 教師へのメモ

- **答えの確認**：9×1＝9（0＋9）、9×2＝18（1＋8）、...、9×9＝81（8＋1）——十の位と一の位の和は必ず9
- **Boalerの核心接続**：「計算を暗記するより、仕組みを理解する方が応用できる」——9の段のパターンはその最もわかりやすい例。「数学は手順でなくパターン」
- **スパイシーの証明**：9×n ＝ 10n − n。十の位は (10n − n) ÷ 10 の商の部分 ＝ n−1（nが1〜9のとき）。一の位は 10 − n。合計 ＝ 9
- **特別支援対応**：まず9の段の答えをブロックで作り、「10のまとまりから1個取る」操作で 9×3 ＝ 30−3 ＝ 27 を体験してから表を見ると、パターンが見えやすい
- **発展**：「18の各桁の和は 1＋8＝9。27は 2＋7＝9。これはどこまで続く？9の倍数は必ず各桁の和が9の倍数になる」——3〜4年生向け発展

## 12. グリッドを歩いて数えよう

**学年目安**: 3〜5年（非カリキュラムタスク）  
**数学的ねらい**: 体系的な場合の数・パターンの発見・パスカルの三角形への出会い

### 導入の言葉

黒板に2×2の交差点グリッドを描く。左下をスタート、右上をゴールとする。

```
ゴール
  ・ー・
  ｜　｜
  ・ー・
スタート
```

> 「スタートからゴールまで、右か上にだけ進みます。何通りの行き方がありますか？」

まず「右右」「右上...」と実際に線を引いて見せる。「もっとある？」とだけ問い、答えを言わない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2×2グリッドの全ルートを矢印で描こう。次に、3×2グリッド（横3×縦2）は何通り？ |
| **ミディアム** | 3×3グリッドの全ルートを体系的に数えよう。「右右右上上上」のような記号で表すとわかりやすい |
| **スパイシー** | 各交差点に「そこまでの道の数」を書き込もう。書き込んだ数が三角形を作る。どんなパターン？ |

### 収束の問い（Consolidation questions）

- 「各交差点に道の数を書き込むと、どうやってその数が決まる？」（左から来る数 ＋ 下から来る数）
- 「なぜ足し算になる？」（ある交差点に着くには、左の交差点から右に進むか、下の交差点から上に進むかしかない）
- 全体を見渡して：「この三角形の形を見たことある？」（パスカルの三角形）
- 「1, 1, 2, 1, 1, 3, 3, 1, 1, 4, 6, 4, 1...——二項係数の三角形。数学の世界で何百年も研究されてきた」

```
（4×4グリッドで書き込まれる数）
1
1  1
1  2  1
1  3  3  1
1  4  6  4  1
```

- 「タスク6（おにぎりの組み合わせ）の答えと比べてみよう」（C(5,3)＝10 がこの三角形のどこかに現れる）

### 教師へのメモ

- **答え**：2×2: 2通り、3×2: 3通り、3×3: 6通り、4×4: 20通り（C(2n, n)の公式——高学年発展）
- **収束の核心**：各交差点への「道の数 ＝ 左の点の数 ＋ 下の点の数」という加法規則が、パスカルの三角形の生成ルールそのもの
- **Boalerの接続**：「美しい数学的構造が日常の問題から現れる」体験——パスカルの三角形はグリッドの問題・組み合わせ・二項定理・確率など全方向につながる
- **準備物**：方眼紙（5mm方眼）または黒板に大きく描く
- **特別支援対応**：マイルドは 2×2 グリッドを紙に印刷して渡し、矢印を実際に引かせる。「右・右で来た」「上・右で来た」とルートを言葉で言いながら確かめる
- **タスク6（おにぎりの組み合わせ）との接続**：組み合わせの数え方を別の文脈で再体験させる絶好の拡張タスク

## 13. 10等分の世界

**学年目安**: 3〜4年（カリキュラムタスク：小数の意味）  
**数学的ねらい**: 0.1 の意味を「等分」として体験する・位取りの構造として理解する

### 導入の言葉

1mの紙テープを用意し、10等分に折って見せる。

> 「このテープ全体が1mです。折った1つ分は何mでしょう？どんな数で表しますか？」

テープを広げ、1つ分を指で示す。「何と書けばよいか」だけ問い、計算の仕方は教えない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 3つ分は何m？7つ分は？数直線の0と1の間に書き込もう |
| **ミディアム** | 0.1mは何cm？では0.01mは何cm？テープをもう一度10等分すると何が起きる？ |
| **スパイシー** | 1cmは何m？1mmは何m？10等分するたびに数はどう変わる？言葉で規則を説明しよう |

### 収束の問い（Consolidation questions）

- 「折った1つ分 = 0.1m = 10cm——この3つは同じものを表している。どう確かめる？」
- 「0.1をさらに10等分すると？」（0.01m = 1cm）「もう一度10等分すると？」（0.001m = 1mm）
- 「10等分するたびに、数字はどうなっている？」（小数点が左に1つ動く）
- 「逆に10倍するとどうなる？」（小数点が右に1つ動く）
- 「1m、0.1m、0.01m、0.001m——これは位取りの表と同じ構造をしている」

### 教師へのメモ

- **核心**：「0.1 = 1を10等分した1つ分」という意味を、テープの操作から体験させる
- 折ったテープを切り離して「これが0.3m」と並べると操作的に理解できる
- **Boalerの接続**：小数を「数直線の点」ではなく「等分の結果」として体験——視覚・触覚を使う
- **特別支援対応**：テープを切り離して3本並べ「これ全体が0.3m」と手で操作させる。「0.3 + 0.7 = 1.0」をテープで確かめると加法の意味にもつながる
- 準備物：1mの紙テープ（カット紙やロール紙）、ものさし、数直線ワークシート

## 14. 小数の大小バトル

**学年目安**: 3〜5年（カリキュラムタスク：小数の比較）  
**数学的ねらい**: 小数の大小を位取りで比較する・「桁数が多い＝大きい」という誤概念を壊す

### 導入の言葉

黒板に書く：

> 「0.8 と 0.19、どちらが大きいですか？理由も言ってみよう。」

すぐに答えを言わず、まず全員が自分の考えをノートに書く時間をとる。「どちらだと思う？なぜ？」

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 0と1の間の数直線に 0.8 と 0.19 を書き込もう。どちらが右にある？ |
| **ミディアム** | 0.5 ・0.15 ・0.9 ・0.09 ・1.1 を小さい順に並べよう。どうやって確かめた？ |
| **スパイシー** | 数字1・3・5を1回ずつ使って、「□.□□」の形の小数を全部作ろう。いちばん大きい数は？全部で何通り？ |

### 収束の問い（Consolidation questions）

- 「0.8と0.19、どちらが正解だった？なぜ0.19の方が大きいと思った人がいたのか、説明できる？」
- 「十分の一の位を比べると——0.8は0.8、0.19は0.1。0.8の方が大きい」
- 「整数では19 > 8だが、小数では0.19 < 0.8——どこで考えが変わる？」
- 「小数の大小は十分の一の位から比べ始める。桁数が多くても大きいとは限らない」
- スパイシー：「1.□□の形で□に3,5を入れると→1.35と1.53。最大は1.53」（6通り確認）

### 教師へのメモ

- **最も多い誤概念**：「0.19 > 0.8」——19 > 8 という整数の比較をそのまま小数に使ってしまう。このタスクはその誤概念を意図的に揺さぶる
- **Boalerの接続**：「間違いは脳が成長するタイミング」——わざと「引っかかりそうな問題」から始めることで学びが深まる
- 数直線プリントを用意して0.1刻みの目盛りに書き込む活動が有効
- **特別支援対応**：マイルドで0.1刻みの数直線に書き込むだけで位置関係が視覚化される。目盛りシールを貼る操作にしてもよい
- スパイシーは順列（6通り：1.35, 1.53, 3.15, 3.51, 5.13, 5.31）につながる発展

## 15. かけると小さくなる？

**学年目安**: 4〜5年（カリキュラムタスク：小数の乗法）  
**数学的ねらい**: ×0.1 は ÷10 と同じ・「かけると大きくなる」という思い込みを壊す

### 導入の言葉

黒板に数表を書く：

```
10 × 3   = 30
10 × 2   = 20
10 × 1   = 10
10 × 0   =  0
10 × 0.1 = ?
10 × 0.01= ?
```

> 「続きはどうなるでしょう？パターンを見ながら考えてみよう。」

数え方のヒントは出さない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 表の空欄を埋めよう。かける数が10→1→0→0.1と変わるとき、答えはどう変わる？ |
| **ミディアム** | □ × 10 = 0.01 になる□は何？　□ × 10 = 0.001 は？逆向きに考えよう |
| **スパイシー** | 6 × 0.4 の答えを「6 × 4 = 24 から求められる？」——0.4 = 4÷10 を使って面積図で説明してみよう |

### 収束の問い（Consolidation questions）

- 「10 × 0.1 = 1。かけたのに小さくなった！なぜ？」
- 「×0.1 は ×(1÷10) = ÷10 と同じ——数直線で確認すると？」
- 「0より大きく1より小さい数をかけると、結果は元の数より小さくなる。なぜ？」
- スパイシー確認：「6 × 0.4 = 6 × 4 ÷ 10 = 24 ÷ 10 = 2.4。整数のかけ算から小数のかけ算を導ける」
- 「この仕組みを使えば、小数のかけ算は整数のかけ算に変換して求められる」

### 教師へのメモ

- **誤概念の核心**：「かけると大きくなる」は自然数同士のかけ算では成り立つが、小数では成り立たない。5年生でこの認識の転換が起きる
- **Boalerの接続**：「圧縮された概念」——「×0.1 = ÷10」の一言で小数乗法全体を理解する鍵になる
- 表を「20, 10, 0, -10...」と予想する子も出る（負の数への橋渡し）。それも価値ある発見として扱う
- **特別支援対応**：マイルドで表の埋め方だけに集中。「答えが10ずつ減っている」パターンを確認するだけでも十分
- スパイシーの面積図：縦6、横0.4（= 4÷10）の長方形の面積 = 6×4÷10 = 2.4

## 16. グラフのうそを見破れ

**学年目安**: 3〜5年（非カリキュラムタスク）  
**数学的ねらい**: 縦軸の起点によってグラフの印象が変わることを発見する・データを批判的に読む

### 導入の言葉

同じデータを使った2種類の棒グラフを黒板に描く（データ：A校75点・B校78点）。

```
【グラフA】縦軸 0〜100     【グラフB】縦軸 70〜80
100│                          80│     ■
 75│■  ■                      75│■
   │                          70│
  0└──────                    └──────
     A校 B校                    A校 B校
```

> 「2つのグラフを見て、気づくことを言いましょう。どちらがB校の点数が高く見えますか？」

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2つのグラフからA校とB校の点数を読み取ろう。実際の差は何点？ |
| **ミディアム** | 「B校の方がずっと優秀」と見せたいグラフと「ほとんど差がない」と見せたいグラフを自分で描いてみよう（データは同じ） |
| **スパイシー** | ニュースや広告でよく使われる「誇張グラフ」の例を探して、なぜ誤解を与えるか説明しよう。どんなルールを作れば公平なグラフになる？ |

### 収束の問い（Consolidation questions）

- 「どちらのグラフも正しいデータを使っている。でも印象が全然違う——なぜ？」
- 「縦軸が0から始まっていないと、差が実際より大きく見える」
- 「グラフを見るときに最初に確認すること：①縦軸の起点はどこか　②目盛りの間隔は均等か」
- 「グラフは正確な数字を使っていても、デザインで印象を操作できる——これをデータリテラシーという」
- 「どんな場面でこのような誇張グラフが使われていそう？」（広告・選挙・ニュース）

### 教師へのメモ

- **Boalerの接続**：「数学は現実を批判的に読むツール」——正解・不正解でなく「どう読み、どう使うか」を問うタスク
- このタスクは「正解を1つ出す」型ではなく「考え方を鍛える」型——Liljedahlの「考える教室」文化を作る
- 準備物：黒板に2つのグラフを大きく描く、または印刷して配布
- **特別支援対応**：マイルドで「両グラフから同じ数を読み取る」だけでも概念に触れられる。「なぜ見え方が違うのか」の説明は教師が引き出せばよい
- 非カリキュラムタスクとして学期初めに使うと「算数は計算だけではない」という教室文化をつくれる

## 17. 平均は正直者？

**学年目安**: 4〜5年（カリキュラムタスク：平均・代表値）  
**数学的ねらい**: 平均の意味と限界を理解する・同じ平均でも分布が異なることに気づく

### 導入の言葉

黒板に書く：

> 「あるクラスの5人のテスト結果（100点満点）は　10, 10, 10, 10, 100点　でした。平均は何点でしょう？」

平均を計算させてから言う：「平均28点——28点に近い人は何人いますか？」

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 平均を計算しよう（(10×4＋100)÷5）。平均28点という数は、このクラスをよく表している？ |
| **ミディアム** | 平均がちょうど50点になる5つの数の組み合わせを3種類作ろう。どれが「50点らしい」データ？ |
| **スパイシー** | 「平均が役に立つ場面」と「役に立たない場面」をそれぞれ2つずつ考えよう。中央値（並べたときの真ん中）と比べるとどうなる？ |

### 収束の問い（Consolidation questions）

- 「平均28点だが、実際に28点前後の人は0人——これはなぜ起きる？」
- 「平均 = 全員が同じ点数だったとしたら何点か、という仮想の数」
- 「外れ値（極端な値）があると、平均は実態を表さなくなる」
- 「中央値（5人を並べたときの真ん中の値）は？」→ 10点。「どちらがこのクラスを正確に表す？」
- 「平均年収・平均身長——日常でも平均が使われている。外れ値がある場合に注意する習慣」

### 教師へのメモ

- **驚きの核心**：「28点は正しい計算だが、誰の点数も表していない」——この矛盾がセレンディピティを生む
- **Boalerの接続**：「数学は現実を批判的に見るツール」。統計の限界を小学校で体験しておく意義が大きい
- ブロックで「均等にならす」操作から平均の意味をつかむと支援に有効
- **特別支援対応**：マイルドで「合計÷人数」の計算に集中。ブロック10個×4人＋100個×1人を5等分するイメージを具体物で
- 発展：「日本の平均年収は約460万円だが、実際に460万円前後の人は全体の何割か」（中学発展）

## 18. 折れ線グラフで物語を読もう

**学年目安**: 3〜5年（カリキュラムタスク：折れ線グラフ）  
**数学的ねらい**: グラフの形から変化のパターンを読む・グラフを自分で設計する

### 導入の言葉

縦軸・横軸の単位を隠した折れ線グラフを黒板に描く。

```
高│
  │         ●
  │      ●     ●
  │   ●           ●
  │●                  ●●
低└─────────────────→
　 1  2  3  4  5  6  7  8（時間→）
```

> 「このグラフはどんな変化を表していると思いますか？何の変化かを3つ考えてみよう。」

単位は何も書かない。「正解はない——考えが大事」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | グラフの変化を言葉で説明しよう（「最初は上がって、次に...」）。「この変化」が表せそうなものを1つ挙げよう |
| **ミディアム** | このグラフが「気温の変化」だとすると何月のデータ？「売上の変化」だとしたら何が起きた？「病気の患者数」なら？3つのシナリオで説明しよう |
| **スパイシー** | 「最初ゆっくり増えて、突然急に落ちて、その後ゆっくり回復する」変化をグラフで描こう。そのグラフが表しそうな「物語」を書こう |

### 収束の問い（Consolidation questions）

- 「グラフの形（上がる・下がる・急・ゆるやか）から何がわかる？」
- 「傾きが急 ＝ 変化が速い。傾きがゆるやか ＝ 変化がゆっくり」
- 「同じ形のグラフでも、何を表すかで意味が変わる——グラフは言語のように読める」
- スパイシー確認：「急落してから回復」→ コロナの観光客数・株価・事故後の通学者数など
- 「グラフを読むだけでなく、グラフを設計できることが大切——設計者は何を伝えたいのか」

### 教師へのメモ

- **Boalerの接続**：「数学と物語をつなぐ」——グラフを「変化の物語の設計図」として扱う。複数の解釈が出ることが正解
- このタスクは「正しい答えは1つ」ではないため、多様な意見を歓迎するクラス文化づくりに使える
- 準備物：単位なしの折れ線グラフ印刷（または黒板に描く）
- **特別支援対応**：マイルドで「上がっている・下がっている・横ばい」を色分けするだけでも参加できる。「これは温度？人数？得点？」と具体的な選択肢を提示してもよい
- スパイシーで子どもが描いたグラフを互いに「このグラフの物語は？」と読み合う活動にすると深まる

## 19. 折って切って開くと？

**学年目安**: 2〜4年（カリキュラムタスク：対称図形）  
**数学的ねらい**: 折り目が対称軸になることを体験する・折り回数と対称軸の数の関係を発見する

### 導入の言葉

正方形の折り紙を半分に折り、折った状態で端に小さな三角形の切り込みを入れる（まだ開かない）。

> 「この紙を開くとどんな形になるでしょう？開く前にノートに予想を描いてください。」

全員が予想を描いてから開いて見せる。「当たった？違った？」

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 自分で折り紙を半分に折り、折った端を自由に切ってみよう。開く前に形を予想して描いてから開こう |
| **ミディアム** | 四つ折り（2回折り）にして切るとどうなる？開く前に予想し、折り目は何本になるか数えよう |
| **スパイシー** | 対称軸が4本になる切り方を作ろう。何回折ればよい？折る回数と対称軸の数にはどんな関係がある？ |

### 収束の問い（Consolidation questions）

- 「折り目のところで折り返したとき、2つの部分がぴったり重なる——これを『線対称』という」
- 「1回折り → 対称軸1本。2回折り → 対称軸2本。3回折り → 対称軸4本。なぜ2倍ずつ増える？」
- 「正方形には対称軸が何本ある？」（4本：縦・横・斜め2本）「円は？」（無限本）
- 「自然界の対称：蝶・葉・雪の結晶——なぜ対称な形が多いと思う？」（機能と美しさの話へ）
- 「折って切った形と、もとの切り口の形はどんな関係？」（折り目を境に鏡映し）

### 教師へのメモ

- **核心**：「折り目 = 対称軸」を身体を使って理解する。「ぴったり重なる」という感覚が対称の定義そのもの
- 切り込みは折った辺（折り目でない方の辺）から入れると穴になる。折り目側から切ると2つに分かれるので注意
- **Boalerの接続**：「見て・触って・驚く」——予想と現実のズレが好奇心を生む最高の場面
- **特別支援対応**：マイルドで「折って開くと同じ形が2つ出てくる」という操作経験だけで十分。「どこで折った？」と折り目を指で確認させる
- **準備物**：折り紙（15cm角）人数分、はさみ

## 20. 三角形の角を全部合わせると？

**学年目安**: 3〜4年（カリキュラムタスク：角度・三角形の性質）  
**数学的ねらい**: 三角形の内角の和が180°であることを実験で発見する・多角形へ拡張する

### 導入の言葉

各自が好きな三角形を画用紙に大きく描いて切り取る。

> 「3つの角をそれぞれ切り取って、1か所に並べてみましょう。どんな形になりますか？」

並べ方のヒントは出さない。「とにかく3つ全部を端が合うように並べよう」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 3つの角を切り離して、頂点を合わせて並べよう。定規の端（直線）と比べると？ |
| **ミディアム** | 形が違う三角形（直角三角形・鈍角三角形・正三角形）で試してみよう。いつも同じになる？表に記録しよう |
| **スパイシー** | 「なぜ3つの角を合わせると必ず一直線になるのか」を図で説明しよう。四角形の4つの角を合わせると何度になる？五角形は？ |

### 収束の問い（Consolidation questions）

- 「どんな三角形でも3つの角を合わせると一直線（180°）になった——これは『三角形の内角の和 = 180°』という性質」
- 「なぜ？」→ 三角形の上の頂点を通る横線（底辺に平行な直線）を引くと、3つの角が直線上にきれいに並ぶ
- 「四角形の4つの角を合わせると？」（360°——対角線で三角形2つに分けると 180°×2）
- 「五角形は？」（540° = 180°×3）「六角形は？」（720° = 180°×4）
- 「n角形の内角の和 = (n−2)×180°——パターンを言葉で説明すると？」

### 教師へのメモ

- **核心操作**：角を「物理的に切り離して並べる」——手で動かすことで「なぜ一直線になるのか」の実感が先に来る。その後に理由を考える順序が大切
- 「鋭角三角形でも鈍角三角形でも同じになる」驚きが学びのエンジンになる
- **Boalerの接続**：「数学の定理を実験で発見し、図で証明する」——暗記でなく発見の体験
- **特別支援対応**：切った角を「定規の端に沿って並べる」作業が視覚的にわかりやすい。角の大きさが「直線を3つで埋める」感覚で180°を体験できる
- **準備物**：画用紙（三角形を大きく描ける厚さ）、はさみ、定規
- 「角を測ってから足し算する」方法と「切って並べる」方法の両方を試して比べると理解が深まる

## 21. 四角形の大家族を整理しよう

**学年目安**: 2〜4年（カリキュラムタスク：平面図形の性質・分類）  
**数学的ねらい**: 四角形を性質で分類する・「正方形は長方形の特別な場合」という包含関係を発見する

### 導入の言葉

様々な四角形のカードを配る（正方形・長方形・ひし形・平行四辺形・台形・不規則な四角形）。

> 「これらをグループに分けてください。どんな分け方でも構いません。理由を言えれば正解です。」

ルールや性質の名前は最初に出さない。子どもが使う言葉から出発する。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 「直角がある」グループと「直角がない」グループに分けよう。三角定規の直角で確かめながら |
| **ミディアム** | 「向かい合う辺が平行」「4辺の長さが全部同じ」「4つの角が全部直角」——この3つの性質で表を作ろう。どの図形がどの性質を持つ？ |
| **スパイシー** | 正方形はどのグループにも入れられる？なぜ？「四角形の大家族図（包含図）」を作ってすべての関係を示そう |

### 収束の問い（Consolidation questions）

- 「正方形は長方形の仲間？」→ 「長方形 = 4つの角が全部直角な四角形」——正方形も全角直角だから仲間！
- 「正方形はひし形の仲間でもある？」→ 「ひし形 = 4辺が全部同じ長さな四角形」——正方形も4辺同じだから仲間！
- 包含関係の図：**四角形 ⊃ 台形 ⊃ 平行四辺形 ⊃ 長方形・ひし形 ⊃ 正方形**
- 「正方形はいちばん『条件が多い』図形——だからいちばん多くのグループに属する」
- 「国語や理科でも『上位概念・下位概念』がある。分類は世界を整理する数学の方法」

### 教師へのメモ

- **核心の驚き**：「正方形は長方形でもあり、ひし形でもある」——多くの子が「違う図形」と思っていたものが実は包含関係にあると気づく瞬間
- 最初の「自由な仲間分け」で「尖っている・丸い」など直感的な基準が出るのをまず受け止める。その後「数学的な性質」へ誘導する
- **Boalerの接続**：「数学は分類と構造の学問」——性質を使って概念を整理する体験
- **特別支援対応**：マイルドで三角定規を使って「直角がある/ない」の2分類だけで完結できる。カードを実際に動かして並べ替える操作が理解を助ける
- **準備物**：四角形カード（印刷して厚紙に貼る）1セット/人〜グループ、三角定規、ものさし

## 22. 数の変換機械

**学年目安**: 2〜4年（非カリキュラムタスク）  
**数学的ねらい**: 入力と出力の規則を発見する・関数的思考の入口・自分でルールを設計する創造性

### 導入の言葉

黒板に「変換機械」の図を描き、入力と出力の例を示す。

```
入力 → ［？機械？］ → 出力
  3  →              →  7
  5  →              → 11
  1  →              →  3
  0  →              →  ?
```

> 「この機械は何をしているのでしょう？入力0のとき出力は何になる？」

「答えから言わず、まずノートに考えを書こう」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 入力0・4・10のときの出力を求めよう。機械のルールを言葉で説明しよう |
| **ミディアム** | ルールを式で表そう（「入力を○倍して○を足す」形で）。入力が1増えるたびに出力はいくつ増える？ |
| **スパイシー** | 自分だけの2ステップルールを作って入出力の例を5つ書き、隣の人に当ててもらおう。逆問題：出力が21のとき入力は？ |

### 収束の問い（Consolidation questions）

- 「ルールは？」（入力×2＋1＝出力）「式で書くと？」（出力＝入力×2＋1）
- 「入力が1増えると出力はいつも2増える——なぜ？」（×2の部分が効いている）
- 「逆問題：出力21のとき → 21＝入力×2＋1 → 入力＝10」（方程式の入口）
- 「どんな入力に対しても出力が1つに決まる仕組みを『関数』という——中学で再登場」
- スパイシー作品を数人発表：「どうやってルールを当てた？何が手がかりになった？」

### 教師へのメモ

- **非カリキュラムタスク**として年度初めに使うと「算数には規則を見つける楽しさがある」という教室文化をつくれる
- 「ルールを言葉→式→グラフ」と3段階で表現する活動が代数的思考の土台になる
- **Boalerの接続**：「数学はパターンの発見」——ルールを式で表す体験と、スパイシーの「自分で設計する」創造性（Creativity: 5Cの一つ）
- **特別支援対応**：マイルドで「入力3→出力7、入力5→出力11…数がいくつ増えた？」と差に注目させる。表を縦に並べて「出力が2ずつ増えている」パターンを先に見つける
- 準備物：黒板のみ（紙・ホワイトボードがあれば個人用）

## 23. 2倍にすると全部2倍？

**学年目安**: 3〜5年（カリキュラムタスク：比例・面積）  
**数学的ねらい**: 比例する量（周）と2乗で増える量（面積）の違いを発見する・「辺2倍→面積4倍」の驚き

### 導入の言葉

黒板に1辺2cmと1辺4cmの正方形を並べて描く。

> 「1辺を2倍にしました。周の長さも2倍になる？面積も2倍になる？まず予想してから確かめよう。」

予想をノートに書かせてから計算させる。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 1辺が1・2・3・4cmの正方形の「周の長さ」と「面積」を表に記録しよう（方眼紙で数えてもよい）|
| **ミディアム** | 「1辺を2倍」すると周は何倍？面積は何倍？「1辺を3倍」では？表のパターンを言葉で説明しよう |
| **スパイシー** | 1辺をn倍にすると周はn倍、面積はn²倍になるのはなぜ？図で説明しよう。立方体（体積）では何倍になる？ |

### 収束の問い（Consolidation questions）

- 「周は辺の長さに比例する（辺×2 → 周×2）——グラフは原点を通る直線」
- 「面積は辺の長さの2乗に比例する（辺×2 → 面積×4！）——予想と違った人は？」
- 図で確認：1辺2cmの正方形4つがぴったり1辺4cmに入る

```
■■ ■■         ■■■■
■■ ■■    →   ■■■■
                ■■■■
                ■■■■
（4cm²×4 ＝ 16cm²）
```

- 「1辺3倍→面積9倍（3²）。1辺n倍→面積n²倍——これは比例ではなく『2乗比例』」
- スパイシー確認：「立方体は1辺n倍→体積n³倍」（プールの設計・建築でも使う）

### 教師へのメモ

- **核心の驚き**：「辺を2倍にしたら面積は4倍」——「全部2倍」という予想を裏切ることが学びのエンジン
- 方眼紙に正方形を描いて面積を1マスずつ数える操作が、数式の前に視覚的理解をつくる
- **Boalerの接続**：「視覚的証明」——小正方形4つが大正方形1つに入るという図が説明そのもの
- **特別支援対応**：マイルドで方眼紙に1・2・3・4cmの正方形を描き、マス目を数えて表を埋める。「なんか4倍になってる！」を自分で発見させる
- 準備物：方眼紙（5mm方眼）、定規

## 24. グラフで未来を予測しよう

| 段階 | 課題 |
|------|------|
| **マイルド** | 植物Aの高さの表を作り（0週:0cm, 1週:3cm, 2週:6cm...）、グラフに点を打って直線でつなごう |

- **Boalerの接続**：「グラフは変化の物語を語る」——植物の成長という具体的文脈でグラフの意味を体験

## 25. どのクラスが頑張った？

> - B組：25人中20人が達成
> - C組：40人中30人が達成
>
> 「どのクラスが一番頑張りましたか？」

「直感で答えてから、理由を説明しよう」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 各クラスの達成人数と全体人数を確認しよう。「達成した人の割合」とは何を計算すること？ |

### 収束の問い（Consolidation questions）

### 教師へのメモ

- **核心の驚き**：「A組24人 > B組20人」なのに「割合は同じ」——人数と割合の違いが学びのエンジン

- **Boalerの接続**：「数学は現実を正確に見るツール」——人数だけで判断する誤りを割合が正す体験
- **特別支援対応**：Mildでテープ図（30マスのうち24マスを塗る）を使って視覚化。「10人に分けたら何人達成？」で割合を直感的につかむ

## 26. 速さをそろえて比べよう

**学年目安**: 4〜5年（カリキュラムタスク：速さ・単位量あたり）  
**数学的ねらい**: 「単位をそろえれば比べられる」——速さを1秒あたりの距離に換算して比較する

### 導入の言葉

黒板に書く：

> - チーター：5秒で150m走った
> - ウサギ：8秒で160m走った
> - 人間（100m走）：100mを10秒で走った
>
> 「どの順番で速い？どうやったら比べられる？」

「計算の仕方は教えない。自分で比べ方を考えよう」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 「1秒あたり何m進むか」を3つ計算しよう。これで順番がわかる？ |
| **ミディアム** | 分速（1分あたり何m）・時速（1時間あたり何km）に換算すると？単位を変えても順番は同じ？ |
| **スパイシー** | チーターとウサギが同時に1kmのレースをすると何秒差でゴール？チーターが50m先からスタートしてもウサギは追いつける？ |

### 収束の問い（Consolidation questions）

- 「チーター：150÷5＝30m/秒、ウサギ：160÷8＝20m/秒、人間：100÷10＝10m/秒」→ チーター > ウサギ > 人間
- 「なぜ距離÷時間で比べられる？」——「1秒あたり」にそろえると同じ単位で比較できる
- 「速さ＝距離÷時間。距離＝速さ×時間。時間＝距離÷速さ——3つは同じ関係の3通りの表し方」
- スパイシー確認：1000÷30≒33.3秒（チーター）、1000÷20＝50秒（ウサギ）→ 約16.7秒差
- 「単位をそろえて比べる発想は割合・密度・濃度など、あらゆる場面に使える」

### 教師へのメモ

- **出発点は「どうやって比べる？」** ——「1秒あたり」というアイデアを子どもから引き出すことが核心。公式（速さ＝距離÷時間）を先に教えない
- 距離と時間が両方違う3つのデータを見せることで、「そのままでは比べられない→統一が必要」という必要感が生まれる
- **Boalerの接続**：動物の速さという親しみやすい文脈で「単位量あたり」の考えを体験
- **特別支援対応**：Mildで「5秒で150m → 1秒で□m」という÷5の計算に集中。「同じ時間で走ったとしたら？」という問い方に変えてもよい
- スパイシーの「50m先スタート」：チーターは(1000-50)÷30≒31.7秒、ウサギは1000÷20＝50秒 → まだチーターが速い

## 27. 比でジュースを作ろう

**学年目安**: 3〜5年（カリキュラムタスク：比）  
**数学的ねらい**: 比の意味を「全体に占める割合のペア」として理解する・比を使って量を求める

### 導入の言葉

> 「オレンジ果汁と水を 2：3 で混ぜると、おいしいジュースができます。合計200mLのジュースを作ります。オレンジ果汁と水をそれぞれ何mL用意すればよいですか？」

できれば実際の計量カップを見せながら伝える。「まず図や絵で考えてみよう」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 「2：3」をテープ図（□□：□□□）で表そう。全体は何つ分？オレンジは全体の何分の何？ |
| **ミディアム** | 200mL・300mL・500mLのジュースを作るときの量を表にしよう。オレンジの量はどう変わる？ |
| **スパイシー** | オレンジ果汁が80mLしかない。2：3の比を守りながらできるだけ多く作ると何mL？水は何mL？ |

### 収束の問い（Consolidation questions）

- 「2：3 → 全体は2＋3＝5つ分。オレンジは5分の2、水は5分の3」
- 「200mLなら：200×2/5＝80mL（オレンジ）、200×3/5＝120mL（水）」
- 「300mLなら：120mLと180mL——オレンジの量はどう増えた？」（200に対して300は1.5倍→80×1.5＝120）
- 「2：3＝4：6＝80：120＝全部同じジュース——比が等しい＝同じ割合」
- スパイシー確認：「オレンジ80mLは1つ分40mL × 2つ分。同じ割合で水は40×3＝120mL、合計200mL」

### 教師へのメモ

- **テープ図が核心**：「2：3」を5つの□に分けて描くと「オレンジ＝全体の2/5」が視覚で分かる
- 実際に果汁と水を計って混ぜると、算数が理科・家庭科とつながり体験型の学習になる（可能なら）
- **Boalerの接続**：「数学は日常生活に埋め込まれている」——料理の文脈で比の意味を体験的に理解
- タスク25（割合）とつなげる：「オレンジは全体の2/5＝40%」——比と百分率が同じことを表す入口
- **特別支援対応**：Mildでテープ図を5マスのプリントに印刷して配布。「200mLを5等分したら1マス＝40mL」という操作から
- 準備物：テープ図ワークシート（任意）、計量カップ（実演用・任意）

## 29. かたちで仲間分けしよう

### 導入の言葉

消しゴム・えんぴつ・丸いボール・空き缶・積み木（立方体）・三角のブロックなど、身の回りの物を机に並べる。

| 段階 | 課題 |

| **マイルド** | 「転がる」ものと「転がらない」ものに分けよう。実際に転がして確かめていいよ |

### 教師へのメモ

- **ローフロアの工夫**：Mildは「実際にコロコロ転がして確かめる」——手を動かすだけで参加できる。正解・不正解でなく「どうして？」を問い続けるだけでよい

- **Boalerの接続**：「数学は分類と構造の学問」——身の回りの物が数学の対象になる体験
- **特別支援対応**：Mildで転がすという身体動作が全員の入口になる。判断が難しい子には「一緒にやってみよう」と教師が横で同じ動作をする
- 準備物：転がる物（ボール・丸缶・えんぴつ）と転がらない物（消しゴム・積み木・箱）を混ぜて机に並べる

## 30. 何本分の長さ？

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | えんぴつを机の端から端まで並べよう。何本並んだ？隣の人の答えと比べよう |
| **ミディアム** | えんぴつではなく消しゴムで測るとどうなる？クーピーでは？答えが変わる理由を言葉で説明しよう |

### 収束の問い（Consolidation questions）

- 「昔の人も同じ問題に悩んだ——手（ひとひら）や足（フィート）で測っていたが、国によって違った。そこで『1cm』という共通の単位を決めた」

> 「この箱をハサミで切り開いて、平らにするとどんな形になるでしょう？切り方は1通りだけかな？」

「予想をノートに描いてから切ってみよう」とだけ伝え、答えを教えない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 牛乳パックをハサミで切って平らに開こう。どんな形になった？紙の上に広げてなぞり、その形を記録しよう |
| **ミディアム** | 別の辺を切ってみると展開図の形が変わる。3通り以上の切り方で開いて比べよう——全部「正方形が6枚」になっている？ |
| **スパイシー** | 「これは立方体の展開図になる？ならない？」と様々な形（プリント参照）を見て判断しよう。全部で何種類の展開図があるか探せるだけ探そう |

### 収束の問い（Consolidation questions）

- 「切り方が違っても、平らにしたとき正方形（または長方形）の数は同じ——立方体は6面あるから6枚になる」
- 「どんな切り方をしても12本の辺がある——開くと何本が『つながった辺』になる？」（7本残る：辺12本−切った5本）
- 「立方体の展開図は全部で11種類——全部見つけた人は数学者と同じ探究をした」
- 「どれが展開図になって、どれがならないか——頭の中で折り上げているはず。これが空間認識力」

### 教師へのメモ

- **ローフロアの工夫**：Mildは「ハサミで切って開く」操作だけ——算数の知識ゼロで参加できる。「こんな形になった！」という驚きが思考の起点
- 牛乳パックは3辺を切るだけで開くので最も入口が低い。同じ箱を2個用意して「違う切り方」を試せると良い
- 立方体の展開図11種類はDuijvestijn（1958年）が証明——歴史を添えると知識の厚みが生まれる
- **特別支援対応**：Mildは「切って開く」操作に集中。形を言葉で表現しなくてよい。「何枚の四角形がある？」と数えることが次のステップ
- 準備物：牛乳パック・ティッシュ箱を各グループ2個ずつ・ハサミ・展開図の判断プリント（Spicy用）

## 40. 反例をひとつ見つけると？

**学年目安**: 3〜5年（非カリキュラムタスク：論理・反例）  
**数学的ねらい**: 「かならず」「いつでも」という主張を確かめる・反例が1つあれば「かならず」が崩れることを発見する

### 導入の言葉

黒板に書く：**「かけ算の答えは、かけられる数よりかならず大きい」**

> 「これは本当ですか？確かめてみよう。正しいなら証拠を、正しくないなら崩す例を1つ見つけよう。」

すぐに答えを言わず、「計算して試してみて」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 3×4、5×2、6×3 を計算しよう。かけられる数より大きい？次に 4×1、7×1 はどうなる？「かならず大きい」は正しい？ |
| **ミディアム** | 3×0.5 はどうなる？4×0 は？「かける数が1より小さいとき」「かける数が0のとき」を調べよう |
| **スパイシー** | 「奇数×奇数はかならず奇数」——これは正しい？正しいなら理由を、正しくないなら反例を探そう |

### 収束の問い（Consolidation questions）

- 「4×1＝4——かけられた数と同じ。『かならず大きい』は正しくない」（反例で崩れる）
- 「例外が1つでも見つかれば、『かならず』という主張は完全に間違いになる——これが反例のパワー」
- 「反例を1つ見つけた：それで十分。でも『かならず正しい』と言うには全部の場合を確かめるか理由を説明しなければならない——非対称だ」
- Spicy確認：奇数×奇数 = (2m+1)(2n+1) = 4mn+2m+2n+1 = 2(2mn+m+n)+1 → 奇数（理由の説明が証明になっている）
- 「数学では『全部試した』では不十分——理由を説明することが重要。でも反例は1つで十分」

### 教師へのメモ

- **ローフロアの工夫**：Mildは既知のかけ算を計算するだけ——かけ算ができれば全員が参加できる。「4×1＝4」という計算結果が反例になる瞬間の驚きが思考の入口
- 「数学は全員が正しいと証明しなければいけない」という思い込みに揺さぶりをかける——反例1つの「一撃」の快感を体験させる
- **Boalerの接続**：「数学は決して間違えてはいけない」という思い込みを崩す——探索して反例を発見するプロセス自体が数学的活動
- **特別支援対応**：Mildはかけ算の答えを出して「かけられる数より大きい・同じ・小さい」に分類するだけでOK。分類という操作が入口になる
- 発展：「素数はかならず奇数？」（2が例外）——反例探しを楽しむ文化を作る

## 42. 数えなくても「多い」とわかる

|------|------|

- 「余った△が3つ——1対1でつないで余った方が多い。全部数えなくても結論が出た」

- 「給食の配膳で『おわんが余った』→ 子どもより多い、と全員数えずにわかる——同じ仕組み」

- 発展：中学数学「関数の全単射」の素朴な経験として機能する

## 44. 並ぶ順番も大事？

**学年目安**: 4〜5年（カリキュラムタスク：順列と組み合わせ）  
**数学的ねらい**: 順列（並び順が重要）と組み合わせ（並び順を問わない）の違いを体験する・÷2の意味を発見する

### 導入の言葉

名前カード（A・B・C）を黒板に貼り、3枚を横に並べる。

> 「A・B・Cの3人が1列に並んで写真を撮ります。全部で何通りの並び方がある？全部書き出してみよう。」

「ABCとACBは違う並び方と考えていいよ」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | A・B・Cの3人の並び方を全部書こう（ABC、ACB、BAC…）。何通りあった？ |
| **ミディアム** | この6通りの中で「AとBの2人だけ選ぶ」場合を考えよう——ABとBAは別々に数える？同じと考える？どちらの答えが何通りかも書こう |
| **スパイシー** | 4人（A,B,C,D）から2人を選ぶ選び方は何通り？「選んで並べる（順列）」と「選ぶだけ（組み合わせ）」の答えを両方出して、なぜ違うか説明しよう |

### 収束の問い（Consolidation questions）

- 「3人の並び方：先頭の選び方（3通り）×次（2通り）×残り（1通り）＝6通り」
- 「ABとBAは違う写真——並ぶ順番が大事なときは『順列』という」
- 「Spicy：4人から2人を選んで並べる＝4×3＝12通り。でもABとBAを同じとする選び方は12÷2＝6通り——これが『組み合わせ』」
- 「なぜ÷2？——ABとBAは選んでいる人は同じ。並べると2通りになるから2回数えてしまっている」
- 「3人から選ぶなら÷6（3!=3×2×1）——並べると6通りあるから」

### 教師へのメモ

- **ローフロアの工夫**：Mildは名前カードを物理的に並べ替えるだけ——「ABCと並べた・ACBと並べた」という操作が全員の入口
- 「何通り？」より「ABとBAは同じか違うか？」という問いかけが順列と組み合わせの違いの核心。この問いを収束の中心に据える
- **特別支援対応**：Mildで名前カード3枚を動かして並べる操作。「書く」より「動かす」が入口。3通り出たら「他にある？」と問い続ける
- 準備物：名前カード（A・B・C・D）各グループ4セット・表のワークシート

## 45. 多角形の対角線を全部引こう

**学年目安**: 4〜5年（カリキュラムタスク：図形・場合の数の応用）  
**数学的ねらい**: 帰納的に規則を見つける・式で一般化する・組み合わせの幾何的応用を体験する

### 導入の言葉

黒板に正方形を描き、対角線を2本引いて見せる。

> 「四角形の対角線は2本。では五角形は？六角形は？全部引いて数えてみよう。表にまとめながら、規則を探してみて。」

「10角形の対角線の本数を計算で出すことはできる？」と問いかけて探究を始める。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | プリントの三角形・四角形・五角形に対角線を全部引いて、本数を数えよう。表にまとめよう |
| **ミディアム** | 六角形・七角形の対角線の本数を予測してから引いて確かめよう。増え方に規則はある？ |
| **スパイシー** | n角形の対角線の本数を求める式を作ろう。（ヒント：1つの頂点から引ける対角線の数は何本？全頂点でその2倍になるのはなぜ？） |

### 収束の問い（Consolidation questions）

- 「三角形0本・四角形2本・五角形5本・六角形9本——差が2, 3, 4, 5…と増えている」
- 「頂点がn個のとき、1つの頂点からはn−3本引ける（自分と隣の2頂点を除く）。全頂点で n×(n−3)本だが、各対角線を2度数えているので÷2」
- 「式：n×(n−3)÷2——10角形なら 10×7÷2＝35本」
- 「タスク44（組み合わせ）の考え方と同じ——nC2（全頂点の組み合わせ）からnを引いた数とも同じ」
- 「式があれば100角形でも100×97÷2＝4850本と瞬時に求められる」

### 教師へのメモ

- **ローフロアの工夫**：Mildは印刷した多角形に定規で線を引く操作——「斜めの線を引いて数える」だけで参加できる
- 「規則を見つける→式を作る」という帰納的思考の良い流れ——表を作ることが思考の足場になる
- タスク44（÷2の理由）とタスク12（パスカルの三角形）とのつながりを収束で語ると知識が体系化される
- **特別支援対応**：Mildは印刷した図形に定規で線を1本ずつ引く。「辺は数えなくていい、頂点と頂点を結ぶ斜めの線だけ」と絞る
- 準備物：三角形〜六角形の印刷済みシート・定規・表のワークシート

## 46. □からnへ——文字の意味を探れ

**学年目安**: 4〜5年（カリキュラムタスク：文字と式）  
**数学的ねらい**: □（未知数）からn（変数）へ——文字が「変わる数の入れ物」であることを表で体験する

### 導入の言葉

黒板に「□＋5＝9」と書く。

> 「□に入る数は？」（4と確認）

続けて書く：「□＋5　← □がいろんな数に変わったらどうなる？」

> 「□が1のとき・2のとき・3のとき…と変えていくと、答えはどう変わる？」

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 「□＋5」の□に1, 2, 3, 4, 5を入れて表を作ろう。□が1増えると答えはどう変わる？ |
| **ミディアム** | 同じことを「n＋5」と書き直そう。nが10・100・0のとき、それぞれいくつになる？ |
| **スパイシー** | 「2×n＋3」はnが変わると答えはどう変わる？この式が表している場面（買い物・図形など）を作ってみよう |

### 収束の問い（Consolidation questions）

- 「□もnも、まだ決まっていない数を入れる『入れ物』——入れる数が変わると答えが変わる」
- 「□は『答えを1つ求めるとき』・nは『いろんな数で考えたいとき』に使うイメージの違いがある」
- 「Spicy：2×n＋3 → ノートをn冊買う（1冊2円）＋えんぴつ1本（3円）の合計——場面を作ると式の意味が見える」
- 「nに10を入れると2×10＋3＝23。100を入れると203——式があれば何でも計算できる」
- 「この『n』を中学では『x』とも書く——今日やったことは中学数学の入口」

### 教師へのメモ

- **ローフロアの工夫**：Mildは□に数を入れて計算するだけ——4年生の□の式から自然につながる。表に数を埋める操作が全員の入口
- 「□→n」の橋渡しは丁寧に：「書き方が違うだけで同じ意味」と言葉で確認する
- タスク41（3つ連続した数の和）でやった□の操作と接続すると理解が深まる
- **特別支援対応**：Mildはプリントの表に電卓で計算しながら数を入れる。「□に3を入れると？」と1つずつ確認する操作が入口
- 準備物：表のワークシート（□/nに数を入れる欄付き）

## 47. 式が物語を語る

**学年目安**: 5年（カリキュラムタスク：文字と式・文脈と式の往復）  
**数学的ねらい**: 式から場面を作る・場面から式を作る——文字式を「算数の言語」として双方向に使う

### 導入の言葉

黒板に「a × 6」と書く。

> 「この式はどんな場面を表している？思いつく場面を全部ノートに書いてみよう。1つでも2つでも何でもいいよ。」

答えをすぐに言わず、ペアで話し合う時間を1分とる。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 「1袋にみかんがa個入っている。6袋で全部何個？」——a＝3, 5, 10のとき計算してみよう。場面に合った絵も描こう |
| **ミディアム** | 「a＋b」「a×b」「a÷b」——それぞれ違う場面を1つずつ作ってみよう |
| **スパイシー** | 「2×a＋3×b」という式の場面を作ろう。「別の書き方」（場面を変えずに式を変形する）はできる？ |

### 収束の問い（Consolidation questions）

- 「a×6：みかん6袋・椅子6列・1人6枚のカード——1つの式が無数の場面を表せる」
- 「式は場面を抽象化したもの——数学の言葉（数の言葉）で世界を表現している」
- 「Spicy：2a＋3b → 鉛筆a本（1本2円）とノートb冊（1冊3円）の合計——場面が変わっても式の構造は同じ」
- 「式を読む力・式を作る力——どちらも算数の中心にある。式は記号ではなく言語」（Boaler, 2015）

### 教師へのメモ

- **ローフロアの工夫**：Mildは具体的な場面（みかん・袋）でaに数を代入する操作——a＝3の計算ができれば参加できる
- 「式→場面」と「場面→式」の両方向を行き来させることがねらい。どちらか一方向だけではない
- Boalerの「数学は言語である」という視点を教師が意識して語る——「数学は記号を暗記するものではない」
- **特別支援対応**：Mildの場面（みかん・袋）を絵カードで示すと式と場面の対応が視覚的に確認できる。aに具体的な数字シールを貼って「入れ替える」操作も有効
- 準備物：場面絵カード・式カード（a×6などを印刷）

## 48. パターンを式で閉じ込めよう

**学年目安**: 5年（カリキュラムタスク：文字と式・数列の一般化）  
**数学的ねらい**: 視覚的パターン（階段タイル）の枚数をnを使った式で表す——三角数の一般化と式のパワーを体験する

### 導入の言葉

黒板に正方形タイルで作った階段を描く（1段・2段・3段・4段）。

> 「4段の階段を作るには何枚のタイルが必要？10段は？100段は？全部数えなくてもわかる方法はある？」

「まず1段〜4段を表にまとめてみよう」とだけ伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 1段・2段・3段・4段のタイルの枚数を数えて表に書こう。5段は積み木（またはます目）で作って確かめよう |
| **ミディアム** | 増え方の規則を言葉で書こう。「n段の階段は全部で何枚？」n＝1, 2, 3, 4で確かめよう |
| **スパイシー** | n段の階段のタイルの合計を式で表そう。（ヒント：合計＝1＋2＋3＋…＋n。2つ並べると長方形になる——何かに気づく？） |

### 収束の問い（Consolidation questions）

- 「1段：1枚、2段：3枚、3段：6枚、4段：10枚——差が1, 2, 3, 4と増えている（タスク7の階段と同じ三角数！）」
- 「タスク7では絵で考えた——今度は式で表す。両方できると数学が広がる」
- 「合計＝1＋2＋3＋…＋n。2つ並べると n×(n＋1) の長方形になる——だから合計は n×(n＋1)÷2」
- 「100段：100×101÷2＝5050——ガウスが10歳で瞬時に計算した式と同じ」
- 「式があれば1000段でも式に代入するだけ——これが『式で閉じ込める』ことのパワー」

### 教師へのメモ

- **ローフロアの工夫**：Mildは積み木やブロックで1段ずつ実際に作って枚数を数える操作——具体物を触るだけで参加できる
- タスク7（階段の形を続けよう）との接続が鍵——「絵でわかっていたことが式でも表せた」という統合体験
- ガウスの逸話（「先生が生徒を静かにさせるために出した1〜100の和を瞬時に計算した」）を語ると式の意味が記憶に残る
- **特別支援対応**：Mildは積み木で実際に作って数える。「4段目に何枚追加した？」と1段ずつ積み上げながら問い、増え方のパターンに気づかせる
- 準備物：方眼紙またはブロック・タイル・表のワークシート（n段と枚数を記入する欄）

## 設計原理のまとめ

このタスク集が使っている設計原理 → 詳細は [[パタン/算数シンキング・タスク]]

| 原理 | このタスク集での実現 |
|------|---------------------|
| **低い床（LFHC）** | マイルドで全員が「できた」を経験できる入口を保証 |
| **高い天井（LFHC）** | スパイシーで平方数・稠密性・組み合わせ論・三角数・LCMまで到達可能 |

| **収束** | 各タスクにConsolidation questionsを設計し、探究が概念につながる |
| **視覚的表現** | タスク7〜9は図・折り紙・百マス表で数学を「見える」化（Boaler, 2015） |
| **構造の発見** | タスク10〜12はフィボナッチ・9の段・パスカルの三角形——「なぜ？」を引き出す設計 |
| **小数の概念** | タスク13〜15は等分・比較・乗法の思い込みを壊す3段階で小数を体験的に理解 |
| **データリテラシー** | タスク16〜18はグラフ批判・平均の限界・変化の読み方——数学で現実を読む力 |
| **図形の構造** | タスク19〜21は折り紙・角の実験・分類——「見て触って発見する」図形探究 |
| **関数的思考** | タスク22〜24は変換機械・比例と2乗・グラフの交点——変化と関係を探究する |
| **割合・比・速さ** | タスク25〜27は割合の比較・速さの統一・比のレシピ——「数量を正しく見る」力 |
| **K〜1年の入口** | タスク28〜30は隠れた数・形の観察・長さ比べ——具体操作が全員の入口になる設計 |
| **測定・単位** | タスク31〜33は重さ・かさ・時間——操作して量ることで「単位の必要性」を体験 |
| **大きな数・位取り** | タスク34〜36はまとめる操作・部屋のメタファー・1億の体感——数の構造を探究 |
| **立体図形・空間認識** | タスク37〜39は展開図・積み木の見取り・投影図——触って・見て・想像する空間的思考 |
| **論理・証明的思考** | タスク40〜42は反例・一般化・1対1対応——「なぜ？」「かならず？」という論理の入口 |
| **場合の数（系統的発展）** | タスク43〜45は樹形図・順列と組み合わせ・対角線——「漏れなく・重なりなく」の体系化 |
| **文字と式** | タスク46〜48は変数の意味・式と場面の往復・一般化——中学数学への橋渡しとしての文字式 |
