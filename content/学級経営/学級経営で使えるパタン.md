# 学級経営で使えるパタン

「このクラスをよくしたい」という場面から、使えるパタンを逆引きする入口。

→ 詳細な索引: [[学級経営/index]]

## 困りごとから探す

| 困りごと・場面 | 使えるパタン | 一言 |
|---|---|---|
| 年度初めに「このクラスって安心していいの？」 | [[パタン/オンボーディング]] | 最初の体験で価値・手順・小さな成功を示す |
| 間違えた子が笑われる雰囲気がある | [[パタン/間違いや失敗から学ぶ文化]] | 間違いを学びの資源として価値づける |
| 発言する子が偏っている | [[パタン/心理的安全性（コンフォートゾーン）]] | 挑戦・発言・失敗が歓迎される場をつくる |
| 聴く力が育っていない | [[パタン/聴き合う文化]] | 聴くことが当たり前の文化をつくる |
| 子どもたちがバラバラでまとまりがない | [[パタン/コミュニティをつくる]] | 帰属感・つながりのある集団を育てる |
| 良い行動・作品が広がらない | [[パタン/エクセレンスの文化]] | 卓越を共有し、クラスの質の基準を上げる |
| 問題行動への対応に疲れている | [[パタン/適切な行動に注目する]] | 望ましい行動に注目し価値づける |
| 子どもが自分で動けない | [[パタン/自己選択自己決定]] | 方法・順序を自分で選ぶ機会をつくる |
| クラスに「考えること」が根付かない | [[パタン/考える文化]] | 考えを持つことが当たり前の規範をつくる |
| 教師から子どもへの言葉かけを変えたい | [[パタン/Iメッセージ]] | 主語を「私」にして行動でなく影響を伝える |
