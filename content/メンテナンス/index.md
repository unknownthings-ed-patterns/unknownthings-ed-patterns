# メンテナンス

wikiをクロコちゃんやCodexで共同編集するときに、作業前後で見る入口。

本文を大きく書き換える前に、まずここで「現在名」「未整備候補」「作業ルール」を確認する。

## 共同編集の基本ルール

| 場面 | ルール |
|------|--------|
| 作業開始前 | GitHubの最新版を確認し、現在の本文を読んでから追記・修正する |
| 既存ページの再生成 | 現在の本文や導線を消さず、必要な追記・修正だけにする |
| content と Obsidian | `content` 側を直したら、対応する Obsidian vault 側にも反映する |
| 実践ページ | 実践側には `## 圧縮されているパタン` を追記する |
| 親パタンページ | 親パタン側には `## このパタンが働く実践` を追記する |
| 文章の扱い | クロコちゃんが生成した文章の意味は大きく変えず、追加・接続・整理を中心にする |
| 作業後 | リンクチェックとビルドを通してからコミット・プッシュする |

## よくある作業

### 旧名・表記ゆれを直す

1. [[メンテナンス/旧名と現在名]] を見る
2. 旧リンクを現在名へ直す
3. 旧名が残る場合は、入口ページ・エイリアス・案内として残せるか考える

### 主要パタン名インデックスを育てる

1. [[メンテナンス/主要パタン候補]] を見る
2. 参照数が多く、親パタンとして使われているページを確認する
3. 必要なら [[パタン名インデックス|主要パタン名インデックス]] に追加する

### 実践に圧縮を書く

1. [[メンテナンス/次に圧縮を書く候補]] を見る
2. 実践本文を読み、意味を変えずに `## 圧縮されているパタン` を追記する
3. 関連する親パタン側にも、必要なら `## このパタンが働く実践` を足す

### 文献を再統合する

1. [[メンテナンス/文献成熟度ダッシュボード]] を見る
2. `literature_status` が未設定・`ingested` の文献から選ぶ
3. 文献ページに「このWikiでの使い道」「この文献から生まれたパタン」「関連する概念」を足す
4. 必要なら [[メンテナンス/未パタン化の論点]] に、まだ圧縮していない問いを移す
5. `npm run update:literature-report` で [[メンテナンス/文献自動レポート]] を更新する
