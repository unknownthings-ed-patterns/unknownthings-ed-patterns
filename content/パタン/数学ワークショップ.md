# 数学ワークショップ

> ウォームアップ、ミニレッスン、個別・小グループでの問題解決、数学的対話、ジャーナルによる振り返りを組み合わせ、子どもが「数学者として考える」場をつくる。

---

## Pattern Connection

**Liljedahl & Giroux（2024）統合（2026-05-14）：**

*Mathematics Tasks for the Thinking Classroom, Grades K-5*（Corwin）は、数学ワークショップの「問題解決フェーズ」で使うタスクを体系化した実践書として機能する。BTC（Building Thinking Classrooms）の14の最適実践のうち、タスク設計と使い方の部分をK-5の50タスクで具体化している。

- **補強された点**：数学ワークショップの問題解決フェーズに「どんなタスクを使うか」の設計原理（LFHC・新しさ・好奇心と粘り強さ）が加わった。収束（Consolidation）が「共有・振り返り」フェーズに対応し、「最も重要で最もよく省略される段階」として明確に位置づけられた。
- **修正・拡張された点**：年度初め1〜2週間を「非カリキュラムタスクだけ使う」期間として設計することで、「算数は考える教科だ」という文化を先に作ってからカリキュラムに入る構造が明確になった。Mild/Medium/Spicyの足場が、特別支援を含む全員参加を保証する仕組みとして機能する。
- **他のパタンへの波及**：[[パタン/算数シンキング・タスク]]（新規）として、タスク設計の原理がパタン化された。[[教材/算数シンキング・タスク集]]（新規）として、日本語版6タスクが実装された。

## 背景（Context）

数学ワークショップは、CTL（Center for Teaching and Learning）で実践されている算数・数学のワークショップ型授業である。

この実践では、計算練習と概念理解のどちらか一方を選ばない。基本的な計算の正確さや自動性を育てながら、同時に、子どもが数学的に推論し、説明し、書き、仲間と考え合うことを重視する。

リーディング・ワークショップが子どもを読書家として育てる場だとすれば、数学ワークショップは子どもを数学者として育てる場である。数学は、手順を覚える教科ではなく、考えを表し、問いを持ち、複数の方法を試し、言葉で説明する文化として扱われる。

## 問題（Problem）

算数・数学の授業は、教師が解き方を説明し、子どもが類題を解く形に偏りやすい。その形だけでは、子どもは計算手順を覚えても、なぜその方法が成り立つのか、別の方法で考えられるのか、自分はどこで分かっていてどこで困っているのかを言語化しにくい。

一方で、概念探究だけに寄せると、基本的な計算や語彙が自動的に使える状態にならず、より複雑な問題に取り組む負荷が高くなる。

## 力のかたち（Forces）

- 子どもには、計算の練習と概念の探究の両方が必要である
- 数学的な概念は、語彙・図・表・説明によって扱えるようになる
- ただ問題を解くだけでは、子どもの考え方やつまずきが見えにくい
- 小グループは助け合いを生むが、答えを教え合うだけになる危険もある
- 数学への自信は、正解数だけでなく、考えを説明し、仲間の考えを聞く経験から育つ
- 教師は全員を一斉に教えるだけでなく、個人や小グループの数学的思考に介入する必要がある

## 解決（Solution）

**短いウォームアップとミニレッスンで数学モードをつくり、その後、個人・小グループで問題解決に取り組み、数学ジャーナルやバインダーに考え・語彙・振り返りを残す。**

数学ワークショップは、次の要素を組み合わせて設計する。

| 要素 | 役割 |
|------|------|
| ウォームアップ／ブラッシュアップ | 計算や既習事項を短く扱い、数学へ意識を切り替える |
| ミニレッスン | その日の手順・慣習・概念を短く焦点化する |
| 個人で考える時間 | 自分の解法や疑問を持つ |
| 数学学習チーム | 仲間に質問し、説明し、複数の解法を比べる |
| 数学ジャーナル／バインダー | 思考、語彙、宿題、振り返り、自己評価を蓄積する |
| 教師のカンファランス | 個人や小グループの考え方を聞き、必要な支援を行う |

## 基本的な授業サイクル

| 時間 | 内容 | ねらい |
|------|------|--------|
| 5〜10分 | ウォームアップ、ブラッシュアップ、暗算、今日の問題 | 数学モードへ入る。既習事項を使い直す |
| 5〜15分 | ミニレッスン | 手順、語彙、戦略、概念を短く導入する |
| 20〜30分 | 個人・ペア・学習チームで問題解決 | 自分の考えを持ち、仲間と相談し、説明する |
| 5分 | 共有・振り返り・ジャーナル | 何を理解したか、どこで困ったか、どんな語彙を使ったかを残す |

### 45分授業の最小モデル

日本の小学校で試すなら、まず45分の中に次の形で入れると扱いやすい。

| 時間 | 活動 | 教師の役割 | 子どもの姿 |
|------|------|------------|------------|
| 5分 | ウォームアップ | [[パタン/ナンバートーク]] や短い計算を出し、考え方を一つだけ共有する | 頭を数学モードへ切り替える |
| 7分 | ミニレッスン | 今日使う概念・語彙・道具を一つに絞って示す | 今日の見方や言葉をつかむ |
| 23分 | 問題解決 | 個人、ペア、[[教材/数学学習チームのルール]] を使った小グループを回り、考えを聞く | 図・式・表・言葉で考えを残す |
| 7分 | 共有 | 代表的な考え、別解、つまずきを取り上げる | 友だちの考えを聞き、自分の考えと比べる |
| 3分 | ジャーナル | 振り返りの問いを一つ選ばせる | [[教材/数学ジャーナルとバインダー]] に、言葉・気づき・困りごとを残す |

最初の数回は、全部をうまく回すことより、時間のリズムを固定することを優先する。ウォームアップ、ミニレッスン、問題解決、共有、ジャーナルの順番が予測できるだけでも、子どもは活動に入りやすくなる。

### ナンバートークとの関係

[[パタン/ナンバートーク]] は、数学ワークショップの冒頭ウォームアップとして使いやすい。

| ナンバートーク | 数学ワークショップの中での役割 |
|----------------|--------------------------------|
| 1問を暗算で考える | 授業冒頭に、全員が数学的に考え始める |
| 複数の解法を共有する | その日の概念や語彙につながる考え方を見つける |
| 「どうやって解いた？」を聞く | 答えよりもプロセスを説明する文化をつくる |
| 解法を図・式・言葉で残す | ミニレッスンやジャーナルへ橋渡しする |

たとえば `15 × 4` のナンバートークで「10×4 と 5×4 に分ける」考えが出たら、その後のミニレッスンで「分ける」「まとまり」「分配」といった語彙を扱える。`50 + 70` なら、[[実践/10や100を単位にして計算しよう]] のように「10を単位にする」考えへつなげられる。

ナンバートークは単独でも価値があるが、数学ワークショップの中に置くと、ウォームアップから概念、問題解決、ジャーナルまでがつながる。

### 授業例

#### 例1：中学年・高学年「15 × 4」

例として、`15 × 4` のナンバートークから、分解・まとまり・説明へつなげる45分を考える。

| 時間 | 活動 | 具体 |
|------|------|------|
| 5分 | ウォームアップ | `15 × 4` を暗算で考え、複数の解法を出す |
| 7分 | ミニレッスン | 「分ける」「まとまり」「2倍」など、出てきた考え方を数学の言葉として整理する |
| 23分 | 問題解決 | `16 × 4`、`25 × 4`、`18 × 5` などを、図・式・言葉で説明する。早い子は別の解き方を探す |
| 7分 | 共有 | 10と残りに分ける考え、2倍を使う考え、近い数にして調整する考えを比べる |
| 3分 | ジャーナル | 「今日使った数学の言葉」「友だちの考えでよかったもの」「次に使いたい考え方」を書く |

この1時間では、答えを速く出すことよりも、計算の背後にある構造を言葉にすることをねらう。`15 × 4` で出た考えを、別の問題に使えるかどうかが、数学ワークショップらしい発展になる。

もう一つの例として、[[実践/10や100を単位にして計算しよう]] では、ナンバートークで `50 + 70` を扱い、その後のミニレッスンで「10を単位にする」へつなげることができる。

#### 例2：低学年「10を単位にして計算する」

[[実践/10や100を単位にして計算しよう]] を数学ワークショップとして組み立てるなら、`50 + 70` のような問題を入口にする。

| 時間 | 活動 | 具体 |
|------|------|------|
| 5分 | ウォームアップ | `50 + 70` を見て、10がいくつあるかを考える |
| 7分 | ミニレッスン | 「10を1つのまとまりとして見る」「10が5こ、10が7こ」という言い方を扱う |
| 23分 | 問題解決 | `30 + 40`、`80 + 60`、`200 + 300` を、数カード・図・式・言葉で説明する |
| 7分 | 共有 | 10を単位にした説明、100を単位にした説明を比べる |
| 3分 | ジャーナル | 「今日、10や100を単位にして考えた問題」を一つ残す |

ここでは、計算の正確さだけでなく、「何を単位として見ているか」を言葉にすることが中心になる。[[教材/増える算数辞典]] に「単位」「10をもとにする」「100をもとにする」を残すと、次の計算でも使い直しやすい。

#### 例3：特別支援級・複式「重さと面積をわたり・ずらしで学ぶ」

[[実践/個別支援級の複式算数：重さと面積をわたり・ずらしで学ぶ]] のように学年や単元が混在する場合も、数学ワークショップの型は使える。

| 時間 | 活動 | 具体 |
|------|------|------|
| 5分 | 共通ウォームアップ | ものを比べる、並べる、数えるなど、全員が参加できる短い問いを出す |
| 7分 | ミニレッスン | 今日使う道具、記録の仕方、困ったときの相談の仕方を一つだけ確認する |
| 25分 | 個別・小グループ | 学年ごとの課題に取り組み、教師は順にカンファランスする |
| 5分 | 共有 | 「今日使った道具」「分かったこと」「まだ迷っていること」を一つずつ出す |
| 3分 | ジャーナル | 図・式・言葉のうち、残しやすい形で記録する |

支援級では、全員が同じ問題を解くことより、活動のリズムと記録の場所を共有することが大事になる。ウォームアップとジャーナルを共通にしておくと、教師が離れている時間も子どもが次に何をするかを見失いにくい。

## ミニレッスンで扱うこと

CTLの数学ワークショップでは、ミニレッスンが大きく三つの領域を扱う。

| 領域 | 内容 |
|------|------|
| 手順 | バインダーの使い方、教具の置き場所、電卓や道具の扱い方 |
| 慣習 | 計算戦略、数学語彙、記号、基本演算の使い方 |
| 概念 | 数と演算、測定、データ分析と確率、図形、代数などの中心概念 |

ミニレッスンは、長く説明する時間ではない。子どもがその後の問題解決で使える考え方・言葉・道具を、短く渡す時間である。

## 学習チーム

数学ワークショップでは、子どもが小グループで問題に取り組む。重要なのは、グループを「答えを教え合う場」にしないことである。

学習チームでは、自分が分からなかった問題を持ち寄り、どこで困ったのかを具体的に質問する。分かっている子は、答えを言うのではなく、例を出したり、問い返したり、別の問題で理解を確かめたりしながら助ける。

このとき、子どもは「自分の理解には自分で責任を持つ」ことと、「仲間の理解を助ける」ことの両方を学ぶ。

詳しくは [[教材/数学学習チームのルール]] に整理する。

## ジャーナルとバインダー

数学ジャーナルとバインダーは、子どもの数学的思考を蓄積する場所である。

そこには、授業中に解いた問題、図・表・言葉による考え、ミニレッスンのメモ、日々の数学的振り返り、宿題ログ、返却物、数学語彙が入る。

数学語彙は、定義だけでなく、図・例・余白とともに残す。理解が深まるにつれて定義が変わることもあるため、書き直しや追記の余地を残す。

詳しくは [[教材/数学ジャーナルとバインダー]] に整理する。

## 追試するなら

最初から大きなシステムとして始めなくてよい。まずは、「明日1回やる」「2回目で道具を足す」「1週間で型にする」の順に試す。

### 明日1回だけやる

1. 授業冒頭に5分のウォームアップを固定する
2. [[パタン/ナンバートーク]] で1問だけ扱う
3. 出てきた考え方から、今日使う語彙や概念を一つ選ぶ
4. 10分以内のミニレッスンで、その語彙・図・考え方を短く確認する
5. 問題を解くとき、式だけでなく、図・表・言葉のどれかを残させる
6. 最後に1分で「今日使った数学の言葉」「友だちの考えでよかったもの」「まだ困っていること」から一つ選んで書く

### 2回目で道具を足す

1. [[教材/数学ジャーナルとバインダー]] の場所を決める
2. 子どもに「ここに考え方、語彙、振り返りを残す」と説明する
3. 小グループで相談する前に、[[教材/数学学習チームのルール]] を一つだけ確認する
4. 新しく出てきた語彙を [[教材/増える算数辞典]] に一語だけ残す
5. 教師は全員を見ようとせず、2〜3人の考え方を短く聞いて記録する

### 1週間続ける

| 回 | 焦点 | できれば十分なこと |
|----|------|--------------------|
| 1回目 | 型を知る | ウォームアップ、ミニレッスン、問題解決、振り返りの順番を経験する |
| 2回目 | ジャーナル | 自分の考えを図・式・言葉で残す |
| 3回目 | 学習チーム | 困ったところを質問し、答えではなく考え方を聞く |
| 4回目 | 語彙 | 今日使った数学の言葉を一つ増やす |
| 5回目 | 振り返り | 「前よりできるようになったこと」を自分で見つける |

1週間の終わりに、教師はノートの美しさではなく、「考え方が残っているか」「語彙を使っているか」「友だちの考えを取り入れているか」を見る。

### 最小セット

- 5分のウォームアップ
- 10分以内のミニレッスン
- 図・式・言葉を残す問題解決
- 1分のジャーナル
- 次回も同じ順番で始まるという予測可能性

日本の小学校なら、[[パタン/ナンバートーク]] をウォームアップに使い、[[教材/増える算数辞典]] を語彙の蓄積に使うと始めやすい。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| ウォームアップが計算プリントだけになる | 「どう考えたか」を一つだけ共有し、戦略や語彙につなげる |
| ミニレッスンが長くなる | その時間に使う言葉・道具・考え方を一つに絞る |
| 小グループが答え合わせになる | 「どこで困った？」「どう説明できる？」をチームのルールに入れる |
| ジャーナルが板書の写しになる | 図、例、自分の疑問、別解、今日の気づきを書いてよいことにする |
| 語彙が暗記になる | [[教材/増える算数辞典]] のように、図・例・使う場面と結びつける |
| 教師が全員を見取れない | 1時間に数人だけでもカンファランスし、記録を短く残す |

## 結果（Consequences）

- 子どもが数学を、手順の暗記ではなく、考えを説明する活動として捉えやすくなる
- 計算練習と概念理解が分離せず、互いに支え合う
- 数学語彙が、定義の暗記ではなく、問題解決や説明の中で使われる
- 小グループで、助けを求めること・助けることの文化が育つ
- ジャーナルやバインダーが、自己評価・ポートフォリオ・カンファランスの資料になる
- ただし、構造が曖昧だと、自由作業・答え合わせ・ノート整理だけに流れやすい

## このパタンが働く実践・教材

| 実践・教材 | どのように働くか |

## Actionable Insight

- **明日1回だけ試す**：授業冒頭5分に「ナンバートーク」を1問入れる——暗算で考え、出てきた解法を1〜2つ共有するだけでよい。ウォームアップの型を先に固める
- **ミニレッスンを10分で切る**：「今日使う数学の言葉・考え方を1つに絞る」という制約をかける。長い説明は問題解決の時間を削る
- **「図か式か言葉のどれかを残す」**：答えだけでなく考え方を1つの形でノートに残させる。正解の数ではなく考え方が積み上がっていくことを目指す
- **最後1分のジャーナル**：「今日使った数学の言葉」「友達の考えでよかったもの」「まだ困っていること」から1つ選んで書かせる——毎回同じ問いを使うことで習慣になる
- **週末の確認**：ノートを見て「考え方・言葉が残っているか」を確認する。そこが次週のミニレッスンの起点になる
