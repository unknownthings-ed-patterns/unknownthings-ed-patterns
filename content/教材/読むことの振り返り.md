# 読むことの振り返り

> 読書への好き嫌い、得意感、友だちとの読書対話、一年間の成長を振り返り、読者としての自分を見つめるシート。

## 教材の概要

「読むこと」の振り返りは、リーディング・ワークショップや読書単元の終わりに使う総括的な振り返りシートである。

読んだ冊数や読書量だけでなく、子どもが「読むこと」をどう感じているか、読者として自分をどう見ているか、どの活動が読む力や読書への好意に役立ったかを見取る。

## 使う場面

- 学期末や年度末に、読むことへの好意や得意感を振り返る
- リーディング・ワークショップの終わりに、読者としての成長を見取る
- [[教材/20冊チャレンジ]] や読書記録を見返したあとに書く
- ブッククラブ、ブックトーク、ミニレッスンなど、どの活動が効いたかを確かめる
- 次年度の読書指導や教室環境づくりを考える資料にする

## 振り返ること

原資料では、次のような項目が用意されている。

| 項目 | 見取れること |
|------|--------------|
| 本などを読むことは好きですか | 読書への好意 |
| 本などを読むことは得意ですか | 読者としての自己効力感 |
| きちんと理解しながら読めるようになりたいですか | 読む力を伸ばしたい意欲 |
| 友だちと本のことについて話すことはありますか | 読書が対話に開かれているか |
| 友だちと本のことについて話し合うのは好きですか | 読書会・ブッククラブへの構え |
| この一年間で読んだ本のベスト5 | 心に残った読書経験 |
| 「読むこと」に関して一年間で成長したこと | 読者としての変化 |
| 役に立った活動へのチェック | どの支援や活動が効いていたか |

## 役に立った活動の例

原資料では、読むことが好きになったり、読む力をつけたりするのに役に立った活動として、次の項目が挙げられている。

- 教室にある本
- 読書の時間（30分間読書など）
- 自分で本を選んだこと
- ブックトーク（先生の本の紹介）
- ブッククラブ
- レターエッセイ
- 本で調べて、報告する活動
- ミニレッスン
- 読み聞かせ
- ブックレビュー
- 先生との会話や先生からのアドバイス
- 友だちとの会話や友だちからの本のおすすめ
- 読書記録

このチェック欄は、教師にとっても重要である。どの環境・活動・支援が子どもの読書に働いていたのかを見直す材料になる。

## 追試するなら

年度末だけでなく、学期末や読書単元の終わりにも使える。

書かせる前に、手元の [[教材/20冊チャレンジ]]、[[教材/1週間の読書目標]]、ブックレビュー、レターエッセイなどを見返す時間を取るとよい。記憶だけで振り返るより、読書の足あとを見ながら書く方が、具体的な成長に気づきやすい。

ベスト5は、冊数の多さを競うためではなく、「自分に残った本」を選ぶために使う。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| 成長したことが書けない | 読書記録や過去の目標を見返して、前の自分と比べる |
| 「好き／嫌い」だけで終わる | 「どんな時にそう感じた？」と具体的な場面を聞く |
| ベスト5が出ない | まず1冊だけ選び、そこから似た本・同じ作者を思い出す |
| チェック欄を機械的に埋める | 「一番役に立ったものを一つ選ぶなら？」を追加する |
| 読むことが苦手な子が落ち込む | 「少し変わったこと」「前よりできたこと」を探す |

## この教材の意味

読むことの振り返りは、読書指導を「どれだけ読んだか」だけで終わらせないための教材である。

子どもは、自分が読むことを好きか、得意だと思っているか、もっと理解しながら読みたいと思っているかを言葉にする。さらに、友だちと本について話した経験や、一年間で心に残った本、役に立った活動を振り返る。

教師にとっては、リーディング・ワークショップのどの手立てが子どもに届いていたかを知る資料になる。子どもにとっては、自分が一年間でどんな読者になってきたかを見えるようにする資料になる。
