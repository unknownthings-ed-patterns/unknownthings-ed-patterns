# 思考の三層（科学・論理・メタ）

## 定義

思考には三つの異なる層がある。この三層を統合して動かすことが深い理解と判断力を生む。

| 層 | 問い | 説明 |
|---|---|---|
| **科学的層** | 何が起きているか？どうやって確かめるか？ | 経験・観察・実験による知識の獲得 |
| **論理的層** | なぜそうなるか？どう筋道立てて考えるか？ | 演繹・推論・因果関係の把握 |
| **メタの層** | この問いはそもそもどのように成り立っているか？ | 自分の思考・認識の条件を問うメタ認知 |

## 哲学史における三者の対応

- **科学的層** → 経験論（ベーコン、ヒューム）：観察から帰納する
- **論理的層** → 合理論（デカルト、ライプニッツ）：演繹・疑って確実なものを探す
- **メタの層** → カント（批判哲学）：経験と論理が「成立するための条件」を問う

### デカルト：内側へ
「すべてを疑う → 疑っている自己は確実だ（我思う、ゆえに我あり）」。確実な足場を内側に求める。

### 科学：外側へ
観察・実験で法則を見つける。外に向かう知識の獲得。

### カント：メタの位置
「科学と論理が成立するための条件を逆算して明らかにする」。経験を可能にする人間の認識構造（感性・悟性・理性）を解明する。

> カントの「コペルニクス的転回」：認識が対象に合わせるのではなく、対象が認識の形式（時間・空間・カテゴリー）に合わせて現れる。

## 三つの出発点の統合

「魔法使いが好き」「デカルト的懐疑」「科学の重要性」という一見バラバラな関心は、同一の構えから生まれている：

**「見えている世界をそのまま受け取らない」**

- 魔法使い → 世界の背後にある仕組みを想像する（科学的探求の原動力）
- デカルト的懐疑 → 与えられたものを疑い確実なものを探す（論理的層）
- カント → 両方が成立する条件を問う（メタの層）

これらは対立するのではなく、段階的に深まる思考の三層を構成している。

## 教育への応用

### 子どもの思考に三層を見る

| 授業場面 | 三層の実践 |
|---|---|
| 実験・観察 | 科学的層：「何を観た？どうやって確かめる？」 |
| 理由の説明 | 論理的層：「なぜそうなると思う？」 |
| 問いの設計 | メタの層：「その問いはどこから来た？別の問い方はある？」 |

### メタ認知の育て方
- 「自分が今どこで詰まっているか」を言語化させる
- 「違うやり方で考えると？」「この問いはどんな問いだろう？」という問い直し
- [[パタン/メタ注意]] [[概念/メタパターン]] と接続

### 知識を疑う文化
- 「これは本当か？」「他の見方はあるか？」を許容し促す授業文化
- デカルト的懐疑を「批判的思考」の導入として使う
- ただし「すべてを疑う」で止まらず「より良い仮説を立てる」へ進む（アブダクション）

### パタン・ランゲージとのつながり
パタン・ランゲージを使うことは「現象を見る（科学）→ 構造を読む（論理）→ なぜこのパタンが効くのかを問う（メタ）」という三層を動かす実践。

「メタ意識」（→ [[パタン/メタ注意]]）はこの三層のなかで最も深く、かつ最も見えにくい層を動かすことを指している。
