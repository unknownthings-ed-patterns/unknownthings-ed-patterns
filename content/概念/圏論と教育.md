# 圏論と教育

教育現象を圏論（Category Theory）の言語で記述する試み。数学的厳密性を借りることで、教育の構造が明確になる。

このページの構成：Milewski（合成・宣言的設計・関手）→ アナロジー表 → 核心命題（作業仮説）→ 5つのフレーム → 米田の補題 → 環境から出る射 → 2圏の階層 → モナド → 非結合律性 → 関係思考の三重収束

**読み方（3ルート）**：
- **A. パタン実践者向け**：アナロジー表 → Actionable Insight（数式は飛ばしてよい。矢印＝手立て、と読めれば十分）
- **B. 圏論に親しい人向け**：核心命題 → 5つのフレーム → 環境から出る射 → 非結合律性
- **C. Wiki 編集者向け**：5つのフレームの「パタンの圏 𝓟」の行 → 2圏の階層（リンク網の設計思想）

## Milewski（2023）——Category Theory for Programmers との接続

プログラマー向け圏論の名著を入口とすることで、抽象数学と教育実践の接続を具体的な類比から展開する。このページで参照する関手・自然変換・モナドの教育的翻訳は、いずれもこの接続から導かれた。

Milewskiは「合成はプログラミングの本質」と述べ、圏論が宣言的アプローチ（「何を」先に決め「どうやって」は後）を数学的に基礎づけると論じた。この本書はプログラマー向けだが、その哲学は教育設計にそのまま転用できる。

- **「問題を分解し→各部分を解き→再合成する」**: 単元設計・授業設計の本質と同型。人間の作業記憶（7±2チャンク）の限界がこの必然性の認知科学的根拠。
- **宣言的設計**: 「最終状態（学習後の姿）を先に宣言する」= [[パタン/逆向き設計]]。手順（活動）から始める命令的設計との哲学的対比。
- **関手（Functor）**: 構造を保ちながら圏を移動する写像。「算数という圏を日常の問いという圏に変換する」カリキュラムの翻案が関手的思考の教育版。

## 基本的なアナロジー

| 圏論の概念           | 教育への翻訳                   |
| --------------- | ------------------------ |
| 対象（Object）      | 教育状況                     |
| 射（Morphism）     | 教育パタン（状況を変換する働きかけ）       |
| Hom(A, B)       | 教育状況 A を状況 B に変換するパタンの集合 |
| 合成（Composition） | 複数のパタンの連続的適用（[[パタン/合成による問題解決]]） |
| 余極限（Colimit）   | 被教育者の「経験」——歩みの全体（状況とパタンの図式）が貼り合わされていく先の普遍対象 |
| 関手（Functor）     | 構造を保ちながら別の圏（文脈・表現・教科）に翻案する写像 |
| 自然変換（Nat. Trans.）| 関手間の射。複数の教授アプローチを系統的に比較・移行する視点 |
| モナド（Monad）     | 文脈付き学習。授業は T(A) を産出する——T には意図した学習と偶発的な発見・感情・つながりが含まれる |

*この表は実践の圏 𝓔 から見た記述。視点によってパタンの位置づけは変わる（→「パタンの圏論的記述——5つのフレーム」節を参照）。なお本ページでは、𝓔 をまず理想化された分析モデル（厳密な圏）として出発させる。実践のより正直な記述は後半で弱2圏・オペラドへ拡張する——「非結合律性と弱い圏」節がその宣言である。*

## 核心命題（作業仮説として）

岩井（2023）は、パタンを「問題解決に繰り返し求められる**関係**」と定義した。「対象」でなく「関係」と定義するのは、繰り返されるのはモノや人ではなく関係だからである——猫も苺も刻一刻と変わっているが、「踏む」という関係のパタンは繰り返される。Alexanderが後の著作でパタンを「要求（requirement）」「ルール」と呼んだのも同じ認識：いずれも関係レベルの概念である。

この「パタン＝関係」という定義と、圏論の射（morphism）の定義には次の構造的な共鳴がある：

| 岩井のパタン定義 | 圏論の射 |
|---|---|
| 「関係レベルの存在」（対象レベルではない） | 射は対象ではなく対象間の関係。「圏論は対象の内部を見ることを積極的に禁じる」（Milewski） |
| 「繰り返し現れる」（具体的文脈を超えて） | 射は構造を保ちながら異なる対象間で成立する |
| 「問題解決に求められる」（Context→Solution→Consequences） | 射はソース対象 A からターゲット対象 B への変換 f: A→B |

この共鳴を前提として、次の**作業仮説**を置く：

> **仮説A**: 教育パタンは、教育状況 A を教育状況 B へと変換する射（morphism）として記述できる可能性がある。
> **仮説B**: 経験とは、歩みの図式（状況とパタンの列 A → B → C → …）の余極限（colimit）として記述できる可能性がある。

仮説Bの含意：経験へ射を放つのは、歩みのなかの一つひとつの状況（余極限の錐の脚）である。パタン f: A → B はその射たちのあいだに立って三角形を可換にする——A から直接入っても、f を経由して B から入っても、経験への到達は同じ一つの到達に合流する。**「全てのパタンは経験に帰っていく」の正確な内容は、この可換性（合流の保証）である。**

**形式化の注意（潰れ問題）**：有限の一本道 A → B → C の余極限は、どの圏でも最後の対象 C になってしまう——素朴に読むと「経験＝最終状態」に潰れ、**経験は結果ではなく過程のまとまりである**というデューイの核心に反する。仮説Bが本当に要求しているのは、**道のり全体を保持する余極限**——2圏でのラックス余極限（Grothendieck 構成）や、軌跡（履歴）の圏での余極限——である。ここでは教育学の主張（経験＝過程のまとまり）が、どの余極限を選ぶかという数学的選択を強制している：記述言語としての圏論の、最も良い働き方の実例だ。あわせて、「同じ一つの到達に合流する」の「同じ」が状態の同値なのか意味の同値なのかは、まだ定義されていない開かれた問いである。

**教育の定義との接続**：『教育のパタン・ランゲージの図解』（バージョン15）は教育を「**意図的に目的的に設計、構造化された『経験』を再構成し続ける過程**」と定義する。圏論の言葉に置けば：一つの歩みの貼り合わせ（余極限）で得られた経験は、次の歩みの図式の始点の対象になる——貼り合わせは一度で終わらず反復される。**教育とはどれか一つの余極限ではなく、貼り合わせの連鎖（再構成の過程）そのもの**であり、デューイの連続性の原理はこの反復の存在主張として読める。

**留保と開かれた問い**：
- 射は方向性（A→B）を持つが、パタンの方向性は常に明確ではない——「既知から未知へ」は方向性を持つが「選択肢を与える」は？
- **教育実践は本来的に非結合律的である**——括弧のかけ方（活動の区切り）を変えると経験の質が変わる。これは仮説Aへの根本的な問い直しを含む（→「非結合律性と弱い圏」節を参照）
- Alexanderの「要求（requirement）」は射よりも制約的な概念に近い——完全な同一視は慎重であるべきだ

## パタンの圏論的記述——視点によって変わる5つのフレーム

「パタンは何か」への答えは、どのレイヤーからどの問いに答えようとするかによって変わる。これらは矛盾ではなく、相補的な記述だ。

| 記述フレーム | パタンの位置づけ | どんな問いに答えるか |
|---|---|---|
| **射**（実践の圏 𝓔） | 教育状況 A → B を変換する手立て | 授業・単元をどう設計するか |
| **対象**（パタンの圏 𝓟） | 観察・洗練・接続される知のオブジェクト | Wikiのパタン間関係をどう構造化するか |
| **プロファンクター** | 双方向の作用（入ってくる射 × 出ていく射） | 教師と学習者の双方向の関係をどう記述するか |
| **オペラド** | 複数の力（Forces）→ 1つの解決の木構造 | 相反する複数の張力が1つのパタンを呼び出す構造をどう扱うか |
| **環境から出る射**（カリー化） | 教師を含む環境 E から出る働きかけ p: E → [L, L′] | 教師のレパートリー・成長・自己教育をどう記述するか（→「環境から出る射」節） |

これら5つのフレームのあいだの関手（たとえば実践の圏 𝓔 からパタンの圏 𝓟 への「パタン抽出」の関手）を明示的に書くことは、開かれた問いとして残されている。

**レイヤーの二層構造**：

| レイヤー | 対象 | 射 | 合成の意味 |
|---|---|---|---|
| **実践の圏 𝓔**（教室を見る） | 教育状況 A, B | 教育パタン P | パタンの連鎖・単元設計 |
| **パタンの圏 𝓟**（Wikiを見る） | 教育パタン P, Q | メタパタン M（前提・生成・包含関係） | パタン体系の構造化・洗練 |

このwikiのリンクネットワークは、𝓟 上の射の集合として読める。[[メタパタン/経験から出発する]] のようなメタパタンは 𝓟 圏における射の具体例であり、「このパタンを使うにはあのパタンが前提になる」という依存関係も 𝓟 上の射として記述できる。

**アンチパタンの数学的説明**：同じ射（手立て）でも、目的の圏（教育状況）が異なれば逆方向の射になる——有効なパタンがある文脈ではアンチパタンになるのは、射の向きが目的の圏に対して逆向きになっているためだ。

**フレームの使い分けの実例（一般形）**：型練習の系列——よく似た問題を、一度に一つだけ変えながら並べる配列——は、対象＝問題、生成射＝最小の変化（材料の置換・未知数の交換・条件の追加・場面の転換）とする**圏の提示（生成子による表示）**として読める。学習者に「前の問題と何が同じで、何が違うか」を問うことは、**射の同定**を求めることにほかならない。「対象の内部を見ず、射を見よ」という圏論の視点が、「個々の問題の解き方（内部）でなく変化（射）を学ばせる」という比較ベースの学習設計と一致する。

## 米田の補題と教育への応用——二つの顔の同時使用

**米田の補題の哲学**: A を知るとは、A に関わる射を全部見ること。ここで重要なのは、米田には最初から**二つの顔**があることだ：

- **反変版 Hom(−, A)**：A に**向かってくる**射の全体で A を知る——世界から A への働きかけの総体
- **共変版 Hom(A, −)**：A から**出ていく**射の全体で A を知る——A の応答・行為の総体（米田の共変版〔covariant Yoneda〕として合法な読みである）

反変版だけを選ぶと、被教育者は受動的な対象として描かれ、**主体性・選択・自由・人格**が視野から落ちる。しかしそれは補題の欠陥ではなく、**片方の顔だけを選んだ読みの偏り**である。教育の記述には両方の顔を同時に張る：

- **入ってくる射（←）**: カリキュラム・環境・教師の働きかけ
- **出ていく射（→）**: 行為・応答・探究・道をつくる力

→ 教育は双方向（Hom(X,A) と Hom(A,Y) の両方）で初めて成立する。この双方向性はプロファンクター（積圏 C^op × D → Set への関手）としてモデル化できる——「環境の作用（入ってくる射）× 主体の応答（出ていく射）」が積圏の二方向に対応する。被教育者の主体性は圏論の外から持ち込む補正ではなく、圏論が最初から両手に持っていたものの、もう片方の手を開くことで現れる。

## 環境から出る射——カリー化が結ぶ三つの顔

対象を選び直して、**教師を含めた環境 E** をひとつの対象とすれば、パタンは「E から出ていく射」としても書ける。パタンをもっとも情報を落とさず書けば、環境と学習者の状態を入力にとる多入力の操作である：

> p: E ⊗ L → L′　（E＝環境、L＝学習者の状態、L′＝変換後の状態）

何を固定するかで、三つの顔が現れる：

| 読み | 形 | フレーム |
|---|---|---|
| E を固定して L を主語に | p_E: L → L′ | 状況間の射（実践の圏） |
| 入力を全部並べる | (E, L) → L′ | オペラドの操作 |
| E を主語に | p: E → [L, L′] | **環境から出る射** |

三つはテンソル・ホム随伴 Hom(E ⊗ L, L′) ≅ Hom(E, [L, L′])——**カリー化**——で相互に変換できる。同じひとつの操作の、持ち手のちがいである。注意は一点だけ：「E から出る射」の行き先は学習者そのもの（E → L は型エラー）ではなく、**働きかけそのもの [L, L′]**——環境から出ていくのは学習者ではなく働きかけ、という直観どおりの読みが正しい。

この顔からだけ見えるものが三つある：

1. **共変米田の教師への適用**：教師（環境）を知るとは、そこから出る射の全体 Hom(E, −) を見ること——すなわち**その人のパタン・レパートリー**。一人の教師は、その人のパタン・ランゲージによって（同型を除いて）知られる。
2. **パタンの型署名（signature）**：環境そのものを整える射（E → E′：環境調整・場の設定）／環境と学習者がともに働く射（E ⊗ L → L′：問いかけ・指さし）／学習者の内で閉じる射（L → L′：自己内フィードバック・メタ認知）／そして**教師が自分自身に返す射（E → E：熟慮的練習・省察——自己教育）**。自己教育と子どもの教育が入れ子構造をなすのは、E が射の源であると同時に、自分に返る射の対象でもあるからだ。
3. **段階的手放しの一行定義**：働きかけの署名が E ⊗ L → L′ から L → L′ へ移行していく過程。**足場が消えるとは、環境なしで合成できる射だけが残ること。**

なお E からは二種類の矢が出ている：**働きかけの矢**（パタン、E → [L, L′]）と、**参加の矢**（E も歩みの図式の一員として経験へ伸ばす余極限の脚）。教師もまた経験を undergo する——学習者の歩みの余極限が子どもの経験、E の自己射の列の余極限が教師の経験、両方を含む図式の余極限が**共同の経験**である。

## 2圏の階層構造——教育における3つの抽象レベル

Milewski（Ch.10）は圏論の3層の階層を示す：

- **対象（Objects）** = 小さな圏
- **1-射（Functors）** = 圏間の変換
- **2-射（Natural Transformations）** = 関手間の変換

この階層は教育にも対応する：

| 抽象レベル | 圏論 | 教育版 |
|---|---|---|
| 対象 | 対象（状況） | 教育状況・子どもの学習状態 |
| 1-射 | 射（パタン） / 関手 | 教育パタンの適用 / カリキュラムの翻案 |
| 2-射 | 自然変換 | 複数のパタン適用を比較する省察。「今のやり方を別のやり方に切り替える」系統的な改善 |

「一段高い抽象レベルで行為だったものが、次のレベルでは対象になる」（Milewski）——個々のパタン適用（行為）は、省察レベルでは比較・改善の対象（名詞）になる。これが[[パタン/省察的評価]]の圏論的記述。

なお、この対応表は 2圏として何を選ぶか（ここでは Cat 型の直観）に依存する——比喩の整合性は保たれるが、厳密な対応は圏の選び方で変わる。

**2-cell の二つの読み（規約）**：2-cell には二つの正当な読みがある。**構造としての 2-cell＝メタパタン**（Wiki に書かれ、パタン同士を結ぶもの）と、**過程としての 2-cell＝省察**（教師の中で起きる比較・改善）。両者は矛盾ではなく、省察が言語化され反復されるとメタパタンになる——Wiki の生成過程（実践の還流→パタン化）そのものが、過程としての 2-cell が構造としての 2-cell に結晶するプロセスである。

## モナド（Monad）と学習の文脈性

授業は純粋な変換 `f: 学習状態A → 学習状態B` ではない。実際の教室では、どの授業も意図した学習だけでなく「偶発的な発見・感情の動き・仲間との関係で生まれた気づき・意図しなかったつながり」を産出する。パタンの**力のかたち（Forces）**が記述する相反する張力——子どもの気分・予期せぬトラブル・個々の背景——はすべてこの T に入る「副作用（side effect）」だ。

パタン・ランゲージはその副作用を内包しながら実践者が扱える射へと昇華させるカプセル化の体系として機能する。圏論でこの構造を形式化するのが**モナド**（Milewski, 2023, Ch.20）である。

モナド T は関手に2つの自然変換を加えた構造：

- **unit（η: A → T(A)）**: 純粋な意図 A を文脈 T に埋め込む
- **bind（>>=）**: 文脈付きの値 T(A) を受け取り、次の文脈付き計算 T(B) に渡す
- **join（μ: T∘T → T）**: ネストした文脈 T(T(A)) を T(A) に平坦化する

**教育への翻訳**：

| モナドの操作 | 教育での対応 |
|---|---|
| return/unit（η） | 指導案（純粋な意図）を実際の教室という文脈に埋め込む |
| bind（>>=） | ある授業の「文脈付き結果 T(result)」を次の授業に引き渡す——隠れたカリキュラム・偶発的発見を潰さず持ち越す |
| join（μ） | 振り返り・ポートフォリオ整理で、積み重なった T(T(…)) を「学習の軌跡 T(成長)」として統合する |

**モナド則の教育的意味と留保**：左単位律・右単位律・結合律は「文脈付き計算が一貫して連鎖できる」ことを保証する。授業のたびに振り返り（bind の連鎖）を行っても、学期末にまとめて行っても、同じ学習の軌跡に到達できるという一貫性——これが[[パタン/省察的評価]]のポートフォリオとカンファリングを支える数学的根拠の**候補**である。

ただし結合律が教育実践で成立するかは問いとして留保が必要だ（詳細は「非結合律性と弱い圏」節を参照）。

## 非結合律性と弱い圏——教育実践の構造をより正直に記述する

核心命題の留保で触れた結合律の問いへの答えは明確だ：**教育実践は本来的に非結合律的である。**

なぜか。圏論の結合律 (h∘g)∘f = h∘(g∘f) は「括弧のかけ方（活動の区切り方）を変えても最終結果は同じ」を意味する——しかし教育実践はそうならない。「導入→展開→まとめ」の3活動を、前半でひとまとめにしてからリフレクションして後半へ進む実践と、展開・まとめを一気に駆け抜ける実践とでは、学習者が受け取る「経験の質と意味」が全く異なる。実践は時間軸と文脈に埋め込まれた不可逆な意味生成であり、素朴な意味での結合律は破綻している。

ミニ例：割り算の1時間。「導入と活動」をひとまとめにして最後に振り返った日は、振り返りが「今日ぜんぶ」を対象にして、要点が子どもの言葉になった。同じ3つの活動を「導入→（活動と振り返りの繰り返し）」で刻んだ日は、途中の誤りがその場で拾われて活動そのものの質が変わった。**同じ活動、同じ順序——括り方だけが違い、生まれた経験は別物である。**

しかしこれは教育が圏として記述できないことを意味しない——**非結合律性そのものを構造として扱う**アプローチがある。

### アプローチA：弱2圏（Bicategory）とアソシエータ

(h∘g)∘f と h∘(g∘f) は等しくないが、この二つの間に**アソシエータ（同型射）α** が存在する：

> α: (h∘g)∘f ≅ h∘(g∘f)

これを**弱2圏（Bicategory）**と呼ぶ。等号（=）の代わりに同型射（≅）を使うことで、結合の「ズレ」を消去せずに構造として保持する。

教育での意味：異なる区切り方・順序で実施した実践のズレを、教師の省察が架け橋する——これがアソシエータである。「あの授業を先にやっていたら別の到達になっていたが、振り返りによってその差を意識化し、同じ単元の目的地に辿り着いた」という経験は、α: (h∘g)∘f ≅ h∘(g∘f) の教育版だ。**[[パタン/省察的評価]] はアソシエータの実践形態である。**

### アプローチB：オペラド（Operad）とパタンの多入力構造

オペラドは「複数の入力→1つの出力」の操作と、その**接ぎ木**（ある操作の出力を別の操作の入力スロットに差し込む合成）を扱う。厳密には、オペラドは接ぎ木の結合律を公理として**持つ**——結合律を本当に落とすのはマグマの側だ。オペラドの本当の貢献は結合律の放棄ではなく、**括り方を木として対象化する**ことにある：「(導入;活動);振り返り」と「導入;(活動;振り返り)」は、同じ合成の二つの括弧ではなく、**異なる二本の木**として区別されたまま残る。設計とは、どの木を選ぶかである。

教育での意味：パタンの**力のかたち（Forces）**は複数の張力（複数入力）をSolution（1出力）に収束させる——「既知から未知へ」「安心できる環境」「子どもの興味」という複数の力がひとつのパタンを呼び出す。これはまさにオペラドの操作の構造だ。さらに、Alexanderの「各パタンは、より大きなパタンの中に座り、より小さなパタンを含む」「上位パタンの解決が下位パタンの文脈を生む」という入れ子は、操作の出力を別の操作の入力スロットに接ぎ木するというオペラド合成の定義そのものである。すなわち——

> **パタン＝多圏（multicategory／colored operad）の操作（operation）、パタン・ランゲージ＝オペラド（操作の接ぎ木の文法）。**

核心命題の仮説Aは、ここで**仮説A′**「パタンは多圏の操作であり、ランゲージがオペラドである」へと更新される——単体のパタンと体系（ランゲージ）の関係まで一撃で記述できるのは、このフレームだけである。

### 小括

| 構造 | 結合律 | 教育への対応 |
|---|---|---|
| 圏（Category） | 厳密に成立 | 理想化された分析モデル（出発点） |
| 弱2圏（Bicategory） | 同型射（α）として緩く成立 | 省察がアソシエータとして架け橋 |
| オペラド（Operad） | 括り方を木として対象化（どの木を選ぶかが設計になる） | パタンの多入力構造（Forces→Solution）とランゲージの入れ子（接ぎ木） |

**教育実践が非結合律的であるという事実は、教育が線形な決定論ではないことの証明だ。** 同時に、だからといって完全なカオスでもない——射が集まってくる「普遍対象（経験）」は存在する。非結合律性と普遍性の緊張のなかで、教師の省察（アソシエータ）が構造を保ち続ける。これが教育実践のダイナミズムであり、弱い圏論的構造がその記述言語となる。

## 関係思考の三重収束——圏論・モンテスキュー・パタン・ランゲージ

斎藤正二はモンテスキュー読解を通じて、近代教育学に「思考法の革命」——ニュートン古典力学的思考からアインシュタイン相対性理論的思考への飛躍——が必要だと論じた（斎藤正二著作集7, 2004, pp.15-16）。この「革命」の内実は、**実体（命題・thesis）を絶対視する思考から、関係を基本単位とする思考への転換**である。

三者はこの転換の同一の表現である：

| | 基本単位 | 「実体」思考への批判 |
|---|---|---|
| **モンテスキューの rapport** | 法＝「事物の本性から生じる必然的な**関係**（rapports nécessaires）」 | 「法とは普遍的命題である」という絶対主義（absolutisme）への批判 |
| **圏論の射（morphism）** | 対象（object）ではなく**射（関係・変換）**が数学の基本単位 | 「対象そのものを知る」ことより「対象に向かう射の全体を知る」こと（米田の補題） |
| **パタン・ランゲージのパタン** | 「この文脈においてこの関係が成立する」という**文脈関係的な記述** | 「このパタンはつねに正しい」という命題的適用への批判 |

**教育のパタン・ランゲージという営みそのものが、斎藤の求めた思考法の革命の実践形態である。**

パタンを「命題（thesis）」として絶対視するのではなく、「文脈との関係において成立するかたち」として記述し使う——この関係的・相対的な知の様式は、圏論が数学的に定式化し、モンテスキューが社会哲学として先駆けた認識論と同型である。

## 圏論的記述は Dewey に何を足すか——後追い・鋭利化・総合

このページの経験・余極限・非結合律・完結（consummation）の議論は、多くがジョン・デューイに由来する。**経験は結果でなく過程のまとまりである／一つの経験（an experience）は固有の質で統一される／完結は単なる停止ではない／連続性の原理**——これらは Dewey の言葉だ。だから圏論的記述の一部は、率直に言って **Dewey の形式化（後追い）** である。それを隠す必要はない。ただしこの Wiki の方針（系譜は統合せず、差分を明示する）に立てば、圏論が Dewey に**何を足しているか**は切り分けて言える。足しているのは三つ、いずれも新しい経験哲学ではなく、**形式化がもたらす副産物**である。

### (a) 後追い——Dewey をそのまま形式化した層

consummation ≠ cessation、doing–undergoing、経験＝過程のまとまり、連続性の原理。これらは圏論語（余極限・余錐・ラックス構造）への翻訳であって、Dewey に無いものは足していない。この層では「圏論は Dewey の後追い」で正しい。隠さずそう言う方が、次の (b)(c) の差がはっきりする。

### (b) 鋭利化——散文の区別を「判定できる形」にした層

Dewey が修辞で述べた区別を、圏論は**チェックできる構造**にする。ここに小さな、しかし現場に効く差がある。

- **完結は終点でなく道の性質**：同じ「答えにたどり着いた」でも、外から与えられた到達と、内から満ちた到達は別の経験だ（→[[メタパタン/極限概念と極限クライテリア]]「一つの経験になる条件」）。これを現場の一問に落とすと——**「この終わり方は、外から貼りつけたまとめか、それとも先行する歩みが満ちた結果か」**。Dewey はこの区別を語るが、圏論はそれを「終点そのものでなく、そこへ至る道の性質」という形にして、**問える**ようにする。
- **「活動リストでは経験を書けない」の二つの理由**：道筋の違いで経験が変わること（同じ活動・別の括り方）と、意図の違いで変わること（外から同じに見える別の働きかけ）は、Dewey では一続きだが、圏論では**独立した二つ**に分かれる。
- **余白の非自明性**：何もしない時間は、内容の上では「恒等（何も変えない）」だが経験の上では非自明——だから内容から経験への対応は関手ではない（→下の Actionable Insight「余白を恒等射として…」）。

「判定できる区別が一つ増えること」そのものに価値がある。**外から貼ったまとめか、満ちた結果か**を問えるようになるのは、教師の鑑識眼を一つ具体化することだ。

### (c) 総合——Dewey が決してやらなかった系譜の接続

一番「後追いでない」のはここだ。圏論は Dewey を、**別の思想系譜と一つの言語で結ぶ**。

- **経験（Dewey）と統制的理念（新カント派・左右田喜一郎・牧口常三郎）の接続**：「教育は完結しない」を、経験の再構成の連鎖が指し示す**非表現可能な極限**として書く（→[[メタパタン/極限概念と極限クライテリア]]）。Dewey の経験論と左右田の極限概念は本来べつの系譜だが、圏論はそれを一つの図式に載せる。
- **パタン・ランゲージ（Alexander）と経験（Dewey）の接続**：パタン＝多入力の操作（オペラド）、Context＝適用の定義域、アンチパタン＝定義域違反、そして「すべてのパタンは経験に帰っていく」＝経験への余錐。Alexander と Dewey が同じ機構の中で出会う。
- **経験（Dewey）とカントの総合説の接続**：完結の検査質問「外から貼りつけたまとめか、満ちた結果か」は、カント『純粋理性批判』の一句——**「内容なき思惟は空虚であり、概念なき直観は盲目である」**——にそのまま重なる。**外から貼りつけたまとめ＝内容（生きた歩み）なき概念＝空虚**、**統一する意味のない活動の列＝概念なき直観＝盲目**、そして**完結＝その総合**（閉じる意味が歩みの内から満たされ、歩みが一つの質で貫かれる）。ただしデューイはカントの二元論を治す：統一する質は悟性という別の能力から**課される**のではなく、経験の**内から育つ**——だから「外から貼りつけた」とは、概念を外から課した失敗（＝空虚）にほかならない。なおこれは、上記の統制的理念（＝理念の統制的使用という**別のカントの糸**）とは異なる、直観と概念の総合というカントである。

### まとめ——圏論は Dewey を訂正しない

圏論的記述は Dewey を**訂正**していない。やっているのは形式化（後追い）と、系譜の接続（総合）である。「進展」の中身は、(i) 判定できる現場の問いを生むこと、(ii) 別々の思想系譜を一つの言語で束ねること、(iii) Dewey が融かしていた区別を分けること——の三つで、**新しい経験哲学ではない**。だが後追いであっても、そこから「外から貼ったまとめか、満ちた結果か」のような**問える区別**が出てくるなら、形式化はその働きぶんだけ確かに価値がある。危ういのは、形式化を「進展」そのものと取り違えることの方だ。

## Actionable Insight

- **今週の授業を射の連鎖として紙に描く**: 各活動を A→B→C の矢印でつないでみる。矢印が途切れる場所（接続部が薄い場所）が設計上の「穴」。途切れたら「B の出口と C の入口は噛み合っているか」を問い直す
- **今日の「持ち越し」を1行書き、次の授業の冒頭で開く**: 意図した学習の外で生まれた気づき・つまずき・つながりを1行だけ記録し、次の授業の入口で読み返す——文脈付き結果を次に渡す bind の最小実践
- **5つのフレームで単元を見直す**: 今設計している単元は「実践の圏（射として）」で見ているか、「パタンの圏（対象として洗練する）」で見ているか、「環境から出る射（自分のレパートリーとして）」で見ているか。どれで考えているかを意識するだけで問いの質が変わる
- **余白を恒等射として意図的に配置する**: 「何もしない時間・沈黙・再訪」を活動の並びに一つ意図的に組み込み、それが合成の中でどう機能したかを授業後に振り返る（技術的な注記：恒等射は定義上なにも変えないが、余白は経験を変える——内容の圏で恒等に見える射が経験の圏では非自明なら、内容から経験への対応は関手ではない〔関手は恒等射を保存する〕。活動リストをどれだけ精密に写しても経験は記述できないことの、小さな証明である）
- **授業計画を宣言的に書き直す**: 「何をさせるか（活動リスト）」ではなく「授業後に子どもがどんな状態にあるか（C の宣言）」を先に書いてから活動を逆算する
- **「このパタンを使うと何が変わるか」を射として問う**: 次に使おうとしているパタンについて、「入口（A）はどんな教育状況か」「出口（B）はどんな状態か」を明示してみる
- **授業の「終わり方」を道の性質として問う**: ひとまとまりの学びが終わるとき、「外から貼りつけたまとめで終わったか、それとも先行する歩みが満ちて終わったか」を問う。前者は停止、後者が完結（consummation）——完結は終点そのものでなく、そこへ至る道全体の質である（→[[メタパタン/極限概念と極限クライテリア]]）
