# 胚細胞から具体へ上向する学びを、学校の外の三つの研究から描く（Engeström2020）

## 要約

- **何を論じたか**：ダヴィドフが学校の教授に持ち込んだ「抽象から具体へ上向する」原理を、エンゲストロームの拡張的学習の理論がどう学校の外へ広げたか（pp. 31–33）。理論の論文で、三つの研究を例として描いています。
- **似た考え方との比較**（pp. 32–33, 36）：
  - ワーゲンシャインの「範例学習」は、少数の題材に深く根を下ろせば、その一つが全体を照らす、という考え方です。
  - マイヤーとランドの「閾値概念」は、通ると見え方が一変する「入り口」の概念です。
  - どちらも、生み出す力のある核となる考えを重んじます。しかし、何を核に選ぶかの基準がなく、学ぶ過程の手順もはっきりしません。核が内に矛盾をはらむことにも、実際に行う行為であることにも、目を向けていない、と著者は書きます。
- **イリエンコフとダヴィドフの概念観**（pp. 33–35）：
  - 多くの物に共通する特徴を抜き出してまとめたものは「一般的な表象」であって、概念ではない。
  - 概念をつくるには、その現象の起源をとらえた抽象（胚細胞）をつくり、そこから具体へ上向する必要がある。例は、マルクスの資本主義の分析での「商品」です。
  - 概念は固定した定義ではなく、運動のなかで表される。「どの概念も、物に対するある行為（またはその体系）を隠している」（ダヴィドフ）。
  - 学校は、分類による経験的な概念ばかりを育てがちで、理論的な概念を育てていない、とダヴィドフは批判した。
- **胚細胞の5つの性質**（p. 36）：
  1. 複雑な全体の、もっとも小さく単純な最初の単位である。
  2. 全体の根本の矛盾と、それを乗り越える種を、自らのうちにもつ。
  3. ありふれていて、当たり前すぎて気づかれないことが多い。
  4. 多くの応用・拡張・発展への見通しを開く。
  5. 行為として実際に行われる。言葉にされ、モデルにされる前から、実践のなかにあることが多い。
  - 胚細胞そのものは概念ではなく、概念の出発点であり核である、とも書きます。
- **ダヴィドフの6つの学習行為**（pp. 36–37）：
  1. 課題の条件を変えて、対象の普遍的な関係を明らかにする。
  2. その関係を、物・図・文字でモデルにする。
  3. モデルを変えて、その性質を純粋な形で調べる。
  4. 一般的なやり方で解ける、個別の課題の体系をつくる。
  5. 進め方を点検する。
  6. 一般的なやり方が身についたかを評価する。
- **拡張的学習の7つの行為**（p. 37）：問い直す → 分析する → モデルにする → モデルを調べる → 実際に使う → ふり返る・評価する → 新しい実践として定着させる。
  - ダヴィドフの6つと違い、最初に「いまのやり方を問い直す」行為があります。学びは、うまくいかない兆しと、動機の葛藤から始まる、とします。
- **三つの研究と三つの胚細胞**（pp. 38–42）：
  - **何年もかかる大きな学び**：ヘルシンキの食の協同組合。理事会の27回の会合を記録しました。「会員をもっと増やして収入を増やす」と、「健康な食べ物を得る」というもとの考えが矛盾していました。胚細胞は「会員を200人までに限る」という行為で、そこから作業や栽培の組み直しへと広がりました。
  - **数か月の介入による学び**：ホームレスだった若者の支援住宅（チェンジ・ラボラトリー）。職員と住民を隔てていた窓口の壁をなくし、「対等に、同じ空間で出会う」ことが胚細胞になりました。
  - **一回の場面のなかの学び**：高齢者の訪問介護（17人の利用者の30回の訪問を3年間録画）。安全と自立の矛盾をはらむ胚細胞は、「椅子から立ち上がる」という単純な行為でした。言葉やモデルは、体で行ったあとから来た、とします。
- **結論**（p. 42）：学校は社会の矛盾から切り離されたままではいられない。ダヴィドフの教授学は、社会の変革の一部としての学校の変革と結びつける必要がある。

## 重要な引用

## 根拠の範囲と注意

- **理論と事例の論文**：胚細胞の5つの性質や学習行為の順序は、理論として示されたものです。学校で胚細胞から教えると学力が伸びるかは、この論文では確かめていません。
- **事例は学校の外の大人**：三つの研究は、協同組合・支援住宅・訪問介護で、子どもの学級ではありません。
- **胚細胞を選ぶ基準**：著者は、範例学習や閾値概念には選ぶ基準がないと批判します。胚細胞の5つの性質は、その基準の候補になります。ただし、5つの性質で選んだ胚細胞がよく効くかは、確かめられていません。

## 教育実践への示唆（Wiki側の適用案）

- **胚細胞の候補を5つの性質で点検する**：単元の核にしようとする概念を、次の5つで見直します。
  - もっとも小さな単位か。
  - 内に矛盾や緊張をはらむか。
  - ありふれていて見過ごされていないか。
  - 多くの場面に広がるか。
  - 子どもが行為として実際にやってみられるか。
- **言葉より先に行為で出会う**：胚細胞は、言葉にされる前に行為のなかにあることが多い、とされます。定義を渡す前に、まず胚細胞にあたる行為をしてみる場面をつくります。
- **問い直しから始める**：うまくいかない場面や、「どうして？」と感じる食い違いから単元に入り、胚細胞を探す流れにします。
