# 形の成長を見る

> この形はどのように成長していますか？

## この教材について

Ruth Parker が開発し、Boaler（2015）が "Growing Shapes" として紹介する視覚的パタン課題。「1段目・2段目・3段目…」と成長する図形を見て、「どのように見えるか」を問うだけで、算数と代数をつなぐ深い思考が生まれる。[[パタン/視覚的数学]] と [[パタン/豊かな課題]] の両方を体現する教材。

---

## 課題

以下の図形（階段形）をイメージしてください。

```
■          1段目：1個のブロック

■
■■         2段目：3個のブロック

■
■■
■■■        3段目：6個のブロック
```

### 問い1：「どのように見えますか？」

この形の成長を、自分の言葉で説明してください。図や矢印を使ってもよいです。

- どこに注目しましたか？
- 別の見え方はありますか？

### 問い2：「次はどうなりますか？」

- 4段目は何個のブロックでできていますか？
- 5段目は？

### 問い3：「ずっと先を考えましょう」

- 10段目は何個のブロックでできていますか？
- n 段目は？（式で表してみましょう）

---

## 見え方の例（Boaler, 2015）

同じ「6個のブロックで作られた3段目」を、子どもたちは様々に見る：

**見え方 A：列の足し算として**
> 1 + 2 + 3 = 6（各段の列の数を足す）
> → n 段目は 1 + 2 + … + n = n(n+1)/2

**見え方 B：正方形として**
> 3段目は「3×3の正方形の半分＋半分の列」に見える
> → (n+1)² を折り返した形

**見え方 C：長方形に変形**
> 2つ重ねて長方形にすると n×(n+1) になる
> → n段目は n(n+1)/2

どれも正しい。「見え方」が違うだけで、同じ答えに到達する。

## 発展問題

1. **逆方向**：この形を「反対方向」に成長させたら？（ネガティブスペース → [[教材/ネガティブスペース]]）
2. **3D版**：3方向に成長する形を考えてください
3. **別の形**：自分で「成長する形」を作り、規則を見つけてください
4. **生活の中で**：この形に似た「成長するもの」は、生活の中にありますか？

## 授業での使い方

### 基本の流れ（30〜45分）

1. **図を提示するだけ**（「どのように見えますか？」と問う。答えを急がない）
2. **個人でじっくり見る**（2〜3分。ノートに自分の「見え方」をメモ）
3. **ペアで共有**（「あなたの見え方を教えて」——違いを見つける）
4. **全体共有**（黒板に複数の見え方を図示。「みんな見え方が違う！」）
5. **問い2・3へ進む**（自分の見え方で n 段目を求める）

### 特別支援学級での調整

- 実際にブロック・碁石・タイルを使って形を作る
- 「4段目を作ってみてください」から始める（動かして考える）
- 「次は何個になると思う？」——予測→確認のサイクルを繰り返す
- 問い3（n 段目）はスキップしてよい。「どのように成長するか」を言葉で言えれば十分

### 短時間バージョン（5〜10分、温まり活動として）

1. 図を見せて「1段目、2段目、3段目は何個ですか？数えてみて」
2. 「4段目は？数えなくてもわかりますか？」
3. 何人かの「考え方」を聞いて板書する

## この課題で育つ力

- 視覚的・空間的思考
- パタンを見つけて言葉・式で表す力（代数的思考の入口）
- 「一つの答えに到達する複数の道」を体験する
- 「数学は暗記でなく考えること」という数学観
