# BDA読解授業の設計

Buehl（2017）*Classroom Strategies for Interactive Learning* に基づく、**Before-During-After（読む前・読む間・読んだ後）3段階で読解授業を設計する実践ガイド**。単発のストラテジー指導から「設計として使いこなす」段階へ。

## 設計の前提：どのテキストにも3段階がある

どんな読解授業も——国語の説明文、理科の教科書、社会の資料——3段階で設計できる：

| フェーズ | 目的 | 授業の位置 |
|---|---|---|
| **Before（読む前）** | 知識・語彙・目的の準備 | 最初の5〜15分 |
| **During（読む間）** | 理解のモニタリング・深化 | 読む時間全体 |
| **After（読んだ後）** | 統合・要約・転移・書く | 最後の5〜15分 |

**Beforeに投資するほど Duringが豊かになる。Afterを省略すると理解は定着しない。**

---

## 方略メニュー

### Before（読む前）の方略メニュー

| 方略 | 所要時間 | どんなときに選ぶか |
|---|---|---|
| **アンティシペーション・ガイド** | 5〜10分 | 先入観・誤概念のあるテキスト。認知的葛藤を作りたいとき |
| **テキスト・フレームの提示** | 1〜2分 | 説明文の構造を先に示すだけで読みの目的ができる |
| **チャプター・ツアー** | 3〜5分 | 見出し・図版・キャプションを巡回して概略把握 |
| **KWL（K+W 記入）** | 5分 | 探究的な読みをしたいとき。知りたいことから読む目的を生む |
| **語彙プレビュー** | 5〜10分 | 専門語が多いテキスト。重要語に先に出会わせる |
| **マインド・マッピング（事前）** | 5分 | 既有知識を出し合ってから読む。背景知識に大きな差があるクラス |

### During（読む間）の方略メニュー

| 方略 | 所要時間 | どんなときに選ぶか |
|---|---|---|
| **テキスト・コーディング** | 読書全体 | 長い・難しいテキスト。理解のモニタリングを育てたいとき |
| **ダブルエントリー・ダイアリー** | 読書全体 | 意見・疑問・つながりを残したいとき |
| **ペア読み・ターン＆トーク** | 随時2〜3分 | 複雑な段落を処理したいとき。対話で理解を深める |
| **問いを持ちながら読む** | 読書全体 | 「自分の問いを確かめるために読む」習慣を育てたいとき |
| **シンクアラウド** | 10〜15分 | 教師がモデリングする。新しいストラテジーを初めて教えるとき |

### After（読んだ後）の方略メニュー

| 方略 | 所要時間 | どんなときに選ぶか |
|---|---|---|
| **クイックライト** | 5分 | 毎回使える。「今日学んだことを自由に書く」習慣に |
| **マグネット・サマリー** | 10分 | 要約力を育てたいとき。キーワード→一文要約 |
| **アンティシペーション・ガイドの見直し** | 5分 | Before でガイドを使ったとき。「考えが変わったか」を問う |
| **KWL の L 記入** | 5分 | Before で K+W を書いたとき。「学んだこと＋新しい問い」 |
| **ディスカッション・ウェブ** | 15分 | 賛否・複数の見方を議論したいとき |
| **スケッチ・トゥ・ストレッチ** | 10分 | 抽象的な概念を視覚化したいとき |
| **RAFT ライティング** | 20〜30分 | 視点・立場を変えて書く。深い転移を求めるとき |

## 授業例①：国語「説明文」（4年生・問題と解決の構造）

**テキスト**：「○○について」という社会問題の説明文
**テキスト・フレーム**：問題と解決

**Before（10分）**：
- アンティシペーション・ガイド（4文）を個人記入 → ペアで話し合い（3分）
- 「このテキストは問題と解決の構造で書かれています。どんな問題が書かれているか、どんな解決策が提案されているか、読んで確かめましょう」

**During（20分）**：
- 問題と解決の構造マップを配布
- テキストを読みながら「問題」「原因」「解決策」のボックスに書き込む
- 詰まったらペアで相談可

**After（10分）**：
- アンティシペーション・ガイドに戻る：「考えが変わったところはどこ？」（2分個人）
- 全体シェア：「変わった人は？理由は？」（5分）
- クイックライト：「今日学んだことで、一番驚いたことを書く」（3分）

## 授業例②：理科「水のすがた」（4年生・概念と定義の構造）

**テキスト**：水の3つの状態変化についての教科書ページ
**テキスト・フレーム**：概念と定義

**Before（8分）**：
- アンティシペーション・ガイド（3文・水の誤概念に関する記述）個人記入（2分）
- チャプター・ツアー：見出し・図・グラフを教師と一緒に確認（3分）
- 重要語彙プレビュー：「蒸発」「凝結」「状態変化」に触れる（3分）

**During（15分）**：
- テキスト・コーディング（✓知ってた / ？わからない / ！驚き）しながら読む
- 概念と定義の構造マップ（概念名・特徴・例・非例）に書き込む

**After（7分）**：
- ガイドに戻る：「正しかったのはどれ？間違っていたのはどれ？」（2分）
- スケッチ・トゥ・ストレッチ：水の状態変化を絵で表す（5分）

## 授業例③：社会「江戸時代の産業」（5年生・原因と結果の構造）

**テキスト**：農業・商業の発展と社会の変化についての説明文
**テキスト・フレーム**：原因と結果

**Before（7分）**：
- マインド・マッピング：「江戸時代について知っていること」を2分でウェブに書く
- 「このテキストは原因と結果の構造です。何が変化したか・なぜ変化したかを探しながら読みましょう」
- 原因→結果の構造マップを配布

**During（20分）**：
- 読みながら構造マップに書き込む
- 難しいページでペア読み・ターン＆トーク（2回程度）

**After（8分）**：
- KWL の L 欄：「今日学んだことと、また生まれた問い」（3分）
- 「江戸時代の産業の変化を一文でまとめると？」→ クラス全体でマグネット・サマリー（5分）

## 複数時間のBDA設計（単元レベル）

1時間の授業だけでなく、単元全体を BDA で設計できる：

| 時間 | フェーズ | 内容 |
|---|---|---|
| 第1時 | **Before（単元）** | 単元全体のアンティシペーション・ガイド + KWL（K+W）|
| 第2〜4時 | **During（単元）** | 各テキストを読みながらテキスト・フレームで整理 |
| 第5〜6時 | **After（単元）** | 複数テキストの統合・RAFT ライティング・KWL の L |

---

## BDA 設計のチェックリスト

授業前に確認する：

```
□ Before を計画しているか？（読む前に何を整えるか）
□ テキスト・フレームを特定したか？（どの構造かを先に言うか？）
□ During に何かあるか？（読みながらすることが決まっているか？）
□ After を計画しているか？（読んだ後に何をするか決まっているか？）
□ Before で使う方略はミニレッスンで教えたか？（教えていないことは使わない）
□ 所要時間は現実的か？（詰め込みすぎない）
```
