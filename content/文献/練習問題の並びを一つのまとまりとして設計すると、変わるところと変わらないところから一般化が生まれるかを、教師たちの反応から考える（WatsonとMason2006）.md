# 練習問題の並びを一つのまとまりとして設計すると、変わるところと変わらないところから一般化が生まれるかを、教師たちの反応から考える（WatsonとMason2006）

## 要約

- **問い**（要旨・序論）：練習問題（同じ種類の問いの集まり）を、ばらばらの問いではなく、数学的にも教育的にも構造をもった「一つのまとまり（一つの対象）」として見ると何が見えるか。Marton の変化の理論の「変わりうる次元」と「許される変化の範囲」の二つの考え方で、練習問題が学び手に何を見せ、何を見せないかを分析する理論の論文である。
- **前提**（序論）：学びの出発点は、データの中の変化に気づくことである。ただし、型を見つけるだけでは学んだことにならない。学び手は、なぜその手順で答えが出るかではなく、表面の形をたどり、数を変えて同じ手順をくり返すだけのこともある。
- **タクシー幾何の練習問題**（練習問題への反応の分析）：
  - 点 A を固定し、方眼の上で、縦と横にしか動けないときの A からの距離を、8つの点について求めて方眼に打つ問題（Krause 1986 の教科書）。
  - 3年にわたり、約200人（現職・養成中の小中学校の教師と、年齢のちがう二つの学級の児童生徒）に解いてもらい、話し合いと書いた感想から反応を集めた。
  - 最初のいくつかで「距離はいつも3」「点は一直線に並ぶ」と、気づかないうちに予想を立てる。7つめの点 (0, 0) で一直線がくずれ、多くの人が驚きの声をあげ、「A から距離3の点はどこにあるのか」と考え始めた。最後に多くの人が「タクシー幾何の円」にたどりついた。
  - だんだん速く解けるようになり、型があるので自分で誤りに気づいて直せた。流暢さ・意欲・正確さも生まれた、と参加者は話した。
- **変化の分析**（与えられた練習問題の変化の分析）：
  - 点 A を固定したので、学び手は A との関係だけを比べればよい。変わるものが多すぎると、一つひとつの変化が見えなくなる。「すべてが変わると、何も見分けられないかもしれない」。
  - 最初の3点で距離3を固定し、整数の座標から5つめで分数の座標へ広げる。7つめの (0, 0) は、なじみのある点なのに一直線から外れるので、それまでの一般化が不完全だと気づくきっかけになる。
  - 著者らは、Runesson と Mok の「その面が変化の次元として現れていれば見分けられやすい」を、「ほかの特徴が比較的変わらない中で、その変化が前に出ているときに見分けられやすい」と修正する。
- **傾きの三つの練習問題**（練習問題を数学的な対象として見る）：同じ「2点の傾きを求める」問題でも、①符号の組み合わせがばらばらに変わる並び、②具体から文字の一般式へ進む並び、③1点を固定し、もう1点の x 座標だけを変える並び（途中で x＝4 になると 0 で割ることになり、手順が通じない）で、学び手が一般化できることがちがう。「何が変わり、何が変わらないか」と問うことで、練習問題が学び手に何を差し出しているかを正確に言える。
- **練習（practice）について**（変化を実践に入れる）：多くの教科書の練習問題は、問いが気まぐれにちがうので、止まっては考え直すことになり、速くも正確にもならない。たとえば比を簡単にする問題の集まりは、比の概念に関わらなくても解けてしまう。17−9、27−9、37−9… のように並べると、くり返しの練習を越えて「9の性質」が見えてくる。
- **教師たちの試み**（今後の問い）：研修を受けた教師たちが、変化の次元を意識して問題の集まりをつくった（体系的な研究ではない、と断る）。分数を約分する問題（6/10、18/20、6/8 …）のあとに「答えを比べよう」と問う並びや、「7」を使った分数のかけ算の並び（1/7×7/2、1/7×7/3 … 3/7×14/15 …）があった。後者で生徒がいちばんおもしろいと書いたのは、「7」の役割が急に変わる問題だった。それまで「消すための印」だった7を考え直す必要が生まれた。
- **結論**（今後の問い）：変わりうる次元と変化の範囲を制御することは、ありふれた問題を解く中でも、学び手を数学の構造・一般化・概念化に向かわせる強い設計の手立てである、とする。ただし、学びへの効果を知るには、さらに実験と長い取り組みが要る、と書く。授業の計画の手順として、①学び手に出会ってほしい概念を分析する ②その概念の例にある規則性を見つける ③その規則性を示す変化を決める（どの次元をどう変えるか）④制御された変化で、予想・比較・驚き・確かめが起きる練習問題をつくる ⑤変化への反応の見込みにもとづいて、そうした機会を並べる、の五つを挙げる。

## 根拠の範囲と注意

- **理論の論文**：学びへの効果を比べて測ったものではない。著者ら自身が、効果を知るにはさらに実験が要ると書く。
- **反応の記録の多くは大人（教師）から**：タクシー幾何の課題に取り組んだ約200人の多くは、現職・養成中の教師だった。
- **教師たちの試みは体系的な研究ではない**：著者ら自身がそう断っている。
- **型を見つけるだけでは学びにならない**：著者ら自身が、表面の手順をたどるだけになることがあると注意する。話し合いの役割も大きかった、とする。

## 教育実践への示唆（Wiki側の適用案）

- **一つを固定し、変える次元を絞る**：比べる相手（基準の点・基準の分数）を固定し、変えるのは一つか二つにする。
- **終わり近くに、型をくずす一問を置く**：それまでの予想が通じない問題で、子どもは手順から関係へ目を移す。
- **解き終えたら「答えを比べよう」と問う**：約分の並びのように、まとまり全体を見る問いを最後に置く。
- **問題を教科書のまま出す前に「何が変わり、何が変わらないか」を確かめる**：気まぐれにちがう問いの並びは、速さも理解も育てにくい。

これらはWiki側の適用案で、日本の学校で確かめられたものではない。

## 展開したい問い

- 日本の教科書の練習問題は、どのくらい「変わる次元」が絞られているか。
- 型をくずす一問は、どの子にも驚きを生むか。予想を立てていない子にはどう働くか。
- 単元の終わりの「最後の一段」と、練習問題の中の「型をくずす一問」は、同じ設計の手か。
