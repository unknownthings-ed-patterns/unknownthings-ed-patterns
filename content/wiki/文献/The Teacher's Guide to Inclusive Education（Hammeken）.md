# The Teacher's Guide to Inclusive Education（Hammeken, 2007）

Hammeken, P. A. (2007). *The Teacher's Guide to Inclusive Education: 750 Strategies for Success!* Corwin Press. ISBN 978-1-890455-10-1

著者はミネソタ州の公立小学校で学習障害・知的障害・情緒行動障害のある子どもを担当した特別支援教員。インクルーシブ教育プログラムの立ち上げと教員研修に関わった後、Peytral Publications（インクルーシブ教育専門の出版社）を設立。

---

## 要約

### 核心思想：配慮は「特別扱い」ではなく「よい設計」

Hammeken の立場は一貫している。

> 「障害のある子のために行う配慮の多くは、クラスの他の子どもたちにも効果的だ」

合理的配慮（accommodation）を「特定の子への特別対応」として捉えるのでなく、**よい授業設計が全員を支える**という普遍的デザインの視点に立つ。これはUniversal Design for Learning（UDL）の哲学と完全に一致する。

### 750の方略の構成

10のカテゴリーに体系化されている：

| カテゴリー | 内容 |
|---|---|
| **コミュニケーション** | 視覚支援・代替コミュニケーション・指示の明確化 |
| **授業計画・課題修正** | 教材の簡略化・学習量の調整・スキャフォールディング |
| **行動支援** | 予防的行動管理・ルーティン・選択肢の提示 |
| **配慮と修正** | 授業内・評価時の調整 |
| **評価の調整** | テスト形式・時間・方法の変更 |
| **読むこと** | デコーディング・読解・流暢性の支援 |
| **書くこと** | 手書き・スペリング・作文の支援 |
| **算数・数学** | 概念理解・問題解決の支援 |
| **整理整頓・学習スキル** | 材料・時間・課題の管理 |
| **支援機器（AT）** | テクノロジーツールの活用 |

### 配慮（Accommodation）と修正（Modification）の区別

Hammeken が繰り返し強調する重要な区別：

| 配慮（Accommodation） | 修正（Modification） |
|---|---|
| 学習内容・ゴールは変えない | 学習内容・ゴール自体を変える |
| アクセスの方法を変える | 何を学ぶかを変える |
| 例：テスト時間を延ばす | 例：設問数を半分にする |
| 例：口頭で回答可にする | 例：別の課題に置き換える |

「まず配慮から試みる」が原則。修正は本当に必要なときのみ。

### 教科別の主要方略

**読むこと**：
- ペア読書（相互に読み合う）
- 録音・音声読み上げの活用
- カラーオーバーレイ（読む行を際立たせる）
- 読書ガイド（読む前に重要箇所を示す）
- 事前語彙指導（読む前にキーワードを教える）
- テキストの難易度を合わせた複数版の用意

**書くこと**：
- グラフィック・オーガナイザー（構成の可視化）
- ワードバンク（使っていい言葉のリスト）
- 書き出しの文の枠（センテンス・スターター）
- 書く量を減らして知識を示す（箇条書き・図）
- キーボードや音声入力の選択肢

**算数**：
- 電卓・補助具の使用
- グラフ用紙での計算
- 具体物・操作（マニピュラティブス）
- 文章題のグラフィック・オーガナイザー
- 公式シートの提供

**行動支援**（予防的アプローチ）：
- 期待される行動を視覚化して掲示
- 選択肢を与える（「今やる？5分後にやる？」）
- 休憩システムの制度化
- ポジティブな強化の意図的設計
- サインシステム（目立たない合図）

### 評価の調整

| 調整の種類 | 具体例 |
|---|---|
| 時間 | 延長時間・分割実施 |
| 形式 | 選択式→記述→口頭回答への変換 |
| 量 | 設問数の削減（知識の代表的な問題に絞る） |
| 環境 | 別室・個別空間 |
| 支援 | 読み上げ・読み取り補助 |

### 協働的支援体制

Hammeken は「インクルーシブ教育は通常学級担任だけの仕事ではない」と強調する。

- **通常学級担任 × 特別支援教員の協働**：計画段階から共同設計する
- **パラプロフェッショナル（支援員）の役割**：個別サポートだけでなく、授業設計の補助として機能させる
- **保護者との連携**：IEP（個別支援計画）の実施を日常的なフィードバックでつなぐ

## 重要な引用

> 「インクルーシブ教育は、通常学級の教師が特別支援の専門家になることを意味しない。すべての子どもが学べるように授業を設計することを意味する。」

> 「障害のある子のための調整のほとんどは、クラス全体のために行っても害にならない——むしろ多くの場合、全員の学びを改善する。」

---

## 教育実践への示唆

1. **「この子のため」でなく「全員のために」の視点**：グラフィック・オーガナイザーは学習に困難を抱える子だけでなく、クラス全体の思考整理になる。視覚支援は特別支援学級だけの道具ではない。

2. **配慮と修正を区別して計画する**：「内容は変えずにアクセスの方法を変える配慮」を先に試み、それでも届かないときに「内容を変える修正」を検討する。

3. **予防的行動支援を優先する**：問題行動が起きてから対応するのでなく、起きないような環境・ルーティン・選択肢の設計を先に行う。

4. **評価の調整は「手抜き」でない**：知識があることを証明するための形式を変えることと、知識量を減らすことは違う。

5. **協働を制度化する**：特別支援教員との週1回のミーティングを「子どもの問題を話し合う場」から「授業の共同設計の場」として位置づける。
