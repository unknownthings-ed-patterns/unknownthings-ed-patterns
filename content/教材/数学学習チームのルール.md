# 数学学習チームのルール

> 小グループで問題を解くとき、答えを教え合うのではなく、質問し、説明し、互いの理解を助けるためのルール。

## 教材の概要

数学学習チームのルールは、数学ワークショップで小グループが機能するための約束である。

グループ活動は、ただ席を近づけるだけではうまくいかない。速い子が先に進み、困っている子が答えだけを写し、話し合いが答え合わせで終わることがある。

このルールは、子どもが「自分の理解には自分で責任を持つ」ことと、「仲間の理解を助ける」ことを両立させるために使う。

## 使う場面

- 数学ワークショップで小グループ課題に取り組む前
- 宿題で困った問題を持ち寄って相談するとき
- 複数の解法を比較し、説明し合うとき
- グループでテストや発展問題に取り組むとき
- 小グループが答え合わせだけになっているときの立て直し

## ルールの核

| 核心 | 子どもへの伝え方 |
|------|------------------|
| まず自分で取り組む | 最初から答えを聞かず、自分の考えを持つ |
| 困り方を具体的にする | 「どこで分からなくなったか」を質問する |
| 答えだけを教えない | 例を出す、問い返す、別の問題で確かめる |
| すべての考えを尊重する | 質問、試み、途中の考えも大切にする |
| 考えを紙に残す | 図、表、式、言葉でプロセスを書く |
| チーム全員の理解を大切にする | 速く終わることより、全員が説明できることを目指す |

## 追試するなら

最初のルールは、三つだけでよい。

1. まず自分で考える
2. 困ったら「どこで困ったか」を言う
3. 助ける人は答えだけを言わない

慣れてきたら、次のように広げる。

- 解法を比べる
- 別の方法を探す
- 友だちの説明を聞いて、自分のノートに直す
- 友だちの解法からよい方法を一つ選んで振り返る

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| 答えを教え合うだけになる | 「どう考えたらそこに行ける？」と説明を求める |
| 困っている子が質問できない | 「ここまでは分かる」「ここから分からない」の型を渡す |
| 速い子が先に進みすぎる | チームは全員が説明できるまで終わりではないと確認する |
| 話がそれる | 小声で、チーム内だけに聞こえるように話すルールにする |
| 書かずに話すだけになる | 解法や考えた跡を必ずノートに残す |
