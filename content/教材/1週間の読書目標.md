# 1週間の読書目標

> 今週の読書目標を自分で決め、達成したかどうかを振り返る短期の読書計画シート。

## 教材の概要

1週間の読書目標は、リーディング・ワークショップで使う短期の目標設定・振り返りシートである。

原資料では、次の欄が繰り返し用意されている。

- 月日の週
- 今週の読書目標
- 目標を達成しましたか？（はい／いいえ）
- 振り返り

長期の [[教材/20冊チャレンジ]] が読書の足あとを残す道具だとすれば、1週間の読書目標は「今週どう読むか」を決める道具である。

## 使う場面

- 週のはじめに、今週の読書目標を短く決める
- 読書時間や選書の前に、自分の読み方を意識する
- 週の終わりに、達成できたかどうかを振り返る
- カンファランスで、目標が高すぎるか低すぎるかを一緒に調整する
- [[教材/20冊チャレンジ]] と組み合わせて、短期の計画と長期の記録をつなげる

## 目標の例

目標は、冊数だけでなく、読み方や選書に関するものでもよい。

| 目標の種類 | 例 |
|------------|----|
| 読書量 | 今週は2冊読む |
| 読書時間 | 毎日10分読む |
| 継続 | 同じ本を最後まで読む |
| 選書 | 今まで読んでいないジャンルを1冊選ぶ |
| 読み方 | 心が動いたところに付箋を貼る |
| 共有 | 読んだ本を友だちに1冊紹介する |

「たくさん読む」より、「何をどう読むか」が見える目標にすると振り返りやすい。

## 振り返りの問い

目標を達成したかどうかだけで終わらせず、次の読書につながるように振り返る。

- 目標は達成できたか
- うまくいった理由は何か
- うまくいかなかった理由は何か
- 次の週は目標をどう変えるか
- 読んでみて、自分に合っていた本はどれか

「いいえ」に丸をつけた場合も、失敗ではなく、次の目標を調整するための情報として扱う。

## 追試するなら

週の初めに1分で目標を書く。週の終わりに2分で振り返る。

最初は教師が目標例をいくつか示すとよい。

- 今週は毎日少し読む
- 今読んでいる本を最後まで読む
- 新しい作者の本を読む
- 読んだ本を一人に紹介する

慣れてきたら、子どもが自分で目標を調整する。難しすぎたら小さくする。簡単すぎたら少し広げる。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| 目標が「がんばる」だけになる | 「何を」「いつ」「どれくらい」を入れる |
| 高すぎる目標を立てる | 「今週の生活で本当にできそう？」と問い返す |
| 低すぎる目標になる | 「少しだけ挑戦するとしたら？」と聞く |
| 振り返りが一言で終わる | 「なぜ達成できた？」「次はどうする？」を足す |
| 達成できないと落ち込む | 目標は調整するものだと位置づける |

## この教材の意味

1週間の読書目標は、読書を「時間があれば読む」から「自分で計画して読む」へ変える教材である。

子どもは、目標を立て、実際に読んでみて、達成できたかどうかを振り返る。その小さなサイクルを繰り返すことで、読書の自己調整が育っていく。

長期の [[教材/20冊チャレンジ]] と組み合わせると、短期の計画と長期の足あとがつながる。
