# デイリー5の起動

Boushey & Moser（2014）*The Daily 5* に基づく、**「独立性を教える10ステップ」を使った4〜6週間の起動プラン**。最初の1週間はRead to Self だけに集中し、スタミナが安定してから次のコンポーネントを加えていく。

---

## 起動前の準備

### 必要なもの

- **模造紙・マーカー**：I-チャートを授業中に作るため（事前に作らない）
- **スタミナチャート**：日付と分数を記録する折れ線グラフ用紙 × コンポーネント数
- **IPICK ポスター**：教室の本棚近くに掲示する選書の5つの問い
- **静かな合図**：ベル・ライトのスイッチ・ハンドサインなど1つ決める
- **本の選択肢**：本棚に「よい本」が並んでいること（既にある場合はそのまま）

### 導入前に教師が考えること

- Read to Self から始め、スタミナが10分を超えたら次のコンポーネントを加えるか判断する
- 各ラウンドに何分を割り当てるか（最初は5〜10分、最終的に20〜25分）
- 小グループ指導・カンファリングを Daily 5 の時間にどのように組み込むか
- 「静かな合図」を事前にクラス全体で練習しておく

---

## 週1〜2：Read to Self の起動

### Day 1：Daily 5 を紹介する

全体で説明する：
- 「今日から、毎日5つのリテラシー活動の中から自分が選んだものに取り組む時間を作ります」
- 「今日は最初の活動『自分で読む（Read to Self）』を一緒に作っていきます」
- 「Read to Self が完璧にできるようになってから、次の活動を加えていきます」

### Day 1：独立性を教える10ステップ（Read to Self 版）

**ステップ1：何を教えるか明確にする**
> 「今日は『Read to Self（自分で読む）』とは何かを学びます」

**ステップ2：目的と切迫感を作る**
> 「Read to Self はとても大切です——一人で集中して読む練習が、みなさんを読書家にします。先生が別の子と話している間、みなさんは Read to Self で読む力を育てています」

**ステップ3：I-チャートを生徒と一緒に作る**

模造紙を取り出して、生徒に問う：
- 「誰かが Read to Self をしているとき、どう見えますか？」
- 「どう聴こえますか？」

生徒の言葉を左の列に記録する。次に：
- 「先生はどうしていると思いますか？」

右の列に記録する。

**I-チャートの完成例：**

| 生徒の仕事 | 先生の仕事 |
|---|---|
| 本を目で追っている | 静かに観察する |
| 体が静止している | スタミナを計る |
| 声を出さない | I-チャートを確認する |
| 一か所にとどまっている | 邪魔しない |
| 顔が本に向いている | |

**ステップ4：理想的な行動をモデリングする**

教師が本を手に取り、I-チャートの行動を実演する：
> 「私が Read to Self をするとこうなります。（静かに本を読む）」

**ステップ5：最悪の行動を見せ、次に理想的な行動を再度見せる**

> 「これが良くない Read to Self です（本をパラパラめくる、ぼーっとする、隣に話しかける）」
> 「もう一度、よい Read to Self を見せます（静かに本を読む）」

**ステップ6：生徒を部屋に配置して練習開始**

- 「今から Read to Self を始めます。どこで読みたいか、静かに場所を選んでください」
- 生徒が自分の場所に移動するのを見守る

**ステップ7〜8：スタミナを計る（教師は観察のみ）**

- タイマーをスタート
- I-チャートの行動が続いているかだけを観察する
- 誰かの行動が崩れたら静かな合図でストップ

**ステップ9：静かな合図で戻す**

- 合図を出す（例：ベルを1回）
- 全員が集合場所に戻るのを待つ（声をかけない）

**ステップ10：グループ振り返り**

- 「何分 Read to Self できましたか？（タイマーの時間を見せる）」
- 「よかったこと・難しかったことは？」
- 「次回は何分を目指しましょうか？」
- スタミナチャートに記録する

**初日の目標：1〜3分の成功体験**

---

### Day 1〜2：ファウンデーション・レッスン「本を読む3つの方法」

Read to Self スタミナ練習と並行して、「読む」ことの多様な形を最初に教える：

**Three Ways to Read a Book（本を読む3つの方法）**：
1. **文字を読む**——書かれている言葉を音にする・心の中で読む
2. **絵を読む**——絵を見て何が起きているかを考える（高学年でも絵の細部で深く読める）
3. **前に読んだ話を語り直す**——本を手に持ち、内容をページごとに思い出して語る

**なぜこれが最初か**：「本の字が読めない子」「平仮名が不安定な子」でも「読み手」として Read to Self に参加できる。全員が同じコミュニティの一員として始められる。

**ミニレッスン手順**（15分）：
1. 絵本を1冊手に取り「今から3つの方法を見せます」と告げる
2. 「1つ目：文字を読む」——1ページ文字を読んで見せる
3. 「2つ目：絵を読む」——絵だけを使って「この人は何をしているか」を考えて声に出す
4. 「3つ目：前に読んだ話を語り直す」——別の本を手に持ち、ページをめくりながら内容を語る
5. 子どもたちに「今日、あなたはどれを使いますか？」と問い、自分の本で1分間練習させる

---

### Day 2〜5：Read to Self スタミナを育てる

毎日、10ステップの後半（ステップ6〜10）を繰り返す：

```
Read to Self スタミナの記録例

分
10 |                         ★
 7 |               ★     ★
 5 |       ★   ★
 3 |   ★
 1 | ★
 0 +--+--+--+--+--+--+--→
   Day1  2  3  4  5 ...
```

- 生徒がスタミナチャートに自分で記録できるようにすると所有感が生まれる
- 崩壊（誰かが離脱・話しかける）したら即座に止め、振り返りに移る——崩壊した時間はカウントしない

---

## Appendix I より：最初の2週間の日次スケジュール（実際のタイミング）

Boushey & Moser（2014）の Appendix I に掲載されている日次サンプル（Day 1〜Day 13）から抜粋。上記の「週」区分はあくまで目安——実際のタイミングは以下の通り：

| 日 | 主な活動 | ポイント |
|---|---------|---------|
| **Day 1** | Read to Self 10ステップ + Three Ways to Read a Book | 1〜3分のスタミナ達成が目標 |
| **Day 2〜5** | Read to Self スタミナ練習 | 崩壊したら即座に止めてリセット。毎日チャートに記録 |
| **Day 6〜7** | Read to Self スタミナ継続。教師が小グループを少し試みる | スタミナ8〜10分を目指す |
| **Day 8** | Three Ways to Read a Book の復習 | 概念の再確認、全員が3つの方法を理解しているか確認 |
| **Day 9** | **選択を初めて導入！（Introduce Choice!）** | 「今日は何をしますか？」と初めて生徒が決める。まだ Read to Self のみが選択肢 |
| **Day 10** | Read to Self + 選択の練習続行 | チェックイン申告の練習を継続 |
| **Day 11** | **Read to Someone を追加** | EEKK・Coaching or Time?・How Partners Read を10ステップで導入 |
| **Day 12** | Read to Self / Read to Someone どちらかを選択 | 2択でチェックイン申告の練習 |
| **Day 13** | **Work on Writing を追加** | Think-About・Underline and Move On を10ステップで導入 |

**Day 9 が転換点**：それまで全員が Read to Self をしていたところから、初めて「自分で選ぶ」が始まる。この日を大切に——「今日から選べるようになりました」という宣言と、選択申告の練習を丁寧に行う。

## 週3：Read to Someone を追加する

### Read to Self スタミナが7〜10分を超えたら

Read to Someone の10ステップを同様に行う：

**Read to Someone の I-チャート確認事項：**
- EEKK（Elbow to Elbow, Knee to Knee）——密着して座る
- 声は「ささやき声」——隣のペアに聞こえない音量
- 読み終えたら「どんな話だった？」と確認し合う
- 本は1冊を2人で共有（または各自の本を交互に読み聴かせ合う）

**チェックイン申告の練習**：
- 「今日は Read to Self（R）か Read to Someone（RS）のどちらかを選んでください」
- 申告の練習をする——「〇〇さんは？」と一人ずつ確認し記録する

---

## 週4：Work on Writing を追加する

### Read to Self スタミナが10分以上安定したら

Work on Writing の特別な注意：
- 書くトピックは生徒自身が選ぶ（教師がテーマを与えない）
- 「何を書けばいいか分からない」という生徒のために、教室の壁にトピックリストを掲示する（「今日あったこと・昨日あったこと・好きなもの・家族・友達・ペット・不思議なこと」等）
- 最初の Work on Writing は1〜2分から——スタミナ構築は Read to Self と同じ手順

**Work on Writing のファウンデーション・レッスン**

| レッスン | 内容 |
|---------|------|
| **Think-About（考えの種に戻る）** | 書くことに詰まったら：鉛筆を置き、目を閉じて「自分が書きたいこと（シード・アイデア）」を思い出す。数秒後に再開する |
| **アンダーライン・アンド・ムーブ・オン** | 書いている途中に分からない漢字・言葉が出たら、とりあえず下線を引いて先へ進む——完璧主義でペンが止まらない戦略 |

Think-About は「何を書けばいいか分からない」に対する最初の対処法。I-チャートと同様に「詰まったらどうする？」を生徒と一緒に考えて手順を共同作成する。

---

## 週5：Listen to Reading / Word Work を追加する

### 最後の2コンポーネント

**Listen to Reading の準備**：
- 使う機器（タブレット・CD・スピーカー等）を事前に確認する
- ヘッドフォンの使い方を全体でモデリングする
- テキストを「目で追いながら聴く」ことを強調する

**Word Work の準備**：
- 操作的教材（磁石文字・砂書きトレー・ホワイトボード等）を用意する
- 「言葉で遊ぶ時間」として位置づける——正解・不正解より探求を優先する

---

## 全コンポーネント起動後のチェックイン・ルーティン

週5〜6頃に全5択が揃ったら：

```
ラウンド開始の流れ（5分）

1. 全員が集合場所に集まる（1分）
2. 「今日のラウンド1で何をしますか？」——一人ずつ申告（R/RS/L/W/WW）（2分）
3. 教師がチャートに記録し、小グループの確認をする（1分）
4. 「始めてください」——全員が自分の場所へ移動（1分）
```

## 4週間後の状態チェック

| チェック項目 | OK | 要再指導 |
|---|---|---|
| Read to Self スタミナ10分以上 | □ | □ |
| チェックインの申告が1〜2分で完了 | □ | □ |
| 全員がI-チャートの行動を維持 | □ | □ |
| 静かな合図で即座に戻れる | □ | □ |
| 教師が小グループを10分以上中断なく行える | □ | □ |

「要再指導」が多い場合：崩れているコンポーネントに戻り、10ステップを再度行う。

---

## よくある問題への対処

| 問題 | 対処 |
|---|---|
| スタミナが一向に延びない | 活動中の行動崩壊に気づかず続けていないか確認——崩れた時間はカウントしない |
| Read to Someone で声が大きくなる | EEKK の位置を再モデリング。「ささやき声テスト」——ペアの間に教師の手を置いて聴こえなければOK |
| Work on Writing で「何を書けばいいか分からない」が続く | トピックリストを更新。「昨日、先生に話したこと——それが書けることです」と伝える |
| チェックインに5分以上かかる | 申告の方法を簡略化（指の数・カードをかざす等）。5人ずつ班でまとめるなど |
| 教師が小グループ中に生徒から呼ばれる | 「3 Before Me（先生に聞く前に3人に聞く）」ルールを導入。緊急用のサインだけ決める |
| 一部の生徒が同じコンポーネントしか選ばない | カンファリングで「今週試していない活動」を一緒に考える。義務化はしない |

## リーディング・ワークショップとの統合

デイリー5はRWの独立練習時間をそのまま置き換えることができる：

```
RW + Daily 5 の週間スケジュール例（90分ブロック）

ミニレッスン             15〜20分
──────────────────────────────
Daily 5 ラウンド1        20〜25分
  └ 教師：小グループ指導（ガイデッド・リーディング）

Daily 5 ラウンド2        20〜25分
  └ 教師：個別カンファリング

全体共有                 10〜15分
```
