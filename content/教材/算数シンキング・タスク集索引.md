# 算数シンキング・タスク集索引

[[教材/算数シンキング・タスク集]] は136問あるため、授業で使うときは先にこの索引から選ぶ。

## まず使うなら

| 目的 | タスク・教材 |
|------|--------------|
| 年度初めに考える文化をつくる | タスク1、2、4、7、8、10〜12、40〜42 |
| 低学年でも入りやすい | タスク1、2、6〜11、28〜33、97〜100 |
| 分数を図で考える | タスク5、9、61〜66、[[教科/分数パズル（youcubed）]] |
| 面積・図形を操作で考える | タスク3、19〜21、49〜54、[[教材/面積24の長方形]] |
| パターンから一般化する | タスク4、7、10〜12、22〜24、41、48、[[教材/形の成長を見る]]、[[教材/ネガティブスペース]] |
| 数学の驚きや美しさを味わう | タスク91〜96、105〜136、[[教材/四つの4]] |
