# テキストコーディング

## この実践で働くパタン

- [[パタン/シンクアラウド]] — 印を付ける理由を声に出し、読みの判断を見せる。
- [[パタン/可視化]] — 疑問・驚き・重要箇所を記号で外在化する。
- [[パタン/メタ認知的モニタリング]] — 自分がどこで分かったか、止まったかを追跡する。
- [[パタン/質問する文化]] — 分からなさや疑問を、読む力の一部として扱う。
- [[パタン/推論する（インファリング）]] — 印を手がかりに、書かれていない意味を考える。

- [[パタン/能動的関与]] — 読むだけでなく記号をつける判断をしながらテキストに関わる。
- [[パタン/精緻化]] — 「なぜその記号か」を書く行為が自己説明となり理解を深める。
- [[パタン/問いをもつ（クエスチョニング）]] — ?やHuh?コードで疑問を価値ある読みの情報として扱う。
- [[パタン/段階的手放し]] — 教師のモデリングからペアの練習を経て一人読みへ移行する。
## 実践の概要

読みながら「今何を考えているか」を記号と一言メモで記録する習慣。Harvey & Goudvis（2007）が提唱する "Text Coding" を基に、日本語テキスト・日本の教室に適応した形に再構成。

「テキストに書き込む（またはテキストに付箋を貼る）」という身体的な行為を通して、読書中の思考を可視化する。付箋1枚が「思考1個」の単位になる。

## 使う記号

| 記号   | 意味                           | 使うとき                             |
| ------ | ------------------------------ | ------------------------------------ |
| `TS`   | Text-to-Self（自分との接続）   | 「自分の体験・気持ちと結びついた」   |
| `TT`   | Text-to-Text（テキスト間接続） | 「他の本・映像・記事と結びついた」   |
| `TW`   | Text-to-World（世界との接続）  | 「社会・科学・ニュースと結びついた」 |
| `?`    | 疑問                           | 「わからない」「問いが生まれた」     |
| `!`    | 驚き・強い反応                 | 「すごい！意外だ！なるほど！」       |
| `I`    | Inference（推論）              | 「書いていないことを推論した」       |
| `Huh?` | 混乱・理解の崩れ               | 「急に意味が分からなくなった」       |
| `*`    | 重要だと思う                   | 「これが一番大切だと思う」           |
| `BK`   | Background Knowledge           | 「以前の知識が使えた」               |

→ 最初は `TS / TT / TW / ?` の4つだけに絞ると使いやすい

## 授業での使い方

### ステップ1：記号を教える（1〜2回の授業）

1. 記号の表を板書・掲示する
2. 先生が絵本や短い文章でシンクアラウド（[[パタン/シンクアラウド]]）
3. 「今の先生の考えは何の記号だと思う？」と全体に問う
4. 記号の決め方を子どもたちと確認する

### ステップ2：付箋でコーディングを試す

- 付箋（小サイズ）を1人3〜5枚配る
- 短い文章を読みながら、思ったことを記号＋一言で書いて貼る
- 書く量は「一言でいい」——長い文章を書かせない

```
例：付箋の書き方
TS
「自分も転んだことある。この主人公の気持ちわかる」
```

### ステップ3：ペアで「どの記号を貼ったか」を共有

- 「どこに何の記号を貼った？」→ 同じテキストでも違う記号が出る
- 「なぜその記号？」→ 思考の根拠を語る習慣になる

### ステップ4：「Huh?」コードを教える（3〜4回目以降）

- 「わからなくなったとき、止まって Huh? と書いていい」
- 「先生もわからなくなる。そのときは Huh? と書いて戻ってくる」
- 「Huh? の付箋が一番大事な情報を持っている」

---

## 特別支援学級での調整

- 記号は `?` と `!` の2つから始める
- テキストに直接書き込み可能なコピーを使う（付箋より扱いやすい場合）
- ペア読み：1人が読む→もう1人が記号を選んで貼る
- 「面白かったところに ! を貼ろう」という一点集中課題

---

## シンクシートとの組み合わせ

付箋だけでなく、2列メモ（Think Sheet）と合わせると思考が整理される：

| 気づいたこと・感じたこと     | 記号 |
| ---------------------------- | ---- |
| おじいちゃんと同じだと思った | TS   |
| なんでこんなことをしたの？   | ?    |
| ニュースで見たのと同じ       | TW   |

→ [[実践/2列メモ（シンクシート）]] と組み合わせると読書後の振り返りが豊かになる

---

## うまくいったこと・課題

**うまくいく条件：**

- 「量より質」——付箋1枚1枚の一言が短く、具体的であるほどよい
- 「正解はない」——どの記号を使っても間違いではないと伝えてから始める
- 最初は先生が一緒に読んで立ち止まる（段階的手放し）

**起きやすい課題と対処：**
| 課題 | 対処 |
|------|------|
| 付箋を書かずに読むだけの子 | 「1枚だけ書けたら OK」と基準を下げる |
| 「わかった」「面白かった」しか書かない | 「なんでそう思った？」を一言付け加える練習 |
| 記号を覚えられない | 机に記号の小さなカードを置く |
| 付箋が多すぎて読書が止まる | 「1ページ1枚まで」のルールを設ける |
