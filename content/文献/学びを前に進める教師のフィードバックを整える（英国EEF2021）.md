# 学びを前に進める教師のフィードバックを整える（英国EEF2021）

> 英国の Education Endowment Foundation が、5〜18歳への教師のフィードバックについて六つの勧めを示した指針。書くか話すかという「方法」の議論から離れ、①フィードバックの前に良い授業と形成的評価で土台をつくる、②時機を見て学びを前に進めることに焦点を当てる、③子どもがどう受け取りどう使うかを計画する、の三つの原則を中心に置く。時機の根拠ははっきりしないので、学校の方針で頻度や方法を決めすぎないよう勧める。

**原題**：Teacher Feedback to Improve Pupil Learning: Guidance Report（Education Endowment Foundation、2021年、55ページ）

**読んだもの**：財団が公開しているPDF（2021年6月作成）。前書き・本文・事例・囲み・実施の章まで読み、参考文献は必要な箇所だけ確かめた。指針の土台になった EPPI センターの系統的レビューと、オックスフォード大学の実践のレビュー（Feedback in Action）は読んでいない。

## 要約（六つの勧め）

| 勧め | 中身 |
| --- | --- |
| **原則** 1. 効果的なフィードバックの土台をつくる | フィードバックの前に良い授業をする。形成的評価で学習のねらい（フィードバックが向かう先）を共有し、学びのすき間（フィードバックが埋めるもの）をつかむ |
| 2. 適切な時機に、学びを前に進めることに焦点を当てる | 時機の根拠ははっきりしない。課題・子ども・学級を見て、すぐか、後かを教師が判断する。内容は課題・教科・自己調整に向ける。人柄や能力への言葉、一般的であいまいな言葉は効きにくい |
| 3. 子どもがどう受け取り、どう使うかを計画する | 意欲、自信と自己像、教師への信頼、作業記憶が受け取り方に影響する。フィードバックを使う時間と機会をつくって初めて「ループが閉じる」 |
| **方法** 4. 目的があり時間効率のよい書くフィードバック | 書くフィードバックは成績を上げうるが、効果はばらつく。教師の負担という機会費用が大きい |
| 5. 目的のある話すフィードバック | 話すフィードバックも成績を上げうるし、時間効率がよいこともある。ただし方法より原則1〜3が大事 |
| **実施** 6. 原則を示す学校の方針をつくる | 方針は原則を具体例で示し、頻度・方法・ペンの色などを決めすぎない。実施は出来事でなく段階的な過程で、研修が要る |

## 要約（目立つ点）

- **時機**：レビューでは、学習中・学習直後・1週間以内のフィードバックの効果は同じくらいだった。1週間を超えた研究はなかった（p. 19）。調査した学校の方針では、小学校の69%、中学校以上の76%が書くフィードバックの頻度を決めていた。この細かさは根拠に見合わないとする（p. 19）
- **すでにうまく進んでいる子にフィードバックを与えると、自分で答えにたどりつく機会を奪うこともある**（p. 20）
- **人柄へのフィードバック**：「生まれつきの数学者だね」は改善に使える情報がなく、学びから注意をそらしうる（p. 21）。課題・教科・自己調整の三つに分けた例を、学年段階ごとに表にしている（pp. 22–23）
- **成績・ほめ言葉・努力**：成績だけでは成績は上がらず、コメントのほうがよいという研究と、結果がまちまちな新しい研究がある。ほめるなら、何がよかったかを具体的に。努力について言うなら、何をすればよくなるかにつなげる（p. 24）
- **成績を外してコメントだけにした学校の例**：1年間、成績なしで「詳しいコメント」を受けた中学1年の学級は、成績とわずかなコメントを受けた学級より成績が低かった。子どもは「もっと頑張ろう」「よくできました」のようなコメントしか受けていなかった。だから争点は成績かコメントかではなく、学びのすき間に向けた中身だとする（p. 25）
- **「探偵の課題」**：「二つの段落を入れ替えるとよくなる」と言うかわりに「入れ替えるとよくなる段落が二つある。どれか見つけて」と言う。誤りの行に点だけ打つ（p. 30）
- **書くフィードバックの負担**：中学1〜3年の教師は書くフィードバックに週6.3時間を使っていた（2013年と2018年）（p. 35）
- **Wiliam の序文**：「フィードバックで大事なのは、学び手がそれで何をするかだけである」（p. 5）

## 適用範囲と限界

- **研究の根拠は限られていると指針自身が何度も書く**。時機、成績とコメント、具体的な技法（ライブ・マーキング、記号でのマーキング、学級全体へのフィードバック）には、はっきりした根拠がない。「教室で効くかもしれないこと」は、根拠の解釈と委員の経験からの提案である（p. 9）
- 事例は現在の学校の実践を示すもので、最善の実践とは限らないと断っている（p. 9）
- 扱うのは教師から子どもへのフィードバックだけで、子ども同士・自己・保護者からのフィードバックは扱わない。幼児期は根拠が乏しく対象外（pp. 6–7）
- 根拠として紹介される形成的評価の研修（Embedding Formative Assessment）は Wiliam らが開発したもので、Wiliam は序文を書き、勧めの起草も支えた
- 英国（イングランド）の学校が前提である

## 原典で確かめたこと（wiki との照合）

1. **[[文献/The Power of Feedback（Hattie & Timperley, 2007）]]** の四つのレベル（課題・過程・自己調整・自己）を、本指針は「課題・教科・自己調整」と「人柄」に言い換えて使う。「過程」を「教科」と呼ぶ点が違う。「フィードバックは2番目に起きるもの」という Hattie と Timperley の言葉を、勧め1の出発点に引く（p. 13）
2. **[[概念/形成的評価の5つの戦略（3×3の枠組み）]]** の五つの戦略（Wiliam 2018 の図）をそのまま載せ、フィードバックの前に戦略1（ねらいの共有）と戦略2（学びの証拠を引き出す）が要るとする（p. 14）
3. **[[文献/7〜14歳の算数の指導を研究から整える（英国EEF2017）]]** の「フィードバックは多すぎないように」「丁寧な赤ペンの方針が負担を重くしないよう注意」を、本指針は勧め4と6でくわしく展開している

## 教育実践への示唆（Wiki側の適用案）

以下はこの Wiki の適用案である。

1. **ノートへのコメントは「次に何をするか」を書き、それをする時間を次の授業の最初にとる**
2. **誤りの場所を全部書かず、点や数だけ示して子どもが探す**：「この中に計算ちがいが2つある。見つけて直そう」
3. **すでに順調に進んでいる子には声をかけない**：自分で答えにたどりつく機会を残す
4. **「すごいね」でなく、何がよかったかを言う**：「図に分けて考えたから、どこで間違えたかが分かったね」
5. **学校の方針で、コメントの頻度やペンの色を決めない**
