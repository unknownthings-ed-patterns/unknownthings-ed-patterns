# 文献からパタンを作る

文献を読んで終わらせず、教育パタン・実践・概念へ翻訳するための作業手順。

## 1. 文献を取り込む

1. [[文献/文献ページテンプレート]] で文献ページを作る。
2. `type: literature`、`literature_status: ingested`、`ingested` を入れる。
3. 書誌情報、概要、重要な概念、教育実践への示唆を書く。

## 2. 3行要約を書く

文献ページの冒頭に、次の3行を置く。

- この文献は何を論じているか
- 教育実践にとって何が重要か
- このWikiでは何に使うか

## 3. Wiki内の接続先を探す

| 探すもの | 見る場所 |
|---|---|
| 似たパタン | [[パタン名インデックス]]、[[全パタン一覧]] |
| 実践への接続 | [[実践/index]]、[[メンテナンス/次に圧縮を書く候補]] |
| 概念への接続 | [[概念/教育思想の系譜]]、[[概念/パタン・ランゲージ概論]] |
| 未処理の問い | [[メンテナンス/未パタン化の論点]] |

接続先を足したら、`literature_status: linked` に進める。

## 4. 概念をパタン候補に翻訳する

文献中の概念を、そのまま用語として保存するのではなく、実践で繰り返し現れる関係に変換する。

| 文献の記述 | パタン化するときの問い |
|---|---|
| 理論・概念 | どんな授業場面で繰り返し起きるか |
| 原理 | 何と何の関係として働いているか |
| 事例 | どんな別場面にも移せるか |
| 批判 | どんなアンチパタンを避けているか |

翻訳できたら、`literature_status: translated` に進める。

## 5. パタンdraftを作る

新規パタンが必要なときだけ、`status: draft` で小さく作る。既存パタンへ吸収できる場合は、新規ページを増やさない。

最小構成:

```markdown
---
type: pattern
status: draft
tags: [パタン]
updated: YYYY-MM-DD
---

# パタン名

> 一文の圧縮。

## 背景（Context）

## 問題（Problem）

## 解決（Solution）

## 関連パタン

## 出典
```

## 6. 逆参照を整える

文献ページからパタンへリンクしたら、必要に応じて接続先ページ側にも文献への参照を足す。

| 接続先 | 足す場所 |
|---|---|
| パタン | `## 出典`、`## Pattern Connection`、または関連パタン |
| 実践 | `## 圧縮されているパタン`、`## 参考文献` |
| 概念 | `## 関連するWikiページ`、`## 出典` |
| 教材 | `## 関連パタン`、`## 出典` |

逆参照まで終わったら、`literature_status: integrated` に進め、`reintegrated` を更新する。

## 7. 検査する

```bash
npm run update:literature-report
npm run check:literature
npm run check:wikilinks
```

## 完了条件

- 文献ページに「3行要約」「このWikiでの使い道」「関連するWikiページ」がある
- 関連パタン・実践・概念のリンクが切れていない
- 未パタン化の問いが [[メンテナンス/未パタン化の論点]] に移されている
- 必要な逆参照が接続先ページにある
