# 教室の話し合いを変える研修で、子どもの学力が伸びるかを確かめる（EEFの対話的な授業の評価2017）

> 英国の Education Endowment Foundation（EEF）が、Robin Alexander の「対話的な授業」（dialogic teaching）を、イングランドの小学校76校で学校単位の無作為化比較にかけた評価報告書。5年生の担任が、研修・手引き・授業の録画と録音・校内の指導役（メンター）との2週ごとの振り返りを使い、20週・11の周期で、教師の問い方と子どもの話し方を変えていった。比べた学校より、英語は 0.15 SD（p = 0.051）、理科は 0.12 SD（有意）、算数は 0.09 SD（有意でない）高かった。給食費の補助を受ける子では算数が 0.16 SD（有意）だった。教師の多くは、2学期では定着しきらないと感じていた。開発側の録画の分析では、開いた問い、子どもの長い発言、話し合いが増えた（独立の評価者は検証していない）。一方、授業者からは、学力の低い子や英語を母語としない子には難しかったという声もあった。

**原題**：Dialogic Teaching: Evaluation report and executive summary（Education Endowment Foundation、2017年7月）。評価はシェフィールド・ハラム大学、実施はケンブリッジ初等教育評議会（CPRT）とヨーク大学

**読んだもの**：シェフィールド・ハラム大学の機関リポジトリで公開されている報告書 PDF（全78ページ）の本文（pp. 4–46）を読んだ。付録（事例研究の詳細・開発側の録画分析の表）は一部のみ。以下のページは報告書のページ番号。2年後の全国テスト（KS2）の結果をまとめた追補（2018年予定とされていたもの）は読んでいない。OpenAlex の被引用は42件（2026-11-01）。

## 要約

**手立て**（pp. 4–10）
- 目的は、教師と子どもの教室での話の質を高め、英語・算数・理科の学びと学力を上げること。子どもが推論し、話し合い、論じ、説明することを通して、高次の思考と話す力を育てる
- 5年生の担任と、各校1人の指導役（多くは副校長など）が研修を受け、手引き、Alexander の本、「対話的な授業のレパートリー」のカード（9つの話し方の手＝トークムーブ）、録画・録音の機材を受け取った
- 20週・11の周期で、計画→授業の録画・録音→指導役と見直し→次の焦点、をくり返した。前半は教師と子どもの話し方の幅を広げ、後半はそれを英語・算数・理科などの授業で使った。まず話し合いの約束（よく聴く、相手の考えを尊重する、さえぎらない）をつくり、問い方、説明、返し方、子どもの発言を掘り下げて広げる手などを順に入れた
- 対話的な授業は、教師が閉じた問いを出し、子どもが答え、教師が評価する型（IRF）に対して、問いが考えを引き出し、答えが次の問いの足場となり、やりとりがつながった探究の筋になることを目指す

**研究の作り**（pp. 13–20）
- リーズ、ブラッドフォード、バーミンガムの、給食費の補助を受ける子が20%を超える小学校76校（5年生が2学級以上）。38校ずつに割り付けた（学校の特徴をそろえる割り付け方法）
- 子どもは英語・算数・理科のどれか一つの標準テストを受けた（採点者は群を知らない）。1年生の終わりの全国評価（KS1）をそろえた
- 対象の学校のうち6校が開始前後に、人手の事情で手を引き、1校はテストを返さなかった。分析には、対象31校の1,832人と、比べた38校の2,080人が入った（はじめの約79%）

**結果**（pp. 21–29、表7・表8）
- 学校の特徴（給食費の補助・英語を母語としない子の割合・学校の成績）もそろえたモデルで、英語 +0.15 SD（p = 0.051）、理科 +0.12 SD（p = 0.04）、算数 +0.09 SD（p = 0.19）。EEF の換算では英語と理科が2か月分、算数が1か月分の上乗せ
- 給食費の補助を受ける子：算数 +0.16 SD（p = 0.03）、英語 +0.12 SD、理科 +0.11 SD（どちらも有意でない）
- 1年生の評価だけをそろえたモデルでは、どの教科も有意でなかった（英語 +0.14、算数 +0.08、理科 +0.08）
- 評価の安全度は、EEF の5段階で3（中程度）

**実施と教室の変化**（pp. 31–43）
- 成功の条件として最も挙がったのは、校長がこのための時間（代わりの教員など）を守ること。指導役との振り返りと、授業の録画を一緒に見ることが、最も価値があったとされた
- 手引きと「レパートリー」のカードが最もよく使われた。研修の内容が多すぎる、言葉が難しいと感じた学校もあり、9つのトークムーブに絞って取り組んだ学校が多かった
- 2学期の中で2週ごとの周期を回すのは難しく、学力の成果を急ぐ学校の方針（ノートに残る成果を求める視察など）とぶつかることもあった
- 教師は、問いのあとの追加の問い、子どもの話す量と質、話し合いの約束（敬意をもって反対する、理由を言う）が育ったと答えた。録画を見て、正しく答えそうな子ばかり指名していたことに気づき、無作為に指名を変えたら、ふだん手を挙げない子がよい答えを返した例もあった
- 一方、学力の低い子や、英語を母語としない子には難しかったという声があった。評価者は、そうした子への効果の違いは検定できなかったと書く
- 開発側の録画の分析（26人の教師、独立の評価者は未検証）では、終わりには対象の教師のほうが開いた問い、待ち時間、言い直し、理由を求める手などを多く使い、子どもの長い発言と話し合いが増えた

**結論**（pp. 44–46）
- 2学期では定着しきらないと多くの教師が感じており、より長い期間で確かめる価値がある。研修・手引き・録画・指導役の振り返りのどれが効いたのかを分けることが、今後の課題とされた

## 適用範囲と限界

- イングランドの、給食費の補助を受ける子と英語を母語としない子の多い小学校の5年生の、2学期間の研究である
- 対象の学校の7校がデータを欠いた（すべて対象の側）。評価者自身、肯定的な結果は欠けたデータのため慎重に扱うべきだとする
- 比べた学校で何が行われていたかは調べていない
- 効果量は、評価者が事前に計算した検出できる最小の効果（約0.25）より小さく、学校の特徴をそろえたときに有意になった
- 教室の話の変化の数字は開発側の分析で、独立の評価者は検証していない
- 2年後の全国テスト（KS2）の結果をまとめた追補は読んでいない
- **原典の記述の食い違い**：
  1. 分析の方法の節（p. 15）は、主な分析を「割り付けどおりの分析（intention-to-treat）」と見出しに書くが、方法の別の箇所（p. 17）と結果の節（p. 28）は、データを返したのは実施を終えた学校だけなので「実施した学校だけの分析（on-treatment）」にあたると書く
  2. 要旨の結論2は「給食費の補助を受ける子は英語・理科・算数で2か月分の上乗せ」と書くが、表1・表8でこの差が有意なのは算数だけである（英語 p = 0.21、理科 p = 0.14）。要旨も「人数が少なく確かさは限られる」と断っている

## 原典で確かめたこと（wiki との照合）

1. **[[パタン/IRE型応答の脱却（Talk Move）]]** は、教師の3つめの発言が評価であることが対話を止めるとし、思考を教室に返す手（トークムーブ）を勧める。本報告書の手立ては、まさにその型（IRF）からの脱却を目指し、9つのトークムーブのカードが最も使われた。大規模な無作為化比較で、教室の話が変わり（開発側の分析）、学力にも小さな効果が出た
2. **[[文献/話し合いの約束と個人の推論を確かめる（Mercerほか1999）]]**・**[[文献/理由を出し合う対話を育てる（Mercerほか2004）]]** の「考え合う話し合い」の研究を、本報告書は先行研究として引き、どれも小規模だったとする（たとえば Mercer と Sams 2006 の算数 +0.59、7人の教師）。本報告書の規模（76校）での効果はずっと小さかった
3. **[[パタン/哲学対話（P4C）]]** について、本報告書は EEF の別の無作為化比較（Gorard ほか 2016、原典未読）を引き、全体では算数 +0.10・読み +0.12、給食費の補助を受ける子では算数 +0.20・読み +0.29・書き +0.17 と、恵まれない子でより大きかったとする

## 教育実践への示唆（Wiki側の適用案）

以下はこの Wiki の適用案である。

1. **一度にたくさん変えない**：教師たちは、焦点を絞ること（9つのトークムーブから一つずつ）を最も実際的だと感じていた
2. **自分の授業を録音して聞き返す**：だれを指名しているか、何を問い返しているかは、録って聞くと気づける。録画より録音のほうが話に集中できたという声もあった
3. **話し合いを、学力の低い子や日本語を母語としない子にも届く形にする**：話の速さについていけない子がいた。待ち時間や、ペアで先に話す時間が助けになりうる
4. **成果を急がない**：2学期では定着しきらないと、多くの教師が感じていた
