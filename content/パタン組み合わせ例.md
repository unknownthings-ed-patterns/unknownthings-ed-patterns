# パタン組み合わせ例

授業設計でよく使うパタンの組み合わせ。単体のパタンを選ぶだけでなく、目的に応じて複数のパタンを重ねるためのレシピとして使う。

## 使い方

1. 授業の場面に近いセットを選ぶ。
2. そのまま全部使わず、今の授業に必要な2〜3個へ絞る。
3. [[授業設計テンプレート]] に書き込む。
4. 授業後に [[授業後リフレクションテンプレート]] で、どの組み合わせが働いたかを記録する。

## 導入セット

### 必要感から始める

実践例：[[実践/カエルの算数：勝ちやすさを表で考えよう]]

| パタン                      | 役割                                                   |
| --------------------------- | ------------------------------------------------------ |
| [[パタン/切実性（必要感）]] | 子どもが「これは自分に関係がある」と感じる入口を作る。 |
| [[パタン/オンボーディング]] | 最初の一歩を踏み出せるようにする。                     |
| [[パタン/可視化]]           | ゴール・手順・見通しを見える形にする。                 |

使いどころ：新しい単元や、子どもが「なぜやるのか」を感じにくい学習の入口。

### 驚きから問いへ

実践例：[[教材/ネガティブスペース]]

| パタン                    | 役割                               |
| ------------------------- | ---------------------------------- |
| [[パタン/謎・驚きの感覚]] | 「あれ？」という感情を起こす。     |
| [[パタン/深める問い]]     | 驚きを理由・意味・根拠へ進める。   |
| [[パタン/熟慮的問い]]     | 授業全体を動かす問いとして整える。 |

使いどころ：探究の導入、読解の導入、算数・理科の発見型課題。

## 探究セット

### 考え続ける場を作る

実践例：[[実践/学習する学校をつくる]]

| パタン                        | 役割                                     |
| ----------------------------- | ---------------------------------------- |
| [[パタン/考える文化]]         | 考えることを教室の当たり前にする。       |
| [[パタン/沈黙の間の設計]]     | すぐ答えを求めず、考える時間を保証する。 |
| [[パタン/問い返しのデザイン]] | 出てきた考えを次の思考へつなぐ。         |

使いどころ：発言が浅いとき、教師が説明しすぎてしまうとき。

### 数学的に考える

実践例：[[実践/10や100を単位にして計算しよう]]

| パタン                        | 役割                                 |
| ----------------------------- | ------------------------------------ |
| [[パタン/ナンバートーク]]     | 複数の解法や見方を共有する。         |
| [[パタン/可視化]]             | 数量・関係・変化を見えるようにする。 |
| [[パタン/自己説明（精緻化）]] | 自分の考えを言葉にして理解を深める。 |

使いどころ：算数・数学で、答えだけでなく考え方を扱いたいとき。
