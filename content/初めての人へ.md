# 初めての人へ

このWikiは、教育実践の中で繰り返し働く「よい型」を、パタン・実践・教材・文献の関係として整理するための場所。

> よい教育は、そこに働くパタンの圧縮として観察できる。

一つの授業、一つの教材、一つの実践記録の中には、たいてい複数のパタンが圧縮されている。このWikiでは、その圧縮をほどきながら、他の人が追試しやすい形にしていく。

## 初回のおすすめルート

1. [[まず覚える30パタン]] — 最初に思い出すパタンを選ぶ
2. [[パタン組み合わせ例]] — 2〜3個の組み合わせに絞る
3. [[授業設計テンプレート]] — 授業案に落とす
4. [[授業後リフレクションテンプレート]] — 授業後に働いたパタンを記録する

理論から入りたい場合は、[[概念/パタン・ランゲージ概論]] と [[メタパタン/index|メタパタン]] を先に読む。

自分の実践からパタンを書きたい場合は、[[自分のパタンを作る]] から始める。

## 迷ったら

授業準備中なら、まず [[実践/index|実践]] と [[教材/index|教材]] を見る。  
パタン名が分かっているなら、[[パタン名インデックス|主要パタン名インデックス]] または [[全パタン一覧]] を使う。  
英語名・旧名・別表記から探したいときは、[[検索のための別名・表記ゆれ]] を使う。
