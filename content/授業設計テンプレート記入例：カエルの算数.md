# 授業設計テンプレート記入例：カエルの算数

[[授業設計テンプレート]] を、[[実践/カエルの算数：勝ちやすさを表で考えよう]] に沿って記入した例。

## 授業の概要

| 項目                 | 記入例                                                      |
| -------------------- | ----------------------------------------------------------- |
| 教科・単元           | 算数・場合の数／表で整理する                                |
| 学年・対象           | 小学校中学年以降                                            |
| 時間                 | 1〜2時間                                                    |
| 今日の中心概念       | 起こりやすさは、組み合わせの数として表に整理できる。        |
| 今日のゴール         | サイコロ2個の和について、どの数が出やすいかを表で説明する。 |
| 子どもに残したい経験 | ゲームの予想が、表で確かめられる経験。                      |

## 1. 育てたいこと

- 育てたい力・姿：感覚的な予想を、表・数・理由で説明する力。
- 関係する目標：[[目標から探す]]
- 使う大パタン：
  - [[パタン/熟慮的問い]]
  - [[パタン/熟慮的教材教具]]
  - [[パタン/可視化]]
  - [[パタン/パフォーマンス課題]]

## 2. 導入

| 観点                           | 記入例                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------- |
| 最初に子どもがすること         | カエルのゲームを見て、どのカエルが勝ちやすそうか予想する。                    |
| 必要感・切実性                 | 「勝ちやすいカエルを選びたい」という必要感を作る。                            |
| 見通し・ルール・ゴールの可視化 | ゲームボードと勝ち方を見せ、最後に「表で理由を説明する」と示す。              |
| 小さな成功体験                 | まず1回ゲームを試し、予想する楽しさを体験する。                               |
| 使うパタン                     | [[パタン/切実性（必要感）]] · [[パタン/オンボーディング]] · [[パタン/可視化]] |

## 3. 活動

| 観点               | 記入例                                                                          |
| ------------------ | ------------------------------------------------------------------------------- |
| 中心活動           | サイコロ2個の和を表に整理し、出やすい数を考える。                               |
| 教材・道具         | カエルのゲームボード、サイコロ、組み合わせ表。                                  |
| 活動の順序         | 予想する → 試す → 組み合わせを表にする → 理由を説明する。                       |
| 個別差への対応     | 操作で考える子にはサイコロやカード、早い子には「なぜ7が多いのか」を説明させる。 |
| 子どもが選べること | どのカエルを選ぶか、どの方法で組み合わせを調べるか。                            |
| 使うパタン         | [[パタン/熟慮的教材教具]] · [[パタン/可視化]] · [[パタン/自己説明（精緻化）]]   |

## 4. 共有・対話

| 観点               | 記入例                                                                          |
| ------------------ | ------------------------------------------------------------------------------- |
| 共有するもの       | 予想、表、出やすい数の理由。                                                    |
| 取り上げたい考え   | 「7は組み合わせが多い」「端の数は少ない」という気づき。                         |
| 問い返し           | 「何通りある？」「その数はほかと比べて多い？」「表のどこを見ると分かる？」      |
| 聴き合うための支え | 友だちの説明を表で指差しながら聞く。                                            |
| 使うパタン         | [[パタン/深める問い]] · [[パタン/問い返しのデザイン]] · [[パタン/聴き合う文化]] |

## 5. 振り返り・評価

| 観点                   | 記入例                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| 子どもが記録すること   | 最初の予想、表から分かったこと、考えが変わったこと。                                        |
| 教師が見取ること       | 表を根拠にして説明できているか。                                                            |
| 次の一手につながる情報 | 表が作れるが理由が言えない子、理由は言えるが表が不完全な子。                                |
| 残す作品・記録         | 組み合わせ表、振り返り文。                                                                  |
| 使うパタン             | [[パタン/形成的評価]] · [[パタン/自己内フィードバック]] · [[パタン/ポートフォリオファイル]] |
