# パタン・ランゲージの作り方

教育のパタン・ランゲージは、完成品として一度に作るものではない。経験から出発し、仮のリストを作り、使いながら育てていく。

このページは、岩井輝久「教育のパタン・ランゲージ入門」の考え方を、実践者が自分で始めやすい手順にしたもの。

## 基本方針

1. パタン・ランゲージは完成させなくてよい
2. パタン・ランゲージは作りながら活用する
3. 最初はパタン記述よりパタンリストを重視する

## 手順

### 1. 経験を集める

自分が実践したこと、他の人の実践を観察したこと、同僚から聞いたこと、本で学んだことを集める。最初から理論で分類しようとせず、よい経験が生まれた場面を思い出す。

### 2. くり返し現れる働きを見つける

単なる物や活動名ではなく、問題解決に働いている関係を見る。

例えば「本がある」だけではなく、「子どもの手の届くところに、続けて読める本がある」という働きを見る。

### 3. 仮の名前をつける

名前は、あとで変えてよい。まずは自分が思い出せる名前をつける。

名前がつくと、次に似た場面を見たときに「あれと同じ働きかもしれない」と気づきやすくなる。

### 4. パタンリストに入れる

短い名前のリストとして蓄積する。大きなパタンと小さなパタンが混ざっていてよい。あとでまとめたり、分けたり、削ったりする。

### 5. 使ってみる

授業設計や教材づくりの前にリストを眺める。使えそうなパタンを選び、いくつか重ねてみる。

教育は計画どおりに進まない。即興の判断にも、パタンリストは役に立つ。

### 6. 反事実で確かめる

「もしそのパタンがなかったら、同じよい結果は起きただろうか」と考える。  
なかった場合に結果が弱まるなら、そのパタンは原因として働いていた可能性がある。

### 7. 書きたくなったものを記述する

すべてを本格的に記述しなくてよい。重要だと思ったもの、説明したくなったものから [[パタン作成テンプレート]] を使って書く。

## パタンリストの使い方

| 場面 | 使い方 |
|------|--------|
| 指導案を書く | 使えそうなパタンを手立てとして取り出す |
| 教材を作る | どのパタンを働かせる教材かを考える |
| 授業中に判断する | 状況に応じて、重ねるパタンを選ぶ |
| 授業後に振り返る | 何が働き、何が働かなかったかを見る |
| 同僚と話す | 実践のよさを、名前のある働きとして共有する |

## ObsidianとQuartzについて

ObsidianとQuartzは、パタン同士のつながりを育てる道具として相性がよい。

- Obsidianでは、日々のメモ・実践記録・パタンリストをリンクでつなげられる
- Quartzでは、育ってきたパタン・実践・教材をWebで公開できる

ただし、最初から公開Wikiを作る必要はない。まずは自分の経験からパタンリストを作る。必要になったら、蓄積と公開の道具としてObsidianとQuartzを使う。
