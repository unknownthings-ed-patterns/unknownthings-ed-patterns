## 1. おはじきの分け方

**学年目安**: K〜1年（非カリキュラムタスク）  
**数学的ねらい**: 数の合成・分解（10のボンド）、複数解の存在に気づく

### 導入の言葉

> 「今日は10個のおはじきを使います。このおはじきを2つの山に分けてください。どんな分け方ができますか？全部見つけてみよう。」

おはじきを子どもに配る（または床に置く）。「答えは何通りです」とは言わない。数え方や記録の仕方も指示しない。「どうやって記録する？」と聞かれたら「好きなやり方で」と返す。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 3つの分け方を見つけて、それぞれの数を書こう |
| **ミディアム** | 全部の分け方を見つけよう。どうすれば「全部」と言える？ |
| **スパイシー** | 全部で何通りある？1と9、2と8…と並べてみると何が見える？0や10はどうする？ |

### 収束の問い（Consolidation questions）

- 「どんな分け方が出た？黒板に全部書いてみよう」（子どもが発表したものを教師が板書）
- 「0＋10、1＋9、2＋8……と並べると、どんなことが見える？」
- 「全部で何通りあった？なぜその数になるの？」
- 「いつも2つの数を足したら10になっているね。これを『10のペア（10のボンド）』と呼ぼう」

### 教師へのメモ

- 予想される解法：おはじきを分けてから数える、表にする、式で書く、絵で表す
- 0+10 と 10+0 をどう扱うかで盛り上がる（「どちらが先でも同じ？違う？」）
- Consolidationで10の合成一覧（0+10, 1+9, 2+8, ..., 10+0）を視覚的に並べると、後の計算学習への橋渡しになる
- **特別支援対応**：Mildをさらに下げるなら「5個を2つに分ける」から始める

## 2. 正方形と長方形を全部数えよう

**学年目安**: 1〜2年（非カリキュラムタスク）  
**数学的ねらい**: 体系的な数え方、正方形・長方形の認識

### 導入の言葉

黒板に3×3のマス目を描く（または印刷して配る）。

> 「このマス目の中に、正方形はいくつありますか？小さいのも大きいのも全部数えよう。」

「1個？9個？もっとある？」という問いかけでよい。余分なヒントは出さない。

```
┌─┬─┬─┐
│ │ │ │
├─┼─┼─┤
│ │ │ │
├─┼─┼─┤
│ │ │ │
└─┴─┴─┘
```

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 一番小さい正方形（1マス分）を全部数えよう |
| **ミディアム** | 大きさが違う正方形を全部数えよう（1×1, 2×2, 3×3） |
| **スパイシー** | 正方形だけでなく、長方形も全部数えよう（縦長・横長も含む）|

### 収束の問い（Consolidation questions）

- 「1×1の正方形は何個あった？どうやって数えた？」
- 「2×2の正方形が5個あると言う人と4個あると言う人がいるね。どちら？どうやって確かめる？」
- 「長方形も全部数えたら、どうすれば漏れなく数えられる？」（体系的な数え方の共有）
- 「正方形は長方形の仲間です。なぜ？」

### 教師へのメモ

- 答え：1×1が9個、2×2が4個、3×3が1個 → 正方形合計14個
- 長方形（正方形を含まない）：1×2が6個、1×3が3個、2×3が2個、2×1が6個、3×1が3個、3×2が2個 → 非正方形長方形18個、合計32個
- **体系的数え方の種類**：左上から順に数える・大きさ別に数える・位置別に数える
- 「どうやって間違えないようにしたか」の方法を共有することが本タスクの核心

## 3. 面積が24cm²の長方形を全部見つけよう

**学年目安**: 2〜3年（カリキュラムタスク：面積・かけ算）  
**数学的ねらい**: 面積の意味、因数の概念への入口、周の比較

### 導入の言葉

> 「面積が24cm²の長方形を作ります。辺の長さは整数センチメートルとします。どんな長方形が作れますか？全部見つけよう。」

方眼紙があれば配る（なければ式だけでもよい）。「面積＝縦×横」だけ確認し、他のヒントは出さない。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 2種類の長方形を見つけて、式と図で表そう |
| **ミディアム** | 全部の長方形を見つけよう。漏れなく見つけるにはどうする？ |
| **スパイシー** | 全部の長方形の「周の長さ」を計算しよう。いちばん周が短いのはどれ？なぜそれが短くなるの？ |

### 収束の問い（Consolidation questions）

- 「見つかった長方形をまとめると？」（板書：1×24, 2×12, 3×8, 4×6）
- 「縦の長さと横の長さのペアを見ると、どんな数？」（24の約数のペア）
- 「全部で何種類あった？なぜそれ以上はない？」
- スパイシー到達組へ：「周が一番短いのは4×6。なぜ正方形に近い形ほど周が短いの？」

### 教師へのメモ

- 答え：1×24（周50cm）、2×12（周28cm）、3×8（周22cm）、4×6（周20cm）
- 「縦×横＝24になる整数のペア」＝24の因数ペアである。「因数」という言葉は高学年で出てくるが、概念としてここで経験できる
- Consolidationで「同じ面積でも形が変わると周が変わる」を発見するだけで十分。「最適な形はいつも正方形に近い」まで到達できればスパイシー達成

## 4. 奇数の和のパターン

**学年目安**: 2〜4年（非カリキュラムタスク）  
**数学的ねらい**: 数列・パターン発見・平方数の視覚的理解

### 導入の言葉

黒板に書く：

```
1 = 1
1 + 3 = 4
1 + 3 + 5 = 9
1 + 3 + 5 + 7 = 16
```

> 「続きはどうなると思いますか？どんなパターンが見えますか？」

計算させる前に「どんなパターンが見える？」と一度聞く。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 次の5行を続けよう（1＋3＋5＋7＋9＝？から5行）|
| **ミディアム** | 1＋3＋5＋…＋19はいくつ？式を全部書かずに予想してから確かめよう |
| **スパイシー** | 1＋3＋5＋…＋99はいくつ？なぜいつも平方数になるの？図を使って説明できる？ |

### 収束の問い（Consolidation questions）

- 「答えを並べてみると？（1, 4, 9, 16, 25, ...）これは何という数？」
- 「1×1, 2×2, 3×3, ... と比べると？」
- 図で見せる：奇数個ずつ点を追加すると正方形になる図

```
●          ●●         ●●●
           ●●         ●●●
                      ●●●

1個        4個（+3）   9個（+5）
```

- 「なぜ奇数を足し続けると正方形の数になるのか、この図で説明できる？」

### 教師へのメモ

- スパイシーの答え：1＋3＋…＋99 ＝ 50² ＝ 2500（1から99は50個の奇数）
- 「どこまでが奇数か」の確認：99＝2×50−1なので50番目の奇数
- 図の説明は「L字型の点を追加していくと次の正方形になる」という視覚的証明
- 低学年でもパターンの発見（マイルド・ミディアム）は十分楽しめる。スパイシーは3〜4年生向け

## 5. 1/2と2/3の間の分数

**学年目安**: 3〜4年（カリキュラムタスク：分数の大小）  
**数学的ねらい**: 分数の大小比較・通分・分数の稠密性

### 導入の言葉

> 「1/2と2/3の間にある分数を1つ見つけてください。」

数直線の絵を描いて「1/2と2/3の間」を示してもよい。ヒントは出さない。「本当に間にあるか確かめる方法は？」とだけ問う。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | 1/2と2/3の間にある分数を1つ見つけよう。なぜ「間」といえる？ |
| **ミディアム** | 分母が違う5つの分数を見つけよう（例：分母が4の分数、5の分数、6の分数…）|
| **スパイシー** | 1/2と2/3の間には分数は何個ある？もっともっと探したらどうなる？ |

### 収束の問い（Consolidation questions）

- 「見つかった分数を数直線に並べてみよう」
- 「1/2と2/3の間に分数はいくつある？」（無限にある——いつでも「真ん中の分数」が作れる）
- 「どんな2つの分数の間にも、必ず別の分数が入れられる。なぜ？」
- 「この性質、整数でも同じ？」（整数は稠密ではない——比較）

### 教師へのメモ

- 例となる分数：7/12（通分で確認）、3/5、5/8、11/18など
- 「真ん中を取る」方法：(1/2 + 2/3) ÷ 2 ＝ (3/6 + 4/6) ÷ 2 ＝ 7/12
- スパイシーは「有理数の稠密性」に触れる。小学生向けには「いつでも間の分数が作れる」レベルで十分
- 間違いやすい点：「3/5は1/2と2/3の間？」→ 1/2=0.5, 3/5=0.6, 2/3≈0.667 → 間にある

## 6. おにぎりの組み合わせ

**学年目安**: 2〜3年（カリキュラムタスク：場合の数）  
**数学的ねらい**: 組み合わせの数え方・体系的な列挙・順列と組み合わせの区別

### 導入の言葉

> 「鮭・ツナ・卵・梅・昆布の5種類のおにぎりがあります。この中から3個選んで買います。どんな選び方がありますか？全部見つけよう。」

「たとえば、鮭・ツナ・卵という選び方があります。他には？」と1例だけ示す。「順番は考えない（鮭・ツナ・卵と卵・ツナ・鮭は同じ）」と伝える。

### 足場の三段階

| 段階 | 課題 |
|------|------|
| **マイルド** | できるだけたくさんの選び方を見つけよう（漏れや重複は気にしなくてよい）|
| **ミディアム** | 全部の選び方を漏れなく・重複なく見つけよう。どんな順序で探すと間違えない？ |
| **スパイシー** | ①同じ種類を2個選んでいいとしたら、全部で何通り？　②3個の順番が違っても別の選び方とするなら何通り？ |

### 収束の問い（Consolidation questions）

- 「全部で何通りあった？（10通り）どうやって確認した？」
- 「どの順で探すと漏れなく数えられる？」（例：鮭を必ず入れる場合→4通り、鮭なしツナを入れる場合→3通り、...）
- 表に書いてまとめる：鮭○ の組み合わせ 4、ツナ○鮭× の組み合わせ 3、...合計10
- スパイシー①：重複を許す組み合わせ → C(5+3-1, 3)=35通り（中学生向けの発展）
- スパイシー②：3個を並べる順列 → 10×6＝60通り（順列 vs 組み合わせの区別）

### 教師へのメモ

- 答え（組み合わせ）：C(5,3) ＝ 10通り
  - 鮭を入れる4通り：鮭ツナ卵、鮭ツナ梅、鮭ツナ昆布、鮭卵梅、鮭卵昆布、鮭梅昆布（6通り）→ 間違い。鮭を含む組み合わせはC(4,2)＝6通り
  - 正しい木図：鮭入り6通り+鮭なしC(4,3)=4通り → 計10通り
- 体系的数え方の指導ポイント：「一番左に来る具材を固定して数える」方法が漏れ・重複なし
- 2年生でも「鮭から始めてすべての組み合わせを書く→次はツナから」という方法で取り組める
