# メタパターン

同一のパタンが、目的・状況によってパタンにもアンチパタンにもなる——この相対性を理解し、適切に切り替える上位の知恵。

---

## 核心命題

> **「パターンとアンチパターンは目的状況に依存する。」**

教育実践において、特定の手法が常に「良い」わけではない。文脈・目的・学習者の状態によって、同じ手法がパタンにもアンチパタンにも転じる。

---

## 具体例

### 例1：復唱指導モデル

| 場面                            | 働き                  |
| ----------------------------- | ------------------- |
| 言語定着・発音・漢字の正確な筆順など「型を身につける」場面 | **パタン**             |
| 探究・創造的思考が求められる場面での復唱強要        | **アンチパタン**（個の発想を抑圧） |

### 例2：配列（シークエンス）の順序

| 配列           | 適する場面                     |
| ------------ | ------------------------- |
| 単純→複雑（積み上げ型） | 系統的知識の習得、手順の理解            |
| 複雑→単純（経験先行型） | 全体像・問いを先に体験、後から構造理解へ導く探究型 |

どちらも、違う目的状況では互いにパタンにもアンチパタンにもなる。

### 例3：「成功体験」の設計（特別支援）

障害の重い子どもに「成功体験」を積ませる設計は、通常は有効なパタン。しかし：
- 課題が易しすぎると「達成感のない成功」
- 挑戦がなくなり、力能の発展が止まる

この場合「成功体験の連続」はアンチパタンになりうる。

---

## メタパターン：「状況切替スイッチ」

教育のパタンや技法がそのまま機能しないとき、状況に応じて意図的に切り替える上位の能力。

| 要素    | 内容                        |
| ----- | ------------------------- |
| 使える場面 | 学習者の反応が鈍いとき、活動が硬直化しているとき  |
| 必要な能力 | 経験と直感、仮説検証の思考、「状況の意味の見立て」 |
| リスク   | 判断の軸がなければ迷走する可能性          |

---

## AI時代の含意

AIが「百科事典」として膨大なパタンを提供できる時代でも、**どのページを開くべきか（どのパタンをどの状況で選ぶか）の判断は、人間の教育的知恵**に委ねられる。

> 教育実践は「パターンを選び直す仕事」でもある。  
> **パターンは万能薬ではない。状況に応じて切り替えられる「教育的柔軟性（フィールド感覚）」こそが教師の力である。**

---

## 展開できる命題

- 「教育のパターンは状況における選択肢の集合である」
- 「教育的判断とは"意味の見立て"である」
- 「教師は即興的設計者（improvisational designer）である」
