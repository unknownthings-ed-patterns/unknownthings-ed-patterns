# 主要パタン名インデックス

## 今日の教育に使う入口

| 入口 | 使いどころ |
| --- | --- |
| [[困りごとから探す]] | いま起きている困りごとから探す |
| [[目標から探す]] | 育てたい学習者の姿やパフォーマンスから探す |
| [[まず覚える30パタン]] | 最初に覚える第一軍のパタンから探す |
| [[パタン名インデックス|主要パタン名インデックス]] | 主要パタンを五十音順で探す |
| [[全パタン一覧]] | すべてのパタン名を確認する |

名前から探したい人のために、よく使う主要パタンを集めた入口。名前が分からないときは、先に [[困りごとから探す]] や [[目標から探す]] を見ると探しやすい。

ここでは、親パタン、実践で頻出するパタン、複数ページから参照されるパタンを中心に掲載する。全件確認や抜け漏れ確認には [[全パタン一覧]] を使う。

各行の末尾に1行サマリーを添える。

## 迷ったら読む順

1. [[困りごとから探す]] で、いま起きている状況に近い入口を探す。
2. [[まず覚える30パタン]] で、第一軍のパタンから1つ選ぶ。
3. このページの「カテゴリ別」で、近い主要パタンを広げる。
4. 選んだパタンページの関連パタンをたどる。
5. それでも見つからない場合は、[[全パタン一覧]] で全件から探す。
