# カンファリング（読書会議）

> 「すべての子どもは、自分の世界観と理解を開き、育てるような、親密な個人的対話の瞬間に値する。」——Dana Berg（1年生担任）

## [Pattern Connection]

**Debbie Miller（2002）** は、カンファリングを「子どもの思考への最善の窓」と定義し、読解ストラテジー指導の文脈で1対1の読書会議の価値を示した。

**Patrick Allen（2009）** は Miller の知見を引き継ぎながら、カンファリングに**予測可能な構造（RIPモデル）** と **実践の体系（カンファリングノート・5つのアシュラー）** を与えた。Allen の貢献は「どうすればカンファリングを毎日の日課にできるか」という問いへの実践的な答えである。

二つの視点をまとめると：
- Miller：**カンファリングの「なぜ」と「何を」**——子どもの思考を聴くことの価値・視覚化・推論のエピソード
- Allen：**カンファリングの「どのように」**——RIPモデルによる構造・5つのアシュラーによる環境整備・ノートシステム

**Miller（2002）カンファリングの詳細（2026-05-18追補）：**

- **ノートシステム**：4×6インチのノートを使い、子どもごとのページを設ける。**毎日4〜5人の子どもと会議し、記録する**。このノートがニーズグループ形成とミニレッスン設計の材料になる
- **カンファリングの目的**：「カンファリングはしばしば子どもの思考への最善の窓」——全体指導では見えない、子ども一人ひとりの内側で起きていることが会議で初めて現れる
- **カンファリングでよく現れるストラテジー**：視覚化・推論・スキーマが個別会議で最も豊かに現れる。フランクとグレースの会議（Little Bear）：フランク「リトルベアと兄弟みたい——雪のズボンをもらった！」グレース「本の中にいるけど透明で、起きていることの一部だけどキャラクターには気づかれない」——この二人の会話がクラス全体に広がった
- **選書カンファリング（Sean の例）**：本を選べないショーンと一緒に赤いバスケットの本を見る——ショーンが「この本、読んでみたい」と言うまで押しつけず、傍らで待つ。「お客様には接近しない、でも必要なときはそこにいる」
- **4〜5人/日の実現**：ワークショップの45〜50分の読書時間を使い、教室を歩き回りながら子どもの横に静かに座る。「今日読んでいる本について話してくれる？」という開幕から始める

---

## カンファリングとは何か

**カンファリング（Conferring）** とは、教師が一人ひとりの子どもと短い1対1の会議を重ねる読書指導の実践。リーダーズ・ワークショップの「独立読書（Composing）」の時間中に行う。教師は教室を回りながら、一人の子どもの隣に座り、2〜5分の会話をする。

Allen の言葉：「カンファリングはワークショップの要石（Keystone）——それなしに、私のワークショップは成り立たない」

---

## カンファリングの目的

Allen（2009）が整理した「会議から生まれる14の要素」：

| 要素 | 内容 |
|------|------|
| Strategy Knowledge | 子どものストラテジー使用の見取り |
| Listening | 傾聴の技術と文化 |
| Patterns | 子どもの読書行動のパターン把握 |
| History | その子の読書歴・体験歴 |
| Teaching | その場での指導 |
| Processes | 読者としての思考プロセス |
| Records | 記録・評価データ |
| Talk | 対話の質と深さ |
| Experiences | 子どもの読書体験 |
| Challenges | 課題の発見と対処 |
| Rapport | 信頼関係の構築 |
| Instructional Points | 指導の焦点 |
| Goal Setting | 子どもの目標設定 |
| Our Own Learning | 教師自身の学び |

## カンファリングを始める前に：5つのアシュラー

Allen は、会議が機能するための**環境の礎石（Ashlars）**を5つ挙げる。これが整っていなければ、RIPモデルを使っても会議は成立しない。

1. **信頼・尊重・トーンの定義**：クラスに「失敗しても否定されない」という空気をつくる。「本物のリチュアルとルーティンが、自律した読み手を育てる。偽のリチュアルは依存した読み手を育てる」
2. **持久力とスタミナの育成**：子どもたちが一人で長く読める力をつける——持久力（Endurance）とスタミナ（Stamina）を「賢い読者」の条件として年間をかけて育てる
3. **目的と読み手の意識**：「誰のために、なぜ読んでいるか」を子どもが意識できるよう指導する（Purpose Triangle）
4. **段階的手放しモデルの実践**：全体指導→ガイドされた練習→協働→独立という流れが定着していることが前提
5. **リーダーズ・ワークショップの構造（Crafting→Composing→Reflecting）**：会議はComposing（独立読書）中に起きる——この構造が子どもたちに浸透していることが必要

## RIPモデル——会議の3段階構造

[[パタン/RIPモデル]] を参照。概要：

| 段階 | 内容 | 開幕の問い例 |
|------|------|-------------|
| **R**（Review, Read Aloud, Record） | 前回振り返り・音読観察・記録 | 「今日、読者として自分について何か話してくれる？」 |
| **I**（Instruction, Insights, Intrigue） | 指導・気づき共有・探究 | 「今あなたがやったこと、それは〇〇だよ」「そこ、私も気になった」 |
| **P**（Plan, Progress, Purpose） | 次への計画・成長記録・目的確認 | 「次に読むとき、何を試してみる？付箋に書いてみて」 |

---

## カンファリングの進め方

### ステップ1：隣に座る

子どもの横に静かに座る。急がない。「今日、読者として自分について何か話してくれる？」という開幕の問いで始める。

### ステップ2：聴く（R段階）

- 子どもが話す。教師は最小限しか話さない
- 前回の目標について確認する（「〇〇を試してみるって言ってたけど」）
- 必要なら少し読んでもらい、読み方のパターンを観察する
- **会議は「教師が話す場」でなく「子どもが話す場」**

### ステップ3：一つのことに応答する（I段階）

- 子どもの発言から一つのことを選び、短く応答する
- ストラテジーに名前をつける、洞察を共有する、好奇心から問いを返す
- **「1回の会議では1つのことだけ」**——多くを教えようとしない

### ステップ4：次への目標を決める（P段階）

- 「次に読むとき、今日話したことをどんな形で試してみる？」
- 子ども自身の言葉で計画を語らせる
- 付箋に書いてリットログ（読書ノート）に貼る

### ステップ5：記録する

会議後にカンファリングノートに記録する：

```
[子どもの名前 / 日付]
読書中の本：〇〇
Teaching Point：推論の根拠をテキストに戻って確認する練習
子どもの言葉：「信頼ってテーマだと思う。なぜなら…」
次回確認：推論の根拠をどう見つけたか
```

## 具体的な会議の例

### 例1：視覚化についての会議（Miller, 2002）

Miller のクラス（1年生）が「Little Bear」を読んでいた会議：

**フランク**：「僕は自分をその話の中に置くことができる。まるで映画を自分の頭の中で作っているみたいだ」

**グレース**：「私のイメージはあなたと似ているけど少し違う。本の中にいるのに、本のキャラクターには気づかれない。私は起きていることの一部だけど、透明なの」

教師の応答（I段階）：「グレース、それは驚くほど精緻な視覚化だね。テキストを読みながら、自分がその世界の中にいながら見ている、というイメージを持てている。これが視覚化（Visualizing）のとても豊かな形だよ」

---

### 例2：本の選択についての会議（Allen, 2009）

**Jaryd** が難しすぎる本を読み続けていた。Allen は Lexile レベルを指摘して別の本を選ばせるのではなく、Jaryd が自分で判断できるよう会議を進めた。

Jaryd：「僕はフリをしていた。続けようとしていたけど、自分を信頼しなきゃいけないと気づいた」

Allen（I段階）：「Jaryd、それはすごい発見だね。読者として自分を信頼するって、どういうことだと思う？」

P段階：「次に読む本を決めるとき、その感覚を使ってみて——自分がわかっているかどうかを、自分で判断してみて」

---

### 例3：Jacob との RIP モデル会議（Allen, 2009）

R段階：「どうしてる、Jacob？何を読んでいる？」→ 「Walking to the Creek」について話す

I段階：Jacob が "trust" というテーマを自分で見つける → Allen は「大きなアイデアを探している」と認識し、テキストに戻る問いを返す → Jacob が自分の推論を言語化する

P段階：「次に読むとき、テキストからの証拠を探してみて。付箋に書いてみよう」

## カンファリングノートのシステム

Allen が提案するシンプルなノートシステム：

- **1インチの3リングバインダー**（機能的で軽量）
- 子ども1人につき1セクション
- **カンファリングフォーム**：Teaching Point・子どもの言葉・次回確認
- **Current Reads フォーム**：誰が今何を読んでいるかを週2回更新
- **Conference Check-Off フォーム**：誰といつ会議したかのログ
- ポケットに付箋とペンを常備——「会議中に生まれた宝」を記録する

記録が指導計画になる：
- 多くの子が同じ問いを持っていれば → 次のミニレッスンのテーマ
- 特定の子のメモが積み重なれば → 個別支援の根拠
- 保護者面談での「読書の成長記録」として活用

## 「偽りの信念（Counterfeit Beliefs）」を手放す

Allen（2009）が挙げる、カンファリングを妨げる10の神話：

1. 小グループがあれば個別会議は不要——**誤り**：グループと個別は代替できない
2. 毎日全員と会議しなければ失格——**誤り**：質が量より重要
3. 毎回ランニング・レコードを取らなければ——**誤り**：記録の目的を問い直す
4. すべてのエラーを指摘すべき——**誤り**：1つのことに集中する
5. 専門家の立場をとらなければ——**誤り**：協同探究者として向き合う
6. スキルと流暢性だけに集中すべき——**誤り**：読解・思考の探究が核心
7. 子どもに話しかけているだけで会議になっている——**誤り**：構造と意図が必要
8. 全員と同じ頻度・同じ時間——**誤り**：子どものニーズに応じて柔軟に
9. 全体を「忙しくさせる」ことが前提——**誤り**：読む文化の構築が先
10. 誰かの方法が自分に合わない——**誤り**：試してから判断する

## 特別支援学級での応用

- 会議の時間を2〜3分に短縮（集中持続時間に合わせる）
- 「本について話してみよう」より「この絵、何が見える？」から始める（R段階を視覚から）
- 言語化が難しい場合は「絵に描いて教えて」「指で場所を教えて」も可
- P段階の目標は「1つの行動」に絞る——「次に読んだとき、止まって考えてみて」
- 読みの困難がある場合は、音声書籍・読み聞かせ後に会議する形も有効

---

## うまくいった点（一般的傾向）

- 子どもが「自分の考えを聞いてもらえる」と実感する
- 「1つのことだけ教える」制約が会議の密度を上げる
- 全体指導では見えなかった思考の精緻さが会議で現れる
- P段階で付箋に書いた目標が、子どもの次の読書を変える
- カンファリングが「ある」と知ると、独立読書の集中度が上がる

## 課題・改善点

- 教師が話しすぎる——「指導」の癖が出て、子どもが話す時間が奪われる
- P段階を省略しがち——時間がないと終わらせてしまう
- 記録が途切れると会議の連続性が失われる
- 1クラス30人では全員と週1回は難しい——ローテーションの工夫が必要
- クラスの「読む文化」が育つ前に会議を始めると、騒がしくなる

## 次回への仮説

- カンファリングメモを週次で振り返ることで、次のミニレッスンの精度が上がる
- P段階で付箋に書いた目標を次の会議のR段階で確認するサイクルが回ると、子どもの成長が見えるようになる
- 子どもが「今日先生に言いたいことがある」と待てるようになるとき、読書文化が育っている
