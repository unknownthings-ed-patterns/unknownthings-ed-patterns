# 学んだことを自分で作り変える八つの学び方は、だれに・どんな条件で効くかを整理する（FiorellaとMayer2016）

## 要約

- **生成的な学習とは**（pp. 1–4）：
  - 学ぶ内容を、頭の中で組み立て直し、知っていることと結びつけて意味をつくることです。そうしてはじめて、新しい場面で使えるようになります（Wittrock の考え）。
  - Mayer の「選ぶ・まとめる・つなぐ」の枠組みでは、大事な情報を選び、筋の通ったまとまりに組み、すでにある知識とつなぎます。このうち「まとめる」と「つなぐ」が生成的な処理です（p. 3）。
  - これを動かすのは、意欲と、自分の理解を見張るメタ認知です（p. 3）。
- **どんな方法を選んだか**（p. 4）：研究が多く、一貫して効果が示され、記憶ではなく理解と転移を目ざす方法を八つ選びました。読み返しや下線など、効果のないものや丸暗記向けのものは入れていません。
- **八つの方法と効果**（表1、p. 16。もとは同じ著者の2015年の本のまとめ）：

| 方法 | 内容 | 効果のあった比較 | 効果の大きさ（中央値） |
| --- | --- | --- | --- |
| 要約する | 書く・話して要約する | 30中26 | d = 0.50 |
| 図に組む | 概念地図 | 25中23 | 0.62 |
|  | 決まった関係でつなぐ知識地図 | 6中5 | 0.43 |
|  | 表の形の整理図 | 8中8 | 1.07 |
| 絵をかく | 文章の内容を絵にかく | 28中26 | 0.40 |
| 想像する | 文章の内容を頭に思い描く | 22中16 | 0.65 |
| 自分でテストする | 練習の問題に答える | 76中70 | 0.57 |
| 自己説明する | 自分に向けて説明する | 54中44 | 0.61 |
| 教える | 人に説明する | 19中17 | 0.77 |
| 動作で表す | 物を動かして内容を演じる | 49中36 | 0.51 |

- **方法ごとの条件**：
  - **要約**（pp. 5–6）：中学生の研究で、段落ごとに一文で要約すると理解がよくなり、とくに力の弱い生徒で大きく伸びました（d = 1.58）。ただし、短い説明文で、空間的でない内容に向きます。物理や化学のような空間的な内容には、ほかの方法がよいとしています。年少の子どもには、まとまった練習が要ります（中学生に5週で約6時間の例）。
  - **図に組む**（pp. 6–7）：効果の証拠は強いとしています。ただし、作り方を前もって練習し、作る間も手引きが要ります。時間がかかって飽きやすいので、一部を埋めた図を渡す手もあります。成績の低い学生でとくに効いた研究もあります。
  - **絵をかく**（pp. 7–8）：9年生が洗剤と水の化学の文章を読む研究では、背景と部品があらかじめかいてある紙に絵をかくと、転移のテストがよくなりました（d = 0.81）。何をかくかをはっきり示し、かく手間を減らすことが条件です。
  - **想像する**（pp. 8–9）：前の知識が多い学習者に向きます。知識の少ない学習者には負担が大きすぎるかもしれません。何を思い描くかを具体的に示し、思い描き方を練習しておきます。
  - **自分でテストする**（pp. 9–11）：すぐあとのテストでは読み返した組がよかったのに、2日後・3週間後では自分でテストした組がよくなりました。それでも学生は、読み返した組のほうが「よく学べた」と感じていました（p. 10）。正答の確認があると、より効きます。
  - **自己説明**（pp. 11–12）：数学や理科の複雑な内容、図や例題で学ぶときに向きます。多くの学生は自分からは説明しないので、促しや手引きが要ります。
  - **教える**（pp. 12–14）：教える準備をしただけの学生は、すぐあとの理解のテストでよくなりました。1週間後もよかったのは、準備したうえで実際に教えた学生だけでした（p. 13）。内容をなぞるだけの説明では効果が薄く、聞き手からの問いが説明の質を上げます。
  - **動作で表す**（pp. 14–16）：算数の等式の問題で、身ぶりをまねた子どもは、あとのテストでよくできました。物語をおもちゃで演じると、その物語の記憶はよくなりましたが、新しい物語には広がりませんでした。演じたことを頭の中で思い描く練習を加えると、物がなくても使えるようになりました（pp. 14–15）。
- **どの方法を選ぶか**（pp. 16–17）：
  - 要約・図に組む・絵をかく・自己説明は、力の弱い学習者や前の知識の少ない学習者で、より効く傾向があります。
  - 想像する・動作で表すは、反対に、力のある学習者や前の知識の多い学習者で効く傾向があります。
  - 空間的で複雑な内容には、図・絵・想像・動作のような空間的な方法がとくに役立ちます。
- **これからの課題**（pp. 17–19）：
  - 記憶でなく理解と転移を、すぐあとでなく時間をおいて測る研究が要ります。
  - 学生は自分の学びをうまく判断できません（p. 18）。要約や概念地図、自分でテストすることは、自分の理解の見積もりを正確にする助けにもなります。
  - 一つの方法をいちばんとするより、場面ごとに方法を組み合わせて考えるほうがよい、と著者は書きます（p. 19）。

## 根拠の範囲と注意

- **効果の示された方法を選んでいる**：八つは「一貫して効果が示された」方法として選ばれています（p. 4）。だから、八つとも効果があるという結果は、選び方からある程度予想されます。
- **効果の大きさは中央値**：表1は、同じ著者の2015年の本から、効果のあった比較の数と効果の中央値を写したものです（p. 16）。研究の大きさで重みをつけたメタ分析ではありません。
- **Dunlosky ほか（2013）と評価が違う方法がある**：要約と、文章を頭に思い描く方法は、Dunlosky ほか（2013）では有用性「低」でした（[[文献/学習方法の効果と適用条件（Dunloskyほか2013）]]）。この論文では効果の中央値が 0.50 と 0.65 です。選んだ研究や、測った結果（理解と転移か、記憶か）が違います。どちらも、効くための条件（練習・前の知識・教材）をつけている点は共通です。
- **フィードバックの時期**：この論文は「すぐの」フィードバックと組み合わせるよう勧めています（p. 11）。一方、Dunlosky ほか（2013）は、遅らせたフィードバックのほうが成績がよかった研究を紹介しています（p. 35）。
- **原典の誤植**：
  - 概念地図のメタ分析の著者 Adesope が「Adelsope」と書かれています（p. 7）。
  - 「enactive（動作による）」とすべきところが「inactive」と書かれた箇所があります（p. 15）。

## 教育実践への示唆（Wiki側の適用案）

- **絵や図は、何をかくかを示し、手間を減らす**：かく部品を示し、背景や一部をあらかじめ用意した紙を使います。
- **想像は、知っていることがある内容で**：初めての内容では、絵や図など目に見える方法を先に使います。
- **教える準備で終わらず、実際に教える場をつくる**：準備だけの効果は、1週間後には残っていませんでした。聞き手が問いを返せるようにします。
- **自分でテストすることを、学び方として教える**：子どもは、読み返したときのほうが「分かった」と感じやすいからです。
- **内容の形に合わせて方法を選ぶ**：仕組みや位置関係の内容には図・絵・動作を、筋の通った説明の内容には要約や自己説明を使います。
