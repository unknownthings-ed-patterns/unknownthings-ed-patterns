# 20冊チャレンジ

> 読んだ本を20冊分記録し、読書量と本の広がりを見えるようにする長期の読書記録シート。

## 教材の概要

20冊チャレンジは、リーディング・ワークショップで使う長期の読書記録である。

原資料は、5列×4行の大きな空欄表として作られている。つまり、20冊分の本を記録できるシートである。

読書量を競わせるためだけのシートではない。自分がどんな本を読んできたか、どれくらい読み続けてきたか、ジャンルや作者に偏りがあるかを見えるようにするための道具である。

## 使う場面

- リーディング・ワークショップの読書期間のはじめに配る
- 1冊読み終えたときに、題名・作者・評価などを記録する
- 月末や単元末に、読書の広がりや偏りを見返す
- 次に読む本を選ぶカンファランスの資料にする
- 年度末の [[教材/読むことの振り返り]] の前に、読書の足あととして見返す

## 記録すること

学校や学年に応じて、記録欄に入れる項目は調整できる。

| 項目 | 役割 |
|------|------|
| 本の題名 | 読んだ本を残す |
| 作者 | 作者への関心を育てる |
| 読み終えた日 | 読書の継続を見えるようにする |
| 星の評価 | 自分の好みや読後感を残す |
| ひとことメモ | 次の選書や紹介につなげる |

低学年では「題名」と「星」だけでもよい。高学年では、ジャンル、ページ数、紹介したい相手などを足してもよい。

## 追試するなら

最初に「20冊読むこと」が目的ではなく、「自分の読書の足あとを残すこと」が目的だと伝える。

1冊読み終えたら、表の1マスに記録する。全部埋めることを急がせず、定期的に見返す時間をつくる。

たとえば月末に、次のように振り返る。

- 今月読んだ本で一番心に残った本はどれか
- 同じ作者の本を読んでいるか
- まだ読んでいないジャンルはあるか
- 次に読みたい本は何か

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| 記録だけが目的になる | 月に1回、記録を見て次の選書を考える時間を入れる |
| 冊数競争になる | 冊数だけでなく、ジャンルの広がりや心に残った本も扱う |
| 読むのが遅い子が苦しくなる | 「20冊」は目安として扱い、薄い本・再読・読み聞かせ本も状況に応じて認める |
| 同じ種類の本ばかりになる | 読書記録を見ながら「次は違う棚から選ぶ？」とカンファランスする |
| 書く欄が負担になる | 題名だけ、星だけなど、記録項目を減らす |

## この教材の意味

20冊チャレンジは、読書家としての「足あと」を見えるようにする教材である。

読書は一冊ずつの経験だが、記録として並べると、自分の読書の歴史になる。子どもは「こんなに読んできた」「この作者が好きらしい」「次は違うジャンルも読んでみよう」と、自分の読書を外から見られるようになる。

リーディング・ワークショップでは、この記録が次の選書、ブック・バズ、カンファランス、読書目標へつながっていく。
