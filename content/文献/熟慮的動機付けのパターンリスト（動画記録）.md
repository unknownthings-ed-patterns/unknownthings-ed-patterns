# 熟慮的動機付けのパターンリスト（動画記録）

動画: https://youtu.be/hojW2ZYW8BA

## 概要

熟慮的動機付けのパターンリストについて解説した動画。ARCSモデル（ケラー）を中心に、内発的・外発的動機付け、多方興味（ヘルバルト・牧口常三郎）、ギャップ理論、自己調整など、動機付けに関わるパターンを網羅的に紹介している。

## 主要内容

### ARCSモデル（ケラー）

体系的な動機付けモデル。内発的・外発的動機付けを含む4要素、各3サブパターン。

| 要素 | 意味 | サブパターン |
|------|------|------------|
| A（Attention：注意） | 注意を生み出し維持する | A1. 興味の獲得 / A2. 探究心の刺激 / A3. 注意の持続 |
| R（Relevance：関連性） | 関連性を確立し支援する | R1. ゴールと関連づけること / R2. 興味との一致 / R3. 経験とのつながり |
| C（Confidence：自信） | 自信を構築する | C1. 成功への期待感 / C2. 成功の機会 / C3. 個人の責任 |
| S（Satisfaction：満足） | 満足感をもたらす | S1. 内発的満足感 / S2. 報酬のある成果 / S3. 公平な待遇 |

「ケラーのモデルは内発的動機も外発的動機も含み、かなり体系的にフォローしている」

### ギャップ系

ギャップがあるから自然に埋めようとする気持ちが湧く。

- **過去記憶と現状**：過去の自分より良くなっていると続けようと思う
- **将来展望と現状**：将来の夢・目標と現状のギャップを埋めようとする
- **無知の知**：自分がいかに知らなかったかを自覚することで探求方向へ動機づく
- **認知的コンフリクト**：自分の予測を裏切る出来事（例：磁石の実験）が解消欲求を生む
- **最適化・予測差分の調整**：過大な期待値を持つとやる気低下につながる

### 内発的動機付け

- **自己選択自己決定**：自分で選び決めてやってみる
- **本物を扱う**：プロジェクト学習でリアルな当事者意識が内発的学習につながる
- **自己調整**：適切な目標設定・自己評価・行動の自己管理

### 外発的動機付け・コミットメント

- **コミットメント**：宣言・誓約でやる気を引き出す（1冊の本になるほど大きなパターン）
- **オペラント条件付けの4種類**：
  - 正の強化：心地よいものを与えて行動を増やす
  - 負の強化：不快なものを取り去って行動を増やす
  - 正の罰：不快なものを与えて行動を減らす
  - 負の罰：心地よいものを取り去って行動を減らす
- **アクション**：まず行動することでやる気が出てくる（経験的事実）

### 方向づけのベース

エンゲストロームが言うレイジ・先行オーガナイザー。理解の足場がけをすることで理解を促し、やる気につなげる。

### 多方興味（ヘルバルト / 牧口常三郎）

ヘルバルトの興味理論を牧口常三郎が地理学・教育に応用。子どもと関わる・質問する際の視点にもなる。

| 種類 | 説明 |
|------|------|
| 知覚的交渉（状況的興味） | 自然・社会事象への直接的関わり |
| 利用的交渉 | 自然やものを利用・活用する |
| 研究的交渉 | 科学的探究・調査 |
| 審美的交渉 | 芸術・美へのかかわり |
| 道徳的交渉 | 道徳的価値への関心 |
| 同情的交渉 | 共感・同情 |
| 社会的交渉 | 家族・国家・人との関わり |
| 宗教的交渉 | 宗教・霊的なものへの関心 |

### 自己調整・メタ認知

- **自己教示（セルフトーク）**：自己説明・精緻化・体系化で理解と自信を深める
- **メタ認知的モニタリング・自己記録**：自己調整に含まれる
- **帰属志向性**：成功・失敗をどこに帰属させるか

### ゲーム・感情・想像力

- **ゲーム**：楽しさそのものがやってみようという動機につながる
- **想像力（感情）を触発する**：大きなパターン（別動画あり、ショウレン著書が元）
- **セレンディピティを掴む**：偶然の発見を動機に変える

### 大きなパターン（参照）

「大きなパターンは教育のパターン全体がやる気にかなり繋がっている」

アドベンチャー / 熟慮的配列 / 熟慮的練習 / オンボーディング / 可視化 / 制限化限定化 / 心理的安全性 / 運動 / フィードバック / ギャップ / 多方興味

### 運動について

運動することでドーパミンなどやる気に関わる脳内物質が出やすくなる。脳の発達にも良いことがわかっており、教育設計の中に体を動かす要素を入れることが重要。

## 備考

- 宣言が重複箇所あり（要整理）
- ARCSモデルは他の「やる気を出す」本と比べて偏りが少なく体系的
- 多方興味はヘルバルトの言葉と牧口の言葉が混在している箇所あり
