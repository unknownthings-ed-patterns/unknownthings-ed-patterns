# リテラチャー・サークルの起動

Daniels（2002）*Literature Circles* に基づく、**役割から始めて役割を消す4〜6週間の起動プラン**。最初は役割シートで「準備して来る習慣」を作り、段階的に役割を外して生徒主導の自律的対話へ移行する。

## 起動前の準備

### 本の選定と準備

リテラチャー・サークルの前提は「生徒が本を選ぶ」こと：

- グループ数 × 冊数分（4〜5冊）の候補本を用意する（同じ本を4〜6冊ずつ）
- 同じ難度帯（読書レベル）ではなく「語り合う価値のある本」で選ぶ
- フィクション・ノンフィクション・詩集・グラフィックノベルも候補になる

### 役割シートの作成

6役割のシートを用意する（A4 1枚に役割名・仕事・記入欄）：

| 役割 | シートに含む内容 |
|---|---|
| 討議リーダー | 「今日話し合いたい問いを3〜5つ書きましょう」 |
| コネクター | 「本と自分・他の本・世界とのつながりを3つ書きましょう」 |
| イラストレーター | 「印象に残った場面を絵で描きましょう（説明も添えて）」 |
| 言葉の達人 | 「印象的・重要・難しい言葉を5か所選び、ページと理由を書きましょう」 |
| 要約者 | 「今日読んだ部分の重要な流れを3〜5文でまとめましょう」 |
| 調査員 | 「背景知識・作者・関連する情報を調べてまとめましょう」 |

## Week 1：紹介とブック・トーク

### Day 1：リテラチャー・サークルとは何か

全体で説明する：
- 「今日から、みなさんが選んだ本を小さなグループで読んで話し合います」
- 「グループの話し合いは、みなさんが進めます。先生は外から見ています」
- 「話し合いの準備のために、それぞれ役割を持って読んできます」

### Day 2〜3：ブック・トーク（本の紹介）

教師が候補本を1冊あたり1〜2分で紹介する（ブック・トーク）：
- あらすじではなく「なぜこの本が面白いか」「どんな問いがある本か」を伝える
- 最初のページや印象的な一場面を読んで聴かせる
- 「読んでみたい？」という問いで止める（答えを言わない）

### Day 4：本の選択とグループ形成

- 生徒が第1〜第3希望を書いて提出
- 同じ本を選んだ4〜6人でグループを形成
- グループの中で「最初の役割分担」を決める（くじ引きでもよい）

---

## Week 2：役割シートの練習（全役割）

### Day 1〜2：役割のモデリング

各役割を教師がシンクアラウドでモデリングする：

> 「私は今日、討議リーダーです。この章を読んで、みんなで話し合いたい問いを考えます。例えば……この場面で主人公がとった行動、なぜそうしたと思いますか？これが私の問いです」

全員が同じ範囲を読んでくる（モデリング用の共通本を使う）。

### Day 3〜5：初めての本番

各グループが選んだ本を第1章分読んで、役割シートを持ち寄る：

```
対話の時間の流れ（20〜25分）：
  0〜3分   全員が役割シートを手元に広げ、一人ずつ「自分の担当を確認」
  3〜18分  生徒主導の対話（教師は巡回・観察のみ）
  18〜23分 「今日の対話で読みが変わったことは？」を各自1文で書く
  23〜25分 次の範囲を決め、役割をローテーションする
```

**教師の動き**：巡回しながら観察メモを取る。グループが詰まっていたら「今、誰の問いから始めますか？」と返して外に出る。

---

## Week 3〜4：役割の深化と評価

### 役割ごとの振り返り（Week 3の最初）

全体で問う：
- 「どの役割が一番対話を動かしましたか？」
- 「どの役割が難しかったですか？理由は？」
- 「役割シートなしでできそうな部分はどこですか？」

### 役割シートを「軽くする」

Week 3〜4 で段階的に役割シートを薄くする：

| 変更 | 内容 |
|---|---|
| 記入欄を減らす | 3項目 → 2項目（重要な部分だけ残す）|
| 「自由枠」を追加 | 役割以外で気になったことも書いてよい欄 |
| 役割の選択制 | 「今回は好きな役割を1つ選んで来て」 |
| 準備メモ（自由形式）へ | 役割シートの枠を取り、「今日話したいことを自由にメモ」|

---

## Week 5〜6：役割なしへの移行

### 「補助輪を外す」セッション

役割シートなしで1回試す：
- 「今日は役割シートなしで、今まで学んだ全ての役割を自分の中に持って話し合ってみましょう」
- 「討議リーダーの問いも、コネクターのつながりも、言葉の達人の発見も——全部自分で用意して来ます」

終わった後に振り返る：
- 「役割シートなしで、どうでしたか？」
- 「どんな準備をして来ましたか？」
- 「次もなしで行けそうですか？」

---

## 対話の質を高める：教師の観察ノート

教師は巡回しながら次の観点で観察メモを取る：

```
グループ名：___________  日時：___________
□ 全員が話しているか？　□ 本のページを参照しているか？
□ 仲間の発言を受け取っているか？　□ 考えが変わっているか？

特に印象的な発言：
___________________________________

役割シートを消してよいタイミングかの判断：
□ まだ早い　□ 次回から軽くする　□ 外してよい
```

この観察メモが、役割消去のタイミングを判断する根拠になる。

## よくある問題への対処

| 問題 | 対処 |
|---|---|
| 役割シートの填充が目的化している | 「今日いちばん話したかったことは何だった？」と聞く。シートではなく本の話に戻す |
| 討議リーダーだけが話す | 「次は別の人の役割から聞いてみよう」とグループに伝える |
| 本を読んで来ない子がいる | 範囲を短くする。授業内に読む時間を確保する。読んできた部分だけで参加できると伝える |
| 教師が対話に入ってしまう | 物理的に離れる（教室の別の場所で観察する）。「先生が入ると生徒が先生に話しかける」 |
| 役割を消したら対話が崩壊した | ローテーションに戻す（失敗は消去が早すぎたサイン）。今後は段階をゆっくりにする |

## 本の選択のバリエーション

| 形式 | 説明 |
|---|---|
| **同一本サークル** | クラス全員が同じ本を読み、異なるグループで対話する |
| **複数本サークル** | 複数の候補本を同時に扱い、グループごとに違う本（最も一般的） |
| **ノンフィクション・サークル** | 理科・社会の読み物や新聞記事を使う——内容教科の読解力育成に |
| **短編集サークル** | 短編小説・詩・エッセイを使い、1回で1作品が完結する形式 |

## 定常稼働：リーディング・ワークショップとの連動

リテラチャー・サークルは単独の活動としてだけでなく、リーディング・ワークショップのコンポーネントとして組み込める：

```
RW の週間スケジュール例：
月・火：ミニレッスン → 独立読書（自分の本）
水：リテラチャー・サークルの準備読書
木：リテラチャー・サークルの対話（グループ討議）
金：全体シェア・振り返り
```
