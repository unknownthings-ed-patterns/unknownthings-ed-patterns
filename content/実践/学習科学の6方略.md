# 学習科学の6方略

認知心理学の研究から導かれた6つの学習方略を、授業設計に落とし込む実践ガイド。「明日から1つだけ試す」という視点で使う。

## この実践で働くパタン

- [[パタン/間隔学習]] — 一度に詰め込まず、時間を空けて思い出す機会を作る。
- [[パタン/インターリービング]] — 似た問題を混ぜ、使い分ける判断を育てる。
- [[パタン/テストを繰り返す]] — 覚えたかを読むだけでなく、思い出す行為で強める。
- [[パタン/精緻化]] — なぜそうなるかを説明し、知識同士をつなげる。
- [[パタン/具体例]] — 抽象的な考えを、複数の例で支える。

## 6方略の全体像

| 方略                   | 核心                                 | 授業での位置づけ           |
| ---------------------- | ------------------------------------ | -------------------------- |
| **間隔学習**           | 分散した練習が長期記憶を作る         | 単元をまたぐ復習の設計     |
| **検索練習**           | 思い出すことが記憶を強化する         | 授業冒頭・終わりの確認活動 |
| **インターリービング** | 種類を混ぜた練習が判断力を育てる     | 宿題・練習問題の設計       |
| **精緻化**             | 「なぜ？」が知識をネットワーク化する | 発問・ディスカッション     |
| **具体例**             | 多様な具体例が抽象概念を定着させる   | 説明・板書の設計           |
| **二重符号化**         | 言語＋視覚が記憶の経路を増やす       | ノート・ワークシート・板書 |

## 方略1：間隔学習（Spacing）

**核心**：同じ内容を「忘れかけた頃」に繰り返し思い出すことで、長期記憶への定着が大幅に向上する。

### 授業での実装

**最小実装（今日から）：授業冒頭の想起ウォームアップ**

> 「前回の授業で学んだことを3つ書いてみよう」（2〜3分）

- 書かせてから全体で確認する
- 「前の前の授業」「先週」のことを聞いても良い
- 採点しない——練習として行う

**週単位の設計**

| 時点     | 活動                            |
| -------- | ------------------------------- |
| 次の授業 | 前回の3問想起ウォームアップ     |
| 1週間後  | 週末宿題に先週の単元を1問追加   |
| 1ヶ月後  | 月1回の「まとめ検索練習シート」 |

**注意**：詰め込みは直後には効くが数週間で忘れる。間隔練習は練習中は難しく感じるが長期記憶に残る。

→ 詳細: [[パタン/間隔学習]]

## 方略2：検索練習（Retrieval Practice）

**核心**：情報を「受け取る（再読）」より「取り出す（想起）」行為が記憶を強化する。テストは評価のツールではなく学習のツールだ。

### 授業での実装

**最小実装（今日から）：エグジットチケット**

授業終わりの5分に：

> 「今日学んだ最も重要なことを2つ書こう」  
> 「今日の授業で一番驚いたことは？」  
> 「今日学んだことを知らない友達に説明するとしたら？」

**授業冒頭の3問テスト（採点なし）**

```
1. ______とはどういう意味か？（語彙）
2. 前回の授業で出た____の式を書いてみよう
3. ____と____の違いは？
```

書いた後に答えを確認する。「覚えていなかった問題が最も記憶に残る」（ポジティブな誤り経験）

**形式の多様化**

| 形式               | 例                                               |
| ------------------ | ------------------------------------------------ |
| 自由再生           | 「今日の授業で学んだことを全部書こう」           |
| 穴埋め             | 「***は***の時に起きる」                         |
| キーワードから説明 | 「光合成」という言葉から説明できることを全部書く |
| 友達に説明         | ペアで「今日学んだことを1分で説明し合う」        |

→ 詳細: [[パタン/テストを繰り返す]]

## 方略3：インターリービング（Interleaving）

**核心**：同じ種類の問題を固めて練習するより、異なる種類を混ぜた練習の方が「どれを使うべきか」の判断力が育つ。

### 授業での実装

**最小実装（今週から）：宿題の最後3問を混合に**

今日の単元の問題 7問 + 先週の単元から 1問 + 先々週の単元から 1問 + 先月の単元から 1問

**タイミングの判断**

- **初期学習中（まだ理解できていない段階）**：ブロック練習でOK
- **理解が安定した段階（「一応解ける」）**：インターリービングに移行

**学習者への説明（必須）**

> 「混ぜた練習は難しく感じます。でも、それは力になっている証拠です。どのやり方を使えばいいか判断する練習をしているからです」

→ 詳細: [[パタン/インターリービング]]

## 方略4：精緻化（Elaboration）

**核心**：「なぜ？」「どのように？」を問うことで、新しい知識と既存の知識がつながり、使える理解になる。

### 授業での実装

**最小実装（今日から）：1問の精緻化発問**

どの授業にも最低1問追加する：

- 「なぜそうなるの？」
- 「他にどんな場合に使える？」
- 「これと似ているものを知っている？」
- 「この逆のことが起きたらどうなる？」

**精緻化的質問（Elaborative Interrogation）の型**

| 質問の型   | 例（理科「光合成」）                 |
| ---------- | ------------------------------------ |
| 理由を問う | 「なぜ植物は光が必要なの？」         |
| 機能を問う | 「光合成がなかったら何が起きる？」   |
| 類推を問う | 「人間でいうと食事と何が似ている？」 |
| 範囲を問う | 「光合成ができない植物もある？」     |

**ペア説明（2分）**

「今日学んだことを、まだ習っていない友達に説明するとしたら？」→ ペアで交代説明

→ 詳細: [[パタン/精緻化]]

## 方略5：具体例（Concrete Examples）

**核心**：抽象的な概念に多様な具体例を添えることで理解と記憶が深まる。1つの例より、異なる文脈からの複数例が概念の一般化を助ける。

→ 詳細: [[パタン/具体例]]

### 授業での実装

**最小実装（今日から）：説明に例を2つ以上添える**

「分数とは整体の一部を表す数です」（抽象）
↓
「ピザを4等分した1つが1/4。時間を4等分した1つ（15分）も1/4。お金を4等分した1つ（25円）も1/4。」（3つの文脈から具体例）

**具体例の設計ポイント**

- **馴染みある文脈から始める**：子どもの日常生活から取る
- **複数の文脈から持ってくる**：食べ物・スポーツ・生活・自然など
- **誤例（non-example）も示す**：「これは○○ではない例」が概念の境界を明確にする

**子どもに例を作らせる**

「今日学んだことの例を1つ作ってみよう」→ 自分で例を作る行為が精緻化にもなる。作れない＝まだ理解できていないシグナル。

## 方略6：二重符号化（Dual Coding）

**核心**：言語情報と視覚情報を組み合わせると、脳の2つの記憶経路（言語系・視覚系）に記録が残り、どちらかが取り出しにくくてももう一方から想起できる。

### 授業での実装

**最小実装（今日から）：板書に図・絵を1つ追加する**

言葉で説明しながら黒板に図を描く。説明のキーワードを囲む・矢印でつなぐだけでも効果がある。

**二重符号化の形式**

| 形式               | 実装例                                     |
| ------------------ | ------------------------------------------ |
| テキスト＋図       | 概念の説明に概念図・フローチャートを添える |
| テキスト＋イラスト | 物語の場面に絵を描く                       |
| テキスト＋表       | 複数の概念を表で比較する                   |
| 言葉＋実物         | 実物・模型を見せながら言葉で説明する       |
| 言葉＋身体動作     | ジェスチャーや実演を言葉に添える           |

**学習者に絵・図を描かせる**

「今日学んだことを絵や図で表してみよう」→ 描くこと自体が視覚符号化になる。言葉で説明できなくても、絵で表現できることがある。

**注意**：装飾的な絵は逆効果。概念の構造を表す図が有効。

→ 詳細: [[パタン/マルチモダール]]

## 神話：「学習スタイル」について

「この子は視覚型だから絵で教える」「この子は聴覚型だから話して教える」——これは科学的根拠がない。

**研究が示していること**：

- 学習スタイルに合わせた指導が効果的だという実証研究は存在しない
- 90%以上の教師が信じているが、繰り返し否定されている
- すべての子どもが6つの方略から恩恵を受けられる

→ 学習スタイルで子どもを「分ける」のではなく、全員が6つの方略を使えるよう設計する。

| ------------ | ------------------------------------------ | ---------------------------- |
| 授業冒頭 3分 | 前回の想起ウォームアップ（3問を書く）      | 検索練習・間隔学習           |
| 導入 5分     | 今日のねらいを視覚化した板書               | 二重符号化                   |

| 発問 5分     | 「なぜ？」「どんな場合に？」               | 精緻化                       |
| 授業末 5分   | エグジットチケット（今日学んだことを書く） | 検索練習                     |
| 宿題         | 今日の問題＋先週・先月の問題               | インターリービング・間隔学習 |

## 6方略に共通する原理：望ましい困難

6方略すべてに共通する認知原理がある——「楽に感じる学習法ほど長期記憶への定着が弱く、難しく感じる学習法ほど定着が強い」。これを **望ましい困難（Desirable Difficulties）** と呼ぶ。

各方略が「難しく感じる理由」と「効果がある理由」は直結している：

- 間隔学習 → 忘れかけているから難しい → だから想起努力が記憶を強化する
- インターリービング → どれを使うか判断が必要で難しい → だから弁別力が育つ
- 検索練習 → 取り出しにくいから難しい → だからその行為が記憶を強化する

**これを学習者に伝えることが6方略の実践を成功させる鍵。**

> 「この練習が難しく感じるのは、脳が一生懸命働いている証拠です。楽に感じる再読より、難しく感じる想起練習の方が1週間後にはるかに多く覚えています」
