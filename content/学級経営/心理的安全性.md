# 心理的安全性（学級経営実践）

間違い・未完成・挑戦を出せる安心の土台を、クラスの中に意図的に設計する。

---

## 核心

> 安心できる基盤があってこそ、挑戦への動機が生まれる。

心理的安全性のない教室では、どんな動機付け技術も効果が半減する。まず「ここは安全だ」という感覚を作ることが、すべての学習の前提になる。

---

## 心理的安全性を育てる実践

### 1. 間違いを「資源」として価値付ける

「間違いをありがとう。それで全員が考えられた」という言葉を繰り返す。間違いが出た瞬間が、最大の教育のチャンス。

- → [[パタン/間違いや失敗から学ぶ文化]]
- → [[パタン/成長マインドセット]] — 「まだできていない」は成長の途中を示す

### 2. 「できていること」を可視化する

失敗・困難に注目するのではなく、できていることを見える形で積み上げる。ほめられる機会の設計が「ここは安全だ」という感覚の土台になる。

- → [[パタン/ビッグメッセージ]] — 教室全体への価値観メッセージを繰り返す
- → [[パタン/適切な行動に注目する]] — 望ましい行動に光を当てる
- → [[パタン/可視化]] — 学習の進歩や成果を見える形にする

### 3. 安心して待機できる場所をつくる

集団参加が難しい子に、無理に参加を迫ることは安全性を破壊する。「ここにいていい」という場所を教室内に用意することが、逆に参加への動機を生む。

- → [[パタン/環境調整]] — 物的・空間的な安全基地の設計
- → [[パタン/段階的クールダウン]] — 落ち着ける場所の構造的担保
- → [[特別支援/特別支援級の算数指導]] — 特別支援での安全性設計の実践例

### 4. 伝える手段をつくる

「助けを求めたら応えてもらえた」という体験の積み重ねが援助要求スキルを育てる。援助要求が育っている状態は、心理的安全性が機能している証拠でもある。

- → [[パタン/援助要求スキル]] — 助けを求める行動を育てる
- → [[パタン/合図システム]] — 伝える手段があるという安心感

### 5. 発言・対話の規範をつくる

「どんな発言も受け止める」という発言規範が安全性を構造化する。教師が「おもしろい考えだね」「その見方はあったか」と受け止め続けることで規範が育つ。

- → [[パタン/心理的安全性（コンフォートゾーン）]] — 認められる経験を積み重ねる
- → [[パタン/リヴォイシング（発言を言い換えて確認する発話）]] — 発言を肯定的に言い換えて返す

---

## 特別支援での配慮

発達障害のある子どもへの支援では、心理的安全性は「環境調整の前提」として機能する。

| 状況 | 対応 |
|------|------|
| 集団参加が苦手（感覚疲弊） | 安心して待機できる場所を教室内に用意する |
| 失敗・批判への過剰反応 | 「できていること」を先に言語化して認める |
| 援助要求が難しい | カードやサインなど伝える手段を複数用意する |

---

## 課題・注意点

- 安心すぎると必要な挑戦が起きにくくなる——[[パタン/アドベンチャー]] との緊張関係を意識する
- 教師自身の「失敗への反応」が安全性を最も大きく左右する
- 一度崩れた安全性を回復するには、壊す何倍もの時間がかかる
