# Low Floor High Ceiling タスク集（算数）

Jo Boaler（スタンフォード大学）の提唱する「Low Floor, High Ceiling（LFHC）」の考え方に基づくタスク。

---

## LFHCとは

> 「誰でも入れるが、どこまでも深められる」タスク設計。

- **Low Floor（低い床）**: 事前知識が少なくても取り組める入り口がある
- **High Ceiling（高い天井）**: 上限がなく、深く・広く探究できる
- 正解が一つでなく、複数の方法・表現が尊重される
- 操作・絵・言葉・式など様々な表現方法で考えられる

参考: Jo Boaler（youcubed.org）、`2026-04-16 Jo Boaler.md`

---

## アンカー課題としての活用

このタスク集は[[特別支援/特別支援級の算数指導]]の「アンカー課題の引き出し」としても機能する。
1・2・5年生が同じ教室にいる状況で、同じタスクを異なる深さで取り組める点が特に有効。

---

## 1年生向けタスク（3つ）

### 1-A ｜ 10をつくろう

**問い**: 10になる2つの数の組み合わせを全部見つけよう。

| Low Floor         | →   | High Ceiling            |
| ----------------- | --- | ----------------------- |
| ブロックや指を使って1+9から試す |     | 3つ以上の数で10を作る            |
| 絵に描いて確かめる         |     | 組み合わせに対称のパターンがあることを発見する |
| 先生と一緒に1つ見つける      |     | 「全部で何通りあるか」を証明する        |

**準備物**: ブロック、10マスのフレーム（ten-frame）、ホワイトボード

**問い返し**:
- 「他の方法でも10になる？」
- 「ぜんぶ見つけたって、どうしてわかる？」
- 「0を使うとどうなる？」

---

### 1-B ｜ かたちをつなげよう

**問い**: パターンブロック（三角・四角・六角形など）を使って好きな形を作ろう。何枚使った？どんな形になった？

| Low Floor | →   | High Ceiling           |
| --------- | --- | ---------------------- |
| 自由に並べる    |     | 同じ形を別の組み合わせで作る         |
| 何枚使ったか数える |     | 左右対称になる形を探す            |
| 色と形の種類を言う |     | 三角形だけで大きな三角形を作る（何枚必要？） |

**準備物**: パターンブロック（またはポリドロン）

**問い返し**:
- 「この形、三角形だけで作れる？」
- 「もっと大きな同じ形を作るには何枚いる？」

---

### 1-C ｜ どちらが多い？いくつ違う？

**問い**: 2色のおはじきを両手でひとつかみずつ取る。どちらが多い？いくつ違う？

| Low Floor   | →   | High Ceiling       |
| ----------- | --- | ------------------ |
| 1つずつ並べて比べる  |     | 差を足し算・引き算で表す       |
| どちらが多いか判断する |     | 「どうしたら同じ数になる？」を考える |
| 数を数える       |     | 何回やっても一方が多くなるかを調べる |

**準備物**: 2色のおはじき（または豆・ブロック）

**問い返し**:
- 「同じ数にするには、どちらから何個移せばいい？」
- 「何回やっても、なんで赤が多くなることがあるの？」

---

## 2年生向けタスク（3つ）

### 2-A ｜ 100のなかま

**問い**: 合わせて100になる2つの数の組み合わせをできるだけたくさん見つけよう。

| Low Floor         | →   | High Ceiling           |
| ----------------- | --- | ---------------------- |
| 50+50, 60+40から始める |     | 1の位・10の位に規則性があることを発見する |
| 数直線や百マス表を使う       |     | 3つ以上の数で100を作る          |
| 絵や図で表す            |     | 「全部で何通り？」を説明できる        |

**準備物**: 百マス表、数直線カード

**問い返し**:
- 「1の位の数字を見ると、何か気づく？」
- 「3つの数でも100にできる？それは何通り？」

---

### 2-B ｜ 同じ数に分けると

**問い**: 12このチョコレートを友達みんなに同じ数ずつあげます。何人に分けられる？何通りの分け方がある？

| Low Floor      | →   | High Ceiling                |
| -------------- | --- | --------------------------- |
| 12個の絵を描いて分ける   |     | 全通りを表に整理する                  |
| 2人・3人・4人と順番に試す |     | 「割り切れる数」と「割り切れない数」のちがいを説明する |
| ブロックを実際に並べる    |     | 1人分 × 人数 = 12 という式の構造に気づく   |

**準備物**: ブロック12個、方眼紙

**問い返し**:
- 「5人に分けられる？なぜ？」
- 「1人分の数と人数を掛けるとどうなる？」
- 「12の「なかよし数（約数）」を全部見つけられる？」

---

### 2-C ｜ 手のひらで測ろう

**問い**: 自分の手のひらの幅を「1手」として、教室のいろいろなものを測ってみよう。みんなの答えはそろう？

| Low Floor     | →   | High Ceiling               |
| ------------- | --- | -------------------------- |
| 手のひらで何回分か測る   |     | 人によって手の幅が違うから答えがずれることに気づく  |
| 長いもの・短いものを比べる |     | 「みんなが同じ答えになるには？」→ 標準単位の必要性 |
| 予測してから測る      |     | cmに換算する（自分の手の幅は何cm？）       |

**準備物**: メジャー・定規（後半用）

**問い返し**:
- 「どうしてAさんとBさんの答えが違ったの？」
- 「ずっと前の人たちは、どうやってこの問題を解決したんだろう？」

---

## 5年生向けタスク（3つ）

### 5-A ｜ 分数の間に何がある？

**問い**: 1/2より小さくて、1/3より大きい分数をできるだけたくさん見つけよう。

| Low Floor        | →   | High Ceiling                  |
| ---------------- | --- | ----------------------------- |
| 数直線に1/2と1/3を書く   |     | 何個でも見つかることに気づく（稠密性）           |
| 2/5, 3/8などを試してみる |     | 小数や帯分数との比較                    |
| 図（面積図・テープ図）で確かめる |     | 「この2つの分数の間に必ずある分数」の作り方（メジアント） |

**準備物**: 数直線ワークシート、方眼紙

**問い返し**:
- 「1/2と1/3の間の分数は何個ある？」
- 「全部見つけることはできる？なぜ？」
- 「分母が10以下で見つけられる分数は何個？」

---

### 5-B ｜ 面積が同じ形をつくろう

**問い**: 面積が16マスになる図形を方眼紙にできるだけたくさん書こう。同じ面積でも形はどれだけ違えられる？

| Low Floor              | →   | High Ceiling             |
| ---------------------- | --- | ------------------------ |
| 4×4の正方形から始める           |     | L字型・凹凸のある形・斜めの辺がある形      |
| 長方形（1×16, 2×8, 4×4）を探す |     | 周りの長さを比べる（面積が同じでも周長は違う）  |
| 図を描いて面積を数える            |     | 「面積が同じで周長が一番短い形は？」（等周問題） |

**準備物**: 方眼紙（5mm方眼）、色えんぴつ

**問い返し**:
- 「面積が同じでも、形が全然違うね。周りの長さはどう？」
- 「周りの長さが一番短くなるのはどんな形？」
- 「辺が斜めでも面積を求められる？」

---

### 5-C ｜ 100をわり算で調べよう

**問い**: 100を1から20の数で割ってみよう。割り切れる数はどれ？余りに規則性はある？

| Low Floor | → | High Ceiling |
|-----------|---|--------------|
| 電卓や筆算で1つずつ試す | | 割り切れる数（100の約数）を全部見つける |
| 表に整理する | | 余りの数列を書き出してパターンを発見 |
| 割り切れる・切れないを分類 | | 「なぜ7で割ると余りが周期的になるのか」を説明する |

**準備物**: 表のワークシート、電卓（導入として）

**問い返し**:
- 「割り切れる数は全部で何個ある？」
- 「同じ余りが出る数のペアはある？」
- 「100の約数の個数って、どうやって求める？」

---

## タスクを使うときのヒント

1. **最初の問いは短く**: 長い説明より、シンプルな「問い」を黒板に書くだけでよい
2. **最初はひとりで**: グループ前に自分でしばらく考える時間を確保
3. **複数の表現を歓迎**: 絵・言葉・数式・表、どれで答えてもよいと伝える
4. **「全部見つけた」に問い返す**: 「どうしてそれが全部だとわかる？」
5. **教師は問い返す役**: 答えを教えるのではなく [[パタン/問い返しのデザイン]] を使う
