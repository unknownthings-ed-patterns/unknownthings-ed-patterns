# Practice with Purpose（Diller, 2005）

Diller, D. (2005). *Practice with Purpose: Literacy Work Stations for Grades 3-6*. Stenhouse Publishers / Pembroke Publishers. ISBN 1-57110-395-3

著者は40年以上の小学校教師経験を持つリテラシーコンサルタント。Title I 読書専門家、リテラシーコーチを経て教育コンサルタントとして活動。*Literacy Work Stations: Making Centers Work*（K-2対象）の成功を受け、中学年（3〜6年生）の教室での実装を体系化したのが本書。

---

## 要約

### 核心の問いと答え

**問い**：小グループ読書指導を行っている間、クラスの残りの子どもたちは何をしているべきか？

**答え**：「目的のある練習（Practice with Purpose）」——教えた内容を2人組で意味のある形で練習する「リテラシー・ワークステーション」に取り組む。

Diller が30年のキャリアで一貫して問い続けた言葉は「なぜ？何の目的で？（Why? What's the purpose?）」。この問いが本書の基盤だ。ワークステーションが「フラフとお飾り（fluff and frills）」にならないために、目的を持った本物のリテラシー実践を設計することを徹底する。

---

### GRR（段階的手放し）の明示的な適用

Diller は Pearson & Gallagher（1983）を明示的に引用し、本書全体の理論的枠組みとして GRR を位置づける。

**3ゾーンモデル（Figure 1.3）**：

| ゾーン | 教師の関与 | 主な形式 |
|-------|---------|---------|
| **Modeling（モデリング）** | 全責任を持つ | 読み聞かせ・モデルライティング・ミニレッスン |
| **Handholding（手を引く）** | 共同で支援する | 共有読書・ガイデッド・リーディング・ペア練習 |
| **Independence（独立）** | 観察・フィードバック | **ワークステーションでの練習** |

**洗濯の比喩（Laundry Analogy）**：洗濯のやり方を「見せる → 一緒にやる → 手を取ってやる → 一人でやる」。この比喩で GRR を保護者・生徒に説明できる。

**設計の鉄則**：「ステーションに入れる活動は、必ず Modeling または Handholding ゾーンで先に教えたものだけ」——教えていない活動は Independence で機能しない。

---

### ワークステーション vs. センター

従来の「学習センター（centers）」は、活動が次々と変わり、教師が常に新しい材料を用意し続けることが多かった。Diller のワークステーションは違う：

| センター（従来型） | ワークステーション（Diller） |
|---|---|
| 頻繁に材料を交換する | 同じステーションを2〜4週間使い続ける |
| 活動が独立していることが多い | 授業（ミニレッスン・小グループ指導）と直結 |
| 「何かをさせる」 | 「すでに教えたことを練習させる」 |
| 教師が材料を作る | 教師と生徒が一緒に作る |
| 教師がチェックする | ペアで互いにアカウンタビリティを持つ |

### 9種類のステーション——Easy First（Chapter 5）と Meatier Later（Chapter 6–9）

本書は「まず立ち上げやすいステーションから始め、複雑なステーションを後から追加する」という順序を強調する。

**立ち上げやすいステーション（Chapter 5）——年度初めに導入**：

| ステーション | 主な活動 |
|---|---|
| **リスニング** | テープ・CD に合わせて本を読む；mind picture を描く；語彙のハイライト |
| **バディ読書** | 同じ章を読んで対話；ノンフィクションのまとめを一緒に書く |
| **スペリング** | スペリングゲーム（スクラブル・ハングマン）；難語の視覚的イラスト |
| **オーバーヘッド** | 透明シートで校正；数学の操作的マテリアル |
| **コンピュータ** | 著者研究；WebQuest；ワードプロセッサで発表物を作成 |
| **ハンドライティング** | 筆記体練習；校長への手紙 |
| **新聞** | 子ども向け新聞を読む；記事の事実と意見を色分けする |

**複雑なステーション（Chapter 6–9）——スタミナが安定してから**：

| ステーション | 主な活動 |
|---|---|
| **ワードスタディ** | 語族探し・語源研究・ワードソート；Word Study Notebook（後述） |
| **詩** | 詩の音読；個人詩集（Poetry Anthology）の作成；推薦カード |
| **コンテント・エリア** | 理科・社会・地理・歴史テーマの探究読み書き |
| **ドラマ** | 役割読み・即興演技・One-Minute Sound Bite（後述） |

### "I Can" リスト——各ステーションの例

実際に本書のアペンディックスに掲載されている I Can リストから：

**リスニングステーション**：
```
□ テープ・CDに合わせて本を読む
□ 聞きながら頭の中の映像を描く→パートナーと比べる
□ 聞いた後で読書応答の選択肢から1つ選ぶ
□ 語彙をハイライトしてリストに書く
□ 読み手の声の使い方を真似して録音する
```

**ライティングステーション（初期）**：
```
□ 家族・友達への手紙を書く
□ ライティングフォルダの草稿を書き続ける
□ お祝い・感謝のカードを作る
□ パートナーに書いたものを読んで応答をもらう
```

**ポエトリーステーション（初期）**：
```
□ 好きな詩を探す
□ 詩を読んで感情を考える
□ 好きな詩を個人詩集に書き写す
□ 詩の中の好きな言葉を詩集の後ろのページに集める
```

**ドラマステーション（使用ルール形式）**：
```
□ 台本を選ぶ
□ 登場人物を決めてキャラクターカードを作る
□ 流暢さと表情をつけて読む
□ 要約・対話する
□ 役を交代して読む
```

### ドラマステーション——具体的な技法

単なる「劇をする」ではなく、複数の明示的技法が設計されている：

**「ハイライトされた語を強調する（Stress the Highlighted Word）」**：
1文を数回書き、毎回別の語をハイライトする
→ 強調する語を変えながら何度も音読し、横に解釈を書く
例：「That's a **fancy** new red car you're driving.」

**「感情を当てよう（Guess the Emotion）」**：
読み聞かせ本の台詞をカードに書き（表：台詞、裏：感情）
→ パートナーが劇的に読み、もう一人が感情を当てる

**「葛藤の台詞（Conflict Lines）」**（即興練習）：
- 「Where do you think they could possibly be?」
- 「I can't believe she actually did that!」
- 「This looks too dangerous!」
→ カードを引いて即興で場面を作る

**「プロット拡張（Plot Extension）」**：物語を読み、「物語の前」「物語の後」を即興演技で作る。

**「One-Minute Sound Bite」**：コンテント・エリアの学習内容を使って1〜2分のニュース台本を作り、録音する。

### ワードスタディステーション——具体的な活動

**Word Trees（語木）**：ギリシャ語・ラテン語の語根を「根」に書き、枝に派生語を書く。語族のつながりを視覚化する。

**Word Ladders（語段）**：2文字の語から始め、1文字ずつ変えながら新しい語を作って段を登る。例：at → sat → spat → splat → splats → splits → splints

**Word Sorts（語の分類）**：4ステップ——①分類する→②読む→③書く→④振り返って語を追加。スピードソート（タイマーで自己記録更新）。

**Word Study Notebook（語彙ノート）**：Interesting Words・Word Play・Spelling Patterns・Content-Area Words の4セクションで管理する作文帳。ライティングステーションにも持ち込む。

**4種類の上学年ワードウォール**：
1. **Mini-High-Frequency Wall** — よく誤る語（常に正確な綴りが求められる）
2. **Interesting Words Wall** — 読み聞かせ由来の語を品詞別・本のタイトル別に展示
3. **Content-Area Word Wall** — 単元ごとに交換する教科語彙チャート
4. **Homophones Chart** — 生徒が意味の違いを示すイラストを描いて掲示

### コンテント・エリアステーションの例

**地理ステーション**（ラテンアメリカ単元の例）：白地図に鉛筆で「予測」→アトラスで「確認」→説明文を書く

**歴史ステーション**：黒板下の年表にベルクロで年表カードを配置。「もし主要な出来事が一つなかったら？」というカード問いで探究

**理科ステーション（水循環壁画）**：壁画に付箋で説明・発見・疑問を追加

**クイックライト活動**：タイマー3〜6分、トピックカードを引いて知っていることをすべて書く

### 起動タイムライン

本書が示す段階的な起動の流れ：

| 時期 | 行動 |
|------|------|
| **最初の2週間** | 独立読書と応答ライティングのみ。教室ライブラリを整備。毎日1つのミニレッスン |
| **3週目以降** | 独立読書のルーティンが安定してから、静かな独立読書中に小グループを始める |
| **最初の1ステーション** | 1日10〜15分から。1週間は1ステーションのみ |
| **徐々に追加** | 1週間ごとに1ステーション追加。5〜7ステーション稼働で管理ボードを使う |
| **1か月目** | 教師は教室を巡回して支援（小グループ指導ではなく）。ルーティンが確立してから小グループへ |
| **ドラマ・詩ステーション** | 年度後半に追加。「立ち上げやすいステーション」が安定してから |

### 評価戦略

**基本原則**：「ワークステーションは練習の場。すべてに成績をつける必要はない。評価は一定期間練習した後の評価のためにある。」

**4〜5人/日の観察ローテーション**：毎日4〜5人の子どもを観察し、メモを取る。週でクラス全員をカバーする。

**読書ログの週次回収（段差方式）**：25人のクラスなら1日5冊ずつ回収・確認。火曜7人・水曜6人・木曜6人・金曜6人という掲示スケジュール。

**語彙ノートの評価**：1〜2週間ごとに収集して採点。何を期待するか（例：週5〜10語の収集）を事前に明示。

**「目で見てわかる（Eyeballing）」**：教師が歩いて通り過ぎるだけで子どもが取り組んでいるかが分かる——これが機能している証拠。特にドラマステーションはすぐわかる。

**成績対象となる成果物**：ライティングステーションで書いた文章・本レビュー。対象外：すべての練習ワークシート。

**振り返りカード（リング綴じ）**——毎日1枚引いて全体で振り返る：
- 「今日の独立時間で何を学んだか？」
- 「どのステーションが楽しかったか？なぜ？」
- 「自分をより良い読者・書き手にするために今日したことは？」
- 「ワークステーションをどう変えたいか？」

### 学年別の相違点——K-2 vs. 3-6

| K–2 | 3〜6年 |
|---|---|
| ワークステーションと独立読書時間は別 | 独立読書をワークステーション時間内に含む |
| 1日2〜3ステーションを巡回 | **1日1ステーション**（より長い時間集中） |
| ステーション滞在10〜15分 | **20〜30分滞在**（読み書きのスタミナが増大） |
| ペアで小声読みOK | **基本的に無音**（ELL児童は囁き読みOK） |
| ABCワードスタディ中心 | 語源・ギリシャ語ラテン語根・語彙の深化 |
| 簡単な劇遊び | リーダーズシアター・即興劇・プロット拡張 |
| 活動中心のコンテント・エリア | 探究・調査研究中心のコンテント・エリア |

## 重要な引用

> 「なぜ？何の目的で？（Why? What's the purpose?）」——Diller が30年問い続けてきた言葉

> 「リテラシーセンターは、あなたが教えているスキルから始まることで、目的を持った練習を提供できる。鍵は、フラフとお飾りでなくコンテントに集中すること。」

> 「I Can リストは理想的には生徒と一緒に作る——そうすることで生徒がその仕事を自分のものとする。」

## 教育実践への示唆

1. **GRR を設計原則にする**：「このステーション活動をミニレッスンで教えたか？」が唯一の問い——答えが「否」なら、先にミニレッスン

2. **Chapter 5 の easy ステーションから始める**：リスニング・バディ読書・スペリングは立ち上げやすい。ドラマ・詩・コンテント・エリアは年度後半

3. **「全部グレードしない」を守る**：評価疲れを避けるため、成果物は厳選して評価。練習は練習、評価は評価

4. **3-6年：1ステーション/日・20〜30分**：K-2とは根本的に構造が違う——時間の長さと「1日1か所」が独立性を深める

5. **ドラマステーションは年度後半に、十分な技法を持ってから**：単なる「劇をする」でなく、Stress the Highlighted Word・Guess the Emotion・Conflict Lines 等の具体的技法を先に教える
