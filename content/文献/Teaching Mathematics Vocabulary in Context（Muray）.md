# Teaching Mathematics Vocabulary in Context（Muray, 2004）

> 「数学の語彙は、定義を暗記させるのではなく、意味のある文脈の中で教えなければならない」——Miki Muray

## 要約

- 数学語彙は「定義リストを覚えさせる」従来型指導では定着しない。語彙は**文脈の中で、使いながら**習得される
- 著者は語彙習得の3つのルートを**窓（Windows）・扉（Doors）・秘密の通路（Secret Passageways）**と名付ける
- **窓**：語彙を「見る」だけの受動的な露出（黒板・教材に出てくるが意識されない段階）
- **扉**：語彙への意図的な入り口——教師が意識的に開く「教える場面」（明示的指導）
- **秘密の通路**：語源・他教科・日常語との接続など、予期しない発見ルートで語彙の深みへ至る道
- 数学語彙には固有の難しさがある：日常語と異なる意味を持つ言葉（table、mean、square、right angle…）が多く、子どもは混乱しやすい
- 語彙の定着には**複数のチャンネル**が必要：視覚（図・絵）、言語（説明・討論）、書く（語彙ノート）、身体（操作・ジェスチャー）
- **語彙ノート（Vocabulary Notebook）**は核心的なツール。用語・定義・図・自分の言葉での説明・例・非例を1ページにまとめる
- **語の仲間探し（Word Sort）**：語彙を分類・グルーピングすることで概念の構造を理解する
- 語源（etymology）と語形素（morpheme）の探索が「秘密の通路」を開く——quadrilateral の quad = 4、polygon の poly = 多数、など

## 重要な引用

> 「窓を開けるとき、子どもたちは語彙を『見る』。扉を開けるとき、子どもたちは語彙に『入る』。秘密の通路を見つけるとき、子どもたちは語彙の世界の中で自ら動き始める」

> 「数学語彙を孤立して教えると、子どもたちは定義のコピーを持つが、その語彙を使って考えることができない」

## 教育実践への示唆

- 単元の最初に語彙リストを配るのではなく、**問題文脈の中で語彙が必要になる場面を設計する**（扉を開く）
- 子どもが「この言葉、どういう意味？」と感じる**謎・違和感の瞬間**を作ることが「窓」になる
- 語彙ノートは「用語帳」でなく**思考の記録**——定義＋図＋「自分の言葉での説明」＋「例」＋「間違いやすいこと」を書く
- 語源探しは高学年・特別支援の子どもにとっても動機になる：「この言葉はどこから来た？」という問い
- 日常語と数学語の意味のズレを**明示的に取り上げる**（「学校では table は『表』、家では机——どこが同じ？違う？」）
- **非例（Non-example）**を語彙指導に使う：「これは平行四辺形か？」「これが平行四辺形でない理由は？」
- 算数用語辞典（バインダー内）はこのフレームワークで設計できる——窓・扉・秘密の通路の欄を設ける
