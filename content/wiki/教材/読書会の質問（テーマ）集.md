# 読書会／ブッククラブの質問（テーマ）集

> 読書会やブッククラブで「何を話せばよいか」を支え、あらすじ確認から読みの解釈、問い返しまでをつなぐ質問の道具。

## 教材の概要

読書会やブッククラブで使う質問・テーマの手引きである。原資料には「読書会のための質問（テーマ）集」と「ブッククラブのための質問集」があり、どちらもほぼ同じ構造で、読む前・読んでいる途中・読み終えた後・話し合いの途中に使える問いが整理されている。

読書会では、「自由に話していいよ」だけでは、感想の言い合いやあらすじ確認で止まりやすい。この教材は、読む前、読んでいる途中、読み終えた後、話し合いの途中に使える問いを用意し、子どもたちが本をめぐって対話できるようにする。

質問は、正解を当てるための発問ではなく、読みを開くための入口である。どの問いを選ぶかによって、読書会の焦点が変わる。

## 小さい付箋・書き出しの手引きとの関係

| 道具 | 役割 |
|------|------|
| [[教材/リーディング・ワークショップの小さい付箋]] | 本文中の話したい場所、根拠になる場所に印をつける |
| [[教材/読書反応の書き出しの手引き]] | 自分の考えを理由とともに付箋や読書ノートへ書き出す |
| 読書会／ブッククラブの質問（テーマ）集 | グループで何を話すか、どう問い返すかを選ぶ |

小さい付箋で場所を残し、書き出しの手引きで考えを準備し、この質問集で読書会の対話を始める。

## 使う場面

- ブッククラブの前に、話し合いのテーマを選ぶ
- 読書会中に、話が止まったときの次の問いを選ぶ
- 司会役やグループのメンバーが、友だちの発言に問い返す
- 読書会後に、話し合いの焦点を振り返る

全ての質問を一度に使う必要はない。今日の読書会では「登場人物」「作者の書き方」「結末」「自分とのつながり」など、焦点を一つ選ぶと使いやすい。

## 質問の種類

### 読む前に

- 本の題名からどんなお話だと想像しますか？
- 本のタイトルからどんなお話だと想像しますか？
- 本の表紙、裏表紙の絵から何がわかりますか？どんなお話だと想像しますか？
- この作者の他の本を読んだことはありますか？どんなお話でしたか？

### 読んでいる途中に

読んでいる途中のブッククラブでは、感想だけでなく、書いてあることの確認、解釈、予想、問い返しを行き来する。

### 感想から始める

- どこが面白かった？
- どこが面白かった？どこがつまらなかった？
- どこが心に残った？それはなぜ？
- どこが印象に残った？それはなぜ？
- どの登場人物が好き？どの人物がきらい？それはなぜ？

### 書いてあることを確認する

- 今回の範囲のあらすじは？
- だれが出てきた？
- どんなことが起きた？
- ここまでの話を整理すると？
- 登場人物はどんな性格？どんな外見？それはどこからわかる？

### 読んだことで考える

- ここがよくわからなかったんだけど、みんなはどう考えた？
- 自分が考えていたことが変わってきたんだけど、みんなはどう？
- なぜ登場人物は～のような行動をしたの？
- なぜ登場人物は～のようなことを言ったの？
- なぜ作者は～のような書き方をしたのだろう？
- なぜこんな表現にしたのだろう？
- なぜ～？
- この後どうなるだろう？その理由は？
- 前回の予想と同じだった？ちがった？なぜちがったのだろう？
- この登場人物が変わってきたのでは？どのように変わったか、なぜ変わったかを考えると？
- 登場人物のとった行動や言ったことに賛成？反対？どう思う？
- もし自分がこの人物だったら？
- 自分が作者なら、どんなストーリーにする？どんなふうに書く？
- 似たような経験はある？
- 登場人物同士の関係が変わってきた？どのように変わった？それはどこからわかる？
- ○○と○○を比べてみると？
- 作者はこの文から、またはこの章から、何を伝えたいのだろう？
- 何がこのお話の大事なポイントだろう？何が大事な話し合いのテーマだろう？

### 読み終えた後に

- この本は好き？嫌い？点数を付けるとしたら？その理由は？
- 誰におすすめしたい？
- 誰におすすめする？
- この作品の結末に賛成？反対？結末についてどう思う？
- 作者が伝えたかったことは何だろう？作者が伝えたかったことについてどう思う？
- 作者が伝えたかったテーマは何だろう？そのテーマについてどう思う？
- 登場人物はどのように変わった？なぜ変わった？
- 自分ならどんなタイトルにする？
- この本で覚えておきたいことは？

### 話し合いの途中で使う問い返し

- もっとくわしく教えて。
- どこからそう思った？
- どこに書いてある？
- 今のに付け足しだけど。
- 賛成。その理由は～。
- 私は違うふうに考えたんだけど、それは～。
- 例をあげてくれる？
- その理由は？
- もう一回言ってくれる？
- ○○はどう思う？
- もう一度読む時間をとって整理する？

## 追試するなら

読書会の最初は、質問を3つだけに絞る。

たとえば、最初の読書会では次の3つでよい。

1. どこが心に残った？それはなぜ？
2. 登場人物はどんな性格？それはどこからわかる？
3. どこからそう思った？

慣れてきたら、「作者の書き方」「登場人物の変化」「結末への賛否」など、読書会ごとにテーマを選ぶ。司会役だけが質問を持つのではなく、グループの全員が一つずつ質問を選んで持ち寄ると、話し合いが一人に依存しにくくなる。

## うまくいかないときの支援

| 困りごと | 支援 |
|----------|------|
| あらすじ確認だけで終わる | 「どこからそう思った？」「なぜ？」を使って根拠と解釈へ戻す |
| 話す人が偏る | 「○○はどう思う？」を使い、発言の入口を渡す |
| 感想が浅い | 「それはなぜ？」「例をあげてくれる？」で理由と具体例を聞く |
| 話が広がりすぎる | 「何が大事な話し合いのテーマだろう？」で焦点を戻す |
| 分からないところを出しにくい | 「ここがよくわからなかったんだけど」を教師がモデルとして言ってみせる |
| 本文に戻らない | 小さい付箋を貼ったところを開き、「どこに書いてある？」と聞く |

## この教材の意味

読書会の質は、どんな問いを持ち込むかで大きく変わる。

問いがないと、読書会は「面白かった」「この人物が好き」だけで終わることがある。けれども、「どこからそう思った？」「なぜ作者はこう書いたのだろう？」「この人物はどのように変わった？」という問いがあると、読みは本文、解釈、経験、作者の書き方へ広がる。

この質問集は、子どもたちが読書会を自分たちで進めるための対話の足場である。教師の発問に答えるのではなく、読者同士が問いを持ち寄り、読みを深めるための道具になる。
