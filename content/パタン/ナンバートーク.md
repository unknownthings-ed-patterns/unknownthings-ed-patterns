# ナンバートーク

> 一つの計算問題を全員が暗算で解き、複数の解法をクラスで共有する——この短い活動が、数を「手続き」でなく「概念」として扱う文化を育てる。

## 背景（Context）

算数の授業では、子どもたちは「1つの正しい解き方」を習い、それを繰り返す練習に多くの時間を使う。その結果、数を柔軟に扱う力（数感覚）が育たず、少し違う問題が出ると途端に動けなくなる。

Gray & Tall の研究では、高成績の生徒と低成績の生徒の差は「知識量」でなく「数との関わり方」にあることが示された——高成績の生徒は数を概念的・柔軟に扱い、低成績の生徒は暗記した手順に固執する。

ナンバートークは Kathy Richardson と Ruth Parker によって開発された短い指導活動で、Jo Boaler（2015）が「数感覚を養うための最高の方法の一つ」と評している。

## 問題（Problem）

手順を繰り返す練習だけでは、数の概念的理解が育たない。生徒は「なぜその計算が成り立つのか」を説明できず、文脈が変わると応用できない。また、「速さ＝賢さ」という誤ったメッセージが数学不安を生む。

## 力のかたち（Forces）

- 脳は概念のみを「圧縮」して記憶できる——手順の暗記は長いリストとして記憶に残り続ける
- 一つの計算問題に複数の解法があることを知らない子どもが多い
- 「どうやって解いた？」という問いを立てることが数学的推論の出発点になる
- 多様な解法を公平に扱うことで「自分のやり方がある」という感覚が生まれる

## 解決（Solution）

**一つの計算問題を出し、全員が暗算で解いてから複数の解法を共有する5〜10分の活動を定期的に行う。**

---

### 基本的な進め方

1. **問題を提示する**（口頭または黒板。例：`18 × 5`）
2. **全員が暗算で解く**——答えが出たら静かに親指を立てて合図（声に出さない）
3. **複数の答えを記録する**——正解・不正解を問わず挙げさせる
4. **解法を共有する**——「どうやって解いた？」を聞き、教師が黒板に図・式で描き出す
5. **解法を比較・検討する**——似ている点・違う点・より柔軟な方法を話し合う

---

### 18 × 5 の例（Boaler, 2015 より）

| 解法 | 考え方 |
|------|--------|
| 10×5=50, 8×5=40, 50+40=90 | 分配法則で分解 |
| 18×10=180, 180÷2=90 | 10倍してから半分 |
| 20×5=100, 100-10=90 | 20に近づけて引く |
| 9×5=45, 45×2=90 | 半分にしてから2倍 |
| 18×5 = 9×10 = 90 | 因数を組み替える |

この多様性を見た Udacity のチームは椅子から立ち上がりそうになった——「一つの問題にこんなに多くの見方があるとは想像もしなかった」。

---

### 特別支援学級での実施例

問題：`7 + 8`（低学年向け）

- A児：「7に3足して10にして、5残ってるから15」（補数の発想）
- B児：「8の次が9、10、11、12、13、14、15」（数え上げ）
- C児：「7と7で14、1足して15」（ダブルナンバーから）

どの方法も正しい。黒板に全部書いて「みんな答えは同じ。でも道が違う」と言う。

---

### 授業で使う問題例

最初は「計算が難しい問題」ではなく、「考え方が分かれやすい問題」を選ぶ。

| 段階 | 問題例 | 出やすい考え方 |
|------|--------|----------------|
| 低学年 | `8 + 7` | 10をつくる、ダブルナンバー、数え上げ |
| 低学年 | `14 - 6` | 10まで戻る、6を分ける、足し算で考える |
| 低学年 | `9 + 5` | 10をつくる、5を分ける、9を10に近づける |
| 中学年 | `25 + 37` | 25+35+2、20+30と5+7、37+3+22 |
| 中学年 | `48 + 26` | 50にして引く、40+20と8+6、26を20+6に分ける |
| 中学年 | `15 × 4` | 10×4と5×4、15を2倍してさらに2倍、4を2+2に分ける |
| 高学年 | `18 × 5` | 10倍して半分、20×5から引く、9×10 |
| 高学年 | `99 + 47` | 100+47-1、99+1+46、90+40と9+7 |
| 高学年 | `12 × 15` | 12×10と12×5、15×6×2、12×3×5 |

### 最初の1回の台本

初回は、活動のルールを短く明確にする。

1. 「今日は、答えの速さではなく、考え方の違いを集めます」
2. 「問題を出します。声には出さず、頭の中で考えます」
3. 「答えが出た人は、胸の前で親指を立てます」
4. 「別の方法も思いついた人は、指をもう一本出して合図します」
5. 「いくつか答えを聞きます。まだ正解かどうかは決めません」
6. 「どうやって考えたかを聞きます。先生が黒板にその考え方を描きます」
7. 「同じところ、違うところ、すっきりしているところを見つけます」

教師の最後の一言は「今日は、答えが一つでも道は一つではないことを見つけました」でよい。

### よくある失敗と対処

| 起きやすいこと | 対処 |
|----------------|------|
| 速い子だけが発表する | 答えが出てもすぐ発表させず、全員の考える間を取る |
| 正解探しになってしまう | 「答え」より先に「考え方」を聞く |
| 間違いを教師がすぐ直してしまう | 「この考え方のどこまでは合っている？」と問い返す |
| 解法が一つしか出ない | 「別の道で行ける？」と促し、教師が一つだけ例を追加する |
| 板書が式だけになる | 子どもの言葉、矢印、分解図、数直線も一緒に残す |
| 計算が難しすぎて止まる | 次回は数を小さくし、解法が分かれやすい問題に戻す |

---

### 振り返り宿題との組み合わせ

授業後の振り返り質問（Boaler, 2015）：
> 「今日の数学で新しい解法を知った。それはどんな考え方だったか、自分の言葉で書いてください」

これを家庭でも問いとして使うことで、ナンバートークの効果が持続する。

### 数学ワークショップのウォームアップとして使う

ナンバートークは、[[パタン/数学ワークショップ]] の冒頭5分に置きやすい。

| ナンバートークで起きること | 数学ワークショップへのつながり |
|----------------------------|--------------------------------|
| 全員が暗算で考える | 授業の入口で、数学モードに入る |
| 複数の解法を出す | その日のミニレッスンで扱う語彙や概念の入口になる |
| 解法を図・式・言葉で板書する | 問題解決やジャーナルに使える考え方が残る |
| 新しい解法を振り返る | [[教材/数学ジャーナルとバインダー]] の記入につながる |

たとえば、ナンバートークで「10をつくる」「分ける」「半分にする」といった考え方が出たら、その日のミニレッスンでその言葉を扱い、最後にジャーナルへ「今日使った数学の言葉」として残すことができる。

### 発展パターン

慣れてきたら、ナンバートークを単発の計算活動で終わらせず、次の学習へ広げる。

| 発展 | 進め方 | つながるパタン |
|------|--------|----------------|
| 比較する | 「どの解き方がすっきりしている？なぜ？」と問う | [[パタン/思考や表現のよさを問う]] |
| 図にする | 解法を数直線、面積図、分解図に表す | [[パタン/図に表せないか]]、[[パタン/可視化]] |
| 語彙にする | 「分ける」「10をつくる」「半分にする」などの言葉を残す | [[パタン/数学語彙の文脈的指導]] |
| 振り返る | 新しく知った解法を自分の言葉で書く | [[パタン/精緻化]] |
| 家庭へつなぐ | 家で「別の解き方はある？」と聞いてもらう | [[パタン/学習脈絡の変換]] |

## 結果（Consequences）

- 子どもが「1つの正解の解き方」でなく「数の関係性」を見るようになる
- 「どうやって解いた？」を互いに問い合う文化が育つ
- 間違いや別の解法を提案しても安全だという心理的安全性が生まれる
- 計算の速さよりも柔軟さ・理解の深さが尊重される数学観が定着する
- 数学不安が減り、算数への参加率が上がる

## パタンのつながり

### 圧縮されているパタン

ナンバートークは一つの活動だが、その中に複数のパタンが圧縮されている。実践として使うときはそのままでよいが、設計を深めるときは、内側にあるパタンをほどいて読むとよい。

| ナンバートークの場面 | 圧縮されているパタン | 何が起きているか |
|----------------------|----------------------|------------------|
| 全員が声に出さずに考える | [[パタン/沈黙の間の設計]] | 速い子だけで進まず、一人ひとりの思考時間が守られる |
| 複数の解法を板書する | [[パタン/可視化]] | 頭の中の計算過程が、式・図・言葉として共有できる形になる |
| 「どうやって解いた？」と聞く | [[パタン/考える文化]] | 答えよりも考え方を大切にする教室文化が育つ |
| 間違いや別解も扱う | [[パタン/間違いや失敗から学ぶ文化]] | 誤答が排除されず、考えを深める材料になる |
| 解法の違いを比べる | [[パタン/精緻化]] | 数の関係や計算の構造がより詳しく理解される |
| 新しい解法を言葉にする | [[パタン/数学語彙の文脈的指導]] | 分解、補数、倍、半分などの語彙が実際の思考と結びつく |

この意味で、ナンバートークは「算数の小さな活動」であると同時に、[[パタン/考える文化]]、[[パタン/可視化]]、[[パタン/沈黙の間の設計]] を一度に働かせる実践パタンでもある。

## Actionable Insight

- 今週の算数の冒頭5分でナンバートークを1回試す——問題は `15 × 4` や `25 + 37` などシンプルに
- 答えを出したら「どうやった？」と聞く。生徒の解法を板書して「みんな道が違う」と言うだけでいい
- 最初の数回は「正解は何？」より「何通りの解き方が出た？」を目標にする
