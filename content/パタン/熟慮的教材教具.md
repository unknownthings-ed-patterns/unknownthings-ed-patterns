# 熟慮的教材教具

**一文でいうと**：教材・教具を、価値・目的・使いやすさ・学習者の経験から吟味して設計する。

## 使いどころ・使いすぎ注意

| 観点         | 内容                                               |
| ------------ | -------------------------------------------------- |
| 使いどころ   | 教材の意図や使い方が伝わりにくいとき。             |
| 使いすぎ注意 | 教材を作り込みすぎると、子どもの工夫の余地が減る。 |

> 教育材料について考えない日はない——教材・教具の設計と選択を熟慮することが教育の質を決める。

## 背景（Context）

※旧パタン「熟慮的教育材料」を本ページに統合した（2026-11-11）。2026年6月に「熟慮的教材教具」へ改名したとき、旧ページが残って二枚になっていた。旧ページだけにあった「3軸のチェック」を解決の頭に移した。

教育材料（教材・教具）は教育実践の中核をなす。教科の分類そのものが「価値」から出発している（牧口常三郎）。どんな教材を選び、どう設計し、どう改善するかは教育の成否に直結する。

一方で、教材や教具の選定・デザインは「手近なもの」や「慣例的なもの」に依存されがちである。時間が限られていたり、多様な子どもたちに同時に対応しなければならない場面では、教材教具そのものに深く意識を向けることが後回しにされてしまう。

鈴木克明「教材設計マニュアル」・牧口常三郎の価値論・スペンサーの活動分類・ノーマンのシグニファイアなど複数の理論が交差する領域がここにある。

## 問題（Problem）

教材が「手元にあるから使う」「教科書をそのまま使う」というデフォルトになりがちで、どんな価値・目的のためにどんな教材を設計・選択すべきかという熟慮がなされない。また、教材や教具の選定が不十分な場合、学習者にとって不自然な負荷がかかる。

例：左利きの子どもが数字を書こうとしても、自分の手が数字を隠してしまい、計算がスムーズに進まない。

## 力のかたち（Forces）

- 教育材料には価値論的な根拠（利・善・美）が必要
- 教材設計には引き算の発想が重要（足し算よりも減らす）
- 学習者のレディネス・動機付け・イメージ形成が教材効果に影響する
- 教材の分析手法（クラスター・手順・階層）が設計を精緻化する
- アナログな実装技法（切り貼り・ポケット・色分け）も設計の一部
- 教材教具は学習者にとっての「経験の媒体」であり、身体的・認知的インタラクションの質に強く影響を与える
- 「教材をどう使うか」ではなく「教材自体の質」が教育の本質的な成果を左右する場面も多い
- 学習者の多様性（利き手・特性・年齢など）に対する配慮が求められる

## 解決（Solution）

**教育材料の源泉・価値・種類・設計手順・実装技法を熟慮し、以下のパターンを文脈に応じて重ねて教材を設計・改善する。**

**まず手元に置く3つの問い**（旧「熟慮的教育材料」の3軸のチェック。下位パタンの多いこのページの入口として本Wikiが置いた）：

| 軸 | 問い | 合わないときは |
| --- | --- | --- |
| **価値**（利・善・美。牧口常三郎） | 子どもの生活や学習に役立つか。倫理的に適切で、だれも傷つけないか。美しく、使いたいと思えるか | 教材を選び直す。目的のない教材は意味を届けにくい |
| **シグニファイア**（ノーマン） | 何をすればいいかが、材料そのものから伝わるか | 指示を補うか、もっとはっきりした素材に替える |
| **身体性** | 左利き・感覚の過敏さ・発達の多様さなど、多様な身体で使えるか | ユニバーサルデザインの視点で見直す |

あわせて「何を足すか」より先に「何がなくてもよいか」を問う（[[パタン/引き算＞足し算（教材）]]）。

教材や教具を選ぶとき・作るときには、それが**どのようなインタラクションを可能にするのか（アフォーダンス）**、**何を学習者に示唆しているのか（シグニファイア）**を熟慮する。「誰にとって使いやすいか」「誰にとって障壁となるか」を具体的に想像して設計する。

**具体例：**

- 左利きにも対応したレイアウト設計（10マス計算ドリル、1行マス計算プリント）
- 書く場所が明示されているワークシート（記入欄が視覚的に明確）
- 子どもが操作しやすいサイズ・形状の教具（はさみ・のり・パズルなど）
- むげんプリントの「1行マス計算プリント」：左右どちらの利き手にも対応し視覚的にも整っている
- 杉渕鐵良の「10マス計算ドリル」：スモールステップ設計で成功体験を積み重ねやすい

### 研究の裏づけ

> **研究の裏づけ（2026-10-31）**：『How People Learn』（2000）は、Ball（1993）が3年生に負の数を教えた例を紹介する。ふしぎなピーナッツ・お金・ゲームの得点・数直線上のかえる・地下のある建物など、多くのモデルを検討し、まず建物の階のモデル、次にお金のモデルを使った。階のモデルは「負の数は0と同じ」という誤解を防ぐのに役立つと考えたが、負の数のひき算は表しにくいと分かっていた。実際、5 + (−6) のような問題は扱えず、「−5 は −2 より低いが、小さいとは限らない」という感覚になる心配があった（pp. 166–168）。どのモデルにも限界があり、限界を知って複数のモデルを使い分けることが、教科を教えるための知識の中身だとする。出典：[[文献/人の学び方の研究を授業の設計につなぐ（全米研究評議会2000）]]。

> **研究の裏づけ（2026-11-01）**：教材を深く学ぶことの効果について、Lewis と Perry（2014）の無作為化比較では、分数の教材研究の手引き（日本の教科書と教師用指導書・授業ビデオ・研究論文など）を使って授業研究をした米国の教師のグループが、分数の知識の四つの面のうち三つで有意に伸びた。開発者でない第三者による追試（Schoen ほか 2023）では、分数の手引きを受けた二群で授業の質が上がった（授業研究つき 0.82、一人で学ぶ 0.73）が、子どもの分数のテストはどの群も比較群を上回らなかった（pp. 238–239）。教材を深く学ぶことは授業を良くしたが、子どもの成績まで届くかは、まだ確かめられていない。出典：[[文献/教材の手引きを添えた授業研究で教師の分数の知識が伸びる（LewisとPerry2014）]]・[[文献/授業研究と分数の手引きの効果を追試で分けて確かめる（Schoenほか2023）]]。

> **研究の裏づけ（2026-11-01）**：小学校の算数のメタ分析（Pellegrini ほか 2021）では、教科書やデジタル教材を研修少なめに入れ替えた30研究の効果は +0.05 と小さかった。教材を入れるための研修（2日以上）を伴うと、紙の教材は +0.12、デジタル教材は 0.00 だった（表2、p. 23）。教材は、入れ替えるだけでなく、使い方を教師がつかむまで支えると効きやすい。出典：[[文献/小学校の算数で効いたプログラムの種類を確かめる（Pellegriniほか2021）]]。

> **研究の裏づけ（2026-11-01）**：授業研究を含む教員研修の104研究のメタ分析（Sims ほか 2021）では、授業研究・コーチング・学習共同体という形の効果はどれも 0.06〜0.09 で差がなく、形よりも研修に含まれる仕組みの数が効き目を分けた。教材の手引きを添えた授業研究も、計画・仲間の支え・フィードバックに、手本や練習などの仕組みを足すと効きやすいと読める（pp. 34–36）。出典：[[文献/教員研修の効き目を、研修に含まれる学びの仕組みの数で確かめる（Simsほか2021）]]。

> **研究の裏づけ（2026-11-05）**：具体物は、置くだけでは効かない。55の研究のメタ分析（Carbonneau ほか 2013）では、算数の具体物は条件しだいで学びを助けるにとどまり、3〜6歳では効果がとても小さく、ときに負だった。Laski ほか（2015）は、認知科学の研究から、具体物を効かせる四つの原則を引き出す。①同じ具体物を長い期間、一貫して使う（1年以上使うと中程度の効果、短い期間では具体物なしと変わらない）、②見てすぐ分かる表し方から始め、だんだん抽象的な表し方に移る、③日常の物に似た具体物や、関係のない目立つ特徴のある具体物を避ける（本物そっくりのお札と硬貨では、数字だけの紙よりまちがいが多かった）、④具体物と算数の概念の関係を、言葉と身ぶりではっきり説明する（pp. 2–6）。具体物は概念そのものではなく、概念を表す物なので、何を表しているかを読み取るには抽象的な思考が要る、というのが出発点である（p. 2）。ただし文献の見直しによる原則の提案で、四つを組み合わせた効果は確かめられていない。著者4人のうち3人は米国モンテッソーリ協会の関係者である。出典：[[文献/算数の具体物は、どう使えば効くのかを、認知科学の四つの原則とモンテッソーリ教育の教具から考える（Laskiほか2015）]]。

**混同しやすい組**：
- [[パタン/問題設定]]・[[パタン/課題設定]]・[[パタン/課題の調整]]：問題設定は、何を解決するための教材かという出発の問題。課題設定は、子どもが取り組む課題の難しさ・文脈・意味。課題の調整は、子どもの状態に応じた変え方。
- [[パタン/素材研究から発問内容を見出す]] と [[パタン/問題解決的教材研究]]：どちらも教師が先に教材を体験する。前者は体験から「問いたいこと」を見つけ（土居）、後者は「疑問→調べる→解決」の道そのものを授業の骨格にする（小倉）。
- [[パタン/未完成教材]]・[[パタン/モヤモヤを置く]]・[[パタン/余白をつくる]]：未完成教材は教材の空きを子どもが埋める。モヤモヤを置くは、終わりに解けない問いを残す。余白をつくるは、1時間や教材の中の時間と空間の余白。
- [[パタン/シグニファイア]]・[[パタン/可視化]]・[[パタン/概念モデル]]・[[パタン/対応づけ]]・[[パタン/ナッジ]]：シグニファイアは「何ができるか」の印。可視化は見えないものを見えるようにする大パタンで、シグニファイアはその一部。概念モデルは仕組みの全体像、対応づけは既知との対応、ナッジは行動をそっと押す配置。
- [[パタン/操作物による概念形成]]・[[パタン/半具体物]]・[[パタン/表し方の形を計算の形に合わせる（表現が誤りを強めることがある）]]：操作物は動かして考える具体物、半具体物は実物と記号のあいだの段。表し方の形を合わせるは、どちらを使うときにも、表し方の操作が式の操作と一対一かを確かめる手順。
- [[パタン/教材の構造を見極める]] と [[パタン/クラスター分析]]・[[パタン/手順分析]]・[[パタン/階層分析]]：前者が親で、後の三つはその三つの観点。

**緊張**：
- [[パタン/シグニファイア]] と [[パタン/引き算＞足し算（教材）]]：印を足すか、削るか。見分けは、**その印がなかったら、初めて学ぶ子がどこで迷うか**である。迷うなら足し、迷わないなら削る。印は初めての子に効き、すでに知っている子には回り道になりうる（シグニファイアの研究の裏づけ）。
- [[パタン/操作物による概念形成]] と [[パタン/表し方の形を計算の形に合わせる（表現が誤りを強めることがある）]]：具体物や図は、使えば理解を助けるとは限らない。見分けは、**その表し方の上でする操作が、教えたい計算の操作と同じ形か**である。

## 結果（Consequences）

熟慮された教材教具は、子どもの能動性・集中・納得感のある学びを促進する。無用なストレスや混乱、指導側の説明・補助の負担を軽減する。学習の場がより「意味ある経験」として成立する。

- 教育材料が価値・目的に根ざして設計・選択されるようになる
- 教材の設計・改善が体系的なプロセスとして機能する
- 学習者の動機付け・理解・記憶が教材設計によって支援される

> 「道具のデザインが経験の質を変える。これは教育実践における重要なレバレッジポイントである。」

「熟慮的教材教具」は単なる機能性やコストの議論ではなく、「その道具が教育経験の何を可能にし、何を妨げるか」という視点から捉えることが求められる。

原典はPCKに、類推・例・説明・実演などの表現と、学習者にとっての難しさの理解を含める（pp. 9–10）。Wiki側の適用案として、教材を選ぶ際に「何を示すか」「どこで誤解しやすいか」「別の表し方は何か」を一緒に記す。教材の新しさや見栄えだけで判断しないための補助視点とする。 出典：[[文献/教科内容を教えるための知識に変える（Shulman1986）]]。

## Actionable Insight

- ワークシートを設計するとき「左利きの子どもが使うとどうなるか」を一度確認する——多様な身体的条件を想定するだけで教材の質が変わる
- 今使っている教材から「学習者がやらなくても困らないもの」を1つ探して削ってみる——引き算の原理の第一歩は「足す前に削ること」
- 教具を選ぶとき「これは何を自然に促すか（アフォーダンス）」を1つ言語化する——意図を明示することで選択の根拠が明確になる
