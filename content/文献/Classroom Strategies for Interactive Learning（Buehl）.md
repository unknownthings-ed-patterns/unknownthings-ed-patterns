# Classroom Strategies for Interactive Learning（Buehl, 2014）

Buehl, D. (2014). *Classroom strategies for interactive learning* (4th ed.). Newark, DE: International Reading Association.

（初版1995年・ウィスコンシン州読書協会刊、第2版2001年、第3版2009年、第4版2014年・IRA刊）

著者Doug Buehlはウィスコンシン州マディソン市の教育区で33年間、社会科教師・読書教師・リテラシーコーチとして勤務。IRA（国際読書協会）の青少年リテラシー委員会の創設メンバー。第4版はCommon Core State Standardsへの対応を大幅に強化した改訂版。

---

## 要約

### 核心の哲学

Buehlの中心主張：**読解は受動的な受け取りではなく、能動的な意味の構築**である。

> 「Comprehension is achieved when readers actively create meaning; they do not passively receive it by merely identifying the words on the page.」

テキストの意味は読者と著者と文脈の相互作用によって構築される。読者が既知の知識（スキーマ）を新しい情報と照合する過程が読解である。

**"Interactive Learning"** の意味：テキストと読者が相互作用する学習——学習者が自分の問いを立て、予測し、確認し、修正し、統合する過程を、構造的な方略によって促進する。

---

### 熟達した読者の7つの読解プロセス（Chapter 1・Table 1）

Keene & Zimmermann（2007）の研究をもとに、熟達した読者が行う7つの思考プロセスを整理している。本書の全戦略はこれらのプロセスを育てることを目指す。

| 読解プロセス | 内容 |
|---|---|
| **既有知識とのつながり（Making Connections）** | 既に知っていることと新しい情報を照合し、理解を更新する |
| **問いの生成（Generating Questions）** | 読みながら自分で問いを立てる——著者との内なる対話 |
| **視覚化・感覚的イメージ（Visualizing）** | 言語を体験・感覚と結びつけて心の中の映像を作る |
| **推論（Making Inferences）** | 明示されていない意味を、著者の手がかりと自分の知識で補う |
| **重要性の判断（Determining Importance）** | 多くの情報から「記憶すべき核心」を選び取る |
| **統合（Synthesizing）** | 読んだことをまとめて個人的な解釈・結論・要約を作る |
| **読解の監視と修正（Monitoring & Fix-Up）** | 理解が崩れたときに気づき、立て直す手立てを使う |

### 本書の4章構成（Section 1）

**Chapter 1: Fostering Comprehension of Complex Texts**
複雑なテキストとは何か、読解とはどういうプロセスか、Common Coreの読解基準（Anchor Standards）との関係を整理。

**Chapter 2: Frontloading: Addressing Knowledge Demands of Complex Texts**
読む前の準備（フロントローディング）が読解の最も強力な足場となる。背景知識・語彙・目的を「読む前」に整えることが、読む間の理解を大きく左右する。

**Chapter 3: Questioning for Understanding Through Text Frames**
著者がテキストを組織するために使う6つのテキスト・フレームを読者が意識することで、何に注目して読めばよいかが明確になる（→後述）。

**Chapter 4: Mentoring Reading Through Disciplinary Lenses**
第4版で強化された新領域。教科ごとに「教科固有の読み方」がある。歴史家は歴史家のように、科学者は科学者のように読む。この教科の視点（disciplinary lens）を教師がモデリングすることが核心。

### 3段階の授業設計（Strategy Index）

本書の43戦略は各々、以下の3段階のどこで使うかを示す **Strategy Index** を持つ：

| フェーズ | 書中の用語 | 目的 |
|---|---|---|
| **読む前** | Frontloading Learning | 背景知識の活性化・語彙準備・目的設定 |
| **読む間** | Guiding Comprehension | 理解のモニタリング・つながりの構築・問いの生成 |
| **読んだ後** | Consolidating Understanding | 要約・統合・反省・新しい理解の定着 |

各戦略には「Text Frames（どの文章構造に有効か）」「Comprehension Processes（どの読解プロセスを育てるか）」「Common Core Standards（どのCCSS基準と対応するか）」も示される。

### 6つのテキスト・フレーム（Chapter 3）

Jones, Palincsar, Ogle & Carr（1987）が整理した6つの文章構造をBuehlが授業設計に応用。読む前にどのフレームかを教師が示すことで、読者の注目点が定まる。

| テキスト・フレーム | 典型的な問い | 典型的な文章ジャンル |
|---|---|---|
| **Problem/Solution（問題と解決）** | 問題は何か・誰が解こうとしているか・何が解決策か | 社会問題・医療・工学 |
| **Cause/Effect（原因と結果）** | 何が起きたか・何が原因か・どう相互に関係するか | 理科・社会の説明文・歴史 |
| **Compare/Contrast（比較と対比）** | 何を比べているか・どこが似てどこが違うか | 比較説明文・レビュー |
| **Goal/Action/Outcome（目標・行動・結果）** | 目標は何か・どんな行動が取られたか・結果は何か | 伝記・歴史・プロセス記述 |
| **Concept/Definition（概念と定義）** | その概念はどのカテゴリーか・特徴は何か・例は何か | 辞典・学術説明文 |
| **Proposition/Support（主張と根拠）** | 主張は何か・どんな証拠が示されているか | 議論・論説・意見文 |

### 主な戦略（43戦略から抜粋）

**Frontloading（読む前）の戦略：**

| 戦略 | 概要 |
|---|---|
| **Anticipation Guides** | トピックに関する**4〜6**の記述文に賛否を事前表明し、読後に見直す。Cause/Effect・Problem/Solution・Proposition/Supportフレームに有効。認知的葛藤が理解を深める（Herber, 1978） |
| **Prediction Guides** | Anticipation Guidesの関連版。読後の確認を強調 |
| **K-W-L Plus** | K（知っていること）W（知りたいこと）L（学んだこと）チャートで読みを目的化する |
| **Chapter Tours** | 見出し・図版・キャプションを事前に「巡回」して概略を把握する |
| **Mind Mapping** | トピックについて知っていることをウェブ状に出す |
| **Brainstorming Prior Knowledge** | 語彙・概念の事前活性化 |

**Guiding Comprehension（読む間）の戦略：**

| 戦略 | 概要 |
|---|---|
| **Text Coding** | 記号（✓知ってた・？わからない・！驚き）を使って読みながら考えを追跡する |
| **B/D/A Questioning Charts** | Before/During/After の問いを記録し、読みの変化を追う |
| **Double-Entry Diaries** | ページを半分に割り、左：テキスト引用、右：自分の反応・疑問・つながりを記録 |
| **Interactive Reading Guides** | 読みを構造化するガイド付き質問シートを使いながら読む |
| **Questioning the Author** | 著者の意図・選択に疑問を向けながら読む批判的読み |
| **Say Something Read-Aloud** | パートナーと交互に読み、節ごとに「何か言う」 |

**Consolidating Understanding（読んだ後）の戦略：**

| 戦略 | 概要 |
|---|---|
| **Quick-Writes** | 5〜10分の自由書きで理解を整理・残す |
| **Magnet Summaries** | キーワード（磁石語）を選び、周辺情報を付けて一文要約を書く |
| **RAFT** | 役割（Role）・読者（Audience）・形式（Format）・トピック（Topic）を設定して書く |
| **Discussion Web** | 賛否両論の証拠を整理して、議論・批判的思考を深める |
| **Power Notes** | 主要概念・補助詳細・例を階層化したノートにまとめる |
| **Pyramid Notes** | 要約を階層化したピラミッド形式で整理する |
| **Structured Note-Taking** | テキスト構造に応じたノート形式 |

### コンテント・エリア・リテラシーと教科固有の読み（Chapter 4）

Buehlの重要な主張：**読解力はELA（国語）だけで育つのではない**。

すべての教科（理科・社会・算数・技術）が固有の「教科のリテラシー（disciplinary literacy）」を持つ。歴史家は証拠を吟味して因果を推論する。科学者は実験記録と観察を読む。数学者は記号と論理を読む。

> 「reading through a disciplinary lens（教科の視点で読む）」——教科固有の思考様式で読むことを、教師がモデリングすることが核心。

第4版では全43戦略に **Common Core State Standards との対応表** が付記された（Reading・Writing・Speaking and Listening・Languageの各基準）。

## 重要な引用

> 「Comprehension is achieved when readers actively create meaning; they do not passively receive it by merely identifying the words on the page. And no two people will have exactly the same comprehension of a text because no two people will be reading a text under exactly the same conditions.」

> 「The more students already know about a topic, the better they will be able to comprehend texts about that topic.」（背景知識が読解の最重要変数）

> 「Given knowledge about what good readers do when they read, researchers and educators have addressed the following question: Can we teach students to engage in these productive behaviors? The answer is a resounding yes.」（Duke & Pearson, 2002）

## 教育実践への示唆

1. **3段階で授業を設計する**：読む前（フロントローディング）・読む間（理解のガイド）・読んだ後（統合）の3フェーズで授業を計画すると、各フェーズで何の方略を使うかが明確になる

2. **フロントローディングを惜しまない**：複雑なテキストを読む前に、背景知識・語彙・目的を整えることに時間を使う——「先に整えるほど、読む間の理解が深まる」

3. **テキスト・フレームを使って説明文指導を設計する**：「この文章は問題と解決の構造だ」と事前に伝えるだけで、読みの枠組みが変わる

4. **書くことを読解の道具にする**：Quick-Write・Double-Entry Diaries・RAFT は読解のための書き活動——「理解したことを書く」のではなく「書くことで理解が深まる」

5. **理科・社会を「教科の読み方」を学ぶ場として使う**：内容を覚えるためだけでなく、その教科の専門家がどう読むかをモデリングする場として教科書・一次資料を使う

6. **7つの読解プロセスを授業言語にする**：「今、推論しているね」「ここで統合が起きた」という言葉を授業中に使うことで、生徒が自分の読みを意識できるようになる
