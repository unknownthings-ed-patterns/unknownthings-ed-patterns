## 困りごとから探す

| 困りごと・場面 | 使えるパタン | 一言 |
|---|---|---|
| 次の活動への切り替えが難しい | [[パタン/予告]] | 見通しをもたせて移行をスムーズにする |
| 座っていられない・動き回る | [[パタン/完了したら場所を動かす]] | 活動完了で物理的な移動を設計する |
| 指示が伝わらない | [[パタン/簡明の原則（端的に具体的に出す）]] | 短く・具体的に・肯定形で伝える |
| 感情爆発・パニックの対処 | [[パタン/段階的クールダウン]] | 早期サインの観察と段階的な冷却手順 |
| 「助けて」と言えない | [[パタン/援助要求スキル]] | 助けを求めるスキルを明示的に教える |
| 何をすべきか自分で判断できない | [[パタン/シグニファイア]] | 環境が「次は何をするか」を示す |
| 特定の感覚刺激に過敏 | [[パタン/発達特性と環境調整]] | 感覚特性に合わせた環境を設計する |
| 活動への参加が難しい | [[パタン/授業のユニバーサルデザイン]] | 多様な参加方法を用意する |
| 見通しがないと不安になる | [[パタン/合図システム]] | 環境の変化を予告する合図を設計する |
| 自己評価・振り返りが難しい | [[パタン/自己記録]] | 自分の行動を記録・確認する仕組みをつくる |
